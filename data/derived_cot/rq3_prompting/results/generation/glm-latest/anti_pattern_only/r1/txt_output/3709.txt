class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        i = 0
        n = len(s)

=== ANSWER ===
Looking at this problem: a substring of length k satisfies the conditions if and only if it is exactly a **maximal run** of identical characters of length exactly k. This is because if the run containing the substring were longer than k, then either the character just before or just after the substring would be the same character, violating the conditions.

So the approach is:
1. Split the string into maximal runs of consecutive identical characters.
2. Check if any run has length exactly k.

**Verification with examples:**
- `"aaabaaa"`, k=3: runs are `aaa`(3), `b`(1), `aaa`(3) → a run of length 3 exists → `true` ✓
- `"abc"`, k=2: runs are `a`(1), `b`(1), `c`(1) → no run of length 2 → `false` ✓

Edge case check: `"aaaa"`, k=3: only run has length 4 → `false`. Manually: any length-3 substring has a same character adjacent on one side, so correct.

```python
class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        n = len(s)
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            # run s[i..j-1] has length j - i
            if j - i == k:
                return True
            i = j
        return False
```

This runs in O(n) time and O(1) space, well within the constraints (n ≤ 100).
