The problem: determine if two chessboard squares have the same color.

A square's color can be determined by the parity of (column index + row index). If (col + row) is even, it's one color; if odd, the other. Two squares have the same color if and only if (col1 + row1) and (col2 + row2) have the same parity, i.e., (col1 + row1 + col2 + row2) is even, or equivalently (col1 + row1) % 2 == (col2 + row2) % 2.

- "a1": col = 'a' - 'a' = 0, row = '1' - '1' = 0. Sum = 0, even.
- "c3": col = 'c' - 'a' = 2, row = '3' - '1' = 2. Sum = 4, even.
- Same parity → same color → true. ✓

- "a1": sum = 0, even.
- "h3": col = 'h' - 'a' = 7, row = '3' - '1' = 2. Sum = 9, odd.
- Different parity → different color → false. ✓

```python
class Solution:
    def checkTwoChessboards(self, coordinate1: str, coordinate2: str) -> bool:
        color1 = (ord(coordinate1[0]) - ord('a')) + (ord(coordinate1[1]) - ord('1'))
        color2 = (ord(coordinate2[0]) - ord('a')) + (ord(coordinate2[1]) - ord('1'))
        return color1 % 2 == color2 % 2
```
