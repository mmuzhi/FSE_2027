def main():

    n = int(data[0]); m = int(data[1])

    sufmax = [0] * (k + 1)

    for (x, y) in ws:

Looking at this problem:

- Each row's black cells form a prefix, and each column's black cells form a prefix. This means the black region is exactly a **down-set** (Ferrers diagram anchored at top-left): if cell (r,c) is black, then all cells (r',c') with r'≤r, c'≤c are black.
- The minimal valid black region containing all given B cells is the down-closure of the B cells (union of rectangles [1..x]×[1..y] for each B cell (x,y)).
- A valid coloring exists iff no W cell lies inside this down-closure, i.e., there is no pair of B cell (x,y) and W cell (x',y') with x' ≤ x and y' ≤ y.

**Algorithm:** Sort B cells by x, compute suffix maxima of y. For each W cell (x',y'), binary search for B cells with x ≥ x' and check if any of them has y ≥ y'. If yes for any W cell → "No", otherwise "Yes".

Verification with samples:
- Sample 1: W(3,2): B cells with x≥3 are (4,1) with y=1<2 — no conflict → Yes ✓
- Sample 2: W(1,2): B(2,2) dominates it → No ✓
- Sample 3: no B cells → Yes ✓
- Sample 4: W(1789,211) is dominated by B(1814,712) → No ✓
