class Solution:
    def minOperations(self, queries: List[List[int]]) -> int:
        # Precompute bucket boundaries: bucket k covers [4^(k-1), 4^k - 1], needs k divisions
        POWER4 = [4 ** i for i in range(17)]  # 4^0 .. 4^16
        
        def prefix(n):
            # sum of steps(x) for x = 1..n ; steps(x) = k for x in [4^(k-1), 4^k - 1]
            if n <= 0:
                return 0
            total = 0
            k = 1
            while POWER4[k-1] <= n:
                lo = POWER4[k-1]
                hi = min(n, POWER4[k] - 1)
                total += k * (hi - lo + 1)
                k += 1
            return total
        
        ans = 0
        for l, r in queries:
            t = prefix(r) - prefix(l - 1)

        return ans

Looking at this problem:

- A number x needs `k` divisions by 4 to reach 0, where x ∈ [4^(k-1), 4^k - 1] (e.g., 1-3 need 1, 4-15 need 2, 16-63 need 3...).
- Total divisions needed for range [l, r] is `t = sum of steps(x)`. Each operation performs 2 divisions (one on each of two distinct selected elements), so the answer is at least `ceil(t/2)`.
- This bound is achievable: since l < r the array has ≥ 2 elements, so we can always pair divisions (pairing with an already-zero element is harmless). One can verify via a Gale–Ryser style argument that `ceil(t/2)` operations suffice, and for contiguous ranges `t ≥ steps(r) + steps(r-1) ≥ 2·steps(r) - 1`, so the max individual requirement never exceeds `ceil(t/2)`.

So per query the answer is `ceil(t/2)`, where `t` is computed via a prefix function `f(n) = Σ_{x=1..n} steps(x)` using bucket counting (only ~15 buckets needed since 4^15 > 10^9).
