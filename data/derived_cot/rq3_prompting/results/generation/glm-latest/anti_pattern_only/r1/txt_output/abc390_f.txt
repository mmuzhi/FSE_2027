```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    A = data[1:1+n]
    last = [0] * (n + 2)
    G = 0
    ans = 0
    for R in range(1, n + 1):
        v = int(A[R-1])
        qv = last[v]
        qm = last[v-1]
        qp = last[v+1]
        both = qm if qm < qp else qp
        mx = qv
        if qm > mx: mx = qm
        if qp > mx: mx = qp
        delta = 1
        if both > qv:
            delta -= both - qv
        if R - 1 > mx:
            delta += R - 1 - mx
        G += delta
        ans += G
        last[v] = R
    print(ans)

main()
```

Looking at this problem:

**Key insight:** Each operation erases an interval $[l,r]$ of *values* that must all be present on the blackboard. Since values are only erased, the operations partition the value set $S(L,R)$ into intervals of consecutive integers, and any such partition is achievable. So $f(L,R)$ = number of maximal runs of consecutive integers among the distinct values in $A_L..A_R$.

**Sweep by R:** Let $G(R)=\sum_{L\le R} f(L,R)$. When appending $A_R = v$ to intervals ending at $R-1$, with $q_v, q_-, q_+$ = last occurrences (before $R$) of $v, v-1, v+1$:
- If $L \le q_v$: no change (v already present).
- Else if $L \le \min(q_-,q_+)$: both neighbors present → runs merge, change $-1$.
- Else if $L > \max(q_-,q_+)$: neither neighbor → new run, change $+1$.
- Plus the new singleton $[R,R]$ contributing $+1$.

So $\Delta G = 1 - \max(0,\min(q_-,q_+)-q_v) + \max(0,(R-1)-\max(q_v,q_-,q_+))$, and the answer is $\sum_R G(R)$. This is $O(N)$.
