You are given a simple undirected graph with N vertices and M edges. The i-th edge connects vertices u_i and v_i bidirectionally.
Determine if there exists a way to write an integer between 1 and 2^{60} - 1, inclusive, on each vertex of this graph so that the following condition is satisfied:

- For every vertex v with a degree of at least 1, the total XOR of the numbers written on its adjacent vertices (excluding v itself) is 0.


What is XOR?

The XOR of two non-negative integers A and B, denoted as A \oplus B, is defined as follows:


- In the binary representation of A \oplus B, the bit at position 2^k \, (k \geq 0) is 1 if and only if exactly one of the bits at position 2^k in the binary representations of A and B is 1. Otherwise, it is 0.


For example, 3 \oplus 5 = 6 (in binary: 011 \oplus 101 = 110).

In general, the bitwise XOR of k integers p_1, \dots, p_k is defined as (\cdots ((p_1 \oplus p_2) \oplus p_3) \oplus \cdots \oplus p_k).  It can be proved that this is independent of the order of p_1, \dots, p_k.

The input is given from Standard Input in the following format:

u_2 v_2
\vdots
u_M v_M

Output

If there is no way to write integers satisfying the condition, print No.
Otherwise, let X_v be the integer written on vertex v, and print your solution in the following format. If multiple solutions exist, any of them will be accepted.
Yes
X_1 X_2 \dots X_N

- 1 \leq N \leq 60
- 0 \leq M \leq N(N-1)/2
- 1 \leq u_i < v_i \leq N
- (u_i, v_i) \neq (u_j, v_j) for i \neq j.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(data[idx]); idx += 1
    m = int(data[idx]); idx += 1
    adj = [0] * n
    for _ in range(m):
        u = int(data[idx]) - 1; idx += 1
        v = int(data[idx]) - 1; idx += 1
        adj[u] |= (1 << v)
        adj[v] |= (1 << u)
    
    # Gaussian elimination over GF(2) to RREF
    rows = adj[:]
    pivots = []  # pivot column for each row
    r = 0
    for col in range(n):
        # find pivot
        piv = -1
        for i in range(r, n):
            if (rows[i] >> col) & 1:
                piv = i
                break
        if piv == -1:
            continue
        rows[r], rows[piv] = rows[piv], rows[r]
        pr = rows[r]
        for i in range(n):
            if i != r and ((rows[i] >> col) & 1):
                rows[i] ^= pr
        pivots.append(col)
        r += 1
    
    pivot_set = set(pivots)
    free_cols = [c for c in range(n) if c not in pivot_set]
    
    basis = []
    for c in free_cols:
        v = 1 << c
        for idx2, p in enumerate(pivots):
            if (rows[idx2] >> c) & 1:
                v |= (1 << p)
        basis.append(v)
    
    covered = 0
    for b in basis:
        covered |= b
    
    if covered != (1 << n) - 1:
        print("No")
        return
    
    # Assign values
    X = [0] * n
    for i, b in enumerate(basis):
        bit_val = 1 << i
        for v in range(n):
            if (b >> v) & 1:
                X[v] |= bit_val
    
    print("Yes")
    print(' '.join(map(str, X)))

main()

import sys

def main():
    data = sys.stdin.buffer.read().split()
    ptr = 0
    n = int(data[ptr]); ptr += 1
    m = int(data[ptr]); ptr += 1
    adj = [0] * n
    for _ in range(m):
        u = int(data[ptr]) - 1; ptr += 1
        v = int(data[ptr]) - 1; ptr += 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    # Gaussian elimination over GF(2) to RREF
    rows = adj[:]
    pivots = []
    r = 0
    for col in range(n):
        piv = -1
        for i in range(r, n):
            if (rows[i] >> col) & 1:
                piv = i
                break
        if piv == -1:
            continue
        rows[r], rows[piv] = rows[piv], rows[r]
        pr = rows[r]
        for i in range(n):
            if i != r and ((rows[i] >> col) & 1):
                rows[i] ^= pr
        pivots.append(col)
        r += 1

    pivot_set = set(pivots)
    free_cols = [c for c in range(n) if c not in pivot_set]

    # Null space basis: one vector per free column
    basis = []
    for c in free_cols:
        vec = 1 << c
        for j in range(len(pivots)):
            if (rows[j] >> c) & 1:
                vec |= 1 << pivots[j]
        basis.append(vec)

    covered = 0
    for b in basis:
        covered |= b

    if covered != (1 << n) - 1:
        print("No")
        return

    X = [0] * n
    for i, b in enumerate(basis):
        for v in range(n):
            if (b >> v) & 1:
                X[v] |= 1 << i

    sys.stdout.write("Yes\n" + " ".join(map(str, X)) + "\n")

main()

def main():

    ptr = 0
    n = int(data[ptr]); ptr += 1
    m = int(data[ptr]); ptr += 1
    adj = [0] * n
    for _ in range(m):
        u = int(data[ptr]) - 1; ptr += 1
        v = int(data[ptr]) - 1; ptr += 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

                piv = i
                break

        rows[r], rows[piv] = rows[piv], rows[r]
        pr = rows[r]

Looking at this problem:

- The constraint "XOR of neighbors' values = 0" decomposes bit-by-bit into a GF(2) linear system **A·x = 0** where A is the adjacency matrix (isolated vertices give zero rows, matching that they impose no constraint).
- We need each vertex's value to be nonzero, so for every vertex v, some bit-vector (a null-space vector) must have a 1 at position v.
- Since any null vector is a combination of basis vectors, its support is contained in the union of the basis supports. So a solution exists **iff** every vertex is covered by some null-space basis vector.
- Since nullity = N − rank ≤ N ≤ 60, we can assign each basis vector to its own bit position (0..59), giving values in [1, 2⁶⁰−1].
