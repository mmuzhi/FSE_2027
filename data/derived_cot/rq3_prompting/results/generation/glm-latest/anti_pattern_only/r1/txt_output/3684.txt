class Solution:

        pre, suf = p[:idx], p[idx+1:]

=== ANSWER ===
```python
class Solution:
    def hasMatch(self, s: str, p: str) -> bool:
        idx = p.index('*')
        pre, suf = p[:idx], p[idx+1:]
        i = s.find(pre)
        if i == -1:
            return False
        # Earliest occurrence of pre leaves the most room for suf,
        # so it suffices to check suf occurs at or after i + len(pre).
        return s.find(suf, i + len(pre)) != -1
```
