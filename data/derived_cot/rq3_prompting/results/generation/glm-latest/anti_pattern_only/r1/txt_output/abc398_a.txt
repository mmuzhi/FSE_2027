=== ANSWER ===
Looking at this problem:

- **Odd N**: A palindrome with exactly one `=` must place it at the center. Two adjacent `=`s would require the pair to be symmetric, but for odd N, positions p and p+1 can't satisfy {p, p+1} = {N-p, N+1-p} (that would force p = N/2, not an integer). So the answer is `=` at the center, `-` elsewhere.

- **Even N**: Exactly one `=` is impossible (it would need position p with 2p = N+1, which is odd). Two adjacent `=`s must be symmetric: the pair {p, p+1} must equal its mirror {N-p, N+1-p}, forcing p = N/2, i.e., the two middle characters. So the answer is `==` at the center.

Verification with samples:
- N=4: `-==-` ✓
- N=7: `---=---` ✓

Edge cases: N=1 → `=`, N=2 → `==`, N=3 → `-=-`. All valid and unique.

```python
n = int(input())
if n % 2 == 1:
    print('-' * (n // 2) + '=' + '-' * (n // 2))
```
