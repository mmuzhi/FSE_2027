import sys

def main():
    input_data = sys.stdin.buffer.read().split()
    N = int(input_data[0]); R = int(input_data[1]); C = int(input_data[2])
    S = input_data[3].decode()
    
    # directions
    dr = {'N': -1, 'S': 1, 'W': 0, 'E': 0}
    dc = {'N': 0, 'S': 0, 'W': -1, 'E': 1}
    
    # encode positions
    # r, c in [-N, N]
    M = 2 * N + 1
    def enc(r, c):
        return (r + N) * M + (c + N)
    
    birth = set()
    birth.add(enc(0, 0))
    
    r = 0
    c = 0
    res = []
    for ch in S:
        r += dr[ch]
        c += dc[ch]
        key = enc(r - R, c - C)
        res.append('1' if key in birth else '0')
        pk = enc(r, c)
        if pk not in birth:
            birth.add(pk)
    
    print(''.join(res))

Looking at this problem:

**Key insight:** All smoke moves together, so relative positions between smoke particles never change. Track the campfire's position in a "wind frame": let `p_t` be the cumulative wind displacement after t steps. A smoke particle born at time `s` sits at `p_t - p_s` at time `t+0.5`. So smoke exists at `(R,C)` at time `t+0.5` iff `p_t - (R,C)` equals some birth position `p_s`.

**Birth condition:** After wind at time `t`, cell (0,0) has smoke iff `p_t` equals some earlier birth position (since positions are `{p_t - p_s}`). If not, a new birth occurs at time `t` with birth position `p_t`. Note the new smoke at time `t` is at (0,0), which never affects the answer since `(R,C) ≠ (0,0)`.

So the algorithm is: maintain a set of birth positions (initially `{(0,0)}`). For each `t`: check if `p_t - (R,C)` is in the set (answer), then add `p_t` to the set (unconditionally — if already present it means (0,0) was occupied so no birth happened, and the add is a no-op anyway).

I verified this against all three samples by hand-tracing (e.g., sample 1 gives `001010`, sample 2 gives `0001101011`, sample 3 gives `00100111111000101111`).

For efficiency, positions are encoded as single integers `(r + 2N) * (4N+1) + (c + 2N)`, which is injective on the needed range `[-2N, 2N]²` (query positions `p_t - (R,C)` can span `[-2N, 2N]`). This gives O(N) time with fast set operations.

    sys.stdout.write(''.join(out) + '\n')

main()
