You will be given a competitive programming problem.
In the nation of Atcoder, there are N cities numbered 1 to N, and M trains numbered 1 to M.
Train i departs from city A_i at time S_i and arrives at city B_i at time T_i.
Given a positive integer X_1, find a way to set non-negative integers X_2,\ldots,X_M that satisfies the following condition with the minimum possible value of X_2+\ldots+X_M.

- Condition: For all pairs (i,j) satisfying 1 \leq i,j \leq M, if B_i=A_j and T_i \leq S_j, then T_i+X_i \leq S_j+X_j.
- In other words, for any pair of trains that are originally possible to transfer between, it is still possible to transfer even after delaying the departure and arrival times of each train i by X_i.



It can be proved that such a way to set X_2,\ldots,X_M with the minimum possible value of X_2+\ldots+X_M is unique.

Input

A_1 B_1 S_1 T_1
\vdots
A_M B_M S_M T_M

Output

Print X_2,\ldots,X_M that satisfy the condition with the minimum possible sum, in that order, separated by spaces.

Constraints


- 2 \leq N \leq 2\times 10^5
- 2 \leq M \leq 2\times 10^5
- 1 \leq A_i,B_i \leq N
- A_i \neq B_i
- 0 \leq S_i < T_i \leq 10^9
- 1 \leq X_1 \leq 10^9
- All input values are integers.

Looking at this problem:

- Constraints are of the form $X_j \geq X_i + (T_i - S_j)$ whenever $B_i = A_j$ and $T_i \leq S_j$ (plus $X_j \geq 0$, and $X_1$ fixed).
- Since $T_i \leq S_j < T_j$, every constraint edge goes from a train with strictly smaller $T$ to one with larger $T$, so processing trains in increasing order of $T$ gives a topological order.
- The component-wise minimal feasible solution is the unique sum minimizer (feasible sets of difference constraints are closed under component-wise min, and any feasible solution dominates the minimal one inductively along the topological order). Note that trains feeding *into* train 1 can never be downstream of train 1 (that would require times to strictly increase and wrap around), so they all get $X=0$, which automatically satisfies the constraints targeting train 1 (since $T_i \le S_1 \le S_1 + X_1$). Hence feasibility is always guaranteed.

For each train $j$ (in increasing $T$), the minimal value is $X_j = \max(0,\ \max\{X_i + T_i : B_i = A_j,\ T_i \leq S_j\} - S_j)$. This gives $O(M \log M)$.
