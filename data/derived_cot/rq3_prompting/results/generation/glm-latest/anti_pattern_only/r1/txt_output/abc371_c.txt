You are given simple undirected graphs G and H, each with N vertices: vertices 1, 2, \ldots, N.
Graph G has M_G edges, and its i-th edge (1\leq i\leq M_G) connects vertices u_i and v_i.

What is a simple undirected graph?
 A simple undirected graph is a graph without self-loops or multi-edges, where edges have no direction.

What does it mean for graphs to be isomorphic?
 Two graphs G and H with N vertices are isomorphic if and only if there exists a permutation (P_1,P_2,\ldots,P_N) of (1,2,\ldots,N) such that for all 1\leq i\lt j\leq N:

-  an edge exists between vertices i and j in G if and only if an edge exists between vertices P_i and P_j in H.

import sys
from itertools import permutations

def solve_numpy(N, adjG, adjH, A):
    import numpy as np
    Gm = np.zeros((N, N), dtype=np.int64)
    Hm = np.zeros((N, N), dtype=np.int64)
    Am = np.zeros((N, N), dtype=np.int64)
    for i in range(N):
        for j in range(N):
            if adjG[i] >> j & 1:
                Gm[i, j] = 1
            if adjH[i] >> j & 1:
                Hm[i, j] = 1
            Am[i, j] = A[i][j]
    perms = np.array(list(permutations(range(N))), dtype=np.int64)
    total = np.zeros(perms.shape[0], dtype=np.int64)
    for i in range(N):
        for j in range(i + 1, N):
            a = perms[:, i]
            b = perms[:, j]
            g = int(Gm[i, j])
            h = Hm[a, b]
            diff = (h != g)
            total += np.where(diff, Am[a, b], 0)
    return int(total.min())

def solve_py(N, adjG, adjH, A):
    # Precompute tables
    # For G-edge pairs: cost A[x][y] if H lacks edge (x,y)
    CnoH = [[0]*N for _ in range(N)]
    CH = [[0]*N for _ in range(N)]
    for x in range(N):
        for y in range(N):
            if x == y:
                continue
            if adjH[x] >> y & 1:
                CH[x][y] = A[x][y]
            else:
                CnoH[x][y] = A[x][y]
    g1 = []
    g0 = []
    for i in range(N):
        for j in range(i+1, N):
            if adjG[i] >> j & 1:
                g1.append((i, j))
            else:
                g0.append((i, j))
    best = float('inf')
    for P in permutations(range(N)):
        total = 0
        for i, j in g1:
            total += CnoH[P[i]][P[j]]
        for i, j in g0:
            total += CH[P[i]][P[j]]
        if total < best:
            best = total
    return best

Looking at this problem:

- N ≤ 8, so there are at most 8! = 40320 permutations.
- For a fixed permutation P (mapping G's vertex i to H's vertex P_i), the final H must satisfy: edge (i,j) in G ⟺ edge (P_i, P_j) in H. Each pair where they differ must be toggled exactly once, costing A_{P_i,P_j} (toggling twice is wasteful).
- So the answer is min over all permutations P of Σ over pairs (i,j) with G(i,j) ≠ H(P_i,P_j) of A_{P_i,P_j}.

I precompute two tables to make the inner loop branchless:
- `CnoH[x][y]` = A[x][y] if H lacks edge (x,y), else 0 (cost when an edge must be added).
- `CH[x][y]` = A[x][y] if H has edge (x,y), else 0 (cost when an edge must be removed).

Then split position pairs into those where G has an edge (use CnoH on images) and those where G doesn't (use CH on images). Total work: 40320 × 28 ≈ 1.1M cheap operations — fast enough.

I verified this logic against all samples (e.g., sample 1: permutation [3,0,1,4,2] gives exactly 9; sample 2: permutation [0,1,3,4,2] gives exactly 3; sample 3: identity gives 5; sample 4: 0).
