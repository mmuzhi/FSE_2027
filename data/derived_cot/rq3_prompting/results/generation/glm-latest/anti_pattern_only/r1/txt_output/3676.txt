The problem: given a positive number n, return the smallest number x >= n such that binary representation of x contains only set bits (all 1s).

Numbers with all set bits are of the form 2^k - 1: 1, 3, 7, 15, 31, ...

So find the smallest k such that 2^k - 1 >= n. That is, k = number of bits needed. Simple approach: count bits of n, or loop.

Simple: 
```python
class Solution:
    def smallestNumber(self, n: int) -> int:
        x = 1
        while x < n:
            x = (x << 1) | 1
        return x
```

Start with x = 1 (binary "1"). While x < n, shift left and set bit: 1 -> 3 -> 7 -> 15 -> ...

Check: n = 5: x=1, 1<5 -> 3, 3<5 -> 7, 7>=5 return 7. Correct.
n = 10: 1 -> 3 -> 7 -> 15. Correct.
n = 3: 1 -> 3, 3>=3 return 3. Correct.
n = 1: x=1, 1>=1 return 1. Correct.

Alternatively: return (1 << n.bit_length()) - 1. Check n=5: bit_length=3, 8-1=7. Correct. n=3: bit_length=2, 4-1=3. Correct. n=4: bit_length=3, 7 >= 4, and 3 < 4, so 7. Correct.

=== ANSWER ===

class Solution:
    def smallestNumber(self, n: int) -> int:
        return (1 << n.bit_length()) - 1
