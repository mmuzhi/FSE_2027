You will be given a competitive programming problem.
You are given an m x n grid. A robot starts at the top-left corner of the grid (0, 0) and wants to reach the bottom-right corner (m - 1, n - 1). The robot can move either right or down at any point in time.
The grid contains a value coins[i][j] in each cell:

If coins[i][j] >= 0, the robot gains that many coins.
If coins[i][j] < 0, the robot encounters a robber, and the robber steals the absolute value of coins[i][j] coins.

The robot has a special ability to neutralize robbers in at most 2 cells on its path, preventing them from stealing coins in those cells.
Note: The robot's total coins can be negative.
Return the maximum profit the robot can gain on the route.
 
Example 1:

Input: coins = [[0,1,-1],[1,-2,3],[2,-3,4]]
Output: 8
Explanation:
An optimal path for maximum coins is:

Start at (0, 0) with 0 coins (total coins = 0).
Move to (0, 1), gaining 1 coin (total coins = 0 + 1 = 1).
Move to (1, 1), where there's a robber stealing 2 coins. The robot uses one neutralization here, avoiding the robbery (total coins = 1).
Move to (1, 2), gaining 3 coins (total coins = 1 + 3 = 4).
Move to (2, 2), gaining 4 coins (total coins = 4 + 4 = 8).

```python
class Solution:
    def maximumAmount(self, coins: List[List[int]]) -> int:
        m, n = len(coins), len(coins[0])
        NEG = float('-inf')
        prev_row = None
        for i in range(m):
            row = coins[i]
            cur = [[0,0,0] for _ in range(n)]
            for j in range(n):
                c = row[j]
                if i == 0 and j == 0:
                    if c < 0:
                        cur[0] = [c, 0, 0]
                    else:
                        cur[0] = [c, c, c]
                    continue
                # from up
                if i > 0:
                    up = prev_row[j]
                else:
                    up = None
                # from left
                if j > 0:
                    left = cur[j-1]
                else:
                    left = None
                if up is None:
                    prev = left
                elif left is None:
                    prev = up
                else:
                    prev = [max(up[0],left[0]), max(up[1],left[1]), max(up[2],left[2])]
                if c >= 0:
                    cur[j] = [prev[0]+c, prev[1]+c, prev[2]+c]
                else:
                    v0 = prev[0] + c
                    v1 = prev[1] + c
                    if prev[0] > v1: v1 = prev[0]
                    v2 = prev[2] + c
                    if prev[1] > v2: v2 = prev[1]
                    cur[j] = [v0, v1, v2]
            prev_row = cur
        return prev_row[n-1][2]
```

```python
class Solution:
    def maximumAmount(self, coins: List[List[int]]) -> int:
        m, n = len(coins), len(coins[0])
        NEG = float('-inf')
        # dp0, dp1, dp2: 1D arrays over columns, for current row
        dp0 = [NEG]*n
        dp1 = [NEG]*n
        dp2 = [NEG]*n
        for i in range(m):
            row = coins[i]
            for j in range(n):
                c = row[j]
                if i == 0:
                    if j == 0:
                        if c < 0:
                            dp0[0], dp1[0], dp2[0] = c, 0, 0
                        else:
                            dp0[0] = dp1[0] = dp2[0] = c
                        continue
                    # only from left
                    p0, p1, p2 = dp0[j-1], dp1[j-1], dp2[j-1]
                else:
                    if j == 0:
                        p0, p1, p2 = dp0[0], dp1[0], dp2[0]  # from up (previous row's col 0, currently stored)
                    else:
                        # dp arrays currently hold previous row values at index j (not yet updated for this row)
                        up0, up1, up2 = dp0[j], dp1[j], dp2[j]
                        l0, l1, l2 = dp0[j-1], dp1[j-1], dp2[j-1]  # already updated for current row
                        p0 = up0 if up0 > l0 else l0
                        p1 = up1 if up1 > l1 else l1
                        p2 = up2 if up2 > l2 else l2
                if c >= 0:
                    dp0[j] = p0 + c
                    dp1[j] = p1 + c
                    dp2[j] = p2 + c
                else:
                    dp0[j] = p0 + c
                    dp1[j] = p1 + c if p1 + c > p0 else p0
                    v2 = p2 + c
                    dp2[j] = v2 if v2 > p1 else p1
        return dp2[n-1]
```

Looking at this problem, I need a DP with state (i, j, k) where k = number of neutralizations used (0, 1, or 2). For each cell:
- If coins[i][j] >= 0: dp[k] = best_prev[k] + coins[i][j]
- If coins[i][j] < 0: either pay (best_prev[k] + coins[i][j]) or neutralize (best_prev[k-1], which adds 0)

Using "at most k" semantics keeps states monotone in k, so the answer is dp[m-1][n-1][2]. I use rolling 1-D arrays for the three neutralization counts, sweeping row by row where dp[j] still holds the previous row's value (from above) and dp[j-1] holds the current row's value (from left).

Verified against Example 1 (traces to 8) and Example 2 (traces to 40), plus edge cases like a single robber cell (returns 0 by neutralizing) and paths forced to pay some robbers (negative results allowed, no clamping).
