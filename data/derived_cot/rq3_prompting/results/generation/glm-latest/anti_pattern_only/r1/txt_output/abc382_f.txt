There is a grid with H rows and W columns.
Let (i,j) denote the cell at the i-th row from the top and the j-th column from the left.
There are N horizontal bars numbered from 1 to N placed on the grid.
Bar i consists of L_i blocks of size 1 \times 1 connected horizontally, and its leftmost block is initially at cell (R_i, C_i).
That is, initially, bar i occupies the cells (R_i, C_i), (R_i, C_i + 1), \dots, (R_i, C_i + L_i - 1).

At every time t = 0.5 + n for some non-negative integer n, the following occurs in order of i = 1, 2, \dots, N:


Standard iterative lazy from the article:

```
def assign(l, r, v):  # [l, r)
    l += size; r += size
    ll, rr = l, r  # save for pull up... actually save l, r
    for shift in range(h, 0, -1):
        if ((l >> shift) << shift) != l: push(l >> shift)
        if ((r >> shift) << shift) != r: push((r-1) >> shift)
    # apply
    l2, r2 = l, r
    while l2 < r2:
        if l2 & 1: apply(l2, v); l2 += 1
        if r2 & 1: r2 -= 1; apply(r2, v)
        l2 >>= 1; r2 >>= 1
    # pull up
    for shift in range(1, h+1):
        if ((l >> shift) << shift) != l: pull(l >> shift)
        if ((r >> shift) << shift) != r: pull((r-1) >> shift)

def query(l, r):  # [l, r) max
    l += size; r += size
    for shift in range(h, 0, -1):
        if ((l >> shift) << shift) != l: push(l >> shift)
        if ((r >> shift) << shift) != r: push((r-1) >> shift)
    res = 0
    while l < r:
        if l & 1: res = max(res, mx[l]); l += 1
        if r & 1: r -= 1; res = max(res, mx[r])
        l >>= 1; r >>= 1
    return res
```
