So **ℓ(v) = subtree_size(v) mod K is forced** — a child subtree with nonzero residue has a chain that must extend through its parent v.

- If ≥3 such children → impossible.

- If ≤1 such child: always workable (chain extends upward with length 1 + t1 ≤ K, closing when it equals K; consistency with size mod K holds automatically).

The root's own closure is automatically consistent since |tree| = NK ≡ 0 (mod K).

    visited[1] = True
    oi = 0
    while stack:
        u = stack.pop()
        order[oi] = u; oi += 1
        for w in adj[u]:
            if not visited[w]:
                visited[w] = True
                parent[w] = u
                stack.append(w)

    size = [1] * (M + 1)
    for i in range(M - 1, 0, -1):
        u = order[i]
        size[parent[u]] += size[u]

    cnt = [0] * (M + 1)
    sm = [0] * (M + 1)
    for i in range(1, M):
        u = order[i]
        t = size[u] % K
        if t:
            p = parent[u]
            cnt[p] += 1
            sm[p] += t

    for v in range(1, M + 1):
        c = cnt[v]
        if c > 2 or (c == 2 and sm[v] + 1 != K):
            print("No")
            return
    print("Yes")

main()
