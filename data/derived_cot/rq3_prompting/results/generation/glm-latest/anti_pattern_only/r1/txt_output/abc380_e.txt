There are N cells in a row, numbered 1 to N.
For each 1 \leq i < N, cells i and i+1 are adjacent.
Initially, cell i is painted with color i.
You are given Q queries. Process them in order. Each query is of one of the following two types.

- 1 x c: Repaint the following to color c: all reachable cells reachable from cell x by repeatedly moving to an adjacent cell painted in the same color as the current cell.
- 2 c: Print the number of cells painted with color c.

Input

The input is given from Standard Input in the following format:
N Q
\mathrm{query}_1
\vdots
\mathrm{query}_Q

Each query is given in one of the following two formats:
1 x c

2 c

The i-th line should contain the answer to the i-th such query.

Constraints


- 1 \leq N \leq 5 \times 10^5
- 1 \leq Q \leq 2 \times 10^5
- In queries of the first type, 1 \leq x \leq N.
- In queries of the first and second types, 1 \leq c \leq N.
- There is at least one query of the second type.
- All input values are integers.

Sample Input 1

5 6
1 5 4
1 4 2
2 2
1 3 2
1 2 3
2 3

Sample Output 1

3

=== ANSWER ===
Looking at this problem:

- Cells form contiguous same-color segments. A type-1 query repaints the whole maximal same-color segment containing x (possibly merging with adjacent segments of the new color c). Segments never split — they only merge.
- Since segments only merge, a union-find (DSU) works perfectly: `find(i)` gives the left endpoint (root) of the segment containing i. At each root we store the segment's right endpoint (`rend`) and color (`col`). A count array `cnt[color]` tracks cell counts per color.

For each type-1 query: find the segment containing x; if already color c, it's a no-op (by the invariant that adjacent segments always differ in color). Otherwise, subtract its size from its old color's count; check left/right neighboring segments — if a neighbor has color c, union it into the leftmost root (subtracting its count from c, since it's re-added with the merged total); finally set the merged root's color to c, its right endpoint, and add the total size to `cnt[c]`.

Each type-1 query does at most 2 unions and 3 finds (with path halving), so it's effectively O(α) amortized. Type-2 queries are O(1).

I verified this logic against the sample: after the queries, counts are 3 for color 2 and 4 for color 3, matching expected output.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); q = int(data[1])

    par = list(range(n + 2))          # DSU parent (root = left endpoint of segment)
    rd = list(range(n + 2))           # rd[root] = right endpoint of segment
    cl = list(range(n + 2))           # cl[root] = color of segment
    cn = [0] + [1] * n + [0]          # cn[color] = number of cells with that color

    out = []
    pos = 2
    for _ in range(q):
        if data[pos] == b'1':
            x = int(data[pos + 1]); c = int(data[pos + 2])
            pos += 3
            # find root of x's segment (path halving)
            a = x
            while par[a] != a:
                par[a] = par[par[a]]
                a = par[a]
            l = a
            if cl[l] == c:
                continue
            r = rd[l]
            cn[cl[l]] -= r - l + 1
            # left neighbor
            if l > 1:
                a = l - 1
                while par[a] != a:
                    par[a] = par[par[a]]
                    a = par[a]
                if cl[a] == c:
                    cn[c] -= rd[a] - a + 1
                    par[l] = a
                    l = a
            # right neighbor
            if r < n:
                a = r + 1
                while par[a] != a:
                    par[a] = par[par[a]]
                    a = par[a]
                if cl[a] == c:
                    rr = rd[a]
                    cn[c] -= rr - a + 1
                    par[a] = l
                    r = rr
            cl[l] = c
            rd[l] = r
            cn[c] += r - l + 1
        else:
            c = int(data[pos + 1])
            pos += 2
            out.append(str(cn[c]))

    sys.stdout.write('\n'.join(out) + '\n')

main()
```
