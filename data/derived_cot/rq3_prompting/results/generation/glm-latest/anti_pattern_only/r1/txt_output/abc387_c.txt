=== ANSWER ===
Looking at this problem:

- A Snake number's first digit must be strictly greater than all remaining digits.
- Use `f(N)` = count of Snake numbers ≤ N, answer = `f(R) - f(L-1)`.

**Counting f(N)** with digits `d[0..k-1]`:
1. All shorter lengths `j` (2 to k-1): first digit `a` ∈ 1..9, remaining `j-1` digits each in 0..a-1 → `sum a^(j-1)`.
2. Same length, first digit `c < d[0]` (c ≥ 1): remaining digits free in 0..c-1 → `c^(k-1)` each.
3. Same length, tight prefix: at each position `i ≥ 1` (while prefix digits `d[1..i-1]` are all `< d[0]`), place digit `c` with `c < d[i]` and `c < d[0]` (that's `min(d[i], d[0])` choices), remaining `k-1-i` positions free in 0..d[0]-1 → `d[0]^(k-1-i)` each. Tight path dies once some `d[i] ≥ d[0]`.
4. If the tight path survives all positions, N itself is a Snake number → add 1.
