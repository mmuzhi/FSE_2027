Looking at this problem:

**Key insight:** |x| + |y| = max over sign choices (s1, s2) ∈ {±1}² of s1·x + s2·y. For a fixed sign combo (target quadrant), each move is either a "match" (contributes +1 to the score) or a "mismatch" (contributes -1). With k changes, at any prefix we can convert up to min(b, k) mismatches into matches (each conversion adds 2 to the score), where b is the mismatch count in that prefix.

**Correctness:**
- *Upper bound:* Each change can raise the signed score by at most 2, and only min(b, k) changes within the prefix can be mismatch→match conversions.
- *Achievability:* For the best (prefix, combo) pair, change the first min(b, k) mismatches within that prefix to matches — this uses ≤ k changes and yields score = a − b + 2·min(b, k) at that prefix, and |x|+|y| ≥ that score.

Since a − b + 2·min(b, k) where a + b = i (prefix length), we get: score + 2·min((i − score)/2, k).

Verified on Example 1 ("NWSE", k=1 → 3) and Example 2 ("NSWWEW", k=3 → 6).

```python
class Solution:
    def maxDistance(self, s: str, k: int) -> int:
        x = y = 0
        ans = 0
        i = 0
        k2 = 2 * k
        for c in s:
            i += 1
            if c == 'N':
                y += 1
            elif c == 'S':
                y -= 1
            elif c == 'E':
                x += 1
            else:
                x -= 1
            # four sign combinations: x+y, x-y, -x+y, -x-y
            for score in (x + y, x - y, -x + y, -x - y):
                # mismatches in prefix for this combo: score = matches - mismatches,
                # matches + mismatches = i  =>  mismatches = (i - score) / 2
                b = (i - score) >> 1
                cand = score + (k2 if b >= k else b + b)
                if cand > ans:
                    ans = cand
        return ans
```
