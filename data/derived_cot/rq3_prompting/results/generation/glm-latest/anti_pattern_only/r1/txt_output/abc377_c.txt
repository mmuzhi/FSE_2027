You will be given a competitive programming problem.
There is a grid of N^2 squares with N rows and N columns.
Let (i,j) denote the square at the i-th row from the top (1\leq i\leq N) and j-th column from the left (1\leq j\leq N).

You want to place your piece on an empty square in such a way that it cannot be captured by any of the existing pieces.
A piece placed on square (i,j) can capture pieces that satisfy any of the following conditions:

- Placed on square (i+2,j+1)
- Placed on square (i+1,j+2)

- Placed on square (i+2,j-1)

=== ANSWER ===
Looking at this problem:

- The grid is huge (N up to 10^9), but M ≤ 2×10^5 pieces each attack at most 8 squares (knight moves).
- So the set of "forbidden" squares (occupied or attacked) has at most 9M ≈ 1.8×10^6 candidates — just collect, dedupe, and subtract from N².
- Encode each square (i,j) as `(i << 30) | j` (valid since N ≤ 10^9 < 2^30), which is injective, then use a set.

I verified against all three samples (sample 1: 64 − 26 = 38; sample 2: 10^18 − 3; sample 3: 400 − 62 = 338, computed by hand as occupied 10 + distinct attacked 54 − 2 overlap).

For each move (da,db), a piece (a,b) yields an in-grid square iff `1 ≤ a+da ≤ N` and `1 ≤ b+db ≤ N`, checked via precomputed bounds for speed. Answer is `N*N - len(set of all candidate encodings)`.

Edge cases handled: N=1 or 2 (bounds become empty ranges so all moves are correctly filtered), overlapping attacks (set dedup), occupied squares attacked by other pieces (set union), and huge answers (Python big ints).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    m = int(data[1])
    it = iter(map(int, data[2:2 + 2 * m]))
    z = list(zip(it, it))

    s = set()
    upd = s.update

    # occupied squares
    upd([(a << 30) | b for a, b in z])

    moves = ((2, 1), (1, 2), (-1, 2), (-2, 1),
             (-2, -1), (-1, -2), (1, -2), (2, -1))
    for da, db in moves:
        alo = 1 - da
        ahi = n - da
        blo = 1 - db
        bhi = n - db
        upd([(a + da << 30) | (b + db) for a, b in z
             if alo <= a <= ahi and blo <= b <= bhi])

    print(n * n - len(s))

main()
```
