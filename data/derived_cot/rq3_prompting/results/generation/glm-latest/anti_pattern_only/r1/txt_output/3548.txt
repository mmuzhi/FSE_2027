```python
class Solution:
    def countGoodIntegers(self, n: int, k: int) -> int:
        from math import factorial
        from itertools import product
        
        half_len = (n + 1) // 2
        good = set()
        
        for first in range(1, 10):
            for rest in product(range(10), repeat=half_len - 1):
                half = (first,) + rest
                if n % 2 == 0:
                    digits = half + half[::-1]
                else:
                    digits = half + half[-2::-1]
                # check divisibility by k
                val = 0
                for d in digits:
                    val = (val * 10 + d) % k
                if val == 0:
                    cnt = [0] * 10
                    for d in digits:
                        cnt[d] += 1
                    good.add(tuple(cnt))
        
        total = 0
        fact = [factorial(i) for i in range(n + 1)]
        for cnt in good:
            denom = 1
            for c in cnt:
                denom *= fact[c]
            total += (n - cnt[0]) * fact[n - 1] // denom
        return total
```

Looking at this problem:

- Since n ≤ 10, I can enumerate all n-digit palindromes (only the first half needs enumerating: first digit 1–9, rest 0–9, at most 9·10⁴ palindromes).
- For each palindrome divisible by k, record its digit-count signature (multiset) in a set (different palindromes can share a multiset, e.g. 123321 and 132231).
- For each distinct signature, count n-digit integers (no leading zero) with that multiset: total permutations `n!/∏cnt[d]!` minus those starting with zero, which simplifies to `(n - cnt[0])·(n-1)!/∏cnt[d]!`.

I verified this against all three examples (n=3,k=5 → 27; n=1,k=4 → 2; and a full hand enumeration of n=5,k=6 gave 2468, including tricky cases like multisets `{0:3, 6:2}` from palindrome 60006 where the leading-zero correction matters).

The formula is always an exact integer since it equals the difference of two multinomial coefficients.
