```python
class Solution:
    def minBitwiseArray(self, nums: List[int]) -> List[int]:
        ans = []
        for num in nums:
            if num % 2 == 0:
                ans.append(-1)
            else:
                # count trailing ones
                t = 0
                x = num
                while x & 1:
                    t += 1
                    x >>= 1
                ans.append(num - (1 << (t - 1)))
        return ans
```

=== ANSWER ===
Looking at this problem:

- `x OR (x+1)` equals `x` with its lowest 0 bit set to 1 (adding 1 flips trailing 1s to 0s and the lowest 0 bit to 1, so the OR restores those trailing 1s and adds that bit).
- Therefore `x OR (x+1) = num` requires `x` to be `num` with exactly one bit `p` cleared, where all bits below `p` in `num` are 1 (so that bit `p` is the lowest 0 of `x`).
- If `num` is even, bit 0 is 0, so no valid position exists → -1 (this covers the prime 2).
- Otherwise, let `t` = count of trailing 1 bits of `num`. Valid clear positions are `0..t-1`; to minimize `x`, clear the highest one: `x = num - 2^(t-1)`.

Verification with examples:
- 3 (0b11): t=2, x=3-2=1 ✓ (1|2=3)
- 5 (0b101): t=1, x=5-1=4 ✓ (4|5=5)
- 7 (0b111): t=3, x=7-4=3 ✓ (3|4=7)
- 11 (0b1011): t=2, x=11-2=9 ✓ (9|10=11)
- 13 (0b1101): t=1, x=13-1=12 ✓

- 2: even → -1 ✓
