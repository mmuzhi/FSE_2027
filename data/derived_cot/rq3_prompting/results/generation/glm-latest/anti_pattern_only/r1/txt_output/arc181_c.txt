You will be given a competitive programming problem.
You are given two permutations P=(P_1,P_2,\dots,P_N) and Q=(Q_1,Q_2,\dots,Q_N) of (1,2,\dots,N).
Write one of the characters 0 and 1 in each cell of an N-by-N grid so that all of the following conditions are satisfied:

- Let S_i be the string obtained by concatenating the characters in the i-th row from the 1-st to the N-th column. Then, S_{P_1} < S_{P_2} < \dots < S_{P_N} in lexicographical order.
- Let T_i be the string obtained by concatenating the characters in the i-th column from the 1-st to the N-th row. Then, T_{Q_1} < T_{Q_2} < \dots < T_{Q_N} in lexicographical order.

It can be proved that for any P and Q, there is at least one way to write the characters that satisfies all the conditions.
 What does "X < Y in lexicographical order" mean?
For strings X=X_1X_2\dots X_{|X|} and Y = Y_1Y_2\dots Y_{|Y|}, "X < Y in lexicographical order" means that 1. or 2. below holds.
Here, |X| and |Y| denote the lengths of X and Y, respectively.

-  |X| \lt |Y| and X_1X_2\ldots X_{|X|} = Y_1Y_2\ldots Y_{|X|}. 
-  There exists an integer 1 \leq i \leq \min\lbrace |X|, |Y| \rbrace such that both of the following are true:

-  X_1X_2\ldots X_{i-1} = Y_1Y_2\ldots Y_{i-1}
-  X_i is less than Y_i.

Input

The input is given from Standard Input in the following format:
N
P_1 P_2 \dots P_N
Q_1 Q_2 \dots Q_N

Output

Print a way to fill the grid that satisfies the conditions in the following format, where A_{ij} is the character written at the i-th row and j-th column:
A_{11}A_{12}\dots A_{1N}
\vdots
A_{N1}A_{N2}\dots A_{NN}

If there are multiple ways to satisfy the conditions, any of them will be accepted.

Constraints


- 2 \leq N \leq 500
- P and Q are permutations of (1,2,\dots,N).
- All input values are integers.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    P = data[1:1+n]
    Q = data[1+n:1+2*n]
    P = list(map(int, P))
    Q = list(map(int, Q))
    rp = [0] * (n + 1)
    for idx, val in enumerate(P, start=1):
        rp[val] = idx
    cq = [0] * (n + 1)
    for idx, val in enumerate(Q, start=1):
        cq[val] = idx
    threshold = n + 1
    lines = []
    for i in range(1, n + 1):
        r = rp[i]
        base = threshold - r  # need cq[j] > base
        # column j is 1 iff cq[j] > base, i.e., cq[j] >= base+1
        # Build row: for each column j (1..n), char = '1' if cq[j] + r > n+1 else '0'
        row = ''.join('1' if r + cq[j] > threshold else '0' for j in range(1, n + 1))
        lines.append(row)
    sys.stdout.write('\n'.join(lines) + '\n')

main()
```

*Rows:* Row `i` (rank a) has 1s exactly at columns where `cq[j] > N+1-a`. If `a < b` (row i should be smaller than row i'), row i's threshold is larger, so row i's 1-set is a **subset** of row i''s 1-set. They differ at the column with `cq = N+1-a` (row i has 0, row i' has 1 since `N+1-a > N+1-b`). So at the first differing position row i has 0, row i' has 1, hence `S_i < S_{i'}`. ✓

*Columns:* Column `j` (rank c) has 1s at rows where `rp[i] > N+1-c`. If `c < d`, column j's 1-set is a subset of column j''s 1-set. They differ at the row with `rp = N+1-c` (column j has 0, column j' has 1 since `N+1-c > N+1-d`). So `T_j < T_{j'}`. ✓

**Verification with Sample 1** (N=3, P=[1,2,3], Q=[2,1,3]): rp=[1,2,3], cq=[2,1,3]. Grid:
```
000
001
101
```
Rows: "000" < "001" < "101" ✓ (P order). Columns: T_2="000" < T_1="001" < T_3="011" ✓ (Q order: 2,1,3). This is a valid alternative answer (any valid answer is accepted).

I also verified with N=4, P=[3,1,4,2], Q=[4,2,1,3] by hand — rows give "0000"<"0010"<"1010"<"1110" matching S_3<S_1<S_4<S_2, and columns give "0000"<"0100"<"0101"<"1101" matching T_4<T_2<T_1<T_3. All correct.

Complexity is O(N²), trivial for N ≤ 500.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    P = list(map(int, data[1:1 + n]))
    Q = list(map(int, data[1 + n:1 + 2 * n]))

    rp = [0] * (n + 1)  # rp[i]: rank of row i in P (1-indexed)
    for k in range(n):
        rp[P[k]] = k + 1
    cq = [0] * (n + 1)  # cq[j]: rank of column j in Q (1-indexed)
    for k in range(n):
        cq[Q[k]] = k + 1

    thr = n + 1
    cql = [cq[j] for j in range(1, n + 1)]
    out = []
    for i in range(1, n + 1):
        need = thr - rp[i]  # cell (i,j) is 1 iff cq[j] > need  <=>  rp[i]+cq[j] > N+1
        out.append(''.join('1' if c > need else '0' for c in cql))
    sys.stdout.write('\n'.join(out) + '\n')

main()
```
