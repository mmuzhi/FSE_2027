You are given N strings S_1,S_2,\ldots,S_N. Each string consists of lowercase English letters.
For each k=1,2,\ldots,N, solve the following problem.

Let T=S_k and consider performing the following two types of operations any number of times in any order:

- Pay a cost of 1 to delete the last character of T. This operation is possible when T is not empty.
- Pay a cost of 1 to add any lowercase English letter to the end of T.

Find the minimum total cost needed to make T either empty or match one of S_1,S_2,\ldots,S_{k-1}.

=== ANSWER ===
Looking at this problem:

- Operations only affect the end of the string. To transform T = S_k into target U (empty or some S_j, j < k), the optimal cost is |T| + |U| - 2·LCP(T, U) (delete down to the common prefix, then add). This is provably optimal since any operation sequence keeps some prefix T[:p] of originals at the front, requiring p ≤ LCP(T,U).

- So the answer for k is min(|S_k|, min over j<k of (|S_k| + |S_j| - 2·LCP(S_k, S_j))).

**Key trick:** Build a trie incrementally. Each node stores the minimum length among inserted strings passing through it. For a new string S_k (length m), walk down the trie along S_k's characters as far as possible (depth 0..L where L = max LCP with previous strings). At each depth d, the candidate is `min_len[node] + m - 2d`. Since for a fixed j, |S_j| - 2d is minimized at d = LCP(S_k, S_j), taking the minimum over all depths gives exactly min_j(|S_j| - 2·LCP_j) — no underestimation, since only pairs with d ≤ LCP_j are counted.

Total complexity O(Σ|S_i|) with a flat dict keyed by `(node << 5) | char_index`.

Verified against all three samples (e.g. sample 3, k=8: "tt" matches "tta" via node "tt" with min_len 3, giving 3+2-4=1).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    BIG = 1 << 30
    children = {}
    min_len = [BIG]  # root; min length of inserted strings through each node
    res = []
    get = children.get
    for i in range(1, n + 1):
        s = data[i]
        m = len(s)
        node = 0
        best = m  # make it empty
        # candidate at root (depth 0)
        v = min_len[0]
        c = v + m
        if c < best:
            best = c
        if m < v:
            min_len[0] = m
        d = 0
        idx = 0
        # walk down existing trie nodes along s
        while idx < m:
            key = (node << 5) | (s[idx] - 97)
            nxt = get(key)
            if nxt is None:
                break
            node = nxt
            idx += 1
            d += 1
            ml = min_len[node]
            c = ml + m - 2 * d
            if c < best:
                best = c
            if m < ml:
                min_len[node] = m
        # create new nodes for the remainder of s
        while idx < m:
            key = (node << 5) | (s[idx] - 97)
            nid = len(min_len)
            children[key] = nid
            min_len.append(m)
            node = nid
            idx += 1
        res.append(best)
    sys.stdout.write('\n'.join(map(str, res)) + '\n')

main()
```
