Let `total = sum(nums)`, `left` = left subarray sum, so right sum = `total - left`. The difference is `left - (total - left) = 2*left - total`. Since `2*left` is always even, the parity of the difference depends only on `total`:
- If `total` is even → every partition gives an even difference → answer is `n - 1`
- If `total` is odd → no partition gives an even difference → answer is `0`

Verification with examples:
- `[10,10,3,7,6]`: total = 36 (even) → 4 partitions ✓
- `[1,2,2]`: total = 5 (odd) → 0 ✓
- `[2,4,6,8]`: total = 20 (even) → 3 ✓

```python
from typing import List

class Solution:
    def countPartitions(self, nums: List[int]) -> int:
```
