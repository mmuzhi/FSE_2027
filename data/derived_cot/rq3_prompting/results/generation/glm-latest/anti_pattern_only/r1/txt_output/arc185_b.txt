- Each operation moves 1 unit of value from position j to an earlier position i (i < j). So prefix sums never decrease, and the total sum S is invariant. In fact, B is reachable from A **iff** sum(B)=sum(A) and prefix_k(B) ≥ prefix_k(A) for all k (constructive induction: repeatedly find smallest i with positive prefix-sum of D, and a later j where D_j < 0, and apply op (i,j)).

- So we need a non-decreasing integer B with sum S whose prefix sums dominate A's prefix sums P_k.

- Key lemma: among all non-decreasing integer sequences with sum S = N·f + r (f = ⌊S/N⌋, r = S mod N), the "balanced" sequence B* = (f,...,f, f+1,...,f+1) (with N−r copies of f) maximizes **every** prefix sum simultaneously. Proof: if prefix_k(B) exceeded prefix_k(B*), then B_k ≥ f+1, forcing the suffix to also be ≥ f+1, which makes the total exceed S (case analysis on k ≤ N−r vs k > N−r).

- Therefore the answer is Yes iff for every k: P_k ≤ k·f + max(0, k − (N−r)).

Verification on samples:
- (1,7,5): S=13, f=4, r=1, bounds (4,8,13); P=(1,8,13) → Yes ✓
- (9,0): S=9, f=4, r=1, bounds (4,9); P₁=9 > 4 → No ✓
- Third case: S=6106, f=610, r=6, bounds (610,1220,1830,2440,3051,3662,4273,4884,5495,6106); all prefix sums fit → Yes ✓

Also checked tricky integrality cases (e.g., N=10, S=5, A=(0,0,0,0,2,0,0,0,0,3) correctly gives No — the naive real condition P_k ≤ kS/N would wrongly say Yes, since prefix₅ ≥ 2 forces B₅ ≥ 1 hence sum ≥ 7 > 5).

Complexity: O(N) per test case, O(sum N) total.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    pos = 1
    out = []
    for _ in range(t):
        n = int(data[pos])
        pos += 1
        vals = list(map(int, data[pos:pos + n]))
        pos += n
        s = sum(vals)
        f, r = divmod(s, n)
        d = n - r  # number of f's in the balanced target sequence
        pref = 0
        bound = 0
        k = 0
        ok = True
        for v in vals:
            k += 1
            pref += v
            bound += f
            if k > d:
                bound += 1
            if pref > bound:
                ok = False
                break
        out.append("Yes" if ok else "No")
    sys.stdout.write("\n".join(out) + "\n")

main()
```
