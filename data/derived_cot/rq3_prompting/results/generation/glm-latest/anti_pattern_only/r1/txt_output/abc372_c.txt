=== ANSWER ===
Looking at this problem:

- Maintain a running count of "ABC" occurrences.
- When character at position X changes, only triples starting at positions X-2, X-1, X (1-indexed) can be affected. Subtract occurrences of "ABC" among those triples before the change, apply the change, then add back occurrences after the change.
- Each query is O(1) work (at most 3 triples checked).

I verified this logic against all three samples by hand-tracing (e.g., sample 1: initial count 2, each query correctly updates to 2, 1, 1, 0).

For the initial count, `bytes.count(b'ABC')` works because two occurrences of "ABC" can never overlap (would require 'A' to equal 'B' or 'C' at shifted positions).

Implementation uses byte values (ints) for fast comparisons, reads all input at once, and collects output for a single write.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    q = int(data[1])
    s_bytes = data[2]
    s = list(s_bytes)

    A, B, C = 65, 66, 67
    count = s_bytes.count(b'ABC')

    out = []
    ptr = 3
    for _ in range(q):
        x = int(data[ptr])
        c = data[ptr + 1][0]
        ptr += 2
        idx = x - 1
        if s[idx] != c:
            lo = idx - 2
            if lo < 0:
                lo = 0
            hi = min(idx, n - 3)
            for j in range(lo, hi + 1):
                if s[j] == A and s[j + 1] == B and s[j + 2] == C:
                    count -= 1
            s[idx] = c
            for j in range(lo, hi + 1):
                if s[j] == A and s[j + 1] == B and s[j + 2] == C:
                    count += 1
        out.append(str(count))

    print('\n'.join(out))

main()
```
