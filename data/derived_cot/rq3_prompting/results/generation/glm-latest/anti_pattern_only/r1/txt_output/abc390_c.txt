**Key insight:** Any valid rectangle must contain all already-black (`#`) cells. Therefore it must contain the bounding box of all `#` cells. Conversely, if the bounding box itself contains no white (`.`) cell, we can choose the rectangle to be exactly the bounding box (painting `?` inside black and `?` outside white).

So the answer is **Yes** if and only if the bounding box of all `#` cells contains no `.` cell:
- If a `.` cell lies inside the bounding box, it lies inside every candidate rectangle (since every candidate rectangle contains the bounding box), making it impossible.
- If not, the bounding box itself works.

**Verification with samples:**
- Sample 1: `#` bounding box is rows 1–2, cols 2–4; contains only `#` and `?` → Yes ✓
- Sample 2: bounding box is the whole 3×3 grid; cell (2,2) is `.` inside it → No ✓
