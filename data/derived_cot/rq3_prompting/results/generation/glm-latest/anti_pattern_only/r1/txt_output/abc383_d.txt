Looking at this problem:

A number has exactly 9 divisors iff its prime factorization exponents+1 multiply to 9. The only possibilities are:
- n = p^8 (single prime, exponent 8)
- n = p²·q² with distinct primes p, q (both exponent 2)

**Case 1:** Count primes p with p^8 ≤ N. Since N ≤ 4×10^12, p ≤ ~37.

**Case 2:** p²q² ≤ N ⟺ (pq)² ≤ N ⟺ pq ≤ M where M = isqrt(N) (valid since pq is an integer). With M ≤ 2×10^6, sieve primes up to M. For each prime p (the smaller one, so p² < M), count primes q with p < q ≤ M//p using binary search over the sorted prime list (count of primes ≤ M//p minus count of primes ≤ p).

I verified on sample 1 (N=200 → M=14): p=2 gives q∈{3,5,7} → 36, 100, 196 → answer 3 ✓. Also verified N=256 gives 5 (36,100,196,225,256), and N=10000 gives 32 by hand.

The sieve of 2×10^6 with bytearray slice assignment is fast; the pair loop only runs for p up to √M ≈ 1414 (~224 primes), each with one bisect.
