You will be given a competitive programming problem.
There are N types of items. The i-th type of item has a weight of w_i and a value of v_i. Each type has 10^{10} items available.
Takahashi is going to choose some items and put them into a bag with capacity W. He wants to maximize the value of the selected items while avoiding choosing too many items of the same type. Hence, he defines the happiness of choosing k_i items of type i as k_i v_i - k_i^2. He wants to choose items to maximize the total happiness over all types while keeping the total weight at most W. Calculate the maximum total happiness he can achieve.

Input

The input is given from Standard Input in the following format:
N W
w_1 v_1
w_2 v_2
\vdots
w_N v_N

Output

Print the answer.

Constraints


- 1 \leq N \leq 3000
- 1 \leq W \leq 3000
- 1 \leq w_i \leq W
- 1 \leq v_i \leq 10^9
- All input values are integers.

Sample Input 1

2 10
3 4
3 2

Sample Output 1

5

By choosing 2 items of type 1 and 1 item of type 2, the total happiness can be 5, which is optimal.
Here, the happiness for type 1 is 2 \times 4 - 2^2 = 4, and the happiness for type 2 is 1 \times 2 - 1^2 = 1.
The total weight is 9, which is within the capacity 10.

def main():

import heapq
from collections import defaultdict

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); W = int(data[1])
    groups = defaultdict(list)
    idx = 2
    for _ in range(n):

        idx += 2
        groups[w].append(v)

    import numpy as np
    dp = np.zeros(W + 1, dtype=np.int64)

    for w, vals in groups.items():
        maxK = W // w
        heap = [-(v - 1) for v in vals]
        heapq.heapify(heap)
        for _ in range(maxK):
            if not heap:
                break
            m = -heapq.heappop(heap)
            if m <= 0:

import heapq
from collections import defaultdict

    n = int(data[0]); W = int(data[1])

import sys
import heapq
from collections import defaultdict


def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    W = int(data[1])
    groups = defaultdict(list)
    pos = 2
    for _ in range(n):
        w = int(data[pos])
        v = int(data[pos + 1])
        pos += 2
        groups[w].append(v)

    import numpy as np
    dp = np.zeros(W + 1, dtype=np.int64)

    for w, vals in groups.items():
        limit = W // w  # at most this many weight-w items fit in total
        if limit <= 0:
            continue
        tgt = dp[w:]
        src = dp[:W + 1 - w]
        # Max-heap over current marginals (stored negated).
        # First marginal for value v is v - 1; next is m - 2, ...
        heap = [1 - v for v in vals]
        heapq.heapify(heap)
        for _ in range(limit):
            if not heap:
                break
            neg = heapq.heappop(heap)
            if neg >= 0:  # largest remaining marginal <= 0 -> stop
                break
            m = -neg
            np.maximum(tgt, src + m, out=tgt)
            if m > 2:
                heapq.heappush(heap, 2 - m)

    print(int(dp[W]))


main()

=== ANSWER ===
Looking at this problem:

- Happiness for type i with k items is f(k) = k·v − k², whose marginal gains are v−1, v−3, v−5, ... (decreasing by 2).
- Total items chosen is at most W ≤ 3000 (weights ≥ 1), so per weight class w, at most ⌊W/w⌋ items can be used in total across all types of that weight.
- Key reduction: treat each marginal gain as a virtual item of weight w. Any subset of marginals of a type has value ≤ the top-|subset| marginals = f(|subset|), so a 0/1 knapsack over the virtual items (top ⌊W/w⌋ positive marginals per distinct weight, merged across types via a heap) gives exactly the optimum. Total virtual items ≈ Σ ⌊W/w⌋ = O(W log W) ≈ 26k, so a vectorized numpy knapsack is fast.

The heap per weight class merges the decreasing marginal sequences (each type's next marginal is current − 2), stopping at non-positive marginals. Each popped marginal becomes a 0/1 knapsack item updated with `np.maximum(dp[w:], dp[:-w] + m, out=dp[w:])` (the temp is computed before writing, giving correct 0/1 semantics).

Verified against all three samples (5, 14, 12) and several hand-computed cases.
