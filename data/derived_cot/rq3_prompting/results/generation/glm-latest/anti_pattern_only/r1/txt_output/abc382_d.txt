Print all integer sequences (A_1, A_2, \ldots, A_N) of length N that satisfy all of the following conditions, in lexicographical order.

What is lexicographical order?
A sequence S = (S_1, S_2, \ldots, S_N) of length N is smaller in lexicographical order than a sequence T = (T_1, T_2, \ldots, T_N) of length N if and only if there exists an integer 1 \leq i \leq N such that both of the following hold:

-  (S_1, S_2, \ldots, S_{i-1}) = (T_1, T_2, \ldots, T_{i-1})
-  S_i is less than T_i (as a number).

Looking at this problem:

- Since consecutive elements differ by at least 10 and the minimal sequence is (1, 11, ..., 10N−9), substituting B_i = A_i − (10i−9) converts valid sequences exactly into non-decreasing sequences of length N with values in [0, K] where K = M − (10N−9) ≤ 9. This bijection preserves lexicographic order.
- So I just need all non-decreasing tuples over {0..K} of length N in lex order (at most C(21,9) ≈ 294k of them), mapping each B_i back to A_i = 10i−9+B_i.

For speed in CPython, I split each sequence into a prefix (length N//2, generated via `combinations_with_replacement`, which yields lex order) and precomputed suffix string tables `cur[u]` (strings for the remaining positions with first value ≥ u, built right-to-left). Each output line is then a single string concatenation. Verified against the sample (produces exactly the 10 lines in order) and small hand cases (N=2, N=4).

```python
import sys
from itertools import combinations_with_replacement


def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0])
    M = int(data[1])
    K = M - (10 * N - 9)

    # pieces[d][v] = string of A_d (0-indexed) when A_d = 10*d + 1 + v
    pieces = [[str(10 * d + 1 + v) for v in range(K + 1)] for d in range(N)]

    m = N // 2  # prefix length (>=1); suffix length N-m (>=1) since N >= 2

    # cur[u] = list (in lex order) of strings for positions m..N-1 where the
    # value sequence is non-decreasing and its first value is >= u.
    cur = None
    for d in range(N - 1, m - 1, -1):
        p = pieces[d]
        if d == N - 1:
            cur = [p[u:] for u in range(K + 1)]
        else:
            nxt = []
            for u in range(K + 1):
                lst = []
                ap = lst.append
                for w in range(u, K + 1):
                    head = p[w]
                    for s in cur[w]:
                        ap(head + ' ' + s)
                nxt.append(lst)
            cur = nxt

    out = []
    ext = out.extend
    idx = range(m)
    for pt in combinations_with_replacement(range(K + 1), m):
        pre = ' '.join([pieces[i][pt[i]] for i in idx]) + ' '
        ext([pre + s for s in cur[pt[m - 1]]])

    out.insert(0, str(len(out)))
    sys.stdout.write('\n'.join(out) + '\n')


main()
```
