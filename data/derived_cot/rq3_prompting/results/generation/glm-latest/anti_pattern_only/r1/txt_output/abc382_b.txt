Looking at this problem:

- Takahashi eats the rightmost available cookie each day, for D days.
- This means he eats exactly the D rightmost `@` characters in the string S.
- So I just need to scan from the right, converting the first D `@` characters I encounter to `.`, then output the result.

**Verification with samples:**

Sample 1: `.@@.@`, D=2 → rightmost cookies at positions 5 and 3 (1-indexed) get eaten → `.@...` ✓

Sample 3: `@@@.@@.@@.`, D=4 → rightmost 4 cookies eaten (positions 9, 8, 6, 5) → `@@@.......` ✓

Since S is guaranteed to contain at least D occurrences of `@`, the scan will always find enough cookies before reaching the left end.

```python
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    d = int(data[1])
    s = list(data[2])
    count = 0
    for i in range(n - 1, -1, -1):
        if count == d:
            break
        if s[i] == '@':
            s[i] = '.'
            count += 1
    print(''.join(s))

main()
```

This runs in O(N), which is trivial for N ≤ 100. Tracing sample 1: i=4 eats `@` (count=1), i=3 is `.`, i=2 eats `@` (count=2), then break at i=1, yielding `.@...` — correct.
