You will be given a competitive programming problem.
There are N bags, labeled bag 1, bag 2, \ldots, bag N.
Bag i (1 \leq i \leq N) contains A_i stones.
Takahashi can perform the following operation any number of times, possibly zero:

Choose two bags A and B, and move all stones from bag A into bag B.

Find the number of different possible values for the following after repeating the operation.

- B_1 \oplus B_2 \oplus \cdots \oplus B_N, where B_i is the final number of stones in bag i.
Here, \oplus denotes bitwise XOR.


About bitwise XOR
For non-negative integers a and b, the bitwise XOR a \oplus b is defined as follows:


In the binary representation of a \oplus b, the digit in the 2^k place (k \ge 0) is 1 if and only if exactly one of the digits in the 2^k place of a and b is 1; otherwise, it is 0.


For example, 3 \oplus 5 = 6 (in binary, 011 \oplus 101 = 110).
In general, for k non-negative integers x_1, x_2, \ldots, x_k, their bitwise XOR x_1 \oplus x_2 \oplus \cdots \oplus x_k is defined as (\cdots((x_1 \oplus x_2) \oplus x_3) \oplus \cdots) \oplus x_k, which does not depend on the order of x_1, x_2, \ldots, x_k.

It can be proved that under the constraints of this problem, the number of possible values is finite.

Input

The input is given from Standard Input in the following format:
N
A_1 A_2 \ldots A_N

Output

Print the number of different possible values for B_1 \oplus B_2 \oplus \cdots \oplus B_N after repeating the operation.

Constraints


- 2 \leq N \leq 12
- 1 \leq A_i \leq 10^{17}
- All input values are integers.

Sample Input 1

3
2 5 7

Sample Output 1

3

For example, if Takahashi chooses bags 1 and 3 for the operation, then the numbers of stones in bags 1, 2, 3 become 0, 5, 9.
If he stops at this point, the XOR is 0 \oplus 5 \oplus 9 = 12.
The other possible XOR values after repeating the operation are 0 and 14.
Therefore, the possible values are 0, 12, 14; there are three values, so the output is 3.

```python
import sys
import numpy as np

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    A = list(map(int, data[1:1+n]))
    
    # Full-state over first n-1 elements
    # S: (K, w) matrix, block sums in columns 0..b-1, zeros beyond. w grows.
    S = np.array([[A[0]]], dtype=np.int64)
    b = np.array([1], dtype=np.int64)  # block counts
    w = 1
    for i in range(1, n-1):
        a = A[i]
        K = S.shape[0]
        # existing-block children
        # repeat rows b times
        counts = b
        Srep = np.repeat(S, counts, axis=0)  # (P, w)
        P = Srep.shape[0]
        # column index for each child
        # offsets: exclusive cumsum of counts
        offs = np.zeros(K, dtype=np.int64)
        np.cumsum(counts[:-1], out=offs[1:]) if K > 1 else None
        # hmm, careful with K==1
        cols = np.arange(P, dtype=np.int64) - np.repeat(offs, counts)
        Srep[np.arange(P, dtype=np.int64), cols] += a
        # new-block children
        Spad = np.zeros((K, w+1), dtype=np.int64)
        Spad[:, :w] = S
        Spad[np.arange(K, dtype=np.int64), b] = a
        # concatenate
        S = np.concatenate([np.concatenate([Srep, np.zeros((P,1),dtype=np.int64)], axis=1), Spad], axis=0)
        b = np.concatenate([np.repeat(b, counts), b+1])
        w += 1
    
    # Final element
    a = A[n-1]
    K = S.shape[0]
    XOR = np.bitwise_xor.reduce(S, axis=1)  # (K,)
    counts = b
    P = int(np.sum(counts))
    offs = np.zeros(K, dtype=np.int64)
    if K > 1:
        np.cumsum(counts[:-1], out=offs[1:])
    ks = np.repeat(np.arange(K, dtype=np.int64), counts)
    js = np.arange(P, dtype=np.int64) - np.repeat(offs, counts)
    vals = S[ks, js]
    res_existing = XOR[ks] ^ vals ^ (vals + a)
    res_new = XOR ^ a
    allv = np.concatenate([res_existing, res_new])
    ans = len(np.unique(allv))
    print(ans)
```

```python
def solve_numpy(n, A):
    import numpy as np
    # Full-state over first n-1 elements
    S = np.array([[A[0]]], dtype=np.int64)
    b = np.ones(1, dtype=np.int64)
    for i in range(1, n - 1):
        a = A[i]
        K = S.shape[0]
        counts = b
        P = int(counts.sum())
        offs = np.concatenate((np.zeros(1, dtype=np.int64), np.cumsum(counts)[:-1]))
        # children that join an existing block
        Srep = np.repeat(S, counts, axis=0)
        idx = np.arange(P, dtype=np.int64)
        cols = idx - np.repeat(offs, counts)
        Srep[idx, cols] += a
        Srep = np.concatenate((Srep, np.zeros((P, 1), dtype=np.int64)), axis=1)
        # children that start a new block
        w = S.shape[1] + 1
        Spad = np.zeros((K, w), dtype=np.int64)
        Spad[:, :w-1] = S
        Spad[np.arange(K, dtype=np.int64), b] = a
        S = np.concatenate((Srep, Spad), axis=0)
        b = np.concatenate((np.repeat(b, counts), b + 1))
    # last element with XOR-delta trick
    a = A[n-1]
    K = S.shape[0]
    XOR = np.bitwise_xor.reduce(S, axis=1)
    counts = b
    P = int(counts.sum())
    offs = np.concatenate((np.zeros(1, dtype=np.int64), np.cumsum(counts)[:-1]))
    ks = np.repeat(np.arange(K, dtype=np.int64), counts)
    js = np.arange(P, dtype=np.int64) - np.repeat(offs, counts)
    vals = S[ks, js]
    res_old = XOR[ks] ^ vals ^ (vals + a)
    res_new = XOR ^ a
    allv = np.concatenate((res_old, res_new))
    print(int(np.unique(allv).size))
```
