```python
from typing import List

class Solution:
    def stringSequence(self, target: str) -> List[str]:
        result = []
        prefix = []
        for c in target:
            # Press key 1: append 'a' to the string on screen
            prefix.append('a')
            result.append(''.join(prefix))
            # Press key 2 repeatedly until the last character becomes c
            cur = ord('a')
            goal = ord(c)
            while cur < goal:
                cur += 1
                prefix[-1] = chr(cur)
                result.append(''.join(prefix))
        return result
```

**Explanation:**

- To type `target`, Alice must press key 1 exactly `n` times (once per character, since it's the only way to grow the string, and it always appends `'a'`).
- After appending `'a'` for position `i`, she must press key 2 exactly `ord(target[i]) - ord('a')` times to turn that `'a'` into `target[i]` (each press advances by one character, wrapping `z`→`a`, so this is the minimum; any extra presses that wrap around would be wasted).
- Every key press produces a new string on screen, so we record the string after key 1 (prefix + `'a'`) and after each key 2 press (prefix + next character).

Both examples verify: `"abc"` → `["a","aa","ab","aba","abb","abc"]`, and `"he"` → `["a",...,"h","ha",...,"he"]`. Complexity is O(total output length), at most ~400·26 strings of length ≤ 400.
