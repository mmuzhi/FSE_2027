This is a classic problem: union-find where each component maintains a sorted list (or a small heap) of the top-10 largest vertex numbers, since k ≤ 10.

Approach: DSU with union by size/rank. Each root stores a sorted list of the top 10 largest vertices in its component (kept sorted descending, or ascending). When merging two components, merge the two top-10 lists and keep only the top 10 elements. Since lists have at most 10 elements each, merging is O(20) per union — total O(Q * 10) which is fine.

For a type 2 query, find root of v, look at its list of top-10 (sorted descending). If k ≤ len(list), print list[k-1], else -1.

Wait — the component size could be less than 10, in which case the list holds all vertices. If component size > 10, the list holds the top 10. Since k ≤ 10, if k > len(list), then the component has fewer than k vertices (because if it had ≥ k ≥ ... well if component size ≥ k, then the top-10 list has min(10, size) ≥ k elements... actually if size ≥ k and k ≤ 10, then the list has min(10, size) elements which is ≥ k). So the check works.

Implementation details:
- parent array, size array.
- top[root] = list of largest vertices in descending order (or we can keep ascending and index from the end).

Let me keep descending order lists. Initially top[v] = [v].

Union: find roots ru, rv. If same, do nothing (note: edges could be duplicated? The problem says u < v but doesn't say edges are distinct, so duplicates possible — handle by checking ru == rv). Merge: attach smaller to larger (union by size) to keep DSU efficient, and merge lists: combine top[ru] + top[rv], sort descending, take first 10.

Actually since both lists are sorted descending and each ≤ 10, we could do a manual merge, but sorting 20 elements in Python is fast enough: sorted(l1 + l2, reverse=True)[:10]. With Q up to 2e5 unions, that's 2e5 sorts of ≤20 elements — fine.

For find with path compression — use iterative to avoid recursion depth issues. Or path halving.

import sys

def main():
    input_data = sys.stdin.buffer.read().split()
    idx = 0
    N = int(input_data[idx]); idx += 1
    Q = int(input_data[idx]); idx += 1
    
    parent = list(range(N + 1))
    size = [1] * (N + 1)
    top = [[i] for i in range(N + 1)]  # top[v] = [v], descending
    
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]  # path halving
            x = parent[x]
        return x
    
    out = []
    for _ in range(Q):
        t = input_data[idx]; idx += 1
        if t == b'1':
            u = int(input_data[idx]); idx += 1
            v = int(input_data[idx]); idx += 1
            ru = find(u)
            rv = find(v)
            if ru != rv:
                if size[ru] < size[rv]:
                    ru, rv = rv, ru
                parent[rv] = ru
                size[ru] += size[rv]
                merged = sorted(top[ru] + top[rv], reverse=True)[:10]
                top[ru] = merged
        else:
            v = int(input_data[idx]); idx += 1
            k = int(input_data[idx]); idx += 1
            r = find(v)
            lst = top[r]
            if k <= len(lst):
                out.append(str(lst[k-1]))
            else:
                out.append('-1')
    
    sys.stdout.write('\n'.join(out) + '\n' if out else '')
    
main()
