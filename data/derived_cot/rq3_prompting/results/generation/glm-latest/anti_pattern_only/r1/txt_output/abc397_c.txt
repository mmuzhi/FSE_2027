We have a sequence A of length N. We want to split at position i (1 ≤ i ≤ N-1) into prefix A[1..i] and suffix A[i+1..N]. We want to maximize d(prefix) + d(suffix), where d counts distinct integers.

A standard approach: compute for each i, the number of distinct integers in the prefix A[1..i] (call it pref[i]) and the number of distinct integers in the suffix A[i+1..N] (call it suf[i+1]). Then the answer is max over i of pref[i] + suf[i+1].

Computing pref: iterate left to right, maintain a set/boolean array, count new elements.

Computing suf: iterate right to left, maintain a set/boolean array, count new elements.

Then answer = max(pref[i] + suf[i+1] for i in 1..N-1) — using 1-based indexing; in 0-based Python, split after index i (0 ≤ i ≤ N-2): pref_distinct[i] + suf_distinct[i+1].

Looking at this problem:

- For each split position, I need the count of distinct integers in the prefix plus the count in the suffix.
- Precompute `suf[i]` = distinct count of `a[i:]` by scanning right-to-left with a seen array.
- Then scan left-to-left computing prefix distinct counts on the fly, and for each split after index `i` (0-based, `0 ≤ i ≤ n-2`), the value is `pref_count + suf[i+1]`.

Verification on Sample 1: A = [3,1,4,1,5], pref = [1,2,3,3,3], suf = [4,3,3,2,1]. Splits: 1+3=4, 2+3=5, 3+2=5, 3+1=4 → max 5. ✓
