You will be given a competitive programming problem.
There is an infinite 2D plane.
You are given a positive integer k. You are also given a 2D array queries, which contains the following queries:

The distance of an obstacle at coordinate (x, y) from the origin is given by |x| + |y|.

After queries[2], there are obstacles at distances 6, 8, and 10.

- Compute distance d.
- If heap size < k, push d. If heap size == k now, result is heap top (max of k smallest).
- Else (heap size == k): if d < heap top, pop and push d; result is new top. Else result is heap top.

Wait, careful: when heap size < k before push, after push if still < k, result is -1. If heap reaches exactly k, result is the max (heap top).

```python
import heapq
from typing import List

class Solution:
    def resultsArray(self, queries: List[List[int]], k: int) -> List[int]:
        heap = []  # max-heap via negation, size <= k
        results = []
        for x, y in queries:
            d = abs(x) + abs(y)
            if len(heap) < k:
                heapq.heappush(heap, -d)
                if len(heap) == k:
                    results.append(-heap[0])
                else:
                    results.append(-1)
            else:
                if d < -heap[0]:
                    heapq.heapreplace(heap, -d)
                results.append(-heap[0])
        return results
```

=== ANSWER ===
```python
import heapq
from typing import List

class Solution:
    def resultsArray(self, queries: List[List[int]], k: int) -> List[int]:
        heap = []  # max-heap (via negation) holding the k smallest distances so far
        results = []
        for x, y in queries:
            d = abs(x) + abs(y)
            if len(heap) < k:
                heapq.heappush(heap, -d)
                results.append(-heap[0] if len(heap) == k else -1)
            else:
                if d < -heap[0]:
                    heapq.heapreplace(heap, -d)
                results.append(-heap[0])
        return results
```
