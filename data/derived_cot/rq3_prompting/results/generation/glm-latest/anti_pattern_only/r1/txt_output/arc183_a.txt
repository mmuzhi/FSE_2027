You will be given a competitive programming problem.
You are given positive integers N and K.
An integer sequence of length NK where each integer from 1 to N appears exactly K times is called a good integer sequence.
Let S be the number of good integer sequences.
Find the \operatorname{floor}((S+1)/2)-th good integer sequence in lexicographical order.
Here, \operatorname{floor}(x) represents the largest integer not exceeding x.
 What is lexicographical order for sequences?
A sequence S = (S_1,S_2,\ldots,S_{|S|}) is lexicographically smaller than a sequence T = (T_1,T_2,\ldots,T_{|T|}) if either 1. or 2. below holds.
Here, |S| and |T| represent the lengths of S and T, respectively.

-  |S| \lt |T| and (S_1,S_2,\ldots,S_{|S|}) = (T_1,T_2,\ldots,T_{|S|}). 
-  There exists an integer 1 \leq i \leq \min\lbrace |S|, |T| \rbrace such that both of the following hold:

-  (S_1,S_2,\ldots,S_{i-1}) = (T_1,T_2,\ldots,T_{i-1})
-  S_i is (numerically) smaller than T_i.

Input

The input is given from Standard Input in the following format:
N K

Output

Print the desired integer sequence, with elements separated by spaces.

Constraints


- 1 \leq N \leq 500
- 1 \leq K \leq 500
- All input values are integers.

Sample Input 1

Sample Output 1

Looking at this problem:

- The map `x → N+1−x` on values is an order-reversing bijection on good sequences, so rank `r` maps to rank `S+1−r`. For `N ≥ 2`, `S` is even (by Kummer/popcount: `S` odd would require `popcount(NK) = N·popcount(K)`, impossible since `popcount(NK) ≤ popcount(N)·popcount(K) ≤ (N−1)·popcount(K)`). So the target rank is `m = S/2`.

Tracing the standard greedy (place smallest value `v` whose completion count `M·c_v/T ≥ remaining rank r`, subtracting skipped counts):

- **N even:** at the start all counts equal `K`, each first-value block has size `S/N`. Skipping values while `r = S/2 − (v−1)S/N > S/N` means we place `v = N/2`, and the new rank equals the new block size exactly — i.e., we're at the **last** sequence of that block. Then everything is forced: remaining values in decreasing order.

- **N odd (N≥3):** an invariant shows that while `j < K` copies of `mid=(N+1)/2` are placed, the rank stays exactly `M/2` (each sub-block boundary works out: skip condition `NK−j > 2vK` holds for `v < mid`, and `mid` is placed since `j ≤ K`). After all `K` mids are used, with `T = K(N−1)` and `r = M/2`, cumulative counts reach exactly `M/2` at `v = mid−1`, so we place `mid−1` landing at rank = block size (last of block), followed by remaining values in decreasing order.

- **N=1:** the sequence is just `K` ones.

Verified against all samples: `2 2`→`1 2 2 1`; `1 5`→`1 1 1 1 1`; `6 1`→`3 6 5 4 2 1`; `3 3`→`2 2 2 1 3 3 3 1 1`, plus full exact-count simulations for (N,K) = (3,2),(3,4),(4,2),(5,2),(7,1),(2,5) etc.
