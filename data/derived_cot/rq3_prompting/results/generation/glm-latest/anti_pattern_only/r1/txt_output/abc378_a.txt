=== ANSWER ===
Looking at this problem:

- There are only 4 balls, and each operation discards 2 balls of the same color.
- For each color, if it appears `n` times, we can form `n // 2` pairs (operations). Operations on different colors are independent, so the answer is the sum of `count(c) // 2` over all colors.

**Verification with samples:**
- `2 1 2 1`: color 1 appears twice (1 op), color 2 appears twice (1 op) → total 2 ✓
- `4 4 4 1`: color 4 appears 3 times (1 op), color 1 once (0) → total 1 ✓
- `1 2 3 4`: each color once → 0 ✓

```python
A = list(map(int, input().split()))
ans = 0
for c in range(1, 5):
    ans += A.count(c) // 2
print(ans)
```
