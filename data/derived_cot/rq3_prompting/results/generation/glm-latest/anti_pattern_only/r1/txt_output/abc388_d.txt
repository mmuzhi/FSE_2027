def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    A = data[1:1+n]  # bytes, convert as needed
    D = [0] * (n + 2)

Looking at this problem:

**Key insight 1:** Once an alien becomes an adult, it never receives stones again — it only gives 1 stone at each future coming-of-age event while it still has stones. So if alien `m` has `S_m` stones right after its own ceremony (at time `m`), it gives at events `m+1, m+2, ..., min(m + S_m, N)`, and its final count is `max(S_m - (N - m), 0)`.

**Key insight 2:** Alien `j` receives `g_j` stones where `g_j` = number of earlier adults `m < j` that still have ≥1 stone at time `j`. Alien `m` has stones at time `j` iff `S_m ≥ j - m`, i.e., `S_m + m ≥ j`.

So processing `j = 1..N` in order: each alien `m` contributes +1 to the giver-count for all times in `[m+1, min(m + S_m, N)]` (capping at `N` is valid since queries only go up to `j = N`). Using a difference array with a running prefix sum gives `g_j` in O(1) per step, for O(N) total.

I verified this against all three samples (e.g., sample 1: givers counts 0,1,2,2 → final 2 0 10 5 ✓; sample 3 also matches exactly).

    data = sys.stdin.buffer.read().split()

    D = [0] * (n + 2)
    B = []
    append = B.append
    cur = 0
    for j in range(1, n + 1):
        cur += D[j]  # cur = g_j: number of adults m < j with stones at time j
        s = A[j - 1] + cur  # stones after receiving gifts at time j
        rem = n - j
