There are N foods, each containing exactly one of vitamins 1, 2, and 3.
Specifically, eating the i-th food gives you A_i units of vitamin V_i, and C_i calories.
Takahashi can choose any subset of these N foods as long as the total calorie consumption does not exceed X.
Find the maximum possible value of this: the minimum intake among vitamins 1, 2, and 3.

Input

The input is given from Standard Input in the following format:
N X
V_1 A_1 C_1
V_2 A_2 C_2
\vdots
V_N A_N C_N

Output

Print the maximum possible value of "the minimum intake among vitamins 1, 2, and 3" when the total calories consumed is at most X.

Constraints


- 1 \leq N \leq 5000
- 1 \leq X \leq 5000
- 1 \leq V_i \leq 3
- 1 \leq A_i \leq 2 \times 10^5
- 1 \leq C_i \leq X
- All input values are integers.

Sample Input 1

5 25
1 8 5
2 3 5
2 7 10
3 2 5
3 3 10

Sample Output 1

3

Eating the 1st, 2nd, 4th, and 5th foods gives 8 units of vitamin 1, 3 units of vitamin 2, 5 units of vitamin 3, and 25 calories.
In this case, the minimum among the three vitamin intakes is 3 (vitamin 2).
It is impossible to get 4 or more units of each vitamin without exceeding 25 calories, so the answer is 3.

Looking at this problem:

- Each food provides exactly one vitamin, so the choices for vitamins 1, 2, 3 are **independent knapsacks** (maximize vitamin amount with calorie budget).
- Answer = max `t` such that `mc1(t) + mc2(t) + mc3(t) ≤ X`, where `mc_v(t)` = minimum calories to get ≥ `t` units of vitamin `v`.
- Compute `dp_v[c]` = max units of vitamin `v` with ≤ `c` calories (0/1 knapsack). Then `mc_v(t) = bisect_left(dp_v, t)` since `dp_v` is non-decreasing.
- The answer is always one of the values appearing in the dp arrays (it's the min of three dp values), so scan candidates descending and take the first feasible one.

Knapsack is vectorized with numpy (`dp[c:] = max(dp[c:], dp[:-c] + a)` using pre-update values, which is exactly 0/1 semantics), with a pure-Python fallback. Verified against both samples (answers 3 and 0).
