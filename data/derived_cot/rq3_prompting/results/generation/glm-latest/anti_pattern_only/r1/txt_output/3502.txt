```python
    def numberOfSubstrings(self, s: str, k: int) -> int:
        n = len(s)
        counts = [0] * 26

        l = 0
        ans = 0
        for r, ch in enumerate(s):
```

=== ANSWER ===
Looking at this problem:

- For a fixed right endpoint `r`, if substring `s[l..r]` is valid (some char appears ≥ k times), then any `s[l'..r]` with `l' < l` is also valid (it's a superset). So valid left endpoints for each `r` form a prefix `[0, M(r)]`.
- As `r` increases, `M(r)` is non-decreasing (adding a character can only help), enabling a two-pointer approach.

**Algorithm:** Slide `r` forward, maintaining counts in window `[l, r]` and a counter `valid_chars` = number of characters whose window count ≥ k. While the current window is valid, shrink from the left (this finds the largest `l` for which the window was still valid — after the loop, all left endpoints `0..l-1` give valid substrings ending at `r`). Add `l` to the answer each step.

**Verification with Example 1** (`s="abacb", k=2`): contributions per `r` are 0, 0, 1, 1, 2 → total 4 ✓. Example 2 (`k=1`): every step `l` ends at `r+1`, giving 1+2+...+n = 15 ✓. Also checked `s="aaa", k=2` → 3 and `s="aaaa", k=3` → 3 by hand.

Runs in O(n) time with O(1) extra space.

```python
class Solution:
    def numberOfSubstrings(self, s: str, k: int) -> int:
        counts = [0] * 26
        valid_chars = 0  # number of chars whose count in window >= k
        l = 0
        ans = 0
        for r, ch in enumerate(s):
            c = ord(ch) - 97
            counts[c] += 1
            if counts[c] == k:
                valid_chars += 1
            # Shrink window while it's still valid, to find the largest l
            # such that s[l..r] was valid. After loop, left endpoints
            # 0..l-1 all yield valid substrings ending at r.
            while valid_chars > 0:
                lc = ord(s[l]) - 97
                counts[lc] -= 1
                if counts[lc] == k - 1:
                    valid_chars -= 1
                l += 1
            ans += l
        return ans
```
