=== ANSWER ===
Looking at this problem:

**Key insight:** Track the stack height as a path $s_0=0$, $s_t = s_{t-1}\pm 1$, staying $\ge 0$ (push = up, pop = down). Since height parity satisfies $s_t \equiv t \pmod 2$, the element that ends at stack depth $d$ was pushed at the *last* time the path rises to height $d$, call it $i_d$, and $i_d \equiv d \pmod 2$ with $i_1 < i_2 < \dots < i_m$, where $m = s_N \equiv N \pmod 2$.

Conversely, **any** increasing sequence $i_1 < \dots < i_m$ with $i_d \equiv d \pmod 2$ and $m \equiv N \pmod 2$ is achievable (oscillate the path between adjacent levels between the chosen rise times).

So the answer is the maximum sum of a subsequence whose $d$-th chosen index has the same parity as $d$ (i.e., chosen positions alternate odd, even, odd, even, ... starting with an odd position), with the count $m \equiv N \pmod 2$ ($m \ge 1$ if $N$ is odd).

This is solved by an $O(N)$ DP with two states: `dp0` = best sum using an even number of chosen elements, `dp1` = best sum with an odd count. At an odd position we may extend an even-length choice (making it odd-length); at an even position we extend an odd-length one.

- Sample 2: forced `dp1 = -1` ✓.
- Sample 3: dp trace gives `dp0 = 369` ✓.

Also verified against full brute-force enumeration of all operation sequences for $N=4$ with several arrays (e.g., `[-10,-10,1,1]` → 2 via push/pop/push/push keeping $A_3+A_4$; DP matches all reachable sums $\{a{+}b{+}c{+}d,\ a{+}b,\ a{+}d,\ c{+}d,\ 0\}$).

Edge cases: for even $N$, the empty stack (sum 0) is always achievable and included via `dp0 = 0`; for odd $N$, `dp1` is always finite (at worst a single odd-position element, e.g. $A_1$).

import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    vals = list(map(int, data[1:1 + n]))
    dp0 = 0                 # best sum, even number of chosen elements (incl. empty)
    dp1 = -(1 << 62)        # best sum, odd number of chosen elements

        else:               # position idx+1 is even -> extends odd count to even
