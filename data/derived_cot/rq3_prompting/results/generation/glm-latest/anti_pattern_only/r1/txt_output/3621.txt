```python
class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        if min(nums) < k:
            return -1
        return len(set(x for x in nums if x > k))
```

```python
class Solution:
    def minOperations(self, nums: List[int], k: int) -> int:
        # Operations only ever decrease values, so if any element is below k,
        # it can never reach k.
        if min(nums) < k:
            return -1
        
        # A valid h must have all values > h identical. If d1 is the current
        # maximum distinct value and d2 the second largest, valid effective
        # choices are h in [d2, d1). Each operation therefore can eliminate at
        # most one distinct value greater than k (the current maximum), and we
        # can always eliminate exactly one by choosing h = max(d2, k). Hence the
        # answer is the number of distinct values strictly greater than k.
        return len({x for x in nums if x > k})
```
