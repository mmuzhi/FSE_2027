A sequence X = (X_1, X_2, \ldots) of positive integers (possibly empty) is called a 1122 sequence if and only if it satisfies all of the following three conditions: (The definition of a 1122 sequence is the same as in Problem F.)

- \lvert X \rvert is even. Here, \lvert X \rvert denotes the length of X.
- For each integer i satisfying 1\leq i\leq \frac{|X|}{2}, X_{2i-1} and X_{2i} are equal.
- Each positive integer appears in X either not at all or exactly twice. That is, every positive integer contained in X appears exactly twice in X.

Given a sequence A = (A_1, A_2, \ldots, A_N) of length N consisting of positive integers, print the maximum length of a (contiguous) subarray of A that is a 1122 sequence.

N

- 1\leq A_i \leq N
- All input values are integers.

=== ANSWER ===
Looking at this problem:

- A 1122 subarray must be a concatenation of pairs `(v,v)` at positions `(l,l+1), (l+2,l+3), ...` with all pair values distinct.
- So valid pair-start positions `p` (where `A[p]==A[p+1]`) split by parity into step-2 chains. Any 1122 subarray corresponds to a contiguous run of valid pairs within one parity chain, with distinct values.
- For each parity, I run a sliding window ("longest run without repeats") over pair-boundary positions: on an invalid pair, reset the window; on a duplicate value, shrink past its previous occurrence; track max window size in pairs.

I verified against all samples and edge cases like `[1,1,1,1]` (answer 2, since a value can't appear 4 times) and `[5,5,5,3,3]` (answer 4 via the odd-parity start `(5,5,3,3)`), which the two-parity chain decomposition handles correctly.

The `last` array stores the most recent compressed pair index for each value; a global counter `cnt` compresses valid pairs so stale entries from earlier chains/parities are automatically ignored via the `q >= L` check (windows never span an invalid pair because `L` resets to `cnt` there).

Complexity: O(N) time and space, fine for N ≤ 2×10⁵.
