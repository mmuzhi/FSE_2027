=== ANSWER ===
Looking at this problem:

- Each strawberry requires K **consecutive healthy** teeth, and eating turns exactly those K teeth into cavities.
- Once a tooth becomes X, it never recovers. So the blocks of teeth used for different strawberries must be pairwise disjoint sets of positions that were all initially 'O'.
- A block of K consecutive teeth must lie entirely within a single maximal run of 'O's (runs are separated by 'X', which can never be part of a healthy block).
- Conversely, any set of disjoint K-length blocks of initial 'O's can be eaten (each block stays all-'O' until consumed).
- Within a run of length L, the maximum number of disjoint blocks of length K is ⌊L/K⌋.

So the answer is the sum of ⌊L/K⌋ over all maximal runs of 'O's.

Verification with samples:
1. `OOXOOOO`, K=3: runs of 2 and 4 → 0+1 = 1 ✓
2. `OXXOOOXOOOOX`, K=2: runs of 1, 3, 4 → 0+1+2 = 3 ✓
3. `XXOOOOOOOOXXOOOOOXXXXX`, K=5: runs of 8 and 5 → 1+1 = 2 ✓

A simple way to implement this is to split S on 'X' and sum ⌊length/K⌋ for each piece.

```python
def main():
    import sys
    data = sys.stdin.read().split()
    n, k = int(data[0]), int(data[1])
    s = data[2]
    print(sum(len(part) // k for part in s.split('X')))

main()
```
