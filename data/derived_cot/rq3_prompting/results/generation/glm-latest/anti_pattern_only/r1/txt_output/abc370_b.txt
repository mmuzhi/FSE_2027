Looking at this problem:

- We maintain a "current" element, starting at 1.
- For k = 1 to N, we combine current with k: if current ≥ k, the result is A[current][k]; otherwise it's A[k][current] (since the matrix is given in lower-triangular form).
- Print the final current value.

Since N ≤ 100 and A values are between 1 and N, a direct simulation with O(1) lookups works fine.

```python
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    N = int(data[idx]); idx += 1
    A = [[0] * (N + 1) for _ in range(N + 1)]
    for i in range(1, N + 1):
        for j in range(1, i + 1):
            A[i][j] = int(data[idx]); idx += 1

    current = 1
    for k in range(1, N + 1):
        if current >= k:
            current = A[current][k]
        else:
            current = A[k][current]

    print(current)

main()
```
