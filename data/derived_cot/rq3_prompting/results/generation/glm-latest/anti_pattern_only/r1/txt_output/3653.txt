=== ANSWER ===
Looking at this problem: a subarray `nums[i..j-1]` has length `j - i` divisible by `k` exactly when `i ≡ j (mod k)`, and its sum is `prefix[j] - prefix[i]`. So for each `j`, I want the minimum `prefix[i]` among earlier indices with the same residue mod `k`. This gives an O(n) solution maintaining a running minimum per residue class.

Verification with example 2 (`[-1,-2,-3,-4,-5], k=4`): at `j=4`, residue 0, min prefix is `prefix[0]=0`, candidate `= -10`. At `j=5`, residue 1, min is `-1`, candidate `-14`. Answer `-10`. ✓

Example 3 (`[-5,1,2,-3,4], k=2`): prefix `[0,-5,-4,-2,-5,-1]`; at `j=5`, residue 1, min prefix is `-5`, candidate `= -1 - (-5) = 4`. ✓

Since `k ≤ n`, a valid subarray always exists, so the answer is always set.

```python
from typing import List

class Solution:
    def maxSubarraySum(self, nums: List[int], k: int) -> int:
        INF = float('inf')
        # min_prefix[r] = minimum prefix sum seen so far at an index i (i < j) with i % k == r
        min_prefix = [INF] * k
        min_prefix[0] = 0  # prefix[0] = 0 (index 0, residue 0)
        prefix = 0
        ans = -INF
        
        for j in range(1, len(nums) + 1):
            prefix += nums[j - 1]
            r = j % k
            # Subarray ends at j (exclusive), starts at some i with i % k == r, i < j
            if min_prefix[r] != INF:
                cand = prefix - min_prefix[r]
                if cand > ans:
                    ans = cand
            # Update minimum prefix for this residue class
            if prefix < min_prefix[r]:
                min_prefix[r] = prefix
        
        return ans
```
