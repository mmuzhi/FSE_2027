You are given a positive integer k.

Input: k = 10
Output: "c"

Constraints: 1 <= k <= 500. So the word needs at most 512 characters (2^9 = 512 ≥ 500). That means at most 9 operations.

Given the small constraint, the simplest approach is simulation:
1. Keep performing operations until len(word) >= k.
2. Return word[k-1].

Simulation complexity: The word length doubles each time, so at most ~10 iterations, and each operation processes the current word. Total work is O(2^10) = O(1024) character transformations at most. Trivially fast.

Let me write the simulation:

```python
class Solution:
    def kthCharacter(self, k: int) -> str:
        word = "a"
        while len(word) < k:
            shifted = ''.join(
                chr((ord(c) - ord('a') + 1) % 26 + ord('a')) for c in word
            )
            word += shifted
        return word[k - 1]
```
