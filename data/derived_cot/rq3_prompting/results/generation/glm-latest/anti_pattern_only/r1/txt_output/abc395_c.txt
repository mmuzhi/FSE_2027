=== ANSWER ===
Looking at this problem:

**Key insight:** A subarray contains a repeated value if and only if it contains two equal values at positions i < j. The shortest such subarray containing that pair is exactly [i, j] with length j − i + 1. So the answer is the minimum of j − i + 1 over all pairs of equal values — and this minimum is always achieved by *consecutive* occurrences of the same value (any non-consecutive pair is farther apart than the consecutive pairs between them).

**Algorithm:** Sweep left to right, keeping the last index where each value was seen. When a value reappears, compute the distance to its previous occurrence and track the minimum. If no value ever repeats, output −1.

Verification with samples:
- Sample 1: `[3,9,5,3,1]` — 3 at indices 0 and 3 → length 4. ✓
- Sample 2: all distinct → −1. ✓
- Sample 3: `[1,1,...]` — adjacent 1s → length 2. ✓

Complexity: O(N + max A) time and space, which easily fits N ≤ 2×10⁵, A_i ≤ 10⁶. Using a flat array of size 10⁶+1 (initialized to −1) indexed by value gives fast lookups; early exit when the minimum possible length 2 is found.

Edge cases: N = 1 → no repeat possible → −1 (handled since ans sentinel n+1 exceeds n). All-equal arrays → adjacent pair gives 2. Correct.
