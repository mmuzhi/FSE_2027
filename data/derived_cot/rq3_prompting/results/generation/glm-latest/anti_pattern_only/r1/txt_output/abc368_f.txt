=== ANSWER ===
Looking at this problem:

- Each pile is a number $A_i$; a move replaces $A_i$ with any proper divisor (including 1). Position 1 is terminal for a pile.
- By Sprague–Grundy theory, each pile is an independent game, and the whole game's winner is determined by the XOR of Grundy values.

**Key claim:** The Grundy value of $n$ equals $\Omega(n)$ (number of prime factors counted with multiplicity).

**Proof sketch (induction):** Any proper divisor $d$ of $n$ satisfies $\Omega(d) < \Omega(n)$ since $\Omega$ is completely additive. If $n = p_1 p_2 \cdots p_k$ (with multiplicity), then for each $j \in [0, k-1]$, $d = p_1 \cdots p_j$ is a proper divisor with $\Omega(d) = j$, so all values $0,\dots,k-1$ appear among options and nothing else does. Hence $\operatorname{mex} = k = \Omega(n)$.

Verification with samples:
- $(2,3,4)$: $\Omega = 1,1,2$, XOR $= 2 \neq 0$ → Anna ✓
- $(2,3,4,6)$: $\Omega = 1,1,2,2$, XOR $= 0$ → Bruno ✓

So: compute $\Omega(A_i)$ for each element (via smallest-prime-factor sieve up to $10^5$), XOR them; nonzero → Anna, zero → Bruno.
