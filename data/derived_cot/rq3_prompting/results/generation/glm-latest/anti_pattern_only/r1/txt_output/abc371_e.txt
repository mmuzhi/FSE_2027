We need to compute the sum over all subarrays (i, j) of the number of distinct values in A[i..j].

Standard approach: contribution technique. For each position k, count the number of subarrays where A_k is the "first occurrence" of its value within the subarray. That is, A_k contributes to f(l, r) if l ≤ k ≤ r and there's no earlier occurrence of A_k at position ≥ l. Let prev[k] be the last position before k where the same value appears (0 if none). Then A_k is counted as a new distinct value in subarray (l, r) iff prev[k] < l ≤ k and k ≤ r.

Number of such subarrays: (k - prev[k]) choices for l (l ranges from prev[k]+1 to k) times (N - k + 1) choices for r (r ranges from k to N).

So answer = sum over k of (k - prev[k]) * (N - k + 1).

Looking at this problem, I use the contribution technique: for each position `k`, the value `A_k` counts as a distinct value in subarray `(l, r)` exactly when `l ≤ k ≤ r` and `A_k` doesn't appear in `[l, k-1]`. If `prev[k]` is the last earlier occurrence of `A_k` (0 if none), this means `prev[k] < l ≤ k ≤ r`.

So the number of subarrays where `A_k` contributes a new distinct value is `(k - prev[k]) * (N - k + 1)`.
