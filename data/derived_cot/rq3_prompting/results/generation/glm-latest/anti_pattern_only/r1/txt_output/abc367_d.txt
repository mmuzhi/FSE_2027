Looking at this problem:

- Define position `pos_i = A_1 + ... + A_{i-1}` (with `pos_1 = 0`), and `L = sum(A)`.
- The clockwise distance from s to t is `(pos_t - pos_s) mod L`, which lies in `(0, L)`.
- For a pair with `p_a < p_b`:
  - Going from a to b (no wrap): distance `p_b - p_a`, counts iff `p_b ≡ p_a (mod M)`.
  - Going from b to a (wraps): distance `p_a - p_b + L`, counts iff `p_b ≡ p_a + L (mod M)`.

So iterate positions in increasing order, maintaining a count array of residues seen so far. For each new position with residue `r`, add `cnt[r]` (non-wrapping pairs where it's the destination) and `cnt[(r - L mod M) mod M]` (wrapping pairs where it's the start).

Verification with samples:
- Sample 1: positions 0,2,3,7; L=10, rL=1 → answer 4 ✓
- Sample 2: positions 0,1; M=10^6 → answer 0 ✓  
- Sample 3: L=47, rL=2 → answer 11 ✓

Edge case M=1: rL=0, every pair counted twice (both directions), giving N(N-1), which is correct.

Complexity: O(N + M), well within limits.
