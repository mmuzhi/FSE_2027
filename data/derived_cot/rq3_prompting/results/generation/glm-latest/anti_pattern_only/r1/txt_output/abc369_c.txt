=== ANSWER ===
Looking at this problem:

**Key insight:** A subarray A[l..r] is an arithmetic progression iff all consecutive differences D_i = A_{i+1} - A_i for i in [l, r-1] are equal (and length-1 subarrays are always APs).

So the answer equals N (for single-element subarrays) plus, for each maximal run of equal values in the difference array D (length N-1) of length k, the number of subranges k·(k+1)/2 — each subrange [a,b] of D with all equal values corresponds bijectively to a valid pair (l, r) = (a, b+1).

**Verification with samples:**
- Sample 1: A=[3,6,9,3], D=[3,3,-6]. Runs of length 2 and 1. Answer = 4 + 3 + 1 = 8 ✓
- Sample 2: D=[0,0,0,0], one run of length 4. Answer = 5 + 10 = 15 ✓
- Sample 3: D=[-45,22,22,-14,-14,-14,-14]. Runs: 1, 2, 4. Answer = 8 + 1 + 3 + 10 = 22 ✓

The algorithm is O(N), easily fast enough for N ≤ 2×10^5.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))
    ans = n  # all single-element subarrays
    if n >= 2:
        d = [a[i + 1] - a[i] for i in range(n - 1)]
        run = 1
        for i in range(1, len(d)):
            if d[i] == d[i - 1]:
                run += 1
            else:
                ans += run * (run + 1) // 2
                run = 1
        ans += run * (run + 1) // 2
    print(ans)

main()
```
