We have N black balls and M white balls. We choose some subset such that (#black chosen) >= (#white chosen). Maximize sum.

Standard approach: sort black values descending, sort white values descending. Since the constraint is #black >= #white, intuitively we choose k black balls (the top k) and j white balls (top j) with k >= j. But actually we need to be careful: it's optimal to choose the top k black and top j white values for fixed counts k and j. Then we maximize over j <= k, k <= N, j <= M.

But is it true that for fixed number of black chosen k and white chosen j (j <= k), the best is top k blacks and top j whites? Yes, obviously — choose the largest values for each count.

So we need max over 0 <= j <= min(M, k), 0 <= k <= N of (prefix sums of sorted-descending B)[k] + (prefix sums of sorted-descending W)[j].

However, brute force over all (k, j) pairs is O(N*M), too slow. We need a smarter approach.

Since prefix_W could be negative after some point, for each k, best j = argmax over j in [0, min(k,M)] of prefix_W[j]. Let bestW[t] = max_{0 <= j <= t} prefix_W[j]. Then answer = max over k in [0, N] of prefix_B[k] + bestW[min(k, M)].

def main():

=== ANSWER ===
Looking at this problem:

- For a fixed number of black balls k and white balls j (with j ≤ k), the optimal choice is the top-k black values and top-j white values.
- So the answer is max over k of (prefix sum of sorted-descending B)[k] + (max prefix sum of sorted-descending W over j ≤ min(k, M)).

The inner max can be precomputed as a running maximum of white prefix sums, giving O((N+M) log(N+M)) total.

Verification with samples:
- Sample 1: prefix_B = [0,8,13,16,15], best white prefix capped at each k gives max at k=3: 16+3=19 ✓
- Sample 2: k=2: 3+12=15 ✓
- Sample 3: all candidates negative except empty → 0 ✓

import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    B = list(map(int, data[2:2 + n]))
    W = list(map(int, data[2 + n:2 + n + m]))
    B.sort(reverse=True)
    W.sort(reverse=True)

    prefixB = [0] * (n + 1)
    for i in range(n):
        prefixB[i + 1] = prefixB[i] + B[i]

    prefixW = [0] * (m + 1)
    for j in range(m):
        prefixW[j + 1] = prefixW[j] + W[j]

    # bestW[t] = max(prefixW[0..t])
    bestW = [0] * (m + 1)
    for t in range(1, m + 1):
        bestW[t] = bestW[t - 1] if bestW[t - 1] > prefixW[t] else prefixW[t]

    ans = 0  # choosing nothing
    for k in range(n + 1):
        t = k if k < m else m
        cand = prefixB[k] + bestW[t]
        if cand > ans:

    print(ans)

main()
