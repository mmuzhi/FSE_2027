class Solution:
    def maxFreeTime(self, eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
        n = len(startTime)
        gaps = [startTime[0]]
        for i in range(1, n):
            gaps.append(startTime[i] - endTime[i-1])
        gaps.append(eventTime - endTime[-1])
        
        window = k + 1
        # sliding window over gaps of size window
        cur = sum(gaps[:window])
        ans = cur
        for i in range(window, len(gaps)):
            cur += gaps[i] - gaps[i - window]
            ans = max(ans, cur)
        return ans
```

class Solution:
    def maxFreeTime(self, eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
        n = len(startTime)
        gaps = [startTime[0]]
        for i in range(1, n):
            gaps.append(startTime[i] - endTime[i - 1])
        gaps.append(eventTime - endTime[-1])
        
        w = k + 1
        cur = sum(gaps[:w])
        ans = cur
        for i in range(w, len(gaps)):
            cur += gaps[i] - gaps[i - w]
            if cur > ans:
                ans = cur
        return ans
```

=== ANSWER ===
Looking at this problem:

- There are `n+1` gaps: before the first meeting, between consecutive meetings, and after the last meeting.
- Moving `k` **consecutive** meetings and compacting them together merges the `k+1` gaps surrounding them into one free block. Any achievable free block must have all originally-overlapping meetings moved (a consecutive set of at most `k` meetings), and the block size is bounded by the sum of at most `k+1` consecutive gaps (the moved meetings must still fit in the span between the unmoved neighbors, minus their total duration).
- So the answer is the maximum sum of a window of `k+1` consecutive gaps — a classic sliding window.

Verification with examples:
- Example 1: gaps = [1,1,0], window size 2 → max(1+1, 1+0) = 2 ✓
- Example 2: gaps = [0,1,5,0], window size 2 → max(1, 6, 5) = 6 ✓
- Example 3: all gaps 0 → 0 ✓

Edge case: `k = n` means the single window covers all gaps (total free time), which the code handles since `w = k+1 = n+1 = len(gaps)`.

```python
class Solution:
    def maxFreeTime(self, eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
        n = len(startTime)
        gaps = [startTime[0]]
        for i in range(1, n):
            gaps.append(startTime[i] - endTime[i - 1])
        gaps.append(eventTime - endTime[-1])
        
        w = k + 1
        cur = sum(gaps[:w])
        ans = cur
        for i in range(w, len(gaps)):
            cur += gaps[i] - gaps[i - w]
            if cur > ans:
                ans = cur
        return ans
```
