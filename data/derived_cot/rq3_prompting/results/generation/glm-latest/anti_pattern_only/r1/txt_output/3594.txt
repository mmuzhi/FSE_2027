```python
from collections import Counter
from typing import List

class Solution:
    def getLargestOutlier(self, nums: List[int]) -> int:
        total = sum(nums)
        count = Counter(nums)
        ans = float('-inf')
        for x in count:
            rem = total - x
            if rem % 2:
                continue
            target = rem // 2
            if target in count and (target != x or count[x] >= 2):
                if x > ans:
                    ans = x
        return ans
```

Note: `rem % 2` for negative rem: -7 % 2 = 1 (truthy, skip), -6 % 2 = 0 (falsy, proceed). Correct in Python.

=== ANSWER ===
Looking at this problem:

- Let `total = sum(nums)`. If `x` is the outlier and `s` is the sum element, then the special numbers sum to `total - x - s`, and this must equal `s`. So `s = (total - x) / 2`.
- For each candidate outlier value `x`, check if `(total - x)` is even and whether the value `(total - x) // 2` exists in the array at a **different index**:
  - If the target value differs from `x`, any occurrence is at a different index.
  - If the target equals `x`, we need at least 2 occurrences (one for the sum element, one for the outlier).
- Take the maximum such `x`.

Verified against all three examples (e.g., example 3: total = 15, for x = 5, target = 5 with count 2 ≥ 2 → outlier 5). Runs in O(n) time.
