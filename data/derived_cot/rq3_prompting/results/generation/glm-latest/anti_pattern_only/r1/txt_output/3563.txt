=== ANSWER ===
Looking at this problem:

- At most 10 rows → I can bitmask over rows (1024 states).
- Each distinct value can be used at most once, each row at most once. This is a bipartite matching between values and rows, where value `v` connects to every row containing `v`.

**DP approach:** Process each distinct value once. State `dp[mask]` = best sum using exactly the rows in `mask`. For each value `v`, either skip it, or assign it to some unused row `r` that contains `v` (transition `dp[mask] → dp[mask | 1<<r] = dp[mask] + v`). Since each value is processed exactly once, uniqueness of values is enforced; the row bitmask enforces distinct rows.

Complexity: ≤100 distinct values × 1024 masks × ≤10 rows ≈ 1M operations — easily fast enough.

Verification on examples:
- Example 1: pick 4 (row 1), 3 (row 0), 1 (row 2) → 8. DP reaches `dp[0b111] = 8`. ✓
- Example 2: pick 7 (row 0), 8 (row 1) → 15. DP reaches `dp[0b11] = 15`. ✓

Since all values ≥ 1, taking `max` over non-empty row masks gives the required "one or more cells" answer (single-cell selections are always reachable).

```python
class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        n = len(grid)
        # Map each distinct value to the rows that contain it
        val_rows = {}
        for r in range(n):
            for v in set(grid[r]):
                val_rows.setdefault(v, []).append(r)

        NEG = float('-inf')
        size = 1 << n
        dp = [NEG] * size
        dp[0] = 0

        # Process each distinct value once
        for v in sorted(val_rows, reverse=True):
            rows = val_rows[v]
            ndp = dp[:]  # option: skip value v entirely
            for mask in range(size):
                cur = dp[mask]
                if cur == NEG:
                    continue
                for r in rows:
                    bit = 1 << r
                    if mask & bit:
                        continue  # row already used
                    nm = mask | bit
                    val = cur + v
                    if val > ndp[nm]:
                        ndp[nm] = val
            dp = ndp

        # Exclude empty mask (mask 0) since we need at least one cell;
        # every row has >= 1 cell, so some non-empty mask is always reachable.
        return max(dp[1:])
```
