=== ANSWER ===
Looking at this problem:

- Within a single day, the conversion graph has no contradictions/cycles, so the exchange rate between any two currencies in the same connected component is fixed (the product along the unique path). There's no intra-day arbitrage.
- So the strategy is: end day 1 holding some currency `c` (getting `d1[c]` units from 1.0 initial), then on day 2 convert `c` back to the initial currency. Since day-2 rates are consistent, converting 1 unit of `c` back gives `1/d2[c]` units of initial currency, where `d2[c]` is the day-2 rate from initial to `c`.
- Answer = max over `c` (reachable in both days' components of the initial currency) of `d1[c] / d2[c]`, which is at least 1.0 (doing nothing).

Verification with examples:
- Example 1: d1 = {EUR:1, USD:2, JPY:6}, d2 = {EUR:1, CHF:1/6, USD:1/30, JPY:1/120} → max(1, 60, 720) = 720 ✓
- Example 2: d1={NGN:1, EUR:9}, d2={NGN:1, EUR:6} → 9/6 = 1.5 ✓
- Example 3: JPY unreachable on day 1, so answer is 1.0 ✓

Computing each day's rates is a simple DFS/BFS over the undirected graph (edge with rate `r` forward, `1/r` backward), which is exact due to the no-contradiction guarantee.

```python
from typing import List
from collections import defaultdict


class Solution:
    def maxAmount(self, initialCurrency: str, pairs1: List[List[str]], rates1: List[float], pairs2: List[List[str]], rates2: List[float]) -> float:
        
        def compute(pairs, rates, start):
            # Returns dict: currency -> amount obtainable from 1.0 of `start`
            # (valid because rates are consistent within a day: unique path products)
            adj = defaultdict(list)
            for (a, b), r in zip(pairs, rates):
                adj[a].append((b, r))
                adj[b].append((a, 1.0 / r))
            best = {start: 1.0}
            stack = [start]
            while stack:
                cur = stack.pop()
                for nxt, r in adj[cur]:
                    if nxt not in best:
                        best[nxt] = best[cur] * r
                        stack.append(nxt)
            return best
        
        d1 = compute(pairs1, rates1, initialCurrency)
        d2 = compute(pairs2, rates2, initialCurrency)
        
        ans = 1.0
        for c, amt in d1.items():
            if c in d2:
                cand = amt / d2[c]
                if cand > ans:
                    ans = cand
        return ans
```
