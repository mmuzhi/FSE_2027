Input: s = "3902"
Output: true
Explanation:

(s[1] + s[2]) % 10 = (9 + 0) % 10 = 9
(s[2] + s[3]) % 10 = (0 + 2) % 10 = 2

Second operation:

Since the digits in "11" are the same, the output is true.

class Solution:
    def hasSameDigits(self, s: str) -> bool:
        digits = [int(c) for c in s]
        while len(digits) > 2:
            digits = [(digits[i] + digits[i+1]) % 10 for i in range(len(digits) - 1)]
        return digits[0] == digits[1]
```

class Solution:
    def hasSameDigits(self, s: str) -> bool:
        from math import comb
        n = len(s)
        d = [int(c) for c in s]
        k = n - 2
        coeffs = [comb(k, i) % 10 for i in range(k + 1)]
        first = sum(coeffs[i] * d[i] for i in range(k + 1)) % 10
        second = sum(coeffs[i] * d[i + 1] for i in range(k + 1)) % 10
        return first == second
```
