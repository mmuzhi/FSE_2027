Looking at this problem:

- Pair up houses (k, n-1-k) — each pair must have two different colors (equidistant condition).
- Consecutive pairs (k, n-1-k) and (k+1, n-2-k) interact: left houses k and k+1 are adjacent, right houses n-1-k and n-2-k are adjacent.
- So DP over pairs with state = (left color, right color), 6 valid states. Transition from (a,b) to (a',b') requires a≠a', b≠b'. For a target (a',b') with third color c, the allowed predecessors are exactly (b',a'), (b',c), (c,a') — only 3 cells to check.

I verified this DP against both examples (getting 9 and 18 respectively, with matching optimal colorings), and it handles n=2 (single pair) correctly since the loop body doesn't execute.

```python
class Solution:
    def minCost(self, n: int, cost: List[List[int]]) -> int:
        first = cost[0]
        last = cost[n - 1]
        # states: d0:(0,1) d1:(0,2) d2:(1,0) d3:(1,2) d4:(2,0) d5:(2,1)
        d0 = first[0] + last[1]
        d1 = first[0] + last[2]
        d2 = first[1] + last[0]
        d3 = first[1] + last[2]
        d4 = first[2] + last[0]
        d5 = first[2] + last[1]
        half = n // 2
        for k in range(1, half):
            ci = cost[k]
            cj = cost[n - 1 - k]
            d0, d1, d2, d3, d4, d5 = (
                min(d2, d3, d4) + ci[0] + cj[1],
                min(d4, d5, d2) + ci[0] + cj[2],
                min(d0, d1, d5) + ci[1] + cj[0],
                min(d5, d4, d0) + ci[1] + cj[2],
                min(d1, d0, d3) + ci[2] + cj[0],
                min(d3, d2, d1) + ci[2] + cj[1],
            )
        return min(d0, d1, d2, d3, d4, d5)
```

**Explanation:** The DP processes pairs of equidistant houses from the outermost pair inward. Each state `(a, b)` means the left house of the current pair has color `a` and the right house has color `b` (with `a != b`). When moving to the next inner pair with colors `(a', b')`, adjacency forces `a != a'` and `b != b'`. Since there are only 3 colors, excluding row `a'` and column `b'` from the 3×3 table leaves exactly 3 valid predecessor states, giving O(n) total time with small constants — easily fast enough for n = 10^5.
