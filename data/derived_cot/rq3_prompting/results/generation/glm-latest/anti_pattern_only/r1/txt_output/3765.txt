```python
class Solution:
    def minimumCost(self, nums: List[int], cost: List[int], k: int) -> int:
        n = len(nums)
        S = [0] * (n + 1)
        C = [0] * (n + 1)
        s = 0
        c = 0
        for i in range(n):
            s += nums[i]
            c += cost[i]
            S[i + 1] = s
            C[i + 1] = c
        Sn = S[n]
        Cn = C[n]
        
        # A partition with interior boundaries b_1 < ... < b_r (b_{r+1} = n) has total cost:
        #   Sn*Cn + k*Cn + sum_{i=1..r} t(b_i, b_{i+1}),
        # where t(p, q) = k*(Cn - C[p]) - (S[q] - S[p]) * C[p].
        # D[j] = min(0, min_{p<j} D[p] + t(p, j)) = best chain of boundaries ending at j
        # (chain cost excludes the outgoing term of j itself).
        # Answer = Sn*Cn + k*Cn + min(0, min_{j=1..n-1} D[j] + t(j, n)).
        
        best_final = 0
        # pairs of (A[p], C[p]) where A[p] = D[p] + k*(Cn - C[p]) + S[p]*C[p];
        # D[p] + t(p, q) = A[p] - S[q]*C[p]
        pairs = []
        for j in range(1, n):
            Sj = S[j]
            Cj = C[j]
            best = 0
            for a, cp in pairs:
                cand = a - Sj * cp
                if cand < best:
                    best = cand
            Aj = best + k * (Cn - Cj) + Sj * Cj
            pairs.append((Aj, Cj))
            fc = Aj - Sn * Cj
            if fc < best_final:
                best_final = fc
        return Sn * Cn + k * Cn + best_final
```

Looking at this problem, I apply summation by parts to the total cost. For a partition with interior cut points $b_1 < ... < b_{r}$ (with $b_{r+1}=n$, $b_0=0$), the total cost

$$\sum_{i=1}^{m}(S[b_i]+ki)(C[b_i]-C[b_{i-1}]) = S_n C_n + k C_n + \sum_{i=1}^{m-1} t(b_i, b_{i+1})$$

where $t(p,q) = k(C_n - C[p]) - (S[q]-S[p])C[p]$ (verified against both examples: e.g. example 2 gives $1624 - 322 - 317 = 985$).

So I need the minimum over all chains of cut points of the sum of $t$ over consecutive pairs (ending at $n$). This is a DAG shortest path: $D[j] = \min(0, \min_{p<j} D[p] + t(p,j))$, answer $= S_nC_n + kC_n + \min(0, \min_j D[j] + t(j,n))$. Writing $A[p] = D[p] + k(C_n - C[p]) + S[p]C[p]$, we get $D[p]+t(p,q) = A[p] - S[q]C[p]$, giving a clean $O(n^2)$ DP (≈500K operations for $n=1000$), which avoids the naive $O(n^3)$.

I verified this by hand on both examples (110 and 985) plus several small random cases computed both directly and via the formula.
