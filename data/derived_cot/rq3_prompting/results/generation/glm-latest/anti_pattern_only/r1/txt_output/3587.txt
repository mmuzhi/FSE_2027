You are given two integers, n and k, along with two 2D integer arrays, stayScore and travelScore.

=== ANSWER ===
Looking at this problem:

- **State**: `dp[c]` = maximum points earned so far if the tourist is currently in city `c` (start of day processing).
- **Transition per day `i`**: 
  - Stay: `ndp[c] = dp[c] + stayScore[i][c]`
  - Travel: `ndp[dest] = max(dp[c] + travelScore[c][dest])` over all `c`
- **Answer**: `max(dp)` after `k` days (start city free via `dp` initialized to all zeros).

Since `travelScore[c][c] == 0` and `stayScore ≥ 1`, including `c == dest` in travel never changes the optimum. Complexity is O(k·n²) = 8M ops; using transposed travel columns with `map`/`operator.add` keeps it fast in Python.

Verified against both examples:
- Example 1: dp after day 0 = [2,3] → 3 ✓
- Example 2: dp after day 0 = [3,4,4], after day 1 = [7,6,8] → 8 ✓

```python
from typing import List
from operator import add

class Solution:
    def maxScore(self, n: int, k: int, stayScore: List[List[int]], travelScore: List[List[int]]) -> int:
        # cols[dest][c] == travelScore[c][dest]
        cols = list(zip(*travelScore))
        dp = [0] * n  # dp[c]: best points achievable being in city c at start of current day
        for day in range(k):
            stay = stayScore[day]
            # Option 1: stay in the current city
            ndp = list(map(add, dp, stay))
            # Option 2: travel from some city c to dest (done before this day's points... points earned on arrival day)
            for dest in range(n):
                best = max(map(add, dp, cols[dest]))
                if best > ndp[dest]:
                    ndp[dest] = best
            dp = ndp
        return max(dp)
```
