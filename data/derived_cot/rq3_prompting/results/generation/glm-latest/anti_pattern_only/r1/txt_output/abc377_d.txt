    input_data = sys.stdin.buffer.read().split()
    n = int(input_data[0])
    m = int(input_data[1])

Looking at this problem:

- A pair (l, r) is "bad" if there exists i with l ≤ L_i and R_i ≤ r (i.e., [l,r] contains [L_i,R_i]).
- For a fixed l, define g(l) = min{R_i : L_i ≥ l}. Then (l, r) is bad exactly when r ≥ g(l) (if any such i exists). So the valid r values for this l are r ∈ [l, g(l)−1], giving max(0, g(l) − l) pairs. If no interval has L_i ≥ l, treat g(l) = M+1, giving M − l + 1 pairs (which the same formula handles).
- g(l) is a suffix minimum over L values, computable in O(N + M).
