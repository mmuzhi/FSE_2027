You will be given a competitive programming problem.
For a binary string B = B_1 B_2 \dots B_{3^n} of length 3^n (n \geq 1), we define an operation to obtain a binary string C = C_1 C_2 \dots C_{3^{n-1}} of length 3^{n-1} as follows:

- Partition the elements of B into groups of 3 and take the majority value from each group. That is, for i=1,2,\dots,3^{n-1}, let C_i be the value that appears most frequently among B_{3i-2}, B_{3i-1}, and B_{3i}.

You are given a binary string A = A_1 A_2 \dots A_{3^N} of length 3^N. Let A' = A'_1 be the length-1 string obtained by applying the above operation N times to A.
Determine the minimum number of elements of A that must be changed (from 0 to 1 or from 1 to 0) in order to change the value of A'_1.

Input

The input is given from Standard Input in the following format:
N
A_1 A_2 \dots A_{3^N}

Output

Print the answer.

Constraints


- N is an integer with 1 \leq N \leq 13.
- A is a string of length 3^N consisting of 0 and 1.

Sample Output 1

1

=== ANSWER ===
Looking at this problem:

- Build the ternary majority tree bottom-up. For each node, compute its value (majority of 3 children) and `f` = minimum leaf changes needed to flip that node's value.
- Base: a leaf needs 1 change.
- If the 3 child values are all equal `v`: we must flip at least two children → cost = sum of the two smallest child `f` values.
- If they are `(v, v, 1-v)`: flipping one majority-valued child suffices (flipping the minority child or minority+majority doesn't work) → cost = min `f` over children whose value equals the majority.

This is exact: any set of leaf changes partitions per child (each child's value either flips, costing ≥ its `f`, or not), and the root value depends only on the three child values. Verified against both samples (answers 1 and 2) and several hand-checked cases (e.g., all-equal string of length 3^N gives 2^N).

Total work is O(3^N) ≈ 2.4M node evaluations for N=13, done iteratively level by level (first level special-cased since all leaf costs are 1).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    b = data[1]

    # First reduction (leaves cost 1 each to flip)
    tbl = bytes.maketrans(b'01', b'\x00\x01')
    c = b.translate(tbl)
    sums = [x + y + z for x, y, z in zip(c[0::3], c[1::3], c[2::3])]
    vals = [s >> 1 for s in sums]                # majority bit of each triple
    f = [1 if 0 < s < 3 else 2 for s in sums]    # min flips to invert that triple's output

    for _ in range(n - 1):
        nv = []
        nf = []
        app_v = nv.append
        app_f = nf.append
        for v0, v1, v2, f0, f1, f2 in zip(vals[::3], vals[1::3], vals[2::3],
                                           f[::3], f[1::3], f[2::3]):
            s = v0 + v1 + v2
            if s == 1:
                # exactly one 1 -> majority 0: cheapest among the two 0-children
                if v0:
                    r = f1 if f1 < f2 else f2
                elif v1:
                    r = f0 if f0 < f2 else f2
                else:
                    r = f0 if f0 < f1 else f1
                app_v(0)
            elif s == 2:
                # exactly two 1s -> majority 1: cheapest among the two 1-children
                if v0:
                    if v1:
                        r = f0 if f0 < f1 else f1
                    else:
                        r = f0 if f0 < f2 else f2
                else:
                    r = f1 if f1 < f2 else f2
                app_v(1)
            else:
                # all three equal: must flip two children -> two smallest costs
                if f0 < f1:
                    r = f0 + f1 if f1 < f2 else f0 + f2
                else:
                    r = f1 + f0 if f0 < f2 else f1 + f2
                app_v(v0)
            app_f(r)
        vals = nv
        f = nf

    print(f[0])

main()
```
