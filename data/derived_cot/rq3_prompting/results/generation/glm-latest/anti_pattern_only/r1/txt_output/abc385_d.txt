You will be given a competitive programming problem.
There are N houses at points (X_1,Y_1),\ldots,(X_N,Y_N) on a two-dimensional plane.
Initially, Santa Claus is at point (S_x,S_y). He will act according to the sequence (D_1,C_1),\ldots,(D_M,C_M) as follows:

- For i=1,2,\ldots,M in order, he moves as follows:
- Let (x,y) be the point where he currently is.
- If D_i is U, move in a straight line from (x,y) to (x,y+C_i).
- If D_i is D, move in a straight line from (x,y) to (x,y-C_i).
- If D_i is L, move in a straight line from (x,y) to (x-C_i,y).
- If D_i is R, move in a straight line from (x,y) to (x+C_i,y).





Find the point where he is after completing all actions, and the number of distinct houses he passed through or arrived at during his actions. If the same house is passed multiple times, it is only counted once.

N M S_x S_y

D_1 C_1
\vdots
D_M C_M

Output

Let (X,Y) be the point where he is after completing all actions, and C be the number of distinct houses passed through or arrived at. Print X,Y,C in this order separated by spaces.

Constraints


- 1 \leq N \leq 2\times 10^5
- 1 \leq M \leq 2\times 10^5
- -10^9 \leq X_i,Y_i \leq 10^9
- The pairs (X_i,Y_i) are distinct.
- -10^9 \leq S_x,S_y \leq 10^9
- There is no house at (S_x,S_y).
- Each D_i is one of U, D, L, R.
- 1 \leq C_i \leq 10^9
- All input numbers are integers.

def sweep(intervals, points):

def main():

from collections import defaultdict

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); M = int(data[1])
    x = int(data[2]); y = int(data[3])

    SHIFT = 20
    MASK = (1 << SHIFT) - 1

    base = 4
    end = base + 2 * N
    hxs = list(map(int, data[base:end:2]))
    hys = list(map(int, data[base + 1:end:2]))
    base = end

    houses_by_x = defaultdict(list)  # column -> encoded (y << SHIFT) | house idx
    houses_by_y = defaultdict(list)  # row -> encoded (x << SHIFT) | house idx
    for i in range(N):
        xi = hxs[i]; yi = hys[i]
        houses_by_x[xi].append((yi << SHIFT) | i)
        houses_by_y[yi].append((xi << SHIFT) | i)

    vert = defaultdict(list)  # column -> [(ylo, yhi)]
    horz = defaultdict(list)  # row -> [(xlo, xhi)]

    mtoks = data[base:]
    Ds = mtoks[0::2]
    Cs = map(int, mtoks[1::2])
    for D, C in zip(Ds, Cs):
        if D == b'U':
            ny = y + C
            vert[x].append((y, ny))
            y = ny
        elif D == b'D':
            ny = y - C
            vert[x].append((ny, y))
            y = ny
        elif D == b'L':
            nx = x - C
            horz[y].append((nx, x))
            x = nx
        else:  # b'R'
            nx = x + C
            horz[y].append((x, nx))
            x = nx

    covered = bytearray(N)
    NEG = -(1 << 62)

    def check(point_groups, interval_groups):
        get_ivs = interval_groups.get
        for key, pts in point_groups.items():
            ivs = get_ivs(key)
            if not ivs:
                continue
            ivs.sort()
            pts.sort()

            niv = len(ivs)
            max_b = NEG

                p = code >> SHIFT
                while j < niv and ivs[j][0] <= p:
                    b = ivs[j][1]
                    if b > max_b:
                        max_b = b
                    j += 1
                if max_b >= p:

    check(houses_by_x, vert)
    check(houses_by_y, horz)

    print(x, y, sum(covered))

Looking at this problem:

- Each move is an axis-aligned segment. A house (x,y) is visited iff it lies on some vertical segment at column x (y within the segment's y-range) or some horizontal segment at row y (x within the segment's x-range).
- So I collect, per column, all vertical intervals; per row, all horizontal intervals. Then for each house, check whether it's stabbed by any interval on its column or row. This is a classic "point covered by any interval" query, solved per line by sorting intervals by start, computing prefix-max of ends, and binary searching each query point: point p is covered iff max end among intervals with start ≤ p is ≥ p.
- Each house is checked once for vertical and once for horizontal coverage, with a `covered` flag to dedupe. Final position is just tracked by simulating coordinates (Python handles big ints).
- Complexity: O((N+M) log(N+M)).

Verified against both samples (sample 1: intervals horz[2]=[(1,3)], horz[1]=[(1,2)], vert[2]=[(1,3)] cover houses (2,2) and (2,1), giving "2 3 2"; sample 2 gives "3000000000 0 0").

Points are packed as `(coord << 20) | index` (valid since N ≤ 2×10⁵ < 2²⁰, and Python's arithmetic shift handles negatives correctly) for fast sorting.
