from math import comb
import numpy as np

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); K = int(data[1])
    MOD = 998244353
    A = np.fromiter(map(int, data[2:2+N]), dtype=np.int64, count=N)
    
    # Prefix sums S[0..N] mod MOD
    S = np.empty(N+1, dtype=np.int64)
    S[0] = 0
    if N > 0:
        np.cumsum(A, out=S[1:])
    S[1:] %= MOD
    
    # Power arrays P[t] = S^t mod MOD, t = 0..K
    P = [np.ones(N+1, dtype=np.int64)]

        s = int(prod.sum()) % MOD
        if t & 1:
            ans = (ans - c * s) % MOD
        else:
            ans = (ans + c * s) % MOD
    
    print(ans % MOD)

main()

from operator import mul

Looking at this problem:

- Let $S_0=0, S_i = A_1+\dots+A_i \bmod p$. The subarray sum for $[l,r]$ is $S_r - S_{l-1}$, so we need $\sum_{0\le j<r\le N}(S_r-S_j)^K$.
- Binomial expansion: $(S_r-S_j)^K=\sum_{t=0}^K\binom{K}{t}(-1)^t S_r^{K-t}S_j^t$, so the answer is $\sum_t \binom{K}{t}(-1)^t\sum_{r=1}^N S_r^{K-t}\Big(\sum_{j=0}^{r-1}S_j^t\Big)$.
- Precompute power arrays $P_t[i]=S_i^t$ ($O(NK)$ multiplications), then for each $t$ compute a prefix-sum array of $P_t$ and a dot product with $P_{K-t}$ — all $O(NK)$ total, which is fast enough using `accumulate`/`map`/list comprehensions in CPython.

I verified this by hand on sample 1 ($S=[0,3,4,6]$, terms $149-108+34=75$) and small cases with $K=1,2,3$ against brute force.

    K = int(data[1])
