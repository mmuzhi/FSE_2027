Constraints


- 2 \leq N \leq 2 \times 10^5
- 1 \leq A_i, B_i \leq 10^9
- All input values are integers.

4
5 2 3 7
6 2 8

Sample Output 1

3

Looking at this problem:

- Sort toys `a` ascending and boxes `b` ascending. For a fixed multiset of boxes, a perfect matching exists **iff** the i-th smallest toy fits in the i-th smallest box (`a_i ≤ c_i` for all i) — standard exchange argument (if `a_i > c_i`, the `N-i+1` toys of size ≥ `a_i` can't fit in the `i` smallest boxes, leaving only `N-i` larger boxes).

- If the new box `x` lands at sorted position `k` (requires `b_{k-1} ≤ x ≤ b_k`, with `b_0 = 0`, `b_N = ∞`), then `c_i = b_i` for `i < k`, `c_k = x`, `c_i = b_{i-1}` for `i > k`. Feasibility becomes:
  - prefix: `a_i ≤ b_i` for all `i < k`
  - `a_k ≤ x`
  - suffix: `a_i ≤ b_{i-1}` for all `i > k`

- For each position `k` satisfying prefix & suffix conditions, the minimal candidate is `x = max(a_k, b_{k-1})` (the `x ≤ b_k` bound is automatically implied by `a_k ≤ a_{k+1} ≤ b_k`, but checked anyway). Answer is the minimum over all valid `k`, else -1.
