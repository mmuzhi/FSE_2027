=== ANSWER ===
Looking at this problem:

- Each button press appends either a single digit (buttons 0–9) or two zeros (button "00").
- We need to partition S into blocks of size 1 (any digit) or size 2 (must be "00"), minimizing the number of blocks — equivalently, maximizing the number of "00" blocks.
- "00" blocks can only exist inside maximal runs of zeros, and a run of length m can contain at most ⌊m/2⌋ disjoint pairs. A left-to-right greedy that takes "00" whenever two zeros appear at the current position achieves this maximum, and runs are independent of each other (a pair can't span a nonzero digit).

Verification with samples:
- "1000000007": 8 zeros → 4 pairs → 10 − 4 = 6 ✓
- "998244353": no zeros → 9 presses ✓
- "32000": run of 3 zeros → 1 pair → 5 − 1 = 4 ✓

So a simple greedy scan gives the answer.

```python
S = input().strip()
n = len(S)
i = 0
count = 0
while i < n:
    if i + 1 < n and S[i] == '0' and S[i + 1] == '0':
        i += 2
    else:
        i += 1
    count += 1
print(count)
```
