```python
class Solution:
    def numberOfWays(self, n: int, x: int, y: int) -> int:
        MOD = 10**9 + 7
        m = min(n, x)
        # Stirling numbers of second kind S(n, k) for k in 0..m
        # DP over performers
        # dp[j] = S(i, j)
        dp = [0] * (m + 1)
        dp[0] = 1
        for i in range(1, n + 1):
            ndp = [0] * (m + 1)
            for j in range(1, m + 1):
                ndp[j] = (j * dp[j] + dp[j - 1]) % MOD
            dp = ndp
        # Precompute factorials, C(x, k), y^k
        ans = 0
        yk = 1
        # k! * C(x,k) = x! / (x-k)! = falling factorial
        ff = 1  # falling factorial x*(x-1)*...*(x-k+1)
        for k in range(1, m + 1):
            yk = yk * y % MOD
            ff = ff * (x - k + 1) % MOD
            ans = (ans + ff * dp[k] % MOD * yk) % MOD
        return ans
```

Looking at this problem:

- Total ways = sum over k (number of non-empty stages) of [choose which k stages are used] × [assign n performers onto those k stages surjectively] × [give each of the k bands a score in [1,y]].
- That is: sum_{k=1}^{min(n,x)} C(x,k) · S(n,k) · k! · y^k, where S(n,k) is the Stirling number of the second kind. Note C(x,k)·k! is the falling factorial x·(x-1)···(x-k+1).

Verification with example 3 (n=3, x=3, y=4): k=1: 3·1·4=12; k=2: 6·3·16=288; k=3: 6·1·64=384; total 684 ✓. Example 2 (n=5,x=2,y=1): 2·1·1 + 1·30·1 = 32 ✓. Example 1: 2·1·3 = 6 ✓.
