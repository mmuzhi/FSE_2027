=== ANSWER ===
Looking at this problem:

- We need the minimal connected subtree (Steiner tree on a tree) spanning the K marked vertices.
- Key insight: root the tree at one of the marked vertices (say V_1). Then the minimal subtree consists exactly of all vertices whose subtree contains at least one marked vertex (since every included vertex lies on a path from the marked root to some marked vertex, and conversely any vertex with a marked vertex below it is on such a path).
- So: do a DFS from V_1, compute bottom-up which vertices have a marked vertex in their subtree, and count them.

Verification with samples:
- Sample 1: root=1, vertices with marked descendants: 1, 2, 3, 5 → 4 ✓
- Sample 2: all 4 vertices → 4 ✓
- Sample 3: only vertex 1 → 1 ✓

Implementation uses iterative DFS (avoiding recursion limits for N up to 2×10⁵), processing vertices in reverse pop-order so children are handled before parents.

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(data[idx]); idx += 1
    k = int(data[idx]); idx += 1
    adj = [[] for _ in range(n + 1)]
    for _ in range(n - 1):
        a = int(data[idx]); idx += 1
        b = int(data[idx]); idx += 1
        adj[a].append(b)
        adj[b].append(a)
    marked = [False] * (n + 1)
    for _ in range(k):
        v = int(data[idx]); idx += 1
        marked[v] = True

    # find a marked vertex to serve as root
    root = 1
    for v in range(1, n + 1):
        if marked[v]:
            root = v
            break

    # iterative DFS to get order (children appear after parents in order)
    parent = [0] * (n + 1)
    order = []
    visited = [False] * (n + 1)
    stack = [root]
    visited[root] = True
    while stack:
        u = stack.pop()
        order.append(u)
        for w in adj[u]:
            if not visited[w]:
                visited[w] = True
                parent[w] = u
                stack.append(w)

    # process in reverse order (children before parents)
    has_marked = [False] * (n + 1)
    count = 0
    for u in reversed(order):
        if marked[u]:
            has_marked[u] = True
        if has_marked[u]:
            count += 1
            if parent[u] != 0:
                has_marked[parent[u]] = True

    print(count)

main()
