=== ANSWER ===
Looking at this problem:

- For each query, given type `t` (with parameters `q, r`) and day `d`, I need the smallest day `D >= d` such that `D mod q == r`.
- Key insight: `d + ((r - d) mod q)` gives exactly that. Since `(r - d) mod q` is in `[0, q)`, the result `D` satisfies `d <= D < d + q` and `D ≡ r (mod q)`. Any smaller day `>= d` congruent to `r` mod `q` would differ from `D` by a nonzero multiple of `q` less than `q` in absolute value — impossible, so `D` is minimal.

Verification against samples:
- q=7, r=3, d=1 → 1 + (2 mod 7) = 3 ✓
- q=7, r=3, d=3 → 3 + 0 = 3 ✓
- q=7, r=3, d=4 → 4 + ((3-4) mod 7) = 4 + 6 = 10 ✓
- q=7, r=3, d=15 → 15 + 2 = 17 ✓
- q=4, r=2, d=7 → 7 + ((2-7) mod 4) = 7 + 3 = 10 ✓

All match. Python handles large integers natively so no overflow concerns.
