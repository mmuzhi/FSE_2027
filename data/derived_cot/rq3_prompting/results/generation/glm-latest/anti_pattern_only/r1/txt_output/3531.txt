class Solution:
    def minDamage(self, power: int, damage: List[int], health: List[int]) -> int:
        M = 10 ** 8
        items = []
        for h, d in zip(health, damage):

=== ANSWER ===
Looking at this problem:

- Enemy i needs `t_i = ceil(health[i] / power)` seconds of attacks to die, and deals `damage[i]` per second while alive.
- If enemies are killed in some order, enemy killed k-th deals damage for `T_k = t_{π(1)} + ... + t_{π(k)}` seconds, so total damage = `Σ damage[π(k)] * T_k`.
- This is the classic weighted completion time scheduling problem. Exchange argument on adjacent pair (i, j): putting i first is better iff `t_i * d_j <= t_j * d_i`, i.e., sort by `t_i / d_i` ascending.

Verification with Example 1: power=4, t=[1,2,2,2], sorted by t/d: enemy3, enemy2, enemy0/1 → total = 4·2 + 3·4 + 1·5 + 2·7 = 39 ✓. Examples 2 and 3 also check out (20 and 320).

To avoid floating point issues, I use an integer sort key `t * 10^8 // d`: distinct ratios `t1/d1 ≠ t2/d2` (with d ≤ 10^4) differ by at least `1/(d1·d2) ≥ 10^-8`, so scaled values differ by ≥ 1, and floors preserve strict order (equal rationals give equal keys).

from typing import List

class Solution:
    def minDamage(self, power: int, damage: List[int], health: List[int]) -> int:
        M = 10 ** 8
        items = []
        for h, d in zip(health, damage):
            t = (h + power - 1) // power  # seconds needed to kill this enemy
            items.append((t * M // d, t, d))
        items.sort()
        
        total = 0
        elapsed = 0
        for _, t, d in items:
            elapsed += t
            total += d * elapsed
        return total
