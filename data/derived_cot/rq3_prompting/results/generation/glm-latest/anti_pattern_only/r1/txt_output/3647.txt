Return the maximum number of elements that can be removed from queries, such that nums can still be converted to a zero array using the remaining queries. If it is not possible to convert nums to a zero array, return -1.

Example 3:

Input: nums = [1,2,3,4], queries = [[0,3]]
Output: -1
Explanation:
nums cannot be converted to a zero array even after using all the queries.

Looking at this problem:

1. **Feasibility**: A set of queries can zero out `nums` iff for every index `i`, the number of chosen queries covering `i` is ≥ `nums[i]` (each query contributes at most 1 decrement per index, independently).

2. **Goal**: Keep the *minimum* number of queries satisfying coverage ≥ `nums[i]` everywhere; answer = total − kept, or −1 if even all queries fail.

3. **Greedy (proven optimal for interval covering with demands)**: Sort queries by left endpoint. Sweep positions left→right with a max-heap (by right endpoint) of available unused queries. Maintain current active coverage via a difference array for expirations. Whenever coverage at `i` falls short of `nums[i]`, pop the available query with the largest `r` (best future reach) and use it. If none available covers `i`, total coverage is insufficient → return −1.

Key insight for optimality: at the first deficit position, all earlier positions have zero effective residual demand, so exchanging an optimal solution's covering queries for the greedy's max-`r` picks never breaks feasibility for past positions, and dominates for future ones (batch induction on residual problems).

Verified against all three examples (outputs 1, 2, −1 respectively).

```python
import heapq
from typing import List

class Solution:
    def maxRemoval(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        m = len(queries)
        queries.sort(key=lambda q: q[0])
        
        heap = []          # max-heap of right endpoints (stored negated)
        diff = [0] * (n + 1)  # expiration markers for used queries
        cur = 0            # active coverage at current index
        used = 0
        qi = 0
        
        for i in range(n):
            cur += diff[i]
            # add all queries starting at or before i
            while qi < m and queries[qi][0] <= i:
                heapq.heappush(heap, -queries[qi][1])
                qi += 1
            
            need = nums[i]
            while cur < need:
                if not heap:
                    return -1
                r = -heap[0]
                if r < i:
                    # best available query doesn't cover i -> impossible overall
                    return -1
                heapq.heappop(heap)
                cur += 1
                diff[r + 1] -= 1
                used += 1
        
        return m - used
```
