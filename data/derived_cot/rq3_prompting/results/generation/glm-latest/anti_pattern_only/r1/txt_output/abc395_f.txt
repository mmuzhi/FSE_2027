Looking at this problem:

- Final lengths satisfy $u_i + d_i = H$, so cost $= \sum(U_i+D_i) - N\cdot H$ — depends only on $H$. Thus we want the **maximum feasible** $H$.
- For fixed $H$: $u_i \in [L_i, R_i]$ where $L_i=\max(0, H-D_i)$, $R_i=\min(U_i, H)$, plus $|u_i - u_{i+1}|\le X$.
- Propagating reachable intervals, feasibility $\iff$ for every $i$: $\max_{j\le i}(L_j+jX) - \min_{j\le i}(R_j-jX) \le 2iX$, which is equivalent to the **pair condition**: for all $j,k$: $L_j - R_k \le |j-k|X$.
- Case analysis on $H$ shows pair $(j,k)$ holds $\iff H \le D_j + U_k + |j-k|X$ (for $H \le \max(U_k,D_j)$ the left side is $\le 0$; otherwise it's $H-D_j-U_k$).

Therefore $H^* = \min_{j,k}(D_j + U_k + |j-k|X)$, computable in $O(N)$ with a two-pass distance transform: $f(k)=\min_j(D_j+|j-k|X)$ via forward/backward sweeps, then $H^*=\min_k(U_k+f(k))$. Answer $= \sum(U_i+D_i) - N\cdot H^*$.
