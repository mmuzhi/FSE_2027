=== ANSWER ===
Looking at this problem:

- The rows of the vertical writing are the strings in **reverse order** (S_N on top, S_1 at the bottom), since the (N-i+1)-th character of T_j corresponds to S_i.
- T_j is the j-th column: for each string (in reversed order), take its j-th character, or `*` if the string is too short.
- Trailing `*` must be stripped so no T_j ends with `*`. Since M is the max length, each column j < M contains at least one real letter, so stripping never produces an empty string.

Verification with Sample 1: rows = ["fghi", "de", "abc"]. Columns: "fda", "geb", "h*c", "i**" → strip → "i". Matches expected output.

Verification with Sample 2: rows = ["contest", "beginner", "atcoder"]. Columns: "cba", "oet", "ngc", "tio", "end", "sne", "ter", "*r*" → strip → "*r". Matches expected output.

Using `zip_longest` with `fillvalue='*'` builds the columns directly.
