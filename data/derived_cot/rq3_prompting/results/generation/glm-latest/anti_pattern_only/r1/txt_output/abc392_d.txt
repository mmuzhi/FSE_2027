You will be given a competitive programming problem.
There are N dice.
The i-th die has K_i faces, with the numbers A_{i,1}, A_{i,2}, \ldots, A_{i,K_i} written on them.
When you roll this die, each face appears with probability \frac{1}{K_i}.
You choose two dice from the N dice and roll them.
Determine the maximum probability that the two dice show the same number, when the dice are chosen optimally.

Input

The input is given from Standard Input in the following format:
N
K_1 A_{1,1} A_{1,2} \dots A_{1,K_1}
\vdots
K_N A_{N,1} A_{N,2} \dots A_{N,K_N}

Output

Print the answer.
Your answer is considered correct if the absolute or relative error from the true solution does not exceed 10^{-8}.

Constraints


- 2 \leq N \leq 100
- 1 \leq K_i
- K_1 + K_2 + \dots + K_N \leq 10^5
- 1 \leq A_{i,j} \leq 10^5
- All input values are integers.

Sample Input 1

3
3 1 2 3
4 1 2 2 1
6 1 2 3 4 5 6

Sample Output 1

0.333333333333333

Looking at this problem:

- For dice i and j, P(same) = Σ_v c_i(v)·c_j(v) / (K_i·K_j), where c_i(v) counts faces of die i showing value v.
- With N ≤ 100 and total faces ≤ 10^5, checking all ~4950 pairs is feasible. For each pair, I precompute sorted unique values + counts per die (via `np.unique`), then use `np.searchsorted` of the smaller value list into the larger to find common values, and take the dot product of matching counts (exact in int64 since sums ≤ 2.5×10^9).

Worst case work is about Σ over pairs of min(d_i,d_j)·log ≈ 5×10^6·log element operations in C — fast. A pure-Python fallback (set intersection + `map`-based product sum) is included in case numpy is unavailable.

Verified against both samples (1/3 and 2/3 respectively).

```python
import sys


def solve_np(np, n, Ks, faces):
    vals = []
    cnts = []
    for i in range(n):
        arr = np.array(faces[i], dtype=np.int64)
        v, c = np.unique(arr, return_counts=True)
        vals.append(v)
        cnts.append(c.astype(np.int64))
    best = 0.0
    for i in range(n):
        vi = vals[i]
        ci = cnts[i]
        dlen = len(vi)
        ki = Ks[i]
        for j in range(i + 1, n):
            vj = vals[j]
            cj = cnts[j]
            if dlen <= len(vj):
                qv, qc, tv, tc = vi, ci, vj, cj
            else:
                qv, qc, tv, tc = vj, cj, vi, ci
            pos = np.searchsorted(tv, qv)
            pos = np.minimum(pos, len(tv) - 1)
            match = tv[pos] == qv
            if match.any():
                s = int(np.dot(qc[match], tc[pos[match]]))
                prob = s / (ki * Ks[j])
                if prob > best:
                    best = prob
    return best


def solve_py(n, Ks, faces):
    from collections import Counter
    from operator import mul
    best = 0.0
    dicts = [Counter(f) for f in faces]
    keysets = [set(d) for d in dicts]
    for i in range(n):
        di = dicts[i]
        ksi = Ks[i]
        si = keysets[i]
        for j in range(i + 1, n):
            common = si & keysets[j]
            if common:
                dj = dicts[j]
                s = sum(map(mul,
                            map(di.__getitem__, common),
                            map(dj.__getitem__, common)))
                prob = s / (ksi * Ks[j])
                if prob > best:
                    best = prob
    return best


def main():
    data = sys.stdin.buffer.read().split()
    nums = list(map(int, data))
    ptr = 0
    n = nums[ptr]; ptr += 1
    Ks = []
    faces = []
    for _ in range(n):
        k = nums[ptr]; ptr += 1
        Ks.append(k)
        faces.append(nums[ptr:ptr + k])
        ptr += k

    best = None
    try:
        import numpy as np
        best = solve_np(np, n, Ks, faces)
    except Exception:
        best = None
    if best is None:
        best = solve_py(n, Ks, faces)

    print("%.15f" % best)


main()
```
