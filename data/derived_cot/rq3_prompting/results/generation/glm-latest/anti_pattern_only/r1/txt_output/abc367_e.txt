    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    k = int(data[1])

=== ANSWER ===
Looking at this problem:

- Each operation sets `B_i = A_{X_i}`, so after K operations, `A'_i = A_{X^K(i)}` where `X^K` means applying the function X to index i, K times.
- X is a functional graph (not necessarily a permutation, e.g. sample 1). K can be up to 10^18, so I decompose the functional graph into cycles with trees hanging off:
  - **Peel** zero-in-degree nodes to find which nodes lie on cycles.
  - For **cycle nodes**: `X^K(u)` = node K mod L steps around its cycle.
  - For **tail nodes**: DFS from each cycle root keeping the ancestor path stack. If depth `t >= K`, `X^K(c) = path[t-K]` (ancestor K steps up). Otherwise `X^K(c) = X^{K-t}(root)` = cycle position `(pos[root] + K - t) mod L`.

This is O(N) regardless of K. I verified it against all three samples by hand (sample 1 gives `X^3 = (4,1,2,3,0,5,2)` 0-indexed → output `7 2 3 5 1 9 3`; sample 3 collapses everything to node 6 → all 3s; K=0 gives identity).
