Implementation:

```python
class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        order = []
        for i, row in enumerate(grid):
            if i % 2 == 0:
                order.extend(row)
            else:
                order.extend(reversed(row))
        return order[::2]
```

This is O(m*n) time and space, which is trivially fine for the constraints (50x50 max).
