import sys

def main():
    data = sys.stdin.buffer.read().split()
    S = data[0].decode()
    Q = int(data[1])
    Ks = data[2:2+Q]
    n = len(S)
    out = []
    for kb in Ks:
        K = int(kb) - 1
        i = K // n
        r = K % n
        c = S[r]
        if bin(i).count('1') & 1:
            c = c.swapcase()
        out.append(c)
    print(' '.join(out))

Looking at this problem:

**Key insight:** After the doubling operation, the infinite final string has a block structure. If we split it into blocks of size `n = len(S)`, then block index `i` (0-based) equals `S` flipped if and only if the number of set bits (popcount) of `i` is odd.

**Why:** By induction — `S_{j+1} = S_j + flip(S_j)`. The first half keeps block indices 0..2^j-1 with the same popcount parity. The second half's block `2^j + t` is a flipped copy of block `t`, and `popcount(2^j + t) = popcount(t) + 1` (since `t < 2^j`), so the parity rule carries over.

So for query `K` (1-indexed), let `K-1 = i*n + r`. The answer is `S[r]`, case-flipped iff `popcount(i)` is odd. This is verified against all three samples (e.g., sample 3's `K = 10^18` gives `i = 19230769230769230`, whose popcount is odd, flipping `k` to `K`).

Each query is answered in O(1) big-int operations plus a popcount of a ~60-bit number.
