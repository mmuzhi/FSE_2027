=== ANSWER ===
Looking at this problem:

- Let `pre` be prefix sums, and define `dp[j][i]` = max sum of `j` non-overlapping subarrays (each length ≥ m) within the first `i` elements.
- Transition: `dp[j][i] = max(dp[j][i-1], max_{s ≤ i-m} (dp[j-1][s] + pre[i] - pre[s]))`.
- The inner max over `s` is a running maximum of `dp[j-1][s] - pre[s]`, making the whole DP O(n·k).

Concretely, for each level `j`: compute `h[s] = dp[j-1][s] - pre[s]`, take its prefix max `pm`, then `f[i] = pre[i] + pm[i-m]` (last subarray ends at `i`), and `dp[j][i]` is the prefix max of `f`. Using `itertools.accumulate` keeps it fast in Python.

I verified this against both examples (13 and -10) and edge cases like all-negative arrays and `nums=[1,-1,1], k=2, m=1` (answer 2).

```python
from itertools import accumulate
from typing import List

class Solution:
    def maxSum(self, nums: List[int], k: int, m: int) -> int:
        n = len(nums)
        pre = [0] * (n + 1)
        acc = 0
        for i, x in enumerate(nums):
            acc += x
            pre[i + 1] = acc

        NEG = float('-inf')
        # dp[0][i] = 0 for all i
        prev = [0] * (n + 1)
        for _ in range(k):
            # h[s] = dp[j-1][s] - pre[s]
            h = [a - b for a, b in zip(prev, pre)]
            # pm[t] = max(h[0..t]) : best start point s <= i-m handled via pm[i-m]
            pm = list(accumulate(h, max))
            # f[i] = best value where the j-th subarray ends exactly at position i
            f = [NEG] * m + [pre[i] + pm[i - m] for i in range(m, n + 1)]
            # dp[j][i] = max(f[0..i])
            prev = list(accumulate(f, max))
        return prev[n]
```
