There are N buildings, Building 1, Building 2, \ldots, Building N, arranged in a line in this order. The height of Building i (1 \leq i \leq N) is H_i.
For each i = 1, 2, \ldots, N, find the number of integers j (i < j \leq N) satisfying the following condition:

- 1 \leq H_i \leq N

Looking at this problem:

For a fixed j, the set of i < j that count j is exactly: all i with `p_j ≤ i ≤ j-1`, where `p_j` is the position of the previous (nearest to the left) building strictly taller than H_j (or 0 if none exists). This is because:
- If i < p_j, building p_j lies strictly between i and j and is taller than H_j → fails.
- If i ≥ p_j, everything strictly between p_j and j is shorter than H_j, so everything strictly between i and j is also shorter than H_j → holds.

So `c_i` = number of j > i with `p_j ≤ i`. Each j contributes +1 to the range of indices `[p_j, j-1]`, which can be handled with a difference array. Then `c_i` is the prefix sum of the difference array up to index i.

The previous-greater-element positions are computed with a standard monotonic stack in O(N).

Verified against all three samples (e.g., sample 1: p = [0,1,0,3,0], giving ranges that produce counts 3 2 2 1 0; sample 3 also matches exactly).

```python
import sys
from itertools import accumulate

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    h = list(map(int, data[1:1 + n]))

    diff = [0] * (n + 2)
    st_h = []   # heights on stack (strictly decreasing)
    st_p = []   # their 1-indexed positions

    for jj in range(n):
        hj = h[jj]
        while st_h and st_h[-1] < hj:
            st_h.pop()
            st_p.pop()
        p = st_p[-1] if st_p else 0   # previous greater position (0 if none)
        diff[p] += 1                  # j contributes to i in [p, j-1]
        diff[jj + 1] -= 1
        st_h.append(hj)
        st_p.append(jj + 1)

    res = list(accumulate(diff))      # res[i] = sum(diff[0..i]) = c_i
    print(' '.join(map(str, res[1:n + 1])))

main()
```
