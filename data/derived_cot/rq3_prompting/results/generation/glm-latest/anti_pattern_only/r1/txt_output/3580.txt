    def minStartingIndex(self, s: str, pattern: str) -> int:
        def z_func(t):
            n = len(t)
            z = [0] * n
            l, r = 0, 0
            for i in range(1, n):
                if i < r:
                    z[i] = r - i
                    if z[i - l] < z[i]:

    def minStartingIndex(self, s: str, pattern: str) -> int:
        def z_func(t):
            n = len(t)

Looking at this problem: for each starting index `i`, I need the substring `s[i..i+m-1]` to differ from `pattern` in at most 1 position. 

Key insight: let `a` = longest common **prefix** of `pattern` and `s[i:]`, and `b` = longest common **suffix** of `pattern` and `s[..i+m-1]`. There is at most one mismatch iff `a + b >= m - 1` (if `a < m`, the mismatch is at position `a`, and `b >= m-1-a` guarantees everything after position `a` matches; if `a == m` it's an exact match).

I compute `a` for all `i` via the Z-function on `pattern + '#' + s`, and `b` via the Z-function on `reversed(pattern) + '#' + reversed(s)` (a common suffix becomes a common prefix after reversal; position of end index `j = i+m-1` in reversed `s` is `n-1-j`, so the Z-index is `n-i+1`).

Verified against all four examples (e.g., example 2: at i=4, a=2, b=3, 2+3≥5 → return 4; example 3 correctly gives -1 since no window satisfies the condition).
