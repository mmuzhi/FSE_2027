You will be given a competitive programming problem.
The AtCoder company office is represented as a grid of H rows and W columns. Let (i, j) denote the cell at the i-th row from the top and j-th column from the left.
The state of each cell is represented by a character S_{i,j}. If S_{i,j} is #, that cell has a wall; if S_{i,j} is ., that cell is a floor; if S_{i,j} is H, that cell has a humidifier placed on a floor cell.

Find the number of humidified floor cells.

- 0 \leq D \leq H\times W
- S_{i,j} is #, ., or H. (1 \leq i \leq H, 1 \leq j \leq W)
- All input numbers are integers.

def main():
    data = sys.stdin.buffer.read().split()
    H = int(data[0]); W = int(data[1]); D = int(data[2])

    grid = bytearray(b'#' * ((H + 2) * PW))
    current = []
    for i in range(H):

Looking at this problem:

- It's a **multi-source BFS** problem: start BFS simultaneously from all humidifier ('H') cells with distance 0, expand through non-wall cells, and count all floor cells reached at distance ≤ D.
- Since BFS explores in increasing distance order, every cell visited (before stopping expansion at depth D) is automatically within distance D. Walls never get visited, and H cells count as floor cells (humidifiers sit on floor cells).
- With H, W up to 1000 (10⁶ cells), I use a flat `bytearray` grid padded with a wall border (avoids bounds checks), mark visited cells by turning them into walls, and do level-by-level BFS with an unrolled -direction loop for speed in CPython.

Verification with samples:
- Sample 1: sources (0,0),(1,3); level 1 adds (0,1),(1,2),(0,3) → 5 ✓
- Sample 3: no 'H' cells → 0 ✓
- Sample 2: traced levels 0 (5 cells), 1 (9 cells), 2 (7 cells) → 21 ✓

Edge cases handled: D=0 (only count humidifier cells), no humidifiers (answer 0), walls blocking paths, and large D (BFS exhausts naturally when frontier empties).
