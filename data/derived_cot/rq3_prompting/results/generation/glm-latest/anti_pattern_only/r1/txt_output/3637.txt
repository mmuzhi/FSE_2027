Looking at this problem:

- Total digit sum must be even; let `half = total/2`. There are `even_cnt = (n+1)//2` even indices and `odd_cnt = n//2` odd indices.
- For each digit `d` with count `cnt[d]`, choose `e_d` copies to place at even indices such that `sum(e_d) = even_cnt` and `sum(d*e_d) = half`. Each such assignment contributes `even_cnt!/(∏ e_d!) * odd_cnt!/(∏ (cnt[d]-e_d)!)` distinct permutations, which equals `even_cnt! * odd_cnt! * ∏ C(cnt[d], e_d) / ∏ cnt[d]!`.
- So run a DP over digits with state (number of even slots used, even-index sum), accumulating products of binomials, then multiply by the factorial factor.

```python
            if c == 0:
                continue
            binoms = [fact[c] * inv_fact[k] % MOD * inv_fact[c - k] % MOD
                      for k in range(c + 1)]
            ndp = [[0] * (half + 1) for _ in range(even_cnt + 1)]
            for j in range(even_cnt + 1):
                row = dp[j]
                for s, v in enumerate(row):
                    if not v:
                        continue
                    maxk = even_cnt - j
                    if d:
                        r = (half - s) // d
                        if r < maxk:
                            maxk = r
                    if c < maxk:
                        maxk = c
                    for k in range(maxk + 1):
                        t = ndp[j + k]
                        idx = s + d * k
                        t[idx] = (t[idx] + v * binoms[k]) % MOD
            dp = ndp

        res = dp[even_cnt][half]

        denom = 1
        for d in range(10):
            denom = denom * fact[cnt[d]] % MOD

        res = res * fact[even_cnt] % MOD
        res = res * fact[odd_cnt] % MOD
        res = res * pow(denom, MOD - 2, MOD) % MOD
        return res
```
