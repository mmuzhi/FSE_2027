    def maxFrequency(self, nums: List[int], k: int) -> int:
        total_k = sum(1 for x in nums if x == k)

=== ANSWER ===
Looking at this problem:

- If we pick `x = 0`, the frequency of `k` stays at its original count `total_k`.
- If `x ≠ 0`, then with `v = k - x`, elements equal to `v` inside the chosen window become `k`, while elements equal to `k` inside the window are destroyed (they become `k+x ≠ k`). Resulting frequency = `total_k - (#k in window) + (#v in window)`.

So the answer is `total_k + max(0, max over v≠k of max-subarray-sum of delta)`, where `delta[i] = +1` if `nums[i]==v`, `-1` if `nums[i]==k`, else `0`. Since zeros never help/hurt a window, only the interleaving of `v`-positions (+1) and `k`-positions (-1) matters. Runs of `-1` between consecutive `v` positions can be compressed using a prefix count of `k`, giving Kadane in O(count_v) per value, hence O(n) total.

Verified against both examples: Example 1 → 2, Example 2 → 4 (traced by hand), plus several edge cases (all elements equal k, destroying k's that block v's, etc.).
