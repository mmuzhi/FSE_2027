    def maximizeSumOfWeights(self, edges: List[List[int]], k: int) -> int:
        n = len(edges) + 1
        adj = [[] for _ in range(n)]
        for u, v, w in edges:
            adj[u].append((v, w))
            adj[v].append((u, w))
        
        parent = [-1] * n
        order = []
        visited = [False] * n
        stack = [0]
        visited[0] = True
        while stack:
            u = stack.pop()
            order.append(u)
            for v, w in adj[u]:
                if not visited[v]:
                    visited[v] = True
                    parent[v] = u
                    stack.append(v)
        
        dp0 = [0] * n  # edge to parent not kept -> up to k child edges
        dp1 = [0] * n  # edge to parent kept -> up to k-1 child edges
        
        for u in reversed(order):
            p = parent[u]
            base_sum = 0
            pos = []
            for v, w in adj[u]:
                if v != p:
                    base_sum += dp0[v]
                    g = dp1[v] + w - dp0[v]
                    if g > 0:
                        pos.append(g)
            if len(pos) <= k - 1:
                total = base_sum + sum(pos)
                dp0[u] = total
                dp1[u] = total
            else:
                pos.sort(reverse=True)
                dp1[u] = base_sum + sum(pos[:k - 1])
                dp0[u] = base_sum + sum(pos[:k])
        
        return dp0[0]

Looking at this problem:

- It's a tree DP where we root the tree at node 0.
- For each node `u`, compute:
  - `dp0[u]`: max weight sum in `u`'s subtree if the edge to its parent is **not** kept → `u` can keep at most `k` child edges.
  - `dp1[u]`: max weight sum if the edge to parent **is** kept → at most `k-1` child edges.
- For each child `v` with edge weight `w`, the gain of keeping the edge is `dp1[v] + w - dp0[v]`. Start from the base sum of all `dp0[v]`, then greedily take the largest positive gains up to the budget (`k` for `dp0`, `k-1` for `dp1`).

Verified against both examples (outputs 22 and 65 respectively). An iterative DFS avoids recursion depth issues for n up to 10^5. Total complexity is O(n log n).
