=== ANSWER ===
```python
S = input().strip()
n = len(S)
count = 0
for i in range(n):
    if S[i] != 'A':
        continue
    for j in range(i + 1, n):
        k = 2 * j - i
        if k < n and S[j] == 'B' and S[k] == 'C':
            count += 1
print(count)
```
