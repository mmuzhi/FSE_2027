=== ANSWER ===
```python
from typing import List

class Solution:
    def getFinalState(self, nums: List[int], k: int, multiplier: int) -> List[int]:
        for _ in range(k):
            min_val = min(nums)
            idx = nums.index(min_val)
            nums[idx] *= multiplier
        return nums
```
