=== ANSWER ===
```python
class Solution:
    def reverseDegree(self, s: str) -> int:
        total = 0
        for i, ch in enumerate(s, start=1):
            reverse_index = ord('z') - ord(ch) + 1
            total += i * reverse_index
        return total
```
