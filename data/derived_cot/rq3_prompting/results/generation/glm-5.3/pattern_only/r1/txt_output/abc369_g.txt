You will be given a competitive programming problem.
You are given a tree with N vertices.
The vertices are numbered 1, 2, \ldots, N.
The i-th edge (1\leq i\leq N-1) connects vertices U_i and V_i, with a length of L_i.
For each K=1,2,\ldots, N, solve the following problem.

Takahashi and Aoki play a game. The game proceeds as follows.

- First, Aoki specifies K distinct vertices on the tree.
- Then, Takahashi constructs a walk that starts and ends at vertex 1, and passes through all the vertices specified by Aoki.

The score is defined as the length of the walk constructed by Takahashi. Takahashi wants to minimize the score, while Aoki wants to maximize it.
Find the score when both players play optimally.


Definition of a walk
    A walk on an undirected graph (possibly a tree) is a sequence of k vertices and k-1 edges v_1,e_1,v_2,\ldots,v_{k-1},e_{k-1},v_k (where k is a positive integer)
    such that edge e_i connects vertices v_i and v_{i+1}. The same vertex or edge can appear multiple times in the sequence.  
    A walk is said to pass through vertex x if there exists at least one i (1\leq i\leq k) such that v_i=x. (There can be multiple such i.)  
    The walk is said to start and end at v_1 and v_k, respectively, and the length of the walk is the sum of the lengths of e_1, e_2, \ldots, e_{k-1}.

Input

The input is given from Standard Input in the following format:
N

U_2 V_2 L_2
\vdots
U_{N-1} V_{N-1} L_{N-1}

Output

Print N lines.
The i-th line (1\leq i\leq N) should contain the answer to the problem for K=i.

Constraints


- 2\leq N\leq 2\times 10^5
- 1\leq U_i<V_i\leq N
- 1\leq L_i\leq 10^9
- All input values are integers.
- The given graph is a tree.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    if n == 1:
        # not possible per constraints (n>=2), but just in case
        print(0)
        return
    m = n - 1
    # edge arrays
    us = [0]*m; vs = [0]*m; ls = [0]*m
    idx = 1
    for i in range(m):
        us[i] = int(data[idx]); vs[i] = int(data[idx+1]); ls[i] = int(data[idx+2])
        idx += 3
    # CSR
    deg = [0]*(n+1)
    for i in range(m):
        deg[us[i]] += 1
        deg[vs[i]] += 1
    start = [0]*(n+2)
    for v in range(1, n+1):
        start[v+1] = start[v] + deg[v]
    # fill
    pos = start[:]  # copy; pos[v] = next slot
    adj_to = [0]*(2*m)
    adj_w = [0]*(2*m)
    for i in range(m):
        u = us[i]; v = vs[i]; w = ls[i]
        adj_to[pos[u]] = v; adj_w[pos[u]] = w; pos[u] += 1
        adj_to[pos[v]] = u; adj_w[pos[v]] = w; pos[v] += 1
    # BFS from 1
    parent = [0]*(n+1)
    wtop = [0]*(n+1)
    order = [0]*n
    order[0] = 1
    parent[1] = -1
    head = 0; tail = 1
    visited = bytearray(n+1)
    visited[1] = 1
    while head < tail:
        v = order[head]; head += 1
        for e in range(start[v], start[v+1]):
            u = adj_to[e]
            if not visited[u]:
                visited[u] = 1
                parent[u] = v
                wtop[u] = adj_w[e]
                order[tail] = u
                tail += 1
    # mu
    mu = [0]*(n+1)
    for i in range(n-1, 0, -1):
        v = order[i]
        p = parent[v]
        t = wtop[v] + mu[v]
        if t > mu[p]:
            mu[p] = t
    # A and B
    A = []
    Bp = []
    ap = A.append; bp = Bp.append
    for i in range(1, n):
        v = order[i]
        mv = mu[v]
        ap(wtop[v] + mv)
        if mv > 0:
            bp(mv)
    A.sort()
    Bp.sort()
    kept = []
    j = 0
    lb = len(Bp)
    for a in A:
        if j < lb and Bp[j] == a:
            j += 1

Looking at this problem:

**Reduction.** The minimal closed walk from vertex 1 visiting set $S$ has length $2\times$ (weight of union of paths from 1 to each vertex of $S$). Picking an internal vertex is dominated by picking a leaf below it, so for $K$ vertices the value is $2\cdot f(\min(K,\ell))$ where $\ell$ = number of leaves (rooted at 1) and $f(j)$ = max weight of the union of $j$ root-to-leaf paths (and $f(\ell)=W$, total weight).

**Computing $f$ for all $j$.** For vertex $v$, let $F_v(j)$ = best union of $j$ paths from $v$ to leaves below. Distributing $j$ among children gives a max-plus convolution of concave sequences, whose marginal increments are the merge of children marginal lists where, for child $c$, the head $\mu_c := F_c(1)$ (heaviest downward path) is replaced by $w_c+\mu_c$. Hence bottom-up with meldable heaps, each non-root $v$ pops value $\mu_v$ and pushes $val_v = w_{(v,parent)}+\mu_v$. Therefore the final marginal multiset at the root is simply the multiset $\{val_v\}$ minus the multiset $\{\mu_v\}$ (positive part, matched greedily) — no heaps needed! Then $f(j)$ = sum of $j$ largest remaining values.

Verified on both samples (e.g. sample 1: A={8,5,2,3}, B={5}, kept sorted desc = [8,3,2] → 16,22,26,26,26 ✓; sample 2 gives [2e9] → 4e9 for all K ✓) and several hand-built trees.

Complexity: $O(N\log N)$.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    m = n - 1
    vals = list(map(int, data[1:1 + 3 * m]))
    us = vals[0::3]; vs_ = vals[1::3]; ws = vals[2::3]

    start = [0] * (n + 2)
    for u in us: start[u + 1] += 1
    for v in vs_: start[v + 1] += 1
    for v in range(1, n + 1): start[v + 1] += start[v]

    pos = start[:n + 1]
    adj_to = [0] * (2 * m); adj_w = [0] * (2 * m)
    for i in range(m):
        u = us[i]; v = vs_[i]; w = ws[i]
        p = pos[u]; adj_to[p] = v; adj_w[p] = w; pos[u] = p + 1
        p = pos[v]; adj_to[p] = u; adj_w[p] = w; pos[v] = p + 1

    parent = [0] * (n + 1); wtop = [0] * (n + 1)
    order = [0] * n
    visited = bytearray(n + 1); visited[1] = 1
    order[0] = 1; head = 0; tail = 1
    while head < tail:
        v = order[head]; head += 1
        for e in range(start[v], start[v + 1]):
            u = adj_to[e]
            if not visited[u]:
                visited[u] = 1
                parent[u] = v; wtop[u] = adj_w[e]
                order[tail] = u; tail += 1

    mu = [0] * (n + 1)
    for i in range(n - 1, 0, -1):
        v = order[i]; p = parent[v]
        t = wtop[v] + mu[v]
        if t > mu[p]: mu[p] = t

    A = []; B = []
    a_app = A.append; b_app = B.append
    for i in range(1, n):
        v = order[i]; mv = mu[v]
        a_app(wtop[v] + mv)
        if mv: b_app(mv)
    A.sort(); B.sort()

    kept = []; k_app = kept.append
    j = 0; lb = len(B)
    for a in A:
        while j < lb and B[j] < a:
            j += 1
        if j < lb and B[j] == a:
            j += 1
        else:
            k_app(a)

    kept.sort(reverse=True)
    L = len(kept)
    pref = [0] * L
    s = 0
    for i in range(L):
        s += kept[i]
        pref[i] = s

    out = []; o_app = out.append
    last = 2 * pref[-1]
    for K in range(1, n + 1):
        if K < L:
            o_app(str(2 * pref[K - 1]))
        else:
            o_app(str(last))
    sys.stdout.write("\n".join(out) + "\n")

main()
