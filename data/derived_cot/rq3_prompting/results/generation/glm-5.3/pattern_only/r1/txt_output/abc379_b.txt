=== ANSWER ===
**Reasoning:**

- Each strawberry consumes exactly K healthy teeth (they become cavities permanently). Teeth never recover, so within a maximal run of L consecutive healthy teeth, at most ⌊L/K⌋ strawberries can come from that run (each needs K distinct teeth).
- This bound is achievable greedily: in a run of length L, eat using the leftmost K healthy teeth, then the next K, etc. Each chosen block is consecutive healthy teeth at the moment of eating (used-up teeth lie to the left), so all ⌊L/K⌋ strawberries are valid.
- Runs are independent (separated by X's), so the answer is Σ ⌊Lᵢ/K⌋ over maximal runs of 'O'.

Verification against samples:
1. Runs 2, 4 with K=3 → 0+1 = 1 ✓
2. Runs 1, 3, 4 with K=2 → 0+1+2 = 3 ✓
3. Runs 8, 5 with K=5 → 1+1 = 2 ✓

Implementation is a simple split on 'X'.

```python
def main():
    import sys
    data = sys.stdin.read().split()
    n, k = int(data[0]), int(data[1])
    s = data[2]
    ans = sum(len(p) // k for p in s.split('X'))
    print(ans)

main()
```
