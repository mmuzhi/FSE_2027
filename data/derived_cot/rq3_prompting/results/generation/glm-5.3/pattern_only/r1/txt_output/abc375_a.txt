Looking at this problem:

- **Complexity:** N ≤ 2×10^5, so a single O(N) scan is clearly sufficient — no need for any alternative approach.

- Sample 1 (`#.##.#`): 0-indexed substrings `S[0:3]="#.#"` and `S[3:6]="#.#"` → 2 ✓

- Sample 3 (`##.#.#.##`): matches at 0-indexed i = 1, 3, 5 → 3 ✓

Implementation: read N and S, sum 1 for each i in `range(n-2)` where the 3-character slice equals `"#.#"`.

```python
def main():
    import sys
    data = sys.stdin.read().split()
    n = int(data[0])
    s = data[1]
    print(sum(1 for i in range(n - 2) if s[i:i + 3] == "#.#"))

main()
```
