import sys
import numpy as np

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = np.array(data[1:1 + n], dtype=np.int64)
    S = int(a.sum())
    ans = (n + 1) * S
    maxA = int(a.max())
    k_top = (2 * maxA).bit_length() - 1  # largest k with 2^k <= 2*maxA
    for k in range(1, k_top + 1):
        M = 1 << k
        mask = M - 1
        r = a & mask
        ur, inv = np.unique(r, return_inverse=True)
        cnt = np.bincount(inv).astype(np.int64)
        sm = np.bincount(inv, weights=a).astype(np.int64)
        comp = (M - ur) % M
        pos = np.searchsorted(ur, comp)
        pos = np.minimum(pos, len(ur) - 1)
        match = ur[pos] == comp

        same = (ur == 0) | (ur * 2 == M)

        s1 = sm[cross]

        c2 = cnt[p2]

Looking at this problem:

- Pairs count is ~2×10^10, so we need the identity: f(x) = x − Σ_{k≥1, 2^k | x} x/2^k.
- So answer = (N+1)·ΣA − Σ_k Σ_{i≤j, 2^k | A_i+A_j} (A_i+A_j)/2^k, since Σ_{i≤j}(A_i+A_j) = (N+1)·ΣA.
- For each k ≤ 24, bucket by residue mod 2^k. Same-class buckets r ∈ {0, M/2} contribute (c+1)·σ (each element appears in c+1 pair slots when i≤j, verified: c=1→2a, c=2→3(a+b)); complementary buckets r, M−r (r < M−r) contribute c_r·σ_{M−r} + c_{M−r}·σ_r. Total is divisible by M (exact division).

Verified by hand on sample 1 (36−18−9−3−1=5 ✓), sample 2 (632−215−22−11=384 ✓), plus edge cases n=1 and all-equal arrays. Implementation uses numpy per level (unique + bincount for count/sum per residue, searchsorted for complements), with a pure-Python coarsening fallback. Overflow bounds fit int64 (≤ ~8×10^17).
