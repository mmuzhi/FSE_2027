```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    h = int(data[0]); w = int(data[1])
    grid = [data[2+i].decode() for i in range(h)]
    a, b, c, d = h, -1, w, -1
    for i, row in enumerate(grid):
        if '#' in row:
            if i < a: a = i
            if i > b: b = i
            first = row.find('#')
            last = w - 1 - row[::-1].find('#')
            if first < c: c = first
            if last > d: d = last
    for i in range(a, b+1):
        if '.' in grid[i][c:d+1]:
            print('No')
            return
    print('Yes')

main()
```

=== ANSWER ===
**Analysis:**

The rectangle (if it exists) must contain all existing `#` cells, so it must contain the bounding box of the `#` cells. Taking the bounding box itself as the candidate rectangle is optimal (largest possible rectangle means fewest forced-black cells inside and it's the only rectangle containing all `#`):

- Let `a,b` = min/max row of `#`, `c,d` = min/max column of `#`.
- Cells outside the bounding box contain no `#` by definition, so they can all be painted white — always fine.
- The only failure condition: some cell inside the bounding box is already `.` (it would have to be black but is fixed white).

So the answer is "Yes" iff no `.` appears inside the bounding box of the `#` cells. Complexity O(H·W), fine for 1000×1000.

**Ledger:**
- Invariant: bounding box of `#` is the maximal candidate rectangle.
- Edge cases: guaranteed at least one `#` (so box is well-defined); single cell case works.

**Recheck on samples:**
- Sample 1: box rows 1–2, cols 2–4 → `#?#` / `?#?`, no `.` → Yes ✓
- Sample 2: box is whole grid, center is `.` → No ✓
- Sample 3: box is the single `#` → Yes ✓
