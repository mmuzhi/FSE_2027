You will be given a competitive programming problem.
You are given an integer sequence A=(A_1,A_2,\ldots,A_N) of length N.
For each integer pair (L,R) with 1 \le L \le R \le N, define f(L,R) as follows:

- Start with an empty blackboard. Write the R-L+1 integers A_L, A_{L+1}, \ldots, A_R on the blackboard in order.
- Repeat the following operation until all integers on the blackboard are erased:
- Choose integers l, r with l \le r such that every integer from l through r appears at least once on the blackboard. Then, erase all integers from l through r that are on the blackboard.


- Let f(L,R) be the minimum number of such operations needed to erase all the integers from the blackboard.

Find \displaystyle \sum_{L=1}^N \sum_{R=L}^N f(L,R).

Input

N
A_1 A_2 \ldots A_N

Output

Print the answer.

Constraints


- 1 \le N \le 3 \times 10^5
- 1 \le A_i \le N
- All input values are integers.

Sample Output 1

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    A = list(map(int, data[1:1 + n]))

    last = [0] * (n + 1)
    t1 = 0
    pos = [[] for _ in range(n + 2)]
    for i in range(1, n + 1):
        a = A[i - 1]
        t1 += (i - last[a]) * (n - i + 1)
        last[a] = i
        pos[a].append(i)

    total = n * (n + 1) // 2

    def avoid(P):
        s = 0
        prev = 0
        for p in P:
            g = p - prev - 1
            s += g * (g + 1) // 2
            prev = p
        g = n - prev

Looking at this problem:

**Key insight 1:** Each operation erases exactly an interval of consecutive values (since all of $[l,r]$ must be present, erasing removes exactly $[l,r]$ from the value set). So $f(L,R)$ equals the number of maximal runs of consecutive integers in the set $S(L,R)$ of distinct values of $A[L..R]$.

**Key insight 2:** runs = |S| − (number of pairs $(v, v+1)$ with both in S). So the answer splits into:
- $T_1 = \sum_{L\le R}|S(L,R)|$ (classic distinct-values sum: each position $i$ contributes $(i - \text{prev}[i])(N-i+1)$),
- $T_2 = \sum_{v}$ (number of subarrays containing both values $v$ and $v+1$).

For $T_2$, per pair $(v,v+1)$ use inclusion–exclusion: containing both = total − avoiding $v$ − avoiding $v{+}1$ + avoiding both (i.e., avoiding the merged position set). Avoiding a position set counts subarrays within each gap of length $g$ as $g(g+1)/2$. Each array position participates in at most 2 value pairs, so total work is $O(N\log N)$.

Verified against all three samples analytically (e.g., sample 1: $T_1=18$, $T_2=2$ → 16; sample 3: $T_1=192$, $T_2=18+24+21=63$ → 129). ✓
