You will be given a competitive programming problem.
There are 2N points P_1,P_2,\ldots,P_N, Q_1,Q_2,\ldots,Q_N on a two-dimensional plane.
The coordinates of P_i are (A_i, B_i), and the coordinates of Q_i are (C_i, D_i).

Determine whether there exists a permutation R = (R_1, R_2, \ldots, R_N) of (1, 2, \ldots, N) that satisfies the following condition. If such an R exists, find one.

- For each integer i from 1 through N, let segment i be the line segment connecting P_i and Q_{R_i}.  Then, segment i and segment j (1 \leq  i < j \leq N) never intersect.

Constraints


- 1 \leq N \leq 300
- 0 \leq A_i, B_i, C_i, D_i \leq 5000 (1 \leq i \leq N)
- (A_i, B_i) \neq (A_j, B_j) (1 \leq i < j \leq N)
- (C_i, D_i) \neq (C_j, D_j) (1 \leq i < j \leq N)
- (A_i, B_i) \neq (C_j, D_j) (1 \leq i, j \leq N)

**Approach.** A non-crossing red(P)–blue(Q) perfect matching always exists (ham-sandwich style induction), so `-1` never happens. Constructive D&C: take the lexicographically smallest point `X` (all other points lie at angles in (−90°, 90°] around it). Sort the others by polar angle around `X`; scanning prefixes, the difference `(#opposite-color − #same-color)` starts at 0, ends at 1, and changes by ±1, so there is a first prefix where it equals 1, and that last point `Y` has the opposite color. Match `X–Y`. All points with smaller angle lie strictly in one open half-plane of line `XY`, all with larger angle in the other, and each side is color-balanced, so recurse on both sides. Segments from different subproblems are separated by that line, so no two segments intersect.

Since no three points are collinear, angle sorting has no ties; with coordinates ≤ 5000, distinct directions differ by ≥ 2·10⁻⁸ rad while `atan2` error is ~10⁻¹⁵, so float keys are safe. Complexity is O(N² log N), trivial for N ≤ 300. Verified by hand on Sample 1 (produces `2 3 1`, a listed valid answer) and on small edge cases (N=1, blue leftmost, cut at k=0, cut later in the list).
