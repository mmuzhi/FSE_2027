=== ANSWER ===
Looking at this problem: x must be placed in one of three roles in the arithmetic sequence:
- **x is the largest**: x = 2B − A (sequence A, B, x)
- **x is the smallest**: x = 2A − B (sequence x, A, B)
- **x is the middle**: x = (A+B)/2, only valid when A+B is even (sequence A, x, B)

These are the only candidates. The answer is the number of *distinct* values among them.

**Verification against samples:**
- A=5, B=7: {9, 3, 6} → 3 ✓
- A=6, B=1: {11, −4}, A+B odd → 2 ✓
- A=3, B=3: {3} (all candidates coincide) → 1 ✓

Distinctness analysis confirms the set approach handles everything: 2B−A = 2A−B only when A=B (then all three candidates equal A, counted once); (A+B)/2 coincides with an endpoint candidate only when A=B, which falls in the even case and is still handled by the set.

```python
A, B = map(int, input().split())
candidates = {2 * B - A, 2 * A - B}
if (A + B) % 2 == 0:
    candidates.add((A + B) // 2)
print(len(candidates))
```
