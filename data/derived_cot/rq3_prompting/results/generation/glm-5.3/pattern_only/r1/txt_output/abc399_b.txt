=== ANSWER ===
**Approach:** The described procedure is standard competition ranking — a person's rank is `1 + (number of people with a strictly greater score)`. Verified against all four samples (e.g., sample 4: score 41 has four greater scores → rank 5).

**Plan:** Read scores, for each score count strictly greater scores via a simple O(N²) scan (N ≤ 100, trivially fast), print rank per line. Edge cases (N=1, all equal scores) fall out naturally since a lone/max score gets count 0 → rank 1.

```python
n = int(input())
p = list(map(int, input().split()))
for x in p:
    print(1 + sum(1 for y in p if y > x))
```
