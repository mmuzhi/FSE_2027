=== PROMPT ===
You will be given a competitive programming problem.
There is one humidifier in the AtCoder company office. The current time is 0, and the humidifier has no water inside.
You will add water to this humidifier N times. The i-th addition of water (1 \leq i \leq N) takes place at time T_i, and you add V_i liters of water. It is guaranteed that T_i < T_{i+1} for all 1 \leq i \leq N-1.
However, the humidifier has a leak, and as long as there is water inside, the amount of water decreases by 1 liter per unit time.
Find the amount of water remaining in the humidifier immediately after you finish adding water at time T_N.

Input

The input is given from Standard Input in the following format:
N
T_1 V_1
T_2 V_2
\vdots
T_N V_N

Output

Print the answer.

Constraints


- 1 \leq N \leq 100
- 1 \leq T_i \leq 100 (1 \leq i \leq N)
- 1 \leq V_i \leq 100 (1 \leq i \leq N)
- T_i < T_{i+1} (1 \leq i \leq N-1)
- All input values are integers.

Sample Input 1

4
1 3
3 1
4 4
7 1

Sample Output 1

3

We have a humidifier that starts empty at time 0. Water leaks at 1 liter per unit time as long as there's water inside. We add water N times at times T_1 < T_2 < ... < T_N with amounts V_1, ..., V_N. We need to find the water remaining immediately after the last addition at time T_N.

- Start with `water = 0` at time 0.
- For each addition i: the time elapsed since the previous event (previous addition or time 0) is `T_i - T_{i-1}` (with T_0 = 0). Implementation in Python:

```python
def main():
    import sys
    data = sys.stdin.read().split()
    n = int(data[0])
    water = 0
    prev_t = 0
    idx = 1
    for _ in range(n):
        t = int(data[idx]); v = int(data[idx+1]); idx += 2
        water = max(0, water - (t - prev_t)) + v
        prev_t = t
    print(water)

main()
```
