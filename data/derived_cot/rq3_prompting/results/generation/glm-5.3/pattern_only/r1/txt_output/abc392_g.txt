=== ANSWER ===
**Approach.** A fine triplet is a 3-term arithmetic progression: A + C = 2B. Let `f` be the indicator vector of S over values 1..10⁶. Then the self-convolution `conv = f * f` gives, for each sum s, the number of ordered pairs (A, C) ∈ S² with A + C = s. For each B ∈ S, the number of fine triplets with middle element B is `(conv[2B] − 1) / 2` (subtract the pair (B, B), the rest pair up symmetrically, and parity guarantees exact halving).

**Complexity.** FFT of length 2²¹ ≈ 2·10⁶ → O(M log M). With numpy doubles, spectrum magnitudes reach ≤10¹² so absolute FFT error stays ≪0.5; rounding recovers exact integers.

**Verified** on sample 1 (B=2 gives (1,2,3), B=3 gives (1,3,5), B=5 gives (2,5,8) → 3) and sample 2 (5 APs among the seven values). Edge cases: N=1 → 0; `conv[2B] ≥ 1` always since (B,B) exists, so `(c2−1)//2 ≥ 0`.

import sys
import numpy as np

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    S = np.fromiter(map(int, data[1:1 + n]), dtype=np.int64, count=n)
    M = 10 ** 6
    need = 2 * M + 1                      # max index of convolution is 2*max(S)
    L = 1 << (need - 1).bit_length()      # smallest power of two >= need (2^21)
    f = np.zeros(L, dtype=np.float64)

    F = np.fft.rfft(f)

    print(ans)
