You will be given a competitive programming problem.
There is a grid with H rows and W columns. Let (i, j) denote the cell at the i-th row from the top and j-th column from the left.
Initially, there is one wall in each cell.
After processing Q queries explained below in the order they are given, find the number of remaining walls.
In the q-th query, you are given two integers R_q and C_q.
You place a bomb at (R_q, C_q) to destroy walls. As a result, the following process occurs.

- If there is a wall at (R_q, C_q), destroy that wall and end the process.
- If there is no wall at (R_q, C_q), destroy the first walls that appear when looking up, down, left, and right from (R_q, C_q). More precisely, the following four processes occur simultaneously:
- If there exists an i \lt R_q such that a wall exists at (i, C_q) and no wall exists at (k, C_q) for all i \lt k \lt R_q, destroy the wall at (i, C_q).
- If there exists an i \gt R_q such that a wall exists at (i, C_q) and no wall exists at (k, C_q) for all R_q \lt k \lt i, destroy the wall at (i, C_q).
- If there exists a j \lt C_q such that a wall exists at (R_q, j) and no wall exists at (R_q, k) for all j \lt k \lt C_q, destroy the wall at (R_q, j).
- If there exists a j \gt C_q such that a wall exists at (R_q, j) and no wall exists at (R_q, k) for all C_q \lt k \lt j, destroy the wall at (R_q, j).

Input

The input is given from Standard Input in the following format:
H W Q
R_1 C_1
R_2 C_2
\vdots
R_Q C_Q

Output

Print the number of remaining walls after processing all queries.

Constraints


- 1 \leq H, W
- H \times W \leq 4 \times 10^5
- 1 \leq Q \leq 2 \times 10^5
- 1 \leq R_q \leq H
- 1 \leq C_q \leq W
- All input values are integers.

=== ANSWER ===
**Approach (commit):** This is the classic "Cross Explosion" problem. Maintain 4 union-find-style parent arrays with path halving: for each row, `parL`/`parR` give (via find) the nearest alive wall left/right; for each column, `parU`/`parD` give nearest alive wall up/down. Deleting a cell just rewires its 4 parent pointers (`x → x-1` / `x → x+1`), no finds needed. A cell is alive iff its `parL` entry still equals itself. Finds from dead query cells are correct because chains only pass through dead cells, and path halving compresses them — total work ~O(HW + Q·α).

**Key invariant:** for any dead position `t`, everything strictly between `t` and `parL[t]` (etc.) is dead, so a find root is the true nearest alive wall or a sentinel. The four neighbors found in one query are always distinct cells, so destruction order doesn't matter.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    H = int(data[0]); W = int(data[1]); Q = int(data[2])
    nums = list(map(int, data[3:3 + 2 * Q]))
    RW2 = W + 2
    CH2 = H + 2
    HL = H * RW2
    WL = W * CH2
    parL = list(range(HL))
    parR = list(range(HL))
    parU = list(range(WL))
    parD = list(range(WL))
    destroyed = 0
    sentR = W + 1
    sentD = H + 1
    k = 0
    for _ in range(Q):
        i = nums[k] - 1
        j = nums[k + 1] - 1
        k += 2
        rb = i * RW2
        x = rb + j + 1
        if parL[x] == x:
            parL[x] = x - 1
            parR[x] = x + 1
            y = j * CH2 + i + 1
            parU[y] = y - 1
            parD[y] = y + 1
            destroyed += 1
            continue
        # LEFT
        t = x
        pt = parL[t]
        while pt != t:
            parL[t] = parL[pt]
            t = parL[t]
            pt = parL[t]
        if t != rb:
            parL[t] = t - 1
            parR[t] = t + 1
            yy = (t - rb - 1) * CH2 + i + 1
            parU[yy] = yy - 1
            parD[yy] = yy + 1
            destroyed += 1
        # RIGHT
        t = x
        pt = parR[t]
        while pt != t:
            parR[t] = parR[pt]
            t = parR[t]
            pt = parR[t]
        if t != rb + sentR:
            parL[t] = t - 1
            parR[t] = t + 1
            yy = (t - rb - 1) * CH2 + i + 1
            parU[yy] = yy - 1
            parD[yy] = yy + 1
            destroyed += 1
        # UP
        cb = j * CH2
        y = cb + i + 1
        t = y
        pt = parU[t]
        while pt != t:
            parU[t] = parU[pt]
            t = parU[t]
            pt = parU[t]
        if t != cb:
            parU[t] = t - 1
            parD[t] = t + 1
            xx = (t - cb - 1) * RW2 + j + 1
            parL[xx] = xx - 1
            parR[xx] = xx + 1
            destroyed += 1
        # DOWN
        t = y
        pt = parD[t]
        while pt != t:
            parD[t] = parD[pt]
            t = parD[t]
            pt = parD[t]
        if t != cb + sentD:
            parU[t] = t - 1
            parD[t] = t + 1
            xx = (t - cb - 1) * RW2 + j + 1
            parL[xx] = xx - 1
            parR[xx] = xx + 1
            destroyed += 1
    print(H * W - destroyed)

main()
