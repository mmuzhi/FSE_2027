=== ANSWER ===
```python
class Solution:
    def countPartitions(self, nums: List[int]) -> int:
        # left - right = (total - right) - right = total - 2*right
        # parity of the difference equals parity of the total sum,
        # so the difference is even for every partition iff total is even.
        return len(nums) - 1 if sum(nums) % 2 == 0 else 0
```
