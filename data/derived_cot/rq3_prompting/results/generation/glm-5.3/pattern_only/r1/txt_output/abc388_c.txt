There are N mochi (rice cakes) arranged in ascending order of size.

Python implementation with fast input:

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1+n]))
    ans = 0
    p = 0
    for x in a:
        t = x >> 1
        while p < n and a[p] <= t:
            p += 1
        ans += p
    print(ans)

main()
```

=== ANSWER ===
**Analysis:**

- The array is sorted. For each candidate bottom mochi of size `b`, any mochi with size `a` satisfying `2a ≤ b` (i.e., `a ≤ b//2`) can be placed on top. All such mochi are automatically distinct indices from the bottom (strictly smaller size in a sorted array).
- Answer = sum over each `j` of the count of elements `≤ A[j]//2`.
- Since `A[j]//2` is non-decreasing in `j`, a two-pointer sweep gives O(N) after reading input — well within limits for N = 5×10⁵.
