```python
class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        i = 0
        n = len(s)
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            if j - i == k:
                return True
            i = j
        return False
```

=== ANSWER ===
```python
class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        # A valid substring of length k must be exactly a maximal run
        # of one character whose length is exactly k (neighbors, if any,
        # are different by maximality of the run).
        n = len(s)
        i = 0
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            if j - i == k:
                return True
            i = j
        return False
```
