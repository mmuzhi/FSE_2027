def main():

    n = int(data[0])

                roots.append(nid)

        fact[i] = fact[i-1] * i % MOD
    inv_fact = [1] * (maxf + 1)
    inv_fact[maxf] = pow(fact[maxf], MOD - 2, MOD)
    for i in range(maxf, 0, -1):
        inv_fact[i-1] = inv_fact[i] * i % MOD

    for v in range(m - 1, -1, -1):

        ans = ans * inv_fact[k] % MOD

Looking at this problem:

**Key insight 1:** A balanced substring is always a concatenation of consecutive sibling subtrees in the tree/forest representation of the parenthesis sequence. The operation replaces siblings $c_i,\dots,c_j$ with $\text{mirror}(c_j),\dots,\text{mirror}(c_i)$, where mirror recursively reverses children order.

**Key insight 2 (Invariant):** Every operation preserves the *unordered* tree/forest structure (multiset of children types at every node), since mirror preserves unordered structure.

**Key insight 3 (Completeness):** Adjacent siblings $a,b$ can be swapped: apply interval op → $\text{mirror}(b),\text{mirror}(a)$, then mirror each individually → $b,a$. So **any** reordering of children at any node is reachable (fix top level first, then recurse into subtrees).

Therefore the reachable strings = all distinct ordered versions of the fixed unordered forest. Counting: for a node whose children form a multiset of unordered types with multiplicities $a_1..a_k$ (with $D(t)$ = number of orderings of type $t$):
$$D = \frac{(\sum a_i)!}{\prod a_i!}\prod D(t_i)^{a_i}$$
and similarly for the top-level forest. Canonical unordered types are computed bottom-up via sorted tuples of children type ids (children have larger ids than parents, so one reverse pass works).

Verified on samples: `(())()` → forest [chain2, leaf] → $2!/1!/1! = 2$ ✓; `()` → 1 ✓. Also hand-verified e.g. `(()())` → 1 (identical children give no new strings), `(()(()))()` → 4.

import sys
from collections import Counter

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    s = data[1] if len(data) > 1 else ""
    MOD = 998244353

    children = []
    stack = []
    roots = []
    for ch in s:
        if ch == '(':
            nid = len(children)
            children.append([])
            if stack:
                children[stack[-1]].append(nid)
            else:
                roots.append(nid)
            stack.append(nid)
        else:
            stack.pop()

    m = len(children)
    maxf = m + 1
    fact = [1] * (maxf + 1)
    for i in range(1, maxf + 1):
        fact[i] = fact[i - 1] * i % MOD
    inv_fact = [1] * (maxf + 1)
    inv_fact[maxf] = pow(fact[maxf], MOD - 2, MOD)
    for i in range(maxf, 0, -1):
        inv_fact[i - 1] = inv_fact[i] * i % MOD

    canon = [-1] * m
    type_of = {}
    D = []
    for v in range(m - 1, -1, -1):
        cts = sorted(canon[c] for c in children[v])
        key = tuple(cts)
        t = type_of.get(key, -1)
        if t == -1:
            t = len(D)
            type_of[key] = t
            cnt = Counter(cts)
            val = fact[len(cts)]
            for ct, k in cnt.items():
                val = val * pow(D[ct], k, MOD) % MOD
                val = val * inv_fact[k] % MOD
            D.append(val)
        canon[v] = t

    rts = [canon[r] for r in roots]
    cnt = Counter(rts)
    ans = fact[len(rts)]
    for ct, k in cnt.items():
        ans = ans * pow(D[ct], k, MOD) % MOD
        ans = ans * inv_fact[k] % MOD
    print(ans % MOD)

main()
