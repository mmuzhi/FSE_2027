You will be given a competitive programming problem.
You are given simple undirected graphs G and H, each with N vertices: vertices 1, 2, \ldots, N.
Graph G has M_G edges, and its i-th edge (1\leq i\leq M_G) connects vertices u_i and v_i.
Graph H has M_H edges, and its i-th edge (1\leq i\leq M_H) connects vertices a_i and b_i.
You can perform the following operation on graph H any number of times, possibly zero.

- Choose a pair of integers (i,j) satisfying 1\leq i<j\leq N. Pay A_{i,j} yen, and if there is no edge between vertices i and j in H, add one; if there is, remove it.

Find the minimum total cost required to make G and H isomorphic.
What is a simple undirected graph?
 A simple undirected graph is a graph without self-loops or multi-edges, where edges have no direction.

What does it mean for graphs to be isomorphic?
 Two graphs G and H with N vertices are isomorphic if and only if there exists a permutation (P_1,P_2,\ldots,P_N) of (1,2,\ldots,N) such that for all 1\leq i\lt j\leq N:

-  an edge exists between vertices i and j in G if and only if an edge exists between vertices P_i and P_j in H.

=== ANSWER ===
Looking at this problem:

- N ≤ 8, so at most 8! = 40320 permutations.
- For each permutation P, G is isomorphic to H via P iff for every pair (i,j), edge (i,j) in G ⟺ edge (P_i, P_j) in H. The cost to achieve that is the sum of A over pairs whose status differs (each differing pair toggled exactly once — toggling twice is never useful since costs are positive).
- Answer = min over all permutations of that sum. Complexity O(N!·N²) ≈ 1.1M checks — trivial.

Verification against Sample 1: with perm [3,0,1,4,2] (0-indexed), cost = 2+5+1+1 = 9 ✓. Sample 4 (N=2, no edges): cost 0 ✓. Samples 2 and 3 check out by the same reasoning (3 and 5 respectively).

Implementation ledger:
- Store g, h, A as symmetric N×N matrices so flat index `a*N+b` works in any order.
- Numpy path vectorizes over all permutations; pure-Python fallback (with early break when cost ≥ best) used if numpy is unavailable.
- Edge cases: N=1 (no pairs, answer 0), MG=MH=0.

import sys
from itertools import permutations


def read_inputs():
    data = sys.stdin.buffer.read().split()
    pos = 0
    N = int(data[pos]); pos += 1
    MG = int(data[pos]); pos += 1
    g = [[0] * N for _ in range(N)]
    for _ in range(MG):
        u = int(data[pos]) - 1
        v = int(data[pos + 1]) - 1
        pos += 2
        g[u][v] = 1
        g[v][u] = 1
    MH = int(data[pos]); pos += 1
    h = [[0] * N for _ in range(N)]
    for _ in range(MH):
        a = int(data[pos]) - 1
        b = int(data[pos + 1]) - 1
        pos += 2
        h[a][b] = 1
        h[b][a] = 1
    A = [[0] * N for _ in range(N)]
    for i in range(N - 1):
        for j in range(i + 1, N):
            val = int(data[pos]); pos += 1
            A[i][j] = val
            A[j][i] = val
    return N, g, h, A


def solve_numpy(N, g, h, A):
    import numpy as np
    perms = np.array(list(permutations(range(N))), dtype=np.int64)
    total = np.zeros(perms.shape[0], dtype=np.int64)
    hflat = np.array(h, dtype=np.int64).ravel()
    aflat = np.array(A, dtype=np.int64).ravel()

            total += (hv != g[i][j]) * aflat[t]
    return int(total.min())
