```python
    def sumOfGoodSubsequences(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        size = 10**5 + 3  # index = value + 1, covers values -1..10^5+1
```

=== ANSWER ===
Looking at this problem:

- **Decisive constraint**: n up to 10^5, values up to 10^5 — need an O(n) or O(n + maxV) DP. A subsequence ending at index j is good iff its prefix (ending at an earlier index with value nums[j]±1) is good, so a value-indexed DP works.

- **State**: `count[v]` = number of good subsequences seen so far ending with value v; `total[v]` = sum of their element-sums. For each new element x: new subsequences ending here are `[x]` alone plus every subsequence ending in x−1 or x+1 extended by x. So:
  - `c = 1 + count[x-1] + count[x+1]`
  - `s = x + total[x-1] + total[x+1] + x*(count[x-1]+count[x+1])`

- **Edge cases**: value 0 (x−1 = −1) and value 10^5 (x+1 out of range) — handled by shifting indices by +1 with array size 10^5+3. Each subsequence is counted exactly once (unique last index), verified against both examples (14 and 40) and edge cases like [1,1] → 2, [2,1,2] → 16, [0,1] → 2.

```python
class Solution:
    def sumOfGoodSubsequences(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        # index = value + 1, covering values -1 .. 10^5 + 1
        size = 10**5 + 3
        count = [0] * size   # count[i]: # good subsequences ending with value i-1
        total = [0] * size   # total[i]: sum of element-sums of those subsequences

            cr = count[i + 1]  # value x+1

            count[i] = (count[i] + c) % MOD
            total[i] = (total[i] + s) % MOD
            ans = (ans + s) % MOD
        return ans
```
