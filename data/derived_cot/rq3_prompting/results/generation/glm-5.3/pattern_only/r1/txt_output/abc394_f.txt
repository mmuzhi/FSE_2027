Looking at this problem:

- Any connected subgraph of a tree T is a tree, and it must equal T[V] for a connected vertex set V (spanning tree of induced subgraph = induced subgraph itself).
- An alkane with k degree-4 vertices has 2k+2 leaves, so total 3k+2 vertices, degrees only 1 or 4.

**DP plan:** Root T at 1. For vertex v define dp[v][j] = max vertices of a connected subgraph containing v (within v's subtree) where v has exactly j edges to its children in the subgraph, and every other vertex has degree exactly 1 or 4. Each chosen child c contributes either 1 (c as a leaf) or dp[c][3] (c gets degree 4 via the parent edge). So dp[v][j] = 1 + sum of the j largest child contributions, contribution = max(1, dp[c][3]).

The answer's topmost vertex u has degree 1 or 4 in the alkane. If degree 4 → dp[u][4]. If degree 1 → its child must have degree 4 (otherwise only 2 vertices, invalid), which means dp[u][1] = 1 + dp[c][3] ≥ 5. So answer = max over v of dp[v][4], and dp[v][1] whenever the top contribution ≥ 4 (feasible dp3 values are always ≥ 4, leaf contributions are exactly 1, so checking top contribution ≥ 4 is exact).

Verified on all three samples (8, -1, 11). Complexity O(N log N) from sorting child contribution lists (total elements N−1), well within limits. Implemented iteratively (BFS order, process in reverse) to avoid recursion depth issues.

            u = adj[i]
            if u != pv:
                parent[u] = v
                order[tail] = u
                tail += 1
    dp3 = [0] * (n + 1)  # 0 = infeasible; feasible values are >= 4
    ans = -1
    for oi in range(n - 1, -1, -1):
        v = order[oi]
        pv = parent[v]
        cs = [dp3[u] if dp3[u] > 1 else 1 for u in adj[start[v]:start[v + 1]] if u != pv]
        k = len(cs)
        if k == 0:
            continue
        cs.sort(reverse=True)
        c0 = cs[0]
        if c0 >= 4:  # dp[v][1] with a degree-4 child branch: valid alkane
            t = c0 + 1
            if t > ans:
                ans = t
        if k >= 3:
            dp3[v] = 1 + c0 + cs[1] + cs[2]
        if k >= 4:  # dp[v][4]: v has degree 4, valid alkane
            t = 1 + c0 + cs[1] + cs[2] + cs[3]
            if t > ans:
                ans = t
    print(ans)

main()
