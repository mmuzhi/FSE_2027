There are N toys numbered from 1 to N, and N-1 boxes numbered from 1 to N-1.
Toy i\ (1 \leq i \leq N) has a size of A_i, and box i\ (1 \leq i \leq N-1) has a size of B_i.
Takahashi wants to store all the toys in separate boxes, and he has decided to perform the following steps in order:

- Choose an arbitrary positive integer x and purchase one box of size x.
- Place each of the N toys into one of the N boxes (the N-1 existing boxes plus the newly purchased box).

He wants to execute step 2 by purchasing a sufficiently large box in step 1, but larger boxes are more expensive, so he wants to purchase the smallest possible box.
Determine whether there exists a value of x such that he can execute step 2, and if it exists, find the minimum such x.

B_1 B_2 \dots B_{N-1}

Output

Constraints


- 2 \leq N \leq 2 \times 10^5
- 1 \leq A_i, B_i \leq 10^9
- All input values are integers.

Sample Output 1

3

**Reasoning summary:**

- Sort toys `A` ascending and boxes `B` ascending. A perfect matching (each toy into a box of size ≥ toy) exists iff the sorted combined box multiset dominates sorted toys elementwise.
- The new box of size `x` occupies some sorted position `k`. Then the condition decomposes into:
  - prefix: `b[i] >= a[i]` for `i < k` (`pre[k]`)
  - the new box holds toy `a[k]`, so minimal candidate `x = a[k]`
  - suffix: `b[i] >= a[i+1]` for `i >= k` (`suf[k]`)
- If `pre[k]` and `suf[k]` hold, then `x = a[k]` is feasible (one can prove the actual sorted insertion point `j ≤ k` still satisfies domination using `b[j] ≥ a[k]` and `suf`). Conversely any feasible `x` at position `j` implies `pre[j] ∧ suf[j]` and `x ≥ a[j]`. Hence answer = `min{a[k] : pre[k] ∧ suf[k]}`, and since `A` is sorted, the first valid `k` gives the minimum. If none valid, `-1`.

Verified against all three samples (answers 3, -1, 37).
