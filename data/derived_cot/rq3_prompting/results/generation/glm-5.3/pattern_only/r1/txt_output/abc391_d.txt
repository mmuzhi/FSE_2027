There is a grid with 10^9 rows and W columns. The cell at the x-th column from the left and the y-th row from the bottom is denoted by (x,y).

At times t=1,2,\dots,10^{100}, the blocks are moved according to the following rules:

- If the entire bottom row is filled with blocks, then all blocks in the bottom row are removed.
- For each remaining block, in order from bottom to top, perform the following:
- If the block is in the bottom row, or if there is a block in the cell immediately below it, do nothing.
- Otherwise, move the block one cell downward.

Constraints


- 1 \leq N \leq 2 \times 10^5
- 1 \leq W \leq N
- 1 \leq X_i \leq W
- 1 \leq Y_i \leq 10^9
- (X_i,Y_i) \neq (X_j,Y_j) if i \neq j.
- 1 \leq Q \leq 2 \times 10^5
- 1 \leq T_j \leq 10^9
- 1 \leq A_j \leq N

```python
import sys
from collections import defaultdict

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    N = int(data[idx]); idx += 1
    W = int(data[idx]); idx += 1
    cols = [[] for _ in range(W + 1)]
    X = [0] * N
    Y = [0] * N
    for i in range(N):
        x = int(data[idx]); idx += 1
        y = int(data[idx]); idx += 1
        X[i] = x; Y[i] = y
        cols[x].append((y, i))
    # K*
    K = min(len(cols[x]) for x in range(1, W + 1))
    best = [0] * K  # best[r] = max over columns of (r+1)-th smallest height
    for x in range(1, W + 1):
        lst = cols[x]
        lst.sort()
        for r in range(min(K, len(lst))):
            y = lst[r][0]
            if y > best[r]:
                best[r] = y
    INF = float('inf')
    clear_time = [INF] * N
    for x in range(1, W + 1):
        lst = cols[x]
        for r, (y, i) in enumerate(lst):
            if r < K:
                clear_time[i] = best[r]
    Q = int(data[idx]); idx += 1
    out = []
    for _ in range(Q):
        T = int(data[idx]); idx += 1
        A = int(data[idx]); idx += 1
        A -= 1
        out.append("Yes" if T < clear_time[A] else "No")
    sys.stdout.write("\n".join(out) + "\n")

main()
```

=== ANSWER ===
Looking at this problem:

**Key derivation:** Within a column, since all heights are distinct, each block simply free-falls from its start height at speed 1, floored at (its rank from bottom − cleared rows + 1). Processing bottom-up each step makes blocks maintain order without mid-air collision issues. With $k$ clears done, the height of the rank-$r$ block at end of step $t$ is $\max(r-k+1,\; y_r - t)$.

Row 1 is full at the start of step $t$ (after $k$ clears) iff every column's current bottom block (rank $k$) is at row 1, i.e. $y^{(x)}_k \le t$ for all $x$. Hence the $k$-th clear happens exactly at time $T_k = \max_x y^{(x)}_{k-1}$, valid for $k \le K^* = \min_x n_x$ (after that some column is empty, no more clears). Each clear removes exactly one block per column — its bottom one — so **a block at rank $r$ (0-indexed) in its column disappears at time $\max_x y^{(x)}_r$ if $r < K^*$, otherwise never**.

A block exists at $T+0.5$ iff its clear time $> T$.

Verified against both samples (sample 1: K\*=1, clear time 2 for rank-0 blocks → query (2,3) is No, (1,1) Yes, rank-1 blocks never cleared) and several hand simulations (e.g. col1{1,10}, col2{5,6} → clears at 5 and 10, matching brute force).

Complexity: $O(N \log N + Q)$.

Edge case: if some column has no blocks, $K^*=0$ and no block ever disappears.
