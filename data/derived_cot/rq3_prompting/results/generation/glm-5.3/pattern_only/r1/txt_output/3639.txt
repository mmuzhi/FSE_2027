```python
class Solution:
    def isZeroArray(self, nums: List[int], queries: List[List[int]]) -> bool:
        n = len(nums)
        diff = [0] * (n + 1)
        for l, r in queries:
            diff[l] += 1
            diff[r + 1] -= 1
        cur = 0
        for i in range(n):
            cur += diff[i]
            if cur < nums[i]:
                return False
        return True
```

=== ANSWER ===
**Commit:** Each query can decrement any index in `[l, r]` at most once (subset choice is independent per index, empty subset allowed). So index `i` can receive anywhere from 0 to `count[i]` decrements, where `count[i]` = number of queries covering `i`. Order is irrelevant. The array can be zeroed iff `count[i] >= nums[i]` for all `i`. Compute coverage with a difference array — O(n + q).

**Ledger:** diff array of size n+1 (r+1 can equal n); running prefix sum must stay ≥ nums[i] at every index.

**Recheck:** Example 1: coverage [1,1,1] vs [1,0,1] → true ✓. Example 2: coverage [1,2,2,2] vs [4,3,2,1]; index 0 fails (1 < 4) → false ✓. Edge: nums[i]=0 always ok.

```python
class Solution:
    def isZeroArray(self, nums: List[int], queries: List[List[int]]) -> bool:
        n = len(nums)
        diff = [0] * (n + 1)
        for l, r in queries:
            diff[l] += 1
            diff[r + 1] -= 1
        cur = 0
        for i in range(n):
            cur += diff[i]
            if cur < nums[i]:
                return False
        return True
```
