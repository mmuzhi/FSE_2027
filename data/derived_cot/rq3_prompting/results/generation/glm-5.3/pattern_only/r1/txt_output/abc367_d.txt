**Approach.** Let P be prefix sums (P₀=0, P_k=A₁+…+A_k) and T = ΣA. For an ordered pair (s,t), s≠t, the clockwise distance is P_{t−1}−P_{s−1} when t>s, and T−(P_{s−1}−P_{t−1}) when t<s. So with prefix indices i=s−1, j=t−1:

- t>s (j>i): condition ⟺ (P_j−P_i) mod M == 0
- t<s (j<i): condition ⟺ (P_i−P_j) mod M == T mod M, which with the pair written in increasing index order is (P_{j'}−P_{i'}) mod M == T mod M for i'<j'.

Hence answer = #{i<j : (P_j−P_i) mod M == 0} + #{i<j : (P_j−P_i) mod M == Tm}. Both are computed in one O(N) sweep with a residue count array of size M (the case Tm=0 correctly counts both directions twice). Verified against all three samples (4, 0, 11).
