You will be given a competitive programming problem.
There is a grid with H horizontal rows and W vertical columns.
Let (i, j) denote the cell at the i-th row (1\leq i\leq H) from the top and j-th column (1\leq j\leq W) from the left.
Initially, there is a slime with strength S _ {i,j} in cell (i,j), and Takahashi is the slime in the cell (P,Q).
Find the maximum possible strength of Takahashi after performing the following action any number of times (possibly zero):

- Among the slimes adjacent to him, choose one whose strength is strictly less than \dfrac{1}{X} times his strength and absorb it.
  As a result, the absorbed slime disappears, and Takahashi's strength increases by the strength of the absorbed slime.

When performing the above action, the gap left by the disappeared slime is immediately filled by Takahashi, and the slimes that were adjacent to the disappeared one (if any) become newly adjacent to Takahashi (refer to the explanation in sample 1).

If the minimum adjacent slime satisfies `v * X < strength` (strict), absorbing it is safe — strength only grows, and the frontier only grows (a cell adjacent to the region stays adjacent as the region expands). If the minimum adjacent slime fails the condition, no other adjacent slime can pass it either (all are ≥ min), and since strength can't grow without absorbing, we're stuck — stop.
- Correctness (exchange argument): given any valid absorption sequence starting with the same prefix as greedy, greedy's next minimum frontier cell can be inserted at the front of that sequence while keeping it valid (strength at that point is the same, and later prefix sums only increase). Hence greedy absorbs every cell any valid strategy could absorb, maximizing total strength.

**Ledger:**
- Invariant: heap holds exactly the unvisited frontier cells; cells marked visited on push (no duplicates).
- Strict comparison: absorb iff `v * X < strength` (integers, no floats).
- Edge cases: X=1 with equality (sample 2 → 5), single-cell grid, big values (10^12 × 10^9 fits Python ints).

Trace of sample 1: strength 9 → absorb 4 (8<9) → 13 → absorb 6 (12<13) → 19 → absorb 9 (18<19) → 28 → next min 14 (28<28 false) → stop. Output 28. ✓

Recheck sample 2: start strength 5, neighbors both 10, 10·1=10 not < 5 → output 5. ✓

```python
import sys
import heapq

def main():
    data = sys.stdin.buffer.read().split()
    H = int(data[0]); W = int(data[1]); X = int(data[2])
    P = int(data[3]) - 1; Q = int(data[4]) - 1
    S = [list(map(int, data[5 + i * W: 5 + (i + 1) * W])) for i in range(H)]

    strength = S[P][Q]
    visited = [[False] * W for _ in range(H)]
    visited[P][Q] = True
    heap = []

    for i, j in ((P - 1, Q), (P + 1, Q), (P, Q - 1), (P, Q + 1)):
        if 0 <= i < H and 0 <= j < W:
            visited[i][j] = True
            heapq.heappush(heap, (S[i][j], i, j))

    while heap:
        v, i, j = heapq.heappop(heap)
        if v * X < strength:
            strength += v
            for ni, nj in ((i - 1, j), (i + 1, j), (i, j - 1), (i, j + 1)):
                if 0 <= ni < H and 0 <= nj < W and not visited[ni][nj]:
                    visited[ni][nj] = True
                    heapq.heappush(heap, (S[ni][nj], ni, nj))
        else:
            break

    print(strength)

main()
```
