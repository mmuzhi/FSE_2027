S = input().strip()
n = len(S)
ans = 0
for i in range(n):
    if S[i] != 'A':
        continue
    for j in range(i + 1, n):
        if S[j] != 'B':
            continue
        k = 2 * j - i
        if k < n and S[k] == 'C':
            ans += 1
print(ans)

**Ledger:**
- Invariant: k determined by i, j via k = 2j − i (0-indexed).
- Key edge: bound check k < n before indexing.
- Verified against all three samples (sample 3: pairs at j=6 give i=0,1; at j=7 give i=1,3 → total 4 ✓).

S = input().strip()
