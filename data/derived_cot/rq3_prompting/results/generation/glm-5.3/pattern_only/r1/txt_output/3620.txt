```python
class Solution:
    def maxDistinctElements(self, nums: List[int], k: int) -> int:
        nums.sort()
        count = 0
        last = float('-inf')
        for x in nums:
            v = x - k
            if v <= last:
                v = last + 1
            if v <= x + k:
                count += 1
                last = v
        return count
```

**Commit:** Sort + greedy sweep. Process elements in ascending order, assign each the smallest feasible value strictly greater than the last assigned value: `v = max(x - k, last + 1)`; count it if `v <= x + k`. 

**Invariant:** After processing any prefix, greedy's count is at least the number of distinct values any feasible scheme can produce on that prefix, and greedy's j-th assigned value is pointwise minimal (proved by exchange: any optimal matching can be sorted so elements and values ascend together, and greedy's minimal chain stays below it). Hence skipped elements (when `x + k <= last`) can never be retroactively useful.

**Ledger:** sentinel `last` below any reachable value (`x - k >= 1 - 10^9`); `k = 0` must reduce to counting distinct values.

**Recheck:**
- `[1,2,2,3,3,4], k=2` → assigns `-1,0,1,2,3,4` → 6 ✓
- `[4,4,4,4], k=1` → assigns `3,4,5`, 4th gets `v=6 > 5` skip → 3 ✓
- `[c,c,c], k=0` → assigns `c`, then `v=c+1 > c` skip → 1 (distinct count) ✓
- `k` up to 1e9, values in `[-1e9, 2e9]` — Python ints, no overflow; O(n log n) fits n = 1e5.

Design and tests agree; finalize.
