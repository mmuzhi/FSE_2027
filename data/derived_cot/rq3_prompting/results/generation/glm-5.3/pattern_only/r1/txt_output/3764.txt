You are given a 2D integer matrix grid of size n x m, an integer array limits of length n, and an integer k. The task is to find the maximum sum of at most k elements from the matrix grid such that:

Output: 7

```python
class Solution:
    def maxSum(self, grid: List[List[int]], limits: List[int], k: int) -> int:
```
```python
        pool = []
        for row, lim in zip(grid, limits):
            if lim > 0:
```

=== ANSWER ===
Looking at this problem:

**Key observations:**
1. All grid values are non-negative (`0 <= grid[i][j]`), and `k <= sum(limits)` guarantees we can always pick k elements — so picking exactly k is never worse.
2. Any optimal solution never needs an element outside the top `limits[i]` of row i: if you pick a smaller element from row i while picking `c_i <= limits[i]` from that row, some element among the top `limits[i]` of row i is unpicked and at least as large — swap improves/keeps the sum (exchange argument).
3. Therefore: build a pool of the top `limits[i]` elements of each row; picking any subset of the pool automatically respects row limits. The answer is the sum of the k largest pool elements.

**Complexity:** n·m ≤ 250,000. Sorting rows: O(n·m·log m); pool sort/nlargest: O(S log S) with S ≤ n·m. Easily fast enough.

**Edge cases:** `k = 0` → 0; `limits[i] = 0` → contributes nothing (slice handles it).

**Verification with examples:**
- Ex1: pool = [2] ∪ [4,3] = [2,4,3]; top 2 = 7 ✓
- Ex2: pool = [7,5] ∪ [8,6] = [7,5,8,6]; top 3 = 21 ✓

```python
import heapq
from typing import List

class Solution:
```
