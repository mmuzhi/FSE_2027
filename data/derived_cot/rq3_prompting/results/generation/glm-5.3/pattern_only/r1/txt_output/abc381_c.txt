=== ANSWER ===
**Approach (committed):** For each '/' at index i, the longest 11/22 string centered there uses min(ones immediately before i, twos immediately after i) pairs, giving length 2·min+1. Precompute both counts with one forward and one backward scan — O(N) total.

**Invariant check:** `ones_before[i]` = consecutive '1's ending at i−1; `twos_after[i]` = consecutive '2's starting at i+1. A '/' always yields length ≥ 1, so the answer is at least 1 (guaranteed since S contains '/').

**Edge cases:** S = "/" → 1; "22/11" → min(0,0)+1 = 1 ✓; sample 1 gives 5 ✓ (verified by hand-trace above).

```python
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    s = data[1]

    ones_before = [0] * n
    c = 0
    for i in range(n):
        ones_before[i] = c
        c = c + 1 if s[i] == '1' else 0

    twos_after = [0] * n
    c = 0
    for i in range(n - 1, -1, -1):
        twos_after[i] = c
        c = c + 1 if s[i] == '2' else 0

    ans = 1
    for i in range(n):
        if s[i] == '/':
            ans = max(ans, 2 * min(ones_before[i], twos_after[i]) + 1)
    print(ans)

main()
```
