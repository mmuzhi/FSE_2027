There are N boxes.

You are also given two permutations P = (P_1, P_2, \ldots, P_N) and Q = (Q_1, Q_2, \ldots, Q_N) of (1, 2, \ldots, N).
Takahashi can repeat the following operation any number of times, possibly zero:

- Choose an integer 1 \leq i \leq N, and take all the balls from the i-th box into his hand.
- Put all the red balls in his hand into the P_i-th box.
- Put all the blue balls in his hand into the Q_i-th box.

Determine whether it is possible to achieve his goal, and if possible, print the minimum number of operations needed to achieve it.

Output

Constraints


- 2 \leq N \leq 2 \times 10^5
- 0 \leq A_i, B_i \leq 1
- 1 \leq P_i, Q_i \leq N
- P and Q are permutations of (1, 2, \ldots, N).
- 1 \leq X \leq N
- All input values are integers.

def main():

Looking at this problem:

**Key insights:**
1. A red ball at box `s` can only ever visit boxes on `s`'s cycle of permutation P. So every red ball must lie on the P-cycle containing X (call it `c_0=X, c_1, ..., c_{m-1}`), and every blue ball on the Q-cycle containing X (`e_0=X,...,e_{n-1}`), otherwise -1.
2. Operating X never helps (balls at X are already home; removing X-ops keeps any solution valid), so balls move monotonically forward along their cycle, never overshooting X.
3. A red ball at `c_i` succeeds iff the operation sequence contains ops on `c_i, c_{i+1}, ..., c_{m-1}` in increasing time order. Thus the red requirement is exactly: the word contains `S_R = (c_{dR},...,c_{m-1})` as a subsequence, where `dR` is the minimal index of a red ball outside X (the minimal ball's chain covers all others). Similarly for blue with `S_B`.
4. Conversely, any word containing both `S_R` and `S_B` as subsequences is valid (balls only move forward; extra ops never hurt). So the minimum number of operations = length of Shortest Common Supersequence of `S_R` and `S_B` = `|S_R| + |S_B| - LCS`.
5. Since both sequences have **distinct** elements, LCS = LIS of blue-positions of common boxes, taken in red order — computable in O(N log N).
