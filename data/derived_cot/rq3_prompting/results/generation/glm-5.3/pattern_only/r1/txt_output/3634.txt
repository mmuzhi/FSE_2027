```python
class Solution:
    def calculateScore(self, s: str) -> int:
        stacks = [[] for _ in range(26)]
        total = 0
        for i, ch in enumerate(s):
            c = ord(ch) - 97
            m = 25 - c
            if stacks[m]:
                total += i - stacks[m].pop()
            else:
                stacks[c].append(i)
        return total
```

**Commit:** For each letter, keep a stack of unmarked indices holding that letter. When processing index `i` with char `c`, the closest unmarked `j < i` with `s[j] == mirror(c)` is exactly the top of the mirror-letter's stack (indices are pushed in increasing order; popping on match preserves the "unmarked only" invariant). This gives an O(n) algorithm — the only plausible choice at n = 10⁵ (naive backward scanning risks O(n²)).

**Implementation ledger:**
- Invariant: `stacks[k]` contains exactly the unmarked indices `j < i` with `s[j] == chr(97+k)`, in increasing order.
- Mirror of letter index `c` is `25 - c` (no letter is its own mirror, so no self-match edge case).
- Edge cases: single char (score 0), empty mirror stack → push current index.
