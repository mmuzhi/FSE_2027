class Solution:
    def numberOfSubstrings(self, s: str, k: int) -> int:
        n = len(s)
        total = n * (n + 1) // 2
        cnt = [0] * 26
        bad = 0
        r = 0
        for l in range(n):
            while r < n and cnt[ord(s[r]) - 97] < k - 1:
                cnt[ord(s[r]) - 97] += 1
                r += 1
            bad += r - l
            if r > l:
                cnt[ord(s[l]) - 97] -= 1
            else:
                r = l + 1
        return total - bad

=== ANSWER ===
**Commit:** Count the complement with a sliding window. A substring is "bad" if every character appears at most k−1 times. For each left endpoint `l`, the maximal `r` keeping the window bad is non-decreasing in `l` (shrinking a bad window keeps it bad), so a two-pointer sweep counts all bad substrings in O(n). Answer = n(n+1)/2 − bad.

**Ledger:**
- Invariant: window `[l, r)` has all counts ≤ k−1, `r ≥ l`; extend `r` while `cnt[s[r]] < k−1`, add `r−l` bad substrings starting at `l`.
- Edge case k=1: window stays empty (`cnt < 0` never true), `bad = 0` — handled by advancing `r` past `l` when window empty.
- Verified on "abacb", k=2 → bad = 11, answer 15−11 = 4 ✓; k=1 → answer 15 ✓; "aaa", k=2 → 3 ✓.
