Implementation:

```python
class Solution:
    def maximumTotalSum(self, maximumHeight: List[int]) -> int:
        maximumHeight.sort(reverse=True)
        total = 0
        prev = float('inf')
        for m in maximumHeight:
            h = min(m, prev - 1)
            if h <= 0:
                return -1
            total += h
            prev = h
        return total
```

Invariant: assigned heights are strictly decreasing and each is the element-wise maximum possible k-th largest height (any valid assignment's k-th largest height is bounded by both the k-th largest cap and one less than the (k-1)-th largest height), so the greedy sum is optimal. Key edge cases: duplicates forcing the chain down to 0 (e.g. `[2,2,1]` → -1), and the first tower taking its full cap (`prev` initialized to infinity).
