=== ANSWER ===
**Commit:** The difference constraint means `copy[i] = copy[0] + (original[i] - original[0])`, so the whole array is determined by `x = copy[0]`. Each index i forces `x >= u_i - d_i` and `x <= v_i - d_i` where `d_i = original[i] - original[0]`. Intersect all intervals: `lo = max(u_i - d_i)`, `hi = min(v_i - d_i)`, answer = `max(0, hi - lo + 1)`. O(n) time.

**Ledger:** invariant — interval intersection on x; edge case — empty intersection returns 0 (verified on example 3: lo=3, hi=1 → 0; examples 1 and 2 give 2 and 4).

```python
class Solution:
    def countArrays(self, original: List[int], bounds: List[List[int]]) -> int:
        n = len(original)
        base = original[0]
        lo = bounds[0][0]
        hi = bounds[0][1]
        for i in range(1, n):
            d = original[i] - base
            lo = max(lo, bounds[i][0] - d)
            hi = min(hi, bounds[i][1] - d)
        return max(0, hi - lo + 1)
```
