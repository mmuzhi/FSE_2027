=== ANSWER ===
Looking at this problem:

- **Constraints**: N up to 3×10⁵, values bounded by N. Need O(N) or O(N log N).
- **Approach**: Precompute suffix distinct counts `suf[i]` = distinct count in `A[i..N-1]` with one right-to-left pass. Then sweep left-to-right maintaining running prefix distinct count; for each split point i (prefix `A[0..i]`, suffix `A[i+1..]`), candidate answer is prefix count + `suf[i+1]`. Take the max.

**Key invariant**: `suf[i]` computed by adding elements from the right, incrementing count only for first occurrences (tracked via boolean array indexed by value, valid since 1 ≤ A_i ≤ N).

**Edge case**: N=2 must yield 2 (1 distinct in each half) — the loop range covers i=0 only, giving `1 + suf[1] = 2`. ✓

Verified against both samples mentally:
- Sample 1: f=[1,2,3,3], g=[3,3,2,1] → max 5. ✓

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))

    # suf[i] = number of distinct integers in a[i..n-1]
    suf = [0] * (n + 1)
    seen = [False] * (n + 1)
    cnt = 0
    for i in range(n - 1, -1, -1):
        v = a[i]
        if not seen[v]:
            seen[v] = True
            cnt += 1
        suf[i] = cnt

    seen2 = [False] * (n + 1)
    ans = 0
    cnt = 0
    for i in range(n - 1):  # split: prefix a[0..i], suffix a[i+1..n-1]
        v = a[i]
        if not seen2[v]:
            seen2[v] = True
            cnt += 1
        total = cnt + suf[i + 1]
        if total > ans:
            ans = total
    print(ans)

main()
```
