=== ANSWER ===
**Approach.** Count is ≥ 2 iff a match exists and the greedy *leftmost* positional match differs from the greedy *rightmost* one. Justification: for any match P = (p_1<…<p_M), the greedy leftmost match L satisfies l_i ≤ p_i for all i (induction: l_i is the first occurrence of B_i after l_{i-1}, and p_i > p_{i-1} ≥ l_{i-1}), and symmetrically the greedy rightmost match R satisfies p_i ≤ r_i for all i. Hence L = R forces every match to equal L (exactly one match), while L ≠ R (with a match existing) gives two distinct matches directly. Both greeds run in O(N + M).

Verified against all three samples (e.g. sample 2: leftmost = rightmost = (0,1) → No; sample 1: (0,1) vs (2,3) → Yes). Edge case M = N: leftmost = rightmost = whole array → No, correct since at most one positional selection exists.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    A = list(map(int, data[2:2 + n]))
    B = list(map(int, data[2 + n:2 + n + m]))

    # Leftmost greedy match
    l = [-1] * m
    j = 0
    for i in range(n):
        if j < m and A[i] == B[j]:
            l[j] = i
            j += 1
            if j == m:
                break
    if j < m:
        print("No")
        return

    # Rightmost greedy match
    r = [-1] * m
    j = m - 1
    for i in range(n - 1, -1, -1):
        if j >= 0 and A[i] == B[j]:
            r[j] = i
            j -= 1
            if j < 0:
                break
    if j >= 0:
        print("No")
        return

    print("Yes" if l != r else "No")

main()
```
