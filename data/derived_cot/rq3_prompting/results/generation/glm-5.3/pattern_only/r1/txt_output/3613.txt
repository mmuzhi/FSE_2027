```python
class Solution:
    def maxAmount(self, initialCurrency: str, pairs1: List[List[str]], rates1: List[float], pairs2: List[List[str]], rates2: List[float]) -> float:
        from collections import deque
        
        def best_from(src, pairs, rates):
            # returns dict: currency -> max amount obtainable starting with 1.0 src
            # using conversions (both directions) in given pairs/rates
            adj = defaultdict(list)
            for (a, b), r in zip(pairs, rates):
                adj[a].append((b, r))
                adj[b].append((a, 1.0 / r))
            dist = {src: 1.0}
            dq = deque([src])

                u = dq.popleft()
                for v, r in adj[u]:

                        dist[v] = dist[u] * r
                        dq.append(v)
```

```python
from collections import deque, defaultdict
from typing import List

class Solution:
    def maxAmount(self, initialCurrency: str, pairs1: List[List[str]], rates1: List[float], pairs2: List[List[str]], rates2: List[float]) -> float:
        def products_from(src, pairs, rates):
            # Max amount of each currency obtainable from 1.0 unit of src,
            # given conversions a->b at r and b->a at 1/r.
            adj = defaultdict(list)
            for (a, b), r in zip(pairs, rates):
                adj[a].append((b, r))
                adj[b].append((a, 1.0 / r))
            best = {src: 1.0}
            dq = deque([src])
            while dq:
                u = dq.popleft()
                for v, r in adj[u]:
                    if v not in best:
                        best[v] = best[u] * r
                        dq.append(v)
            return best

        # Day 1: amount of each currency X we can hold after day 1.
        f = products_from(initialCurrency, pairs1, rates1)
        # Day 2: d2[X] = amount of X obtainable from 1.0 initialCurrency on day 2,
        # so 1 unit of X converts back to 1/d2[X] initialCurrency on day 2.
        d2 = products_from(initialCurrency, pairs2, rates2)

        ans = 0.0
        for cur, amt in f.items():
            if cur in d2:
                cand = amt / d2[cur]
                if cand > ans:
                    ans = cand
        return ans
```

Looking at this problem:

**Key insight:** The guarantees ("no contradictions or cycles", bounded output ≤ 5·10¹⁰) imply rates within each day are fully consistent — every undirected cycle has product exactly 1 (otherwise you could loop a profitable cycle infinitely). Therefore the exchange factor between any two currencies in a connected component is path-independent on a given day.

**Plan:**
1. **Day 1:** BFS/DFS from `initialCurrency` over the bidirectional graph (edge `a→b` rate `r`, `b→a` rate `1/r`) to get `f[X]` = amount of currency X held after day 1 (starting from 1.0). Path-independence makes first-visit assignment exact.
2. **Day 2:** Similarly compute `d2[X]` = amount of X obtainable from 1.0 `initialCurrency` on day 2. By consistency, converting 1 unit of X back to `initialCurrency` on day 2 yields exactly `1/d2[X]`.
3. **Answer:** `max over X of f[X] / d2[X]` (X must be reachable in both days' components; `initialCurrency` itself gives 1.0, matching "do nothing").

**Verification against examples:**
- Ex 1: f = {EUR:1, USD:2, JPY:6}, d2 = {EUR:1, CHF:1/6, USD:1/30, JPY:1/120} → max(1, 60, 720) = 720 ✓
- Ex 2: f = {NGN:1, EUR:9}, d2 = {NGN:1, EUR:6} → max(1, 1.5) = 1.5 ✓
- Ex 3: f = {USD:1, EUR:1}, d2 = {USD:1} (USD absent from day-2 pairs) → 1.0 ✓

Edge cases: `initialCurrency` isolated in either graph (seeded with 1.0 in both BFS dicts, so answer ≥ 1.0 always holds); duplicate pairs/multi-paths (consistency makes first-visit value exact); precision (≤20 multiplications of doubles, output ≤ 5·10¹⁰ — fine).
