You will be given a competitive programming problem.
You are given two strings S and T consisting of lowercase English letters. Here, S and T have equal lengths.
Let X be an empty array, and repeat the following operation until S equals T:

- Change one character in S, and append S to the end of X.

 What is lexicographical order on arrays of strings?
A string S = S_1 S_2 \ldots S_N of length N is lexicographically smaller than a string T = T_1 T_2 \ldots T_N of length N if there exists an integer 1 \leq i \leq N such that both of the following are satisfied:

-  S_1 S_2 \ldots S_{i-1} = T_1 T_2 \ldots T_{i-1}
-  S_i comes earlier than T_i in alphabetical order.

An array of strings X = (X_1,X_2,\ldots,X_M) with M elements is lexicographically smaller than an array of strings Y = (Y_1,Y_2,\ldots,Y_M) with M elements if there exists an integer 1 \leq j \leq M such that both of the following are satisfied:

-  (X_1,X_2,\ldots,X_{j-1}) = (Y_1,Y_2,\ldots,Y_{j-1})
-  X_j is lexicographically smaller than Y_j.

**Analysis:** The minimum number of operations is exactly D = number of positions where S and T differ (each op fixes one differing position to T's character). For lexicographic minimality of X, greedy per step:

- Changing position i (with S[i]≠T[i]) to T[i] yields a string differing from S only at i.
- If T[i] < S[i], the result is smaller than S; any such "decreasing" change beats any "increasing" one (T[i] > S[i]) regardless of position, and among decreasing changes the leftmost position is best.
- If no decreasing change exists, pick the rightmost differing position to minimize the increase.

Any order of fixing positions is valid, so committing greedily to the smallest next string is optimal (fixed-length array, standard lexicographic greedy).

```python
import sys

def main():
    data = sys.stdin.read().split()
    S = list(data[0])
    T = list(data[1])
    n = len(S)
    res = []
    while S != T:
        pos = -1
        # leftmost position where changing decreases the string
        for i in range(n):
            if S[i] != T[i] and S[i] > T[i]:
                pos = i
                break
        if pos == -1:
            # no decreasing change; take rightmost differing position
            for i in range(n - 1, -1, -1):
                if S[i] != T[i]:
                    pos = i
                    break
        S[pos] = T[pos]
        res.append(''.join(S))
    out = [str(len(res))]
    out.extend(res)
    print('\n'.join(out))

main()
```
