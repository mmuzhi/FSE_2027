You will be given a competitive programming problem.
You are given integers N, M and three integer sequences of length M: X = (X_1, X_2, \ldots, X_M), Y = (Y_1, Y_2, \ldots, Y_M), and Z = (Z_1, Z_2, \ldots, Z_M). It is guaranteed that all elements of X and Y are between 1 and N, inclusive.
We call a length-N sequence of non-negative integers A = (A_1, A_2, \ldots, A_N) a good sequence if and only if it satisfies the following condition:

- For every integer i with 1 \le i \le M, the XOR of A_{X_i} and A_{Y_i} is Z_i.

Determine whether a good sequence A=(A_1,A_2,\ldots,A_N) exists, and if it exists, find one good sequence that minimizes the sum of its elements \displaystyle \sum_{i=1}^N A_i.

Notes on XOR

For non-negative integers A and B, their XOR A \oplus B is defined as follows:


- In the binary representation of A \oplus B, the digit in the place corresponding to 2^k \,(k \ge 0) is 1 if and only if exactly one of the digits in the same place of A and B is 1; otherwise, it is 0.


For example, 3 \oplus 5 = 6 (in binary: 011 \oplus 101 = 110).

Input

The input is given from Standard Input in the following format:
N M
X_1 Y_1 Z_1
X_2 Y_2 Z_2
\vdots
X_M Y_M Z_M

Output

If no good sequence exists, print -1.
If a good sequence exists, print one good sequence that minimizes the sum of its elements, separated by spaces.
If there are multiple good sequences with the same minimum sum, printing any of them is accepted.

Constraints


- 1 \le N \le 2\times 10^5
- 0 \le M \le 10^5
- 1 \le X_i, Y_i \le N
- 0 \le Z_i \le 10^9
- All input values are integers.

Looking at this problem:

- Constraints are XOR relations → weighted DSU (potential = XOR to parent). Union/validate with `w[rx] = wx ^ wy ^ z`; cycle check `wx ^ wy == z`, else `-1`.
- After building, each component's values are `A_v = t ^ p_v` where `p_v` = XOR to root, `t = A_root` free. Bits are independent: for bit k, choosing `t`'s bit gives `cnt1` or `cnt0` ones; pick the smaller (root bit = 1 iff `2*cnt1 > size`). Since `Z ≤ 1e9 < 2^30`, 30 bits suffice.
- Count bits per component with numpy `bincount` per bit (fast); pure-Python fallback included.

Verified against all three samples (sample 1 → `0 3 4`, sample 2 → `-1`, sample 3 → `0 2 9 6 0`).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); M = int(data[1])
    parent = list(range(N + 1)); weight = [0] * (N + 1); size = [1] * (N + 1)

    def find(v):
        par = parent; wgt = weight
        path = []
        while par[v] != v:
            path.append(v); v = par[v]
        r = v; acc = 0
        for u in reversed(path):
            acc ^= wgt[u]; par[u] = r; wgt[u] = acc
        return r, acc

    idx = 2
    for _ in range(M):
        x = int(data[idx]); y = int(data[idx + 1]); z = int(data[idx + 2]); idx += 3
        rx, wx = find(x); ry, wy = find(y)
        if rx == ry:
            if (wx ^ wy) != z:
                sys.stdout.write("-1\n"); return
        else:
            w = wx ^ wy ^ z
            if size[rx] < size[ry]:
                parent[rx] = ry; weight[rx] = w; size[ry] += size[rx]
            else:
                parent[ry] = rx; weight[ry] = w; size[rx] += size[ry]

    root_of = [0] * (N + 1); p = [0] * (N + 1)
    for v in range(1, N + 1):
        r, w = find(v); root_of[v] = r; p[v] = w

    try:
        import numpy as np
        p_arr = np.array(p[1:], dtype=np.int64)
        root_arr = np.asarray(root_of[1:], dtype=np.int64)
        uniq, inv = np.unique(root_arr, return_inverse=True)
        inv = inv.astype(np.int64).ravel()
        C = int(uniq.shape[0])
        sizes = np.bincount(inv, minlength=C).astype(np.int64)
        root_vals = np.zeros(C, dtype=np.int64)
        for k in range(30):
            cnt1 = np.bincount(inv, weights=((p_arr >> k) & 1), minlength=C)
            root_vals += np.where(cnt1 * 2 > sizes, np.int64(1 << k), np.int64(0)).astype(np.int64)
        A_arr = root_vals[inv] ^ p_arr
        out = ' '.join(map(str, A_arr.tolist()))
    except ImportError:
        from collections import defaultdict
        comp = defaultdict(list)
        for v in range(1, N + 1):
            comp[root_of[v]].append(p[v])
        root_val = {}
        for r, vals in comp.items():
            n = len(vals); rv = 0
            for k in range(30):
                bit = 1 << k; c = 0
                for pv in vals:
                    if pv & bit:
                        c += 1
                if 2 * c > n:
                    rv |= bit
            root_val[r] = rv
        out = ' '.join(str(root_val[root_of[v]] ^ p[v]) for v in range(1, N + 1))
    sys.stdout.write(out + '\n')

main()
```
