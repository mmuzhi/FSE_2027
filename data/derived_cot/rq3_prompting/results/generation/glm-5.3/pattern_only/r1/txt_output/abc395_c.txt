```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = data[1:1+n]
    last = {}
    ans = float('inf')
    for i, x in enumerate(a):
        if x in last:
            d = i - last[x] + 1

        last[x] = i
```

=== ANSWER ===
Looking at this problem:

**Key insight:** A subarray has a repeated value iff it contains two equal values. The shortest such subarray must have equal values at its two endpoints (otherwise it could be shrunk). For each value, the best pair of occurrences to use is a *consecutive* pair (minimizing span). So the answer is the minimum over all consecutive occurrence pairs (i, j) of the same value of j - i + 1.

**Plan:** Single left-to-right pass with a dict `last` mapping value → most recent index. For each i, if A[i] was seen before at index p, candidate answer is i - p + 1; then update last[A[i]] = i. If nothing repeats, print -1.

**Ledger:**
- Invariant: `last[x]` = most recent index of x before current position, so each candidate is exactly the shortest repeat-ending subarray at i.
- Edge cases: N=1 → -1; all distinct → -1.
- Verified against all three samples (4, -1, 2).

Complexity O(N), fine for N ≤ 2·10⁵.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = data[1:1 + n]
    last = {}
    ans = float('inf')
    for i, x in enumerate(a):
        p = last.get(x)
        if p is not None:
            d = i - p + 1
            if d < ans:
                ans = d
        last[x] = i
    print(ans if ans != float('inf') else -1)

main()
```
