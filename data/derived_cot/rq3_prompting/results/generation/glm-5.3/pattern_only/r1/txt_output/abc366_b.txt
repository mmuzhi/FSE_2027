=== ANSWER ===
**Commit:** The problem is a grid transposition. Place strings as rows from top to bottom in reverse input order (S_N on top, ..., S_1 at bottom), pad each row with `*` to the max length M, then each T_j is column j with trailing `*` stripped. Complexity O(N·M) ≤ 10⁴ — trivial.

**Invariant:** Row r (top-indexed) is S_{N-r+1}; column j read top-to-bottom gives T_j; stripping only trailing `*` guarantees T_j ends with a letter and satisfies the "does not exist or is `*`" condition for shorter strings.

**Edge cases:** A column always contains at least one letter (some string has length M), so `rstrip('*')` never empties a line. Verified against both samples mentally (e.g. sample 1 column 4: `i`,`*`,`*` → `i`; sample 2 column 8: `*`,`r`,`*` → `*r`).

```python
n = int(input())
s = [input() for _ in range(n)]
m = max(map(len, s))
out = []
for j in range(m):
    col = ''.join(s[i][j] if j < len(s[i]) else '*' for i in range(n - 1, -1, -1))
    out.append(col.rstrip('*'))
print('\n'.join(out))
```
