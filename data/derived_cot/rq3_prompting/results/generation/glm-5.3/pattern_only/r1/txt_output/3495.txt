Let me analyze this problem.

We need to process queries one by one. Each query adds an obstacle. After each addition, we need to find the k-th nearest obstacle from the origin (distance = |x| + |y|), or -1 if fewer than k obstacles.

Constraints: queries.length up to 2*10^5, k up to 10^5.

Approach: Use a max-heap of size k. Maintain the k smallest distances in a max-heap. When adding a new distance:
- If heap size < k, push the distance. If heap size == k after push, the top of the max-heap is the k-th smallest.
- Else, if new distance < heap top, pop top and push new distance. The new top is the k-th smallest.
- Answer is heap top if heap size == k, else -1.

Python's heapq is a min-heap, so we store negated distances for a max-heap.

Implementation:

```python
import heapq
from typing import List

class Solution:
    def resultsArray(self, queries: List[List[int]], k: int) -> List[int]:
        heap = []  # max-heap via negation, holds k smallest distances
        results = []
        for x, y in queries:
            d = abs(x) + abs(y)
            if len(heap) < k:
                heapq.heappush(heap, -d)
                if len(heap) == k:
                    results.append(-heap[0])
                else:
                    results.append(-1)
            else:
                if d < -heap[0]:
                    heapq.heapreplace(heap, -d)
                results.append(-heap[0])
        return results
```

```python
import heapq
from typing import List

class Solution:
    def resultsArray(self, queries: List[List[int]], k: int) -> List[int]:
        # Max-heap (via negation) holding the k smallest distances seen so far.
        # Invariant: if len(heap) == k, then -heap[0] is the k-th smallest distance.
        heap = []
        results = []
        for x, y in queries:
            d = abs(x) + abs(y)
            if len(heap) < k:
                heapq.heappush(heap, -d)
                results.append(-heap[0] if len(heap) == k else -1)
            else:
                if d < -heap[0]:
                    heapq.heapreplace(heap, -d)
                results.append(-heap[0])
        return results
```
