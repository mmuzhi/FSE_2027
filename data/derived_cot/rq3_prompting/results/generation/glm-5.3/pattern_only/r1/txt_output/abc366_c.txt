- **Constraints:** Q ≤ 2×10⁵, x ≤ 10⁶ → need O(Q) processing with fast I/O.
- **Approach (single viable one):** maintain a count array indexed by x plus a running `distinct` counter = number of x with count > 0. Type 1: if count was 0, increment `distinct`, then increment count. Type 2: decrement count, if it hits 0, decrement `distinct`. Type 3: print `distinct`.
- **Invariant:** `distinct` always equals the number of integers present with positive count.
- **Edge case:** removing the *last* copy of x must decrement `distinct` (verified against Sample 2 where two copies of 2 exist and only one removal keeps distinct unchanged).
