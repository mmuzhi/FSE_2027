class Solution:
    def countGoodArrays(self, n: int, m: int, k: int) -> int:
        MOD = 10**9 + 7
        # answer = C(n-1, k) * m * (m-1)^(n-k-1)
        # Precompute factorials up to n-1
        maxN = n
        fact = [1] * (maxN + 1)
        for i in range(1, maxN + 1):
            fact[i] = fact[i-1] * i % MOD
        inv_fact = [1] * (maxN + 1)
        inv_fact[maxN] = pow(fact[maxN], MOD - 2, MOD)
        for i in range(maxN, 0, -1):
            inv_fact[i-1] = inv_fact[i] * i % MOD

            if b < 0 or b > a:
                return 0
            return fact[a] * inv_fact[b] % MOD * inv_fact[a-b] % MOD
        
        ans = comb(n-1, k) * (m % MOD) % MOD
        ans = ans * pow(m - 1, n - k - 1, MOD) % MOD
        return ans

**Commit:** The structure of the array is determined by which of the n−1 adjacent gaps are "equal" (k of them) — choose them with C(n−1, k). This splits the array into n−k blocks: first block has m value choices, each subsequent block must differ from its predecessor, giving (m−1) choices each. So the answer is **C(n−1, k) · m · (m−1)^(n−k−1) mod 1e9+7**.

**Ledger:**
- Invariant: gap pattern ↔ block structure is a bijection; consecutive-block values must differ.
- Edge cases: k = n−1 (exponent 0, pow(0,0)=1 in Python handles m=1); m=1 with k<n−1 gives factor 0 correctly; n=1 forces k=0.

**Recheck against examples:**
- n=3,m=2,k=1: C(2,1)·2·1^1 = 4 ✓
- n=4,m=2,k=2: C(3,2)·2·1^1 = 6 ✓
- n=5,m=2,k=0: C(4,0)·2·1^4 = 2 ✓
