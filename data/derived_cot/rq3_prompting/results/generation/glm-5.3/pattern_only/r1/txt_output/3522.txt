class Solution:
    def resultsArray(self, nums: List[int], k: int) -> List[int]:
        n = len(nums)

=== ANSWER ===
Looking at this problem: a window of size k starting at i is "good" iff every adjacent pair satisfies nums[j+1] == nums[j] + 1. The max of such a strictly ascending run is simply the last element nums[i+k-1].

**Decisive approach:** Precompute `cnt[i]` = length of the consecutive-ascending run ending at index i (i.e., `cnt[i] = cnt[i-1]+1` if `nums[i] == nums[i-1]+1`, else 1). Window starting at i of size k is good iff `cnt[i+k-1] >= k`, and then the answer is `nums[i+k-1]`. This is O(n) time/space.

**Ledger:**
- Invariant: `cnt[i]` counts run length ending exactly at i.
- Edge case: k=1 → cnt[i] >= 1 always → answer nums[i] (correct: single element is trivially valid).
- Key check: validity uses the run length at the window's *right* endpoint, not the left.

**Recheck with Example 3** ([3,2,3,2,3,2], k=2): cnt = [1,1,2,1,2,1] → results [-1,3,-1,3,-1] ✓. Example 1: cnt=[1,2,3,4,1,1,1] → [3,4,-1,-1,-1] ✓. Example 2: cnt all 1s, k=4 → [-1,-1] ✓.

class Solution:
    def resultsArray(self, nums: List[int], k: int) -> List[int]:

        cnt = [1] * n
        for i in range(1, n):
