So skipping is global — positions 0, 2, 4, ... in the full zigzag order.

Interesting observation: in the zigzag order, the position index of cell (i, j):
- If i is even (row traversed L→R): index = i * cols + j.
- If i is odd (row traversed R→L): index = i * cols + (cols - 1 - j).

We keep cells where index % 2 == 0.

For even row i: j must be even (since i*cols parity depends on cols... wait, index = i*cols + j, index even means i*cols + j even).
For odd row i: index = i*cols + cols - 1 - j, even means (i+1)*cols - 1 - j even, i.e., (i+1)*cols - 1 - j ≡ 0 mod 2.

But the simplest approach given tiny constraints (50x50 max) is just to build the full zigzag sequence and take every other element. O(n*m) time and space, trivially fine.

Plan:
1. Build traversal order list.
2. Return traversal[::2].

Implementation:

```python
class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        order = []
        for i, row in enumerate(grid):
            if i % 2 == 0:
                order.extend(row)
            else:
                order.extend(row[::-1])
        return order[::2]
```

=== ANSWER ===
```python
class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        order = []
        for i, row in enumerate(grid):
            if i % 2 == 0:
                order.extend(row)
            else:
                order.extend(reversed(row))
        return order[::2]
```
