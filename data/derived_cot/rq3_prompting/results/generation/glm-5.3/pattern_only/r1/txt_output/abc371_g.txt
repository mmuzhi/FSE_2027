You will be given a competitive programming problem.
You are given permutations P = (P_1, P_2, \ldots, P_N) and A = (A_1, A_2, \ldots, A_N) of (1,2,\ldots,N).
You can perform the following operation any number of times, possibly zero:

- replace A_i with A_{P_i} simultaneously for all i=1,2,\ldots,N.

Print the lexicographically smallest A that can be obtained.
What is lexicographical order?
 For sequences of length N, A = (A_1, A_2, \ldots, A_N) and B = (B_1, B_2, \ldots, B_N), A is lexicographically smaller than B if and only if:

- there exists an integer i\ (1\leq i\leq N) such that A_i < B_i, and A_j = B_j for all 1\leq j < i.

Input

The input is given from Standard Input in the following format:
N
P_1 P_2 \ldots P_N
A_1 A_2 \ldots A_N

Output

Let (A_1, A_2, \ldots, A_N) be the lexicographically smallest A that can be obtained. Print A_1, A_2, \ldots, A_N in this order, separated by spaces, in one line.

Constraints


- 1\leq N\leq2\times10^5
- 1\leq P_i\leq N\ (1\leq i\leq N)
- P_i\neq P_j\ (1\leq i<j\leq N)
- 1\leq A_i\leq N\ (1\leq i\leq N)
- A_i\neq A_j\ (1\leq i<j\leq N)
- All input values are integers.

```python
import sys
from math import gcd

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    P = [int(x) - 1 for x in data[1:1 + n]]
    A = [int(x) for x in data[1 + n:1 + 2 * n]]

    visited = [False] * n
    cycles = []
    for i in range(n):
        if visited[i]:
            continue
        cyc = []
        cur = i
        while not visited[cur]:
            visited[cur] = True
            cyc.append(cur)
            cur = P[cur]
        cycles.append(cyc)

    M = 1
    k = 0
    for cyc in cycles:
        L = len(cyc)
        if L == 1:
            continue
        avals = [A[c] for c in cyc]
        g = gcd(M, L)
        base = k % g
        # choose r in [0, L), r ≡ base (mod g), minimizing avals[r]
        best_r = base
        best_val = avals[base]
        for r in range(base + g, L, g):
            v = avals[r]
            if v < best_val:
                best_val = v
                best_r = r
        Lg = L // g
        if Lg > 1:
            diff = (best_r - k) // g
            Mg = (M // g) % Lg
            inv = pow(Mg, -1, Lg)
            t = (diff % Lg) * inv % Lg
            k += M * t
            M *= Lg

    B = [0] * n
    for cyc in cycles:
        L = len(cyc)
        s = k % L
        if s == 0:
            for c in cyc:
                B[c] = A[c]
        else:
            vals = [A[c] for c in cyc]
            rot = vals[s:] + vals[:s]
            for idx, c in enumerate(cyc):
                B[c] = rot[idx]

    sys.stdout.write(' '.join(map(str, B)))

main()
```

=== ANSWER ===
**Approach.** After `k` operations, `B_i = A[P^k(i)]`. Positions split into cycles of `P`; within a cycle of length `L` written as `c_0, c_1, ..., c_{L-1}` (with `c_{t+1}=P(c_t)`), we get `B_{c_j} = A_{c_{(j+k) mod L}}`. All cycles rotate by the **same** `k`, so we do a lexicographic greedy over positions `1..N`:

- Maintain the candidate set as a single residue class `k ≡ k_cur (mod M)` where `M` = lcm of lengths of already-fixed cycles.
- When first meeting a new cycle (at its smallest index `c_0`), the achievable shifts are residues `r ≡ k_cur (mod g)` with `g = gcd(M,L)`. Since `A` has distinct values, the value `A_{c_r}` has a unique minimum among those — pick that `r` (total scanning work ≤ N).
- Merge `k ≡ r (mod L)` with the old constraint via CRT (compatible by construction), updating `M ← lcm(M,L)` (kept as a Python big int; CRT arithmetic is cheap).

At the end, any representative `k` works; output `A` rotated by `k mod L` inside each cycle. Verified against all three samples (sample 3 yields `k = 245` with cycles of lengths 13, 11, 2).
