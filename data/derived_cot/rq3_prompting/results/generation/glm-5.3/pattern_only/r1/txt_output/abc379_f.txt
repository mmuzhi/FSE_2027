You will be given a competitive programming problem.
There are N buildings, building 1, building 2, \ldots, building N, arranged in this order in a straight line from west to east. Building 1 is the westernmost, and building N is the easternmost. The height of building i\ (1\leq i\leq N) is H_i.
For a pair of integers (i,j)\ (1\leq i\lt j\leq N), building j can be seen from building i if the following condition is satisfied.

- There is no building taller than building j between buildings i and j. In other words, there is no integer k\ (i\lt k\lt j) such that H_k > H_j.

You are given Q queries. In the i-th query, given a pair of integers (l_i,r_i)\ (l_i\lt r_i), find the number of buildings to the east of building r_i (that is, buildings r_i + 1, r_i + 2, \ldots, N) that can be seen from both buildings l_i and r_i.

Input

The input is given from Standard Input in the following format:
N Q
H_1 H_2 \ldots H_N
l_1 r_1
l_2 r_2
\vdots
l_Q r_Q

Output

Print Q lines. The i-th line (1 \leq i \leq Q) should contain the answer to the i-th query.

Constraints


- 2 \leq N \leq 2 \times 10^5
- 1 \leq Q \leq 2 \times 10^5
- 1 \leq H_i \leq N
- H_i\neq H_j\ (i\neq j)
- 1 \leq l_i < r_i \leq N
- All input values are integers.

Looking at this problem:

**Key reduction:** Building $j$ (for $j>i$) is visible from $i$ iff the nearest previous greater element $pg(j)$ (largest $k<j$ with $H_k>H_j$, or 0 if none) satisfies $pg(j)\le i$. Since queries have $l<r<j$, visibility from $l$ ($pg(j)\le l$) automatically implies visibility from $r$ ($pg(j)\le r$). So the answer for $(l,r)$ is simply $|\{j : j>r,\ pg(j)\le l\}|$ — a 2D dominance count.

**Algorithm:** Compute $pg$ with a monotonic stack in $O(N)$. Then offline: process queries sorted by $r$ descending, inserting points $j$ (at Fenwick index $pg(j)+1$) for $j=N,N-1,\dots,r+1$, and answer each query as the BIT prefix sum up to $l+1$. Total $O((N+Q)\log N)$.

I verified this against both samples by hand (e.g., sample 1: $pg=[\_,0,1,0,3,0]$ gives answers 2,0,1; sample 2 all 10 match), including tracing the BIT/pointer mechanics. Edge cases: $r=N$ gives 0 (tree empty when processed first), $pg=0$ handled via index shift.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); Q = int(data[1])
    H = list(map(int, data[2:2 + N]))

    # pg[j] (1-based j): nearest index k < j with H_k > H_j, or 0 if none.
    pg = [0] * (N + 1)
    st = []
    for j in range(N):
        h = H[j]
        while st and H[st[-1]] < h:
            st.pop()
        if st:
            pg[j + 1] = st[-1] + 1
        st.append(j)

    m = 2 + N
    vals = list(map(int, data[m:m + 2 * Q]))
    buckets = [[] for _ in range(N + 1)]
    for i in range(Q):
        l = vals[i + i]
        r = vals[i + i + 1]
        buckets[r].append((l, i))

    tree = [0] * (N + 1)
    ans = [0] * Q
    p = N
    for r in range(N, 1, -1):
        while p > r:
            k = pg[p] + 1
            while k <= N:
                tree[k] += 1
                k += k & (-k)
            p -= 1
        for l, i in buckets[r]:
            k = l + 1
            s = 0
            while k:
                s += tree[k]
                k -= k & (-k)
            ans[i] = s

    sys.stdout.write('\n'.join(map(str, ans)) + '\n')

main()
