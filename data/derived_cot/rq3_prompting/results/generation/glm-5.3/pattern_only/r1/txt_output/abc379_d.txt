Let me analyze this problem.

We have Q queries (up to 2×10^5). Type 1: add a plant with height 0. Type 2 T: all plants grow by T. Type 3 H: harvest all plants with height ≥ H, output count.

Standard approach: maintain a global "time offset" `elapsed` = total T so far. Each plant is stored by its planting time (or equivalently, its height at time 0 would be... actually store the planting time; current height = elapsed - plant_time). Type 3 H: harvest plants with elapsed - plant_time ≥ H, i.e., plant_time ≤ elapsed - H. So we need to count and remove all planted times ≤ elapsed - H.

Since plants are planted in increasing time order (planting takes zero time, so all plants planted at the same elapsed moment have the same plant_time), we can maintain a deque (or queue) of plant times, sorted in non-decreasing order. Type 1: append current elapsed. Type 3 H: pop from the front while front ≤ elapsed - H, counting. Each plant added/removed once → O(Q) total.

Use collections.deque. Since multiple plants can be planted at the same elapsed time, popping from left while condition holds works because the deque is sorted by plant time (non-decreasing since elapsed only increases and appends happen in chronological order).

Edge case: elapsed - H could be negative; since plant_time ≥ 0, nothing harvested — the condition front ≤ elapsed - H handles this naturally.

Also H can be up to 10^9, T up to 10^9, Q up to 2×10^5, so elapsed up to 2×10^14 — fine in Python.

Implementation: read input fast with sys.stdin.

Code:

```python
import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    q = int(data[0])
    idx = 1
    elapsed = 0
    plants = deque()
    out = []
    for _ in range(q):
        t = data[idx]; idx += 1
        if t == b'1':
            plants.append(elapsed)
        elif t == b'2':
            elapsed += int(data[idx]); idx += 1
        else:
            h = int(data[idx]); idx += 1
            threshold = elapsed - h
            cnt = 0
            while plants and plants[0] <= threshold:
                plants.popleft()
                cnt += 1
            out.append(cnt)
    sys.stdout.write('\n'.join(map(str, out)) + '\n')

main()
```
