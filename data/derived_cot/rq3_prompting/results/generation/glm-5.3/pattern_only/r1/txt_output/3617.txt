Code:

```python
class Solution:
    def possibleStringCount(self, word: str) -> int:
        n = len(word)
        total = 1
        i = 0
        while i < n:
            j = i
            while j < n and word[j] == word[i]:
                j += 1
            total += (j - i) - 1
            i = j
        return total
```

=== ANSWER ===
```python
class Solution:
    def possibleStringCount(self, word: str) -> int:
        # Each adjacent equal pair marks one spot where a character could
        # have been over-typed; for a run of length L there are L-1 such
        # pairs, matching the L-1 shorter original runs (down to length 1).
        # Add 1 for the case of no long press at all.
        return 1 + sum(word[i] == word[i - 1] for i in range(1, len(word)))
```
