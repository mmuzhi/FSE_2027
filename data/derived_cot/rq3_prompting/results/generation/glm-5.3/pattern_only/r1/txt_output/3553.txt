```python
class Solution:
    def checkTwoChessboards(self, coordinate1: str, coordinate2: str) -> bool:
        # A square's color depends on the parity of (column index + row number).
        # Both squares share a color iff these parities match.
        color1 = (ord(coordinate1[0]) - ord('a')) + int(coordinate1[1])
        color2 = (ord(coordinate2[0]) - ord('a')) + int(coordinate2[1])
        return color1 % 2 == color2 % 2
```
