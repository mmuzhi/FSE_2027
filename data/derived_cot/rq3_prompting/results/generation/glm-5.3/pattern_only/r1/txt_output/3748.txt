        n = len(grid)

Looking at this problem:

- Diagonals are those with constant `i - j` (top-left to bottom-right direction).
- Reading each diagonal from its top-left end: diagonals with `i - j >= 0` (bottom-left triangle + middle) must be non-increasing → sort descending and write back from the start cell `(d, 0)`. Diagonals with `j - i > 0` (top-right) must be non-decreasing → sort ascending and write back from `(0, d)`.

**Verification with Example 1:** main diagonal `[1,8,6]` → desc `[8,6,1]` placed at (0,0),(1,1),(2,2); `[7,2]` → asc `[2,7]` at (0,1),(1,2) → matches `[[8,2,3],[9,6,7],[4,5,1]]`. Example 2: `[0,2]` → `[2,0]` → `[[2,1],[1,0]]`. ✓

Edge cases: `n=1` (single element loop still works), duplicates and negatives handled by sorting. Complexity O(n² log n), trivial for n ≤ 10.

```python
class Solution:
    def sortMatrix(self, grid: List[List[int]]) -> List[List[int]]:
        n = len(grid)

        def get_diagonal(si, sj):
            vals = []
            i, j = si, sj
            while i < n and j < n:
                vals.append(grid[i][j])
                i += 1
                j += 1
            return vals

        def set_diagonal(si, sj, vals):
            i, j, k = si, sj, 0
            while i < n and j < n:
                grid[i][j] = vals[k]
                i += 1
                j += 1
                k += 1

        # Bottom-left triangle + middle diagonal (i - j >= 0): non-increasing
        for d in range(n):
            vals = get_diagonal(d, 0)
            vals.sort(reverse=True)
            set_diagonal(d, 0, vals)

        # Top-right triangle (j - i > 0): non-decreasing
        for d in range(1, n):
            vals = get_diagonal(0, d)
            vals.sort()
            set_diagonal(0, d, vals)

        return grid
```
