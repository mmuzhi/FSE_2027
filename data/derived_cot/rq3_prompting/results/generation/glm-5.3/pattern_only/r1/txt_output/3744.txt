```python
class Solution:
    def minOperations(self, queries: List[List[int]]) -> int:
        # Precompute boundaries: pow4[k] = 4^k
        pow4 = [4 ** k for k in range(20)]  # pow4[0]=1
        total = 0
        for l, r in queries:
            S = 0
            for k in range(1, 20):
                if 4 ** (k - 1) > r:
                    break
                lo = max(l, pow4[k - 1])
                hi = min(r, pow4[k] - 1)
                if lo <= hi:
                    S += k * (hi - lo + 1)
            total += (S + 1) // 2
        return total
```

Looking at this problem:

- For a single value x, the number of floor-divisions by 4 to reach 0 is `steps(x) = k` where `4^(k-1) <= x < 4^k` (number of base-4 digits).
- Each operation applies one division to each of two elements, so total operations ≥ ceil(S/2) where S = sum of steps over the range. Since the range is contiguous with at least 2 elements, the second-largest element has steps ≥ m−1 (where m = steps(r)), so S ≥ 2m−1 and ceil(S/2) ≥ m — the pairing bound is always achievable (pair positive elements while S ≥ 2; for S = 1 pair with any zero element).
- So answer per query = ceil(S/2), where S is computed by counting, for each k, how many numbers in [l, r] fall in [4^(k-1), 4^k − 1]. Since r ≤ 10^9 < 4^15, k goes up to ~16.

Verification with examples:
- [1,2]: steps = 1+1 = 2 → 1 op. [2,4]: 1+1+2 = 4 → 2 ops. Sum = 3 ✓
- [2,6]: 1+1+2+2+2 = 8 → 4 ops ✓

Complexity: O(17) per query, fine for 10^5 queries.
