There are N foods, each containing exactly one of vitamins 1, 2, and 3.

Find the maximum possible value of this: the minimum intake among vitamins 1, 2, and 3.

Input

N X

=== ANSWER ===
Looking at this problem:

- **Key structure**: Each food gives exactly one vitamin, so the three vitamins are independent knapsacks. For each vitamin v, compute `f_v[c]` = max units of vitamin v with calorie budget ≤ c (0/1 knapsack, calories 0..X).
- **Answer**: Maximize t such that `mincost_1(t) + mincost_2(t) + mincost_3(t) ≤ X`, where `mincost_v(t)` = smallest c with `f_v[c] ≥ t`. Since this sum is non-decreasing in t, binary search on t (t can be up to ~10⁹, so direct iteration is out).
- **Complexity**: Knapsack is O(N·X) = 25M — vectorized per-item with numpy slicing (`dp[c:] = max(dp[c:], dp[:X+1-c] + a)` — reading the shifted copy makes it a correct one-shot 0/1 update). Binary search costs ~30 iterations of 3 `searchsorted` calls.

Edge cases: a vitamin with no foods → `f_v` all zeros → answer 0 (matches sample 2). Verified sample 1 by hand: t=3 costs 5+5+10=20 ≤ 25, t=4 costs 30 > 25 → answer 3. ✓
