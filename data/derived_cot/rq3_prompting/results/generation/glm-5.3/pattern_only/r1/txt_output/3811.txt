=== ANSWER ===
```python
class Solution:
    def reverseDegree(self, s: str) -> int:
        # Reversed alphabet value of char c: 'a'->26 ... 'z'->1, i.e. 123 - ord(c)
        # Multiply by 1-indexed position and sum.
        return sum((123 - ord(c)) * i for i, c in enumerate(s, start=1))
```
