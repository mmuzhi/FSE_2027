from math import lcm

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); k = int(data[1])
    L = lcm(*range(1, 51))
    funcs = []

            v = a * dp[j-1] + b

Looking at this problem:

**Key insight (exchange argument):** For two adjacent functions a (outer) and b (inner), the total x-coefficient is the product of all A's regardless of order, so only the constant term changes when swapping. Comparing `B_a + A_a·B_b` (a outer) vs `B_b + A_b·B_a` (b outer), a should be outer iff `(A_a-1)/B_a ≥ (A_b-1)/B_b`. This is a total order (B > 0), so for any fixed chosen set, the optimal order sorts functions by `(A-1)/B` descending from outermost to innermost.

**DP:** Sort all N functions by this key descending. Any optimal solution is a subsequence in this order. Process from innermost to outermost: `dp[j]` = best value composing j functions from the suffix processed so far. Transition when adding function (a,b) as outermost of j: `dp[j] = max(dp[j], a·dp[j-1] + b)`. Answer is `dp[K]`. Complexity O(N log N + N·K) ≤ ~2×10⁶ steps.

Verified on sample 1 (gives 26 via sorted order f3, f1, f2 → picks {f3, f2}) and sample 2 (finds set {5,1,6}: f5(f1(f6(1))) = 216223, respecting sorted order since keys 1.516 > 1.175 > 1.091).
