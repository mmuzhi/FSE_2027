=== ANSWER ===
**Approach:** Sort both descending, use prefix sums. If we pick the top k whites, we may pick any j ≥ k blacks; the best j is captured by the suffix maximum of black prefix sums. Answer = max over k of (white prefix sum of k) + (suffix-max of black prefix sums from k). This is O((N+M) log(N+M)).

Verified against all three samples (19, 15, 0), including the "choose nothing" edge case handled by k = 0 since prefix sum 0 is always included in the suffix max.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    B = list(map(int, data[2:2 + n]))
    W = list(map(int, data[2 + n:2 + n + m]))
    B.sort(reverse=True)
    W.sort(reverse=True)

    Bpref = [0] * (n + 1)
    for i in range(n):
        Bpref[i + 1] = Bpref[i] + B[i]

    # sufmax[j] = max over i >= j of Bpref[i]
    NEG = -(1 << 62)
    sufmax = [NEG] * (n + 1)
    sufmax[n] = Bpref[n]
    for j in range(n - 1, -1, -1):
        sufmax[j] = max(sufmax[j + 1], Bpref[j])

    ans = sufmax[0]  # k = 0 whites (>= 0 since Bpref[0] = 0 included)
    wsum = 0
    for k in range(1, min(n, m) + 1):
        wsum += W[k - 1]
        cand = wsum + sufmax[k]
        if cand > ans:
            ans = cand
    print(ans)

main()
```
