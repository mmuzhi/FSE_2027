class Solution:
    def findMinimumTime(self, strength: List[int], K: int) -> int:
        n = len(strength)
        INF = float('inf')
        dp = [INF] * (1 << n)
        dp[0] = 0
        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            x = 1 + bin(mask).count('1') * K
            for i in range(n):
                if not (mask >> i) & 1:
                    cost = (strength[i] + x - 1) // x
                    nm = mask | (1 << i)
                    if dp[mask] + cost < dp[nm]:
                        dp[nm] = dp[mask] + cost
        return dp[(1 << n) - 1]
```

from typing import List

class Solution:
    def findMinimumTime(self, strength: List[int], K: int) -> int:
        n = len(strength)
        full = (1 << n) - 1
        INF = float('inf')
        dp = [INF] * (1 << n)
        dp[0] = 0
        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            broken = bin(mask).count('1')
            x = 1 + broken * K
            base = dp[mask]
            for i in range(n):
                bit = 1 << i
                if mask & bit:
                    continue
                cost = (strength[i] + x - 1) // x
                nm = mask | bit
                if base + cost < dp[nm]:
                    dp[nm] = base + cost
        return dp[full]
```

**Decisive constraints:** n ≤ 8, so state space over subsets of locks is at most 256.

**Key reduction:** After breaking `j` locks, the state is fully determined: energy = 0, X = 1 + j·K (independent of *which* locks were broken). So breaking lock `i` at position `j` costs exactly `ceil(strength[i] / (1 + j·K))` minutes, and total time = sum of position costs. Waiting never helps (energy resets, X only grows by breaking). The problem is thus a min-cost assignment of locks to positions → **bitmask DP**: `dp[mask]` = min time to break locks in `mask`; transition adds lock `i` at cost `ceil(strength[i] / (1 + popcount(mask)·K))`.

**Invariant:** any permutation is a DP path and vice versa, with cost depending only on (lock, position) — DP explores all orders optimally.

**Ledger:**
- Main: forward subset DP, O(2^n · n).
- Edge: n=1 → answer = strength[0]; ceiling division via `(s + x - 1) // x`.
