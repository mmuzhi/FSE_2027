```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    INF = m + 1
    minR = [INF] * (m + 2)  # 1-indexed, index 0 unused; also index m+1 as INF sentinel
    idx = 2
    for _ in range(n):
        l = int(data[idx]); r = int(data[idx+1]); idx += 2
        if r < minR[l]:
            minR[l] = r
    # suffix min
    ans = 0
    cur = INF
    for l in range(m, 0, -1):
        if minR[l] < cur:
            cur = minR[l]
        if cur > l:
            ans += cur - l
    print(ans)

main()
```

=== ANSWER ===
**Approach.** A pair (l,r) is *invalid* iff some i has l ≤ L_i and R_i ≤ r. For fixed l, the pair is invalid exactly when r ≥ min{R_i : L_i ≥ l}. Define f(l) as that suffix minimum (M+1 if empty). Then valid r for this l are l ≤ r ≤ f(l)−1, contributing max(0, f(l) − l). Summing over l gives the answer.

Verified on all three samples (5, 0, 102). Complexity O(N+M).
