We have a string S of length N, and Q queries. Each query changes one character at position X to C, then asks how many times "ABC" appears as a substring.

Approach: Maintain a counter `cnt` of occurrences of "ABC" in S. When a character at position X (1-indexed) changes, only occurrences of "ABC" that overlap position X can be affected. Those are occurrences starting at positions X-2, X-1, X (1-indexed). So for each of the three starting positions p in {X-2, X-1, X}, if 1 <= p <= N-2, check if S[p..p+2] == "ABC" before the change, subtract 1 if so; after the change, check again, add 1 if so.

Implementation: Use a list of characters for S (0-indexed internally). For query X, C:
- idx = X-1 (0-indexed)
- before change: for p in {idx-2, idx-1, idx} with 0 <= p <= N-3: if S[p:p+3] == "ABC": cnt -= 1
- S[idx] = C
- after: same loop: if matches: cnt += 1
- print cnt

Complexity: O(Q) total with small constant (each check is O(3)). That's fine for 2×10^5 queries in Python. To speed up, compare characters directly: S[p]=='A', S[p+1]=='B', S[p+2]=='C'.

Looking at this problem:

**Key insight:** When character at position X changes, only occurrences of "ABC" starting at positions X-2, X-1, X can be created or destroyed. So maintain a running count; per query, subtract matches in those (up to) 3 windows before the change, apply the change, add matches after, and print the count.

**Complexity:** O(N + Q) with tiny constants — fine for N, Q ≤ 2×10⁵.

**Edge cases:**
- Query where C equals the existing character: subtract-then-add of identical windows nets zero, handled naturally.
- Window indices must be clipped to valid start positions 0..N-3 (verified with N=3 sample where j=0 is the only valid window and the unchanged character gives cnt back to 1).

I traced Sample 1 fully (including the tricky query 3 where replacing position 5 destroys an "ABC" at index 4 but creates one at index 2, netting 1) and Sample 2 — outputs match.

Implementation uses a `bytearray` for O(1) in-place mutation and fast int comparisons against ord('A')=65, ord('B')=66, ord('C')=67; bulk stdin read for speed.
