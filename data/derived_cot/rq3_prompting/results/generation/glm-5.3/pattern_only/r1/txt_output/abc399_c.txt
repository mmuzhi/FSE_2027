def main():

=== ANSWER ===
**Approach:** A forest on N vertices with C connected components has exactly N−C edges. So the minimum deletions = M − (N − C). Equivalently, run Union-Find: every edge whose endpoints are already connected forms a cycle with kept edges and must be deleted; all other edges can be kept (they form a spanning forest). Counting such "redundant" edges gives the answer.

**Ledger:**
- Invariant: each edge either unions two components (keep) or increments answer (must delete).
- Edge cases: M=0 → answer 0; no self-loops/multi-edges guaranteed.
- Verified against all three samples: (1: M−(N−C)=4−3=1), (2: 0), (3: 10−8=2).

    data = sys.stdin.buffer.read().split()

    parent = list(range(n + 1))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    ans = 0
    idx = 2
    for _ in range(m):

        ru, rv = find(u), find(v)
        if ru == rv:
            ans += 1
        else:
            if size[ru] < size[rv]:
                ru, rv = rv, ru
            parent[rv] = ru
