class Solution:
    def minimumSumSubarray(self, nums: List[int], l: int, r: int) -> int:
        n = len(nums)
        ans = float('inf')
        for i in range(n):
            cur = 0
            for j in range(i, min(i + r, n)):
                cur += nums[j]
                length = j - i + 1
                if length >= l and cur > 0:
                    ans = min(ans, cur)
        return ans if ans != float('inf') else -1

**Commit:** With n ≤ 100, brute force over all starts with a running sum is optimal in practice — O(n·r) ≤ 10⁴ operations. For each start `i`, extend up to `r` elements, tracking the running sum; consider it only when length ≥ l and sum > 0.

**Implementation ledger:**
- Invariant: `cur` = sum of `nums[i..j]`, length = `j - i + 1` bounded above by `r` via loop range, below by `l` via explicit check.
- Edge cases: strictly positive check (sum == 0 excluded), no valid subarray → return -1 (sentinel `inf`).

**Draft verified against examples:** [3,-2,1,4], l=2, r=3 → finds [3,-2] sum 1 ✓; [-2,2,-3,1] → all sums ≤ 0, returns -1 ✓; [1,2,3,4], l=2 → [1,2] sum 3 ✓. Extra edge: nums=[-5], l=r=1 → -1 ✓; nums=[0,1] → 1 ✓.
