import heapq
from typing import List

class Solution:
    def findMaxSum(self, nums1: List[int], nums2: List[int], k: int) -> List[int]:
        n = len(nums1)
        order = sorted(range(n), key=lambda i: nums1[i])
        ans = [0] * n
        heap = []  # min-heap of the k largest nums2 values
        cur = 0    # sum of heap
        i = 0
        while i < n:
            j = i
            v = nums1[order[i]]
            while j < n and nums1[order[j]] == v:
                j += 1
            # indices order[i:j] all have nums1 == v

                ans[order[t]] = cur
            for t in range(i, j):
                x = nums2[order[t]]
                if len(heap) < k:
                    heapq.heappush(heap, x)
                    cur += x
                elif x > heap[0]:
                    cur += x - heapq.heapreplace(heap, x)
            i = j
        return ans

=== ANSWER ===
Looking at this problem:

**Key insight:** For each index i, the answer is the sum of the k largest `nums2[j]` values among indices with `nums1[j] < nums1[i]`. If we process indices in increasing order of `nums1`, we can maintain a running structure of the top-k `nums2` values seen so far.

**Plan:**
- Sort indices by `nums1` value.
- Process groups of equal `nums1` together (equal values don't count for each other, since we need strict `<`).
- For each group: first assign the current running sum as the answer for all members, *then* insert their `nums2` values into a min-heap of size k (tracking the k largest values and their sum).
- Heap invariant: heap holds the k largest `nums2` values among all strictly smaller `nums1` groups; `cur` is their sum.

**Trace check (Example 1):** groups by nums1: {1: idx2} → ans 0, push 30; {2: idx1} → ans 30, push 20 (sum 50); {3: idx4} → ans 50, replace 20 with 50 (sum 80); {4: idx0} → ans 80; {5: idx3} → ans 80. Result `[80,30,0,80,50]` ✓.

**Edge cases:** all equal nums1 → single group, all answers 0 ✓. Fewer than k elements available → heap smaller than k, sum of all of them ✓.

Complexity: O(n log n) sort + O(n log k) heap — fine for n = 10^5.

```python
import heapq
from typing import List

class Solution:
    def findMaxSum(self, nums1: List[int], nums2: List[int], k: int) -> List[int]:
        n = len(nums1)
        order = sorted(range(n), key=lambda i: nums1[i])
        ans = [0] * n
        heap = []  # min-heap holding the k largest nums2 values so far
        cur = 0    # sum of values in heap
        i = 0
        while i < n:
            v = nums1[order[i]]
            j = i
            while j < n and nums1[order[j]] == v:
                j += 1
            # All indices in order[i:j] share the same nums1 value:
            # answer comes only from strictly smaller values already in heap.
            for t in range(i, j):
                ans[order[t]] = cur
            # Now add this group's nums2 values into the top-k structure.
            for t in range(i, j):
                x = nums2[order[t]]
                if len(heap) < k:
                    heapq.heappush(heap, x)
                    cur += x
                elif x > heap[0]:
                    cur += x - heapq.heapreplace(heap, x)
            i = j
        return ans
```
