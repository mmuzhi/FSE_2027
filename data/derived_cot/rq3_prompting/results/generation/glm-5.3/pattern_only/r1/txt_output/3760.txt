```python
class Solution:
    def assignElements(self, groups: List[int], elements: List[int]) -> List[int]:
        MAX = 100001
        best = [-1] * MAX
        seen = [False] * MAX
        for j, v in enumerate(elements):
            if seen[v]:
                continue
            seen[v] = True
            for m in range(v, MAX, v):
                if best[m] == -1:
                    best[m] = j
        return [best[g] for g in groups]
```

=== ANSWER ===
Looking at this problem:

**Key constraints:** up to 10^5 groups and 10^5 elements, values up to 10^5. Naive O(n·m) pairing is 10^10 — too slow.

**Two candidate approaches:**
1. Per-group divisor enumeration: for each group value g, check all divisors and take min element index among them — O(n·√M) ≈ 3×10^7, risky in Python.
2. Sieve-style: precompute for each value v the smallest index where v appears in elements, then for each distinct value, propagate its index to all multiples ≤ 10^5. Since we process element indices in increasing order, the first writer to a multiple wins — that's exactly the minimal index. Total work is M·H(M) ≈ 10^5 × 12 ≈ 1.2×10^6 — very fast.

Committing to approach 2 (sieve), which is decisively better on the bottleneck.

**Implementation ledger:**
- Invariant: iterate elements by index j; only first occurrence of each value v spreads to multiples; `best[m]` set only if currently -1, so smallest j wins.
- State: `best[m]` = smallest element index assignable to a group of size m; `seen[v]` marks first occurrence.
- Edge cases: element value 10^5 (range covers it, MAX=100001); group with no divisor among elements stays -1.

**Verification on Example 1:** groups=[8,4,3,2,4], elements=[4,2]. j=0, v=4 marks 4,8,12,... j=1, v=2 marks 2 (4,8 already taken). Results: 8→0, 4→0, 3→-1, 2→1, 4→0 → [0,0,-1,1,0] ✓. Examples 2 and 3 also check out (odd numbers get index of value 1's first occurrence, etc.).

**Recheck:** no index out of bounds (all values ≤ 10^5), memory is two arrays of size 100001, inner loop total ≈ 1.2M iterations — well within limits.

```python
class Solution:
    def assignElements(self, groups: List[int], elements: List[int]) -> List[int]:

        best = [-1] * MAX
        seen = [False] * MAX
        for j, v in enumerate(elements):
            if seen[v]:
                continue
            seen[v] = True
            for m in range(v, MAX, v):
                if best[m] == -1:
                    best[m] = j
        return [best[g] for g in groups]
```
