=== ANSWER ===
Looking at this problem:

- **Target**: Count splits of A into contiguous blocks where no block sums to K, modulo 998244353. N up to 2×10^5, so we need O(N) or O(N log N).

**Approach**: DP where `dp[i]` = number of valid splits of the first i elements. Transition: `dp[i] = Σ dp[j]` for all `j < i` where `sum(A[j+1..i]) ≠ K`. Using prefix sums, the forbidden condition is `prefix[j] = prefix[i] - K`. So maintain a running total S of all dp values and a hashmap from prefix value → sum of dp[j] with that prefix, letting us subtract the forbidden contributions in O(1) per step.

**Key invariant**: After computing `dp[i]`, add it to S and to `cnt[prefix[i]]` (only for future indices j > i, which is exactly what we want since blocks are non-empty).

**Verification**:
- Sample 1 (A=[1,2,3], K=3): dp ends at 2 ✓
- Sample 2 (zeros, K=0): each block of zeros sums to 0=K, so any split has a bad block; dp collapses to 0 ✓
- Sample 3: hand-traced through all 10 elements → 428 ✓

Edge cases handled: K=0 with j=i excluded naturally (dp added to cnt only after computing next steps); negative prefix sums fine as Python dict keys; modular subtraction with negative intermediate handled by `% MOD`.

```python
import sys
from collections import defaultdict

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0])
    K = int(data[1])
    A = list(map(int, data[2:2 + N]))
    MOD = 998244353

    cnt = defaultdict(int)
    cnt[0] = 1          # dp[0] = 1, prefix[0] = 0
    S = 1               # sum of dp[0..i-1]
    pref = 0
    dp = 1              # dp[0]

    for a in A:
        pref += a
        dp = (S - cnt.get(pref - K, 0)) % MOD
        S = (S + dp) % MOD
        cnt[pref] = (cnt[pref] + dp) % MOD

    print(dp % MOD)

main()
```
