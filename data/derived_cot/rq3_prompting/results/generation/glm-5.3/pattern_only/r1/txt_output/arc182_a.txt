import sys

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); Q = int(data[1])
    P = [0]*Q
    V = [0]*Q
    idx = 2
    for i in range(Q):
        P[i] = int(data[idx]); V[i] = int(data[idx+1])
        idx += 2
    MOD = 998244353

    # coordinate compress V
    sorted_vals = sorted(set(V))
    comp = {v: i for i, v in enumerate(sorted_vals)}
    R = len(sorted_vals)
    r = [comp[v] for v in V]

    INF = 1 << 30
    NEG = -1

    # Fenwick trees
    tmin = [INF] * (R + 1)
    tmax = [NEG] * (R + 1)

    def update(pos, val):
        while pos <= R:
            if val < tmin[pos]:
                tmin[pos] = val
            if val > tmax[pos]:
                tmax[pos] = val
            pos += pos & (-pos)

    def query_min(pos):
        res = INF
        while pos > 0:
            if tmin[pos] < res:
                res = tmin[pos]
            pos -= pos & (-pos)
        return res

    def query_max(pos):
        res = NEG
        while pos > 0:
            if tmax[pos] > res:
                res = tmax[pos]
            pos -= pos & (-pos)
        return res

    emin = [INF] * Q
    emax = [NEG] * Q
    # pass 1: j < i with V[j] > V[i]
    for i in range(Q):
        lim = R - 1 - r[i]  # query prefix of reversed ranks up to lim
        if lim >= 1:
            emin[i] = query_min(lim)
            emax[i] = query_max(lim)
        update(R - r[i], P[i])

    # reset trees
    tmin = [INF] * (R + 1)
    tmax = [NEG] * (R + 1)

    smin = [INF] * Q
    smax = [NEG] * Q
    # pass 2: j > i with V[j] < V[i]
    for i in range(Q - 1, -1, -1):
        if r[i] >= 1:
            smin[i] = query_min(r[i])
            smax[i] = query_max(r[i])
        update(r[i] + 1, P[i])

    free = 0
    for i in range(Q):
        has_e = emin[i] != INF
        has_s = smin[i] != INF
        if not has_e and not has_s:
            free += 1
            continue
        if has_e and has_s:
            mn = emin[i] if emin[i] < smin[i] else smin[i]
            mx = emax[i] if emax[i] > smax[i] else smax[i]

            print(0)
            return

    print(pow(2, free, MOD))

    smin = [INF]*Q
    smax = [-1]*Q

Looking at this problem:

**Key reformulation**: Op `j` choosing a region cries iff some position in the region has value `> V_j`. The value at a position is `V_i` of the *last* op covering it. So a choice sequence is valid **iff for every position k, the values of ops covering k (in time order) form a non-decreasing sequence** — equivalently, for every pair `i < j` with `V_i > V_j`, their regions must be disjoint.

Region intersection for labels (L = prefix `[1,P]`, R = suffix `[P,N]`):
- L,L always share position 1; R,R always share position N → forbidden for decreasing pairs.
- L_i & R_j disjoint iff `P_j > P_i`; R_i & L_j disjoint iff `P_i > P_j`.

So for every pair `i < j` with `V_i > V_j`: **the op with larger P must be R, the one with smaller P must be L** (equal P → answer 0). These are purely per-op forcings; if any op gets both an L-force and an R-force (or an equal-P decreasing pair exists), answer is 0. Ops in no decreasing pair are free (2 choices). Answer = `2^(#free ops)`.

Verified: sample 1 → 1, sample 2 → 0 (equal-P pair), sample 3 → 2^60 mod 998244353 = 682155965 ✓ (matches exactly).

Implementation: for each op `i` find min/max of `P_j` over `S_i = {j<i: V_j>V_i} ∪ {j>i: V_j<V_i}` using two Fenwick (min/max) passes over compressed values (O(Q log Q), safe for Q ≤ 5000). Contradiction iff `mn == P_i` or `mx == P_i` or `mn < P_i < mx`.
