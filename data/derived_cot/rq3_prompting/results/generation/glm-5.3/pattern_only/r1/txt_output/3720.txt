```python
class Solution:
    def minMaxWeight(self, n: int, edges: List[List[int]], threshold: int) -> int:
        import heapq
        # reversed adjacency
        head = [-1] * n
        nxt = [-1] * len(edges)
        to = [0] * len(edges)
        wt = [0] * len(edges)
        for i, (a, b, w) in enumerate(edges):
            to[i] = a
            wt[i] = w
            nxt[i] = head[b]
            head[b] = i
        INF = float('inf')
        dist = [INF] * n
        dist[0] = 0
        pq = [(0, 0)]
        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:
                continue
            e = head[u]
            while e != -1:
                v = to[e]
                nd = d if d > wt[e] else wt[e]
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))
                e = nxt[e]
        ans = max(dist)
        return ans if ans != INF else -1
```

```python
import heapq

class Solution:
    def minMaxWeight(self, n: int, edges: List[List[int]], threshold: int) -> int:
        radj = [[] for _ in range(n)]
        for a, b, w in edges:

        dist[0] = 0

                    push(pq, (nd, v))

        return -1 if ans == INF else ans
```

Looking at this problem, the decisive observation is the direction of the constraints:

**Key insight:** Since `threshold >= 1` is guaranteed, and any node that can reach 0 only needs *at least one* outgoing edge (an in-arborescence toward 0 gives every non-root node exactly **1** outgoing edge via a BFS tree in the reversed graph), the out-degree constraint is always satisfiable alongside reachability. So the problem reduces to: find the minimum W such that every node can reach node 0 using only edges of weight ≤ W.

That equals `max over v` of the **minimax bottleneck** (minimum possible max-edge-weight on a path) from v to 0. Reversing edges makes this a minimax path problem from node 0 — solvable with a Dijkstra variant where `dist[v] = min over paths of (max edge weight on path)`, relaxing with `nd = max(dist[u], w)`.

**Verification against examples:**
- Ex1: reversed graph from 0: dist = [0,1,1,1,1] → 1 ✓ (node 2 routes 2→1→0).
- Ex2: no edges into 0 → some INF → -1 ✓.
- Ex3: dist = [0,2,2,2,1] → 2 ✓.
- Ex4: node 3 has no outgoing edges → INF → -1 ✓.

**Correctness of answer value:** The Dijkstra/BFS tree uses ≤ 1 outgoing edge per node (satisfies threshold ≥ 1), its max edge equals `max dist`, and any valid subgraph must contain a path to 0 for each v, so its max weight ≥ dist[v]. Hence answer = max dist, or -1 if unreachable.
