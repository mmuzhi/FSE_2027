## Approach

**Key insight — track puffs by creation position:**

A puff of smoke created at time `s` sits at `(0,0)` at time `s+0.5`, then is carried by all subsequent winds. If `pos(k)` denotes the cumulative wind displacement after the first `k` steps (`pos(0)=(0,0)`), then at time `t+0.5` the puff created at time `s` is at position `pos(t) - pos(s)`.

- **Creation rule:** at time `t` (after the wind), cell `(0,0)` is empty iff `pos(t) ≠ pos(s)` for every previously created time `s`. So `t` creates smoke iff `pos(t)` is not among the positions of created times.
- **Query:** smoke exists at `(R,C)` at time `t+0.5` iff some created `s ≤ t` satisfies `pos(t) - pos(s) = (R,C)`, i.e. `pos(t) - (R,C)` is in the set of creation positions.

So maintain a hash set of `pos(s)` over created times; per step: add `pos(t)` (a no-op if already present, which correctly means "no new smoke"), then answer by membership test of `pos(t) - (R,C)`. This is O(N) total.

Encode `(r,c)` as integer `r*1000001 + c` (valid since `|c| ≤ N < 500001`, no collisions).

**Verification on sample 1** (`N=6, R=-2, C=1, S=NNEEWS`) reproduces `001010`, and sample 2 (`NEESESWEES`, R=1, C=2) reproduces `0001101011` — including the subtle case at `t=8` where `pos(8)=pos(6)` so no new smoke is generated.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); R = int(data[1]); C = int(data[2])
    S = data[3].decode()

    base = 1000001
    r = c = 0
    seen = {0}          # pos(0) = (0,0): initial smoke
    tkey = R * base + C  # target offset key
    res = []

    for ch in S:
        if ch == 'N':
            r -= 1
        elif ch == 'S':
            r += 1
        elif ch == 'E':
            c += 1
        else:  # 'W'
            c -= 1
        key = r * base + c
        seen.add(key)  # no-op if smoke already at (0,0) -> no new puff, set unchanged
        res.append('1' if (key - tkey) in seen else '0')

    sys.stdout.write(''.join(res) + '\n')

main()
```
