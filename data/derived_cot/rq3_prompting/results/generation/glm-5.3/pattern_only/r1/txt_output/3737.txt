class Solution:
    def minCost(self, n: int, cost: List[List[int]]) -> int:
        half = n // 2
        c0 = cost[0]
        cL = cost[n - 1]
        # dp state: d[a][b] = min cost of pairs 0..k-1 with pair k-1 = (a, b), a != b
        d01 = c0[0] + cL[1]
        d02 = c0[0] + cL[2]
        d10 = c0[1] + cL[0]
        d12 = c0[1] + cL[2]
        d20 = c0[2] + cL[0]
        d21 = c0[2] + cL[1]
        for k in range(1, half):
            L = cost[k]
            R = cost[n - 1 - k]
            n01 = L[0] + R[1] + min(d10, d12, d20)
            n02 = L[0] + R[2] + min(d20, d21, d10)
            n10 = L[1] + R[0] + min(d01, d02, d21)
            n12 = L[1] + R[2] + min(d21, d20, d01)
            n20 = L[2] + R[0] + min(d02, d01, d12)
            n21 = L[2] + R[1] + min(d12, d10, d02)
            d01, d02, d10, d12, d20, d21 = n01, n02, n10, n12, n20, n21
        return min(d01, d02, d10, d12, d20, d21)

class Solution:
    def minCost(self, n: int, cost: List[List[int]]) -> int:
        half = n // 2
        c0 = cost[0]
        cL = cost[n - 1]
        d01 = c0[0] + cL[1]
        d02 = c0[0] + cL[2]
        d10 = c0[1] + cL[0]
        d12 = c0[1] + cL[2]
        d20 = c0[2] + cL[0]
        d21 = c0[2] + cL[1]
        for k in range(1, half):
            L = cost[k]
            R = cost[n - 1 - k]
            n01 = L[0] + R[1] + min(d10, d12, d20)
            n02 = L[0] + R[2] + min(d20, d21, d10)
            n10 = L[1] + R[0] + min(d01, d02, d21)

            n20 = L[2] + R[0] + min(d02, d01, d12)
            n21 = L[2] + R[1] + min(d12, d10, d02)
            d01, d02, d10, d12, d20, d21 = n01, n02, n10, n12, n20, n21

Looking at this problem:

**Key insight:** Pair up house `k` with house `n-1-k` (mirror pairs). Process pairs from outside in. State for pair `k` is `(a, b)` = colors of houses `k` and `n-1-k`, requiring `a != b` (mirror constraint). Adjacency constraints become `a_k != a_{k+1}` and `b_k != b_{k+1}`.

**Critical simplification:** With only 3 colors, for target state `(a, b)` (a≠b, third color `c`), the allowed previous states `(a', b')` with `a' != a`, `b' != b`, `a' != b'` are *exactly* `{(b,a), (b,c), (c,a)}` (since `a' ∈ {b,c}`, `b' ∈ {a,c}`, and `(c,c)` is invalid). So each transition is just a min over 3 fixed states — O(n) total with 6 states per pair.

**Verification on Example 1** (n=4): pair 0 dp values give min 6 at (0,1); pair 1 computes (1,2) = 2+1+min(d21,d20,d01)=3+6=9 ✓. **Example 2** gives 18 at (1,2) backtracking to [1,3,2,3,1,2] ✓. Edge case n=2: single pair, answer = min over 6 states, handled by initialization ✓.
