## Approach

**Key insight:** The minimal connected subtree containing all K marked vertices is exactly the union of paths from any fixed marked vertex `r` to every other marked vertex. Rooting the tree at a marked vertex `r`, a vertex `v` belongs to this Steiner tree **iff** the subtree of `v` contains at least one marked vertex (since `v` lies on `path(r, u)` precisely when `u` is in `v`'s subtree, and conversely a vertex on a path between two marked vertices must have a marked vertex at-or-below it when the root is marked).

**Algorithm (O(N)):**
1. Root the tree at some marked vertex.
2. Do an iterative DFS to get a pre-order and parent array.
3. Process vertices in reverse pre-order (children before parents): if a vertex "has a mark in its subtree," count it and propagate the flag to its parent.
4. The count is the answer.

Verified against all three samples (4, 4, 1). Edge cases: `K=1` gives 1 (only the root survives); `N=1` works since there are no edges.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); k = int(data[1])
    m = n - 1
    ptr = 2
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        a = int(data[ptr]); b = int(data[ptr + 1]); ptr += 2
        adj[a].append(b)
        adj[b].append(a)
    marked = [False] * (n + 1)
    for _ in range(k):
        marked[int(data[ptr])] = True
        ptr += 1
    root = 1
    while not marked[root]:
        root += 1
    parent = [0] * (n + 1)
    parent[root] = -1
    order = []
    stack = [root]
    while stack:
        v = stack.pop()
        order.append(v)
        for u in adj[v]:
            if parent[u] == 0:
                parent[u] = v
                stack.append(u)
    count = 0
    for v in reversed(order):
        if marked[v]:
            count += 1
            p = parent[v]
            if p > 0:
                marked[p] = True
    print(count)

main()
```
