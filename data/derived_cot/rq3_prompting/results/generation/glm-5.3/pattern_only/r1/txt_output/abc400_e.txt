=== ANSWER ===
**Approach.** A 400 number is p^(2a)·q^(2b) = (p^a·q^b)², i.e. exactly the squares m² where m has exactly 2 distinct prime factors. Since A ≤ 10¹², m ≤ 10⁶. So: sieve ω(m) (distinct prime count) for m ≤ 10⁶, collect the sorted list of m with ω(m)=2, and answer each query with r = isqrt(A), taking the largest good m ≤ r via bisect; answer m². Since A ≥ 36, r ≥ 6 and 6 = 2·3 works, so an answer always exists.

**Key checks.** 10⁶ = 2⁶·5⁶ has ω = 2 (handles A = 10¹²); 11111 = 41·271 (matches sample); sieve `cnt[p]==0` correctly identifies primes since smaller primes already marked their multiples; slice-assignment keeps the sieve fast (~2.9M element updates total).

import sys
from math import isqrt
from bisect import bisect_right

def main():
    data = sys.stdin.buffer.read().split()
    Q = int(data[0])
    N = 10**6
    cnt = [0] * (N + 1)
    for p in range(2, N + 1):
        if cnt[p] == 0:  # p is prime (smaller primes already touched their multiples)
            cnt[p::p] = [c + 1 for c in cnt[p::p]]
    goods = [m for m, c in enumerate(cnt) if c == 2]

        out.append(str(m * m))
