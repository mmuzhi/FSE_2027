**Decisive transformation:** Write d = x − y ≥ 1. Then

N = x³ − y³ = d(x² + xy + y²) = d(3y² + 3dy + d²).

Since y ≥ 1, we get N = d(3y² + 3dy + d²) > d³, so **d < N^(1/3) ≤ 10⁶**, and **d must divide N**. That gives at most 10⁶ candidate d values — a single cheap loop.

**Checking a divisor d:** Let m = N/d. Solve 3y² + 3dy + d² = m. Multiplying by 12 and completing the square:

(6y + 3d)² = 12m − 3d².

So a solution exists for this d iff disc = 12m − 3d² is a positive perfect square s², with num = s − 3d > 0 and num ≡ 0 (mod 6); then y = num/6, x = y + d. A final exact verification x³ − y³ = N guards against any algebra slip.

**Verification on samples:**
- N = 397: d = 1 → m = 397, disc = 4761 = 69², num = 66 → y = 11, x = 12 ✓ (12³ − 11³ = 397).
- N = 1: d = 1 → disc = 9, s = 3, num = 0 → rejected → −1 ✓.
- N = 39977273855577088: d = 276544 divides N, disc = (6·66212 + 3·276544)² → x = 342756, y = 66212 ✓.

**Complexity:** ~10⁶ modulo operations (fast in CPython), plus a handful of `isqrt` calls on actual divisors. Cube-root limit is computed via float then corrected exactly with integer arithmetic.

```python
import sys
from math import isqrt

def main():
    N = int(sys.stdin.buffer.read())
    # d = x - y must satisfy d^3 < N (since N = d(3y^2+3dy+d^2) > d^3 for y >= 1)
    limit = int(round(N ** (1.0 / 3.0)))
    while limit ** 3 > N:
        limit -= 1
    while (limit + 1) ** 3 <= N:
        limit += 1
    for d in range(1, limit + 1):
        if N % d:
            continue
        m = N // d
        disc = 12 * m - 3 * d * d
        if disc <= 0:
            continue
        s = isqrt(disc)
        if s * s != disc:
            continue
        num = s - 3 * d
        if num <= 0 or num % 6:
            continue
        y = num // 6
        x = y + d
        if x * x * x - y * y * y == N:
            print(x, y)
            return
    print(-1)

main()
```
