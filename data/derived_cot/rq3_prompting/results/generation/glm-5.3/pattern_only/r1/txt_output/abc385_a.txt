=== ANSWER ===
Looking at this problem: with exactly three items, the only ways to split them into 2+ groups are:
- **2 groups** (one singleton vs. a pair): valid iff one number equals the sum of the other two → `A+B==C` or `A+C==B` or `B+C==A`
- **3 groups** (all singletons): valid iff `A == B == C`

**Led check against samples:**
- `3 8 5`: 3+5=8 → Yes ✓
- `2 2 2`: all equal → Yes ✓
- `1 2 4`: 3≠4, 5≠2, 6≠1, not all equal → No ✓

Edge case: all-equal values (e.g., 5 5 5) only pass via the equality condition since sums of positives always exceed each element, so that condition is essential.

Complexity is O(1).

```python
a, b, c = map(int, input().split())
if a + b == c or a + c == b or b + c == a or (a == b == c):
    print("Yes")
else:
    print("No")
```
