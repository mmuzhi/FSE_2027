We have a sequence $A = (A_1, \ldots, A_N)$ and $f(l, r)$ is the number of distinct values in the subsequence $A_l, \ldots, A_r$. We need to compute $\sum_{i=1}^{N} \sum_{j=i}^{N} f(i, j)$.

**Standard approach: contribution technique.**

Instead of computing $f(i,j)$ for each pair directly (which would be $O(N^2)$ pairs, too many for $N = 2 \times 10^5$), we count, for each element occurrence (or each distinct value), how many intervals it contributes to.

The classic trick: for a value $v$ appearing at positions $p_1 < p_2 < \ldots < p_k$, the value $v$ contributes 1 to $f(l, r)$ if and only if the interval $[l, r]$ contains at least one of these positions. It's easier to count "at least one occurrence" via the first occurrence in the interval: $v$ contributes 1 to $f(l,r)$ iff $l \le p_t \le r$ for some $t$, equivalently the first occurrence of $v$ at position $\ge l$ is $\le r$.

Alternative standard formulation: For each position $j$, count the number of intervals $[l, r]$ where $A_j$ is the **first occurrence** of its value in the interval. Then $A_j$ contributes 1 to each such interval.

$A_j$ is the first occurrence of value $v = A_j$ in $[l, r]$ iff:
- $l \le j \le r$,
- $l > \text{prev}(j)$, where $\text{prev}(j)$ is the last position before $j$ with the same value $v$ (or 0 if none).

So $l$ ranges over $(\text{prev}(j), j]$, giving $(j - \text{prev}(j))$ choices, and $r$ ranges over $[j, N]$, giving $(N - j + 1)$ choices.

Therefore the answer is:
$$\sum_{j=1}^{N} (j - \text{prev}(j)) \cdot (N - j + 1)$$

=== ANSWER ===
**Approach (contribution counting):** Instead of summing $f(i,j)$ over all $O(N^2)$ intervals, count each distinct value's contribution per interval. For position $j$, element $A_j$ is the *first* occurrence of its value within interval $[l, r]$ exactly when $\text{prev}(j) < l \le j \le r$, where $\text{prev}(j)$ is the previous position with the same value (0 if none). That gives $(j - \text{prev}(j)) \cdot (N - j + 1)$ intervals to which $A_j$ contributes exactly 1. Summing over all $j$ yields the answer in $O(N)$.

**Verification on Sample 1** ($A=[1,2,2]$): contributions $1\cdot3 + 2\cdot2 + 1\cdot1 = 8$ ✓.
**Sample 2** ($A=[5,4,2,2,3,2,4,4,1]$): $9+16+21+6+25+8+15+2+9 = 111$ ✓.
**Edge cases:** $N=1$ gives $1$; all-equal array $[2,2,2]$ gives $3+2+1=6$, matching the direct sum. Python big ints handle the max (~$N^3/6 \approx 1.3\times10^{15}$) safely.
