```python
class Solution:
    def numberOfWays(self, n: int, x: int, y: int) -> int:
        MOD = 10**9 + 7
        m = min(n, x)
        
        # dp[k] = number of ways to place current performers onto exactly k
        # non-empty labeled stages (surjections onto k chosen stages)
        dp = [0] * (m + 1)
        dp[0] = 1
        for _ in range(n):
            ndp = [0] * (m + 1)
            for j in range(1, m + 1):
                ndp[j] = (j * dp[j] + dp[j - 1]) % MOD
            dp = ndp
        
        # Precompute binomial coefficients C(x, k)
        fact = [1] * (x + 1)
        for i in range(1, x + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (x + 1)
        inv_fact[x] = pow(fact[x], MOD - 2, MOD)
        for i in range(x, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD
        
        ans = 0
        ypow = 1
        for k in range(1, m + 1):
            c = fact[x] * inv_fact[k] % MOD * inv_fact[x - k] % MOD
            ypow = ypow * y % MOD
            ans = (ans + c * dp[k] % MOD * ypow) % MOD
        return ans
```

**Reasoning summary:**

- **Key structure:** Each event = a stage assignment where exactly k stages are non-empty, times a score per non-empty band. Answer = Σ_{k=1}^{min(n,x)} C(x,k) · Surj(n,k) · y^k, where Surj(n,k) = k!·S(n,k) counts assignments of n distinct performers onto k specific non-empty stages.
- **DP invariant:** `dp[j] = j*dp[j] + dp[j-1]` over n iterations builds surjection counts in O(n·x) ≤ 10^6 steps.
- **Verification against examples:** n=1,x=2,y=3 → 2·1·3=6 ✓; n=5,x=2,y=1 → 2·1+1·30=32 ✓; n=3,x=3,y=4 → 12+288+384=684 ✓.
