```python
class Solution:
    def maxFreeTime(self, eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
        n = len(startTime)
        gaps = [startTime[0]]  # gap before first meeting
        for i in range(1, n):
            gaps.append(startTime[i] - endTime[i-1])
        gaps.append(eventTime - endTime[-1])
        
        window = k + 1
        window = min(window, len(gaps))  # k <= n so k+1 <= n+1 = len(gaps), so this is fine but safe
        cur = sum(gaps[:window])
        ans = cur
        for i in range(window, len(gaps)):
            cur += gaps[i] - gaps[i - window]
            ans = max(ans, cur)
        return ans
```

```python
class Solution:
    def maxFreeTime(self, eventTime: int, k: int, startTime: List[int], endTime: List[int]) -> int:
        n = len(startTime)
        gaps = [startTime[0]]
        for i in range(1, n):
            gaps.append(startTime[i] - endTime[i - 1])
        gaps.append(eventTime - endTime[-1])
        
        w = k + 1
        cur = sum(gaps[:w])
        ans = cur
        for i in range(w, len(gaps)):
            cur += gaps[i] - gaps[i - w]
            if cur > ans:
                ans = cur
        return ans
```

**Commit:** The free time structure is fully captured by the n+1 gaps between/around meetings (before first, between consecutive, after last). Rescheduling a meeting merges its two adjacent gaps; rescheduling k *consecutive* meetings i..i+k-1 (compacting them against one boundary of their span) merges the k+1 consecutive gaps g_i..g_{i+k} into one block whose size is exactly the sum of those gaps — since total span minus total durations of moved meetings equals that gap sum.
