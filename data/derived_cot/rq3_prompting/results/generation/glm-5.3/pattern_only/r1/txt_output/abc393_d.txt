```python
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    s = data[1]
    ps = [i for i, c in enumerate(s) if c == '1']
    # 1-indexed positions
    b = [p - i for i, p in enumerate(ps)]  # p (0-indexed) - i = (1-indexed pos) - (i+1), same thing
    b.sort()
    med = b[len(b) // 2]
    ans = sum(abs(x - med) for x in b)
    print(ans)

main()
```

Looking at this problem:

- Let positions of the 1s be p_1 < p_2 < ... < p_k. Each adjacent swap of a 1 with a 0 moves one 1 by one position, so the minimum cost to place the 1s at consecutive target positions q_1 < ... < q_k is sum |p_i - q_i| (optimal matching on a line is the sorted matching).
- If the block occupies positions m, m+1, ..., m+k-1, then q_i = m + i - 1, so the cost is sum |(p_i - i) - (m-1)|.
- Setting b_i = p_i - i, the optimal m is the median of the b_i values, and the answer is sum |b_i - median|. Since b_i ∈ [0, N-k], the median always yields a valid block position.
