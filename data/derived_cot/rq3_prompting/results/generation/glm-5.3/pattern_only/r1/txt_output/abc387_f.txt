=== ANSWER ===
Looking at this problem:

- The pointers i → A_i form a functional graph. Around any cycle, the constraints force all cycle values equal.
- Non-cycle nodes form trees hanging off cycle nodes, with x_child ≤ x_parent.
- Define G_t(v) = number of labelings of the subtree of tree-node t with x_t ≤ v. Then G_t(v) = Σ_{u≤v} Π_{c child of t} G_c(u), leaf: G_t(v) = v.
- Each cycle contributes Σ_{v=1..M} Π (over all tree children of its cycle nodes) of G_child(v). Answer = product over cycles.

This is O(N·M) pointwise array operations — verified against all three samples (6, 2025, 10010). Using numpy (with a pure-Python fallback) for speed; arrays are length M, values < MOD so int64 cumsum/products are safe.

Key edge cases checked: self-loops (cycle of length 1), all-cycle graphs (answer M per cycle), M=1, path-shaped trees (iterative BFS order, no recursion).
