   Implementation of Manacher (the common one):
   ```
   def manacher(s):
       t = '#' + '#'.join(s) + '#'
       n = len(t)
       p = [0]*n
       c = 0, r = 0  # center, right boundary (r = c + p[c])
       for i in range(n):
           if i < r:
               p[i] = min(r - i, p[2*c - i])
           while i - p[i] - 1 >= 0 and i + p[i] + 1 < n and t[i - p[i] - 1] == t[i + p[i] + 1]:
               p[i] += 1
           if i + p[i] > r:
               c, r = i, i + p[i]
       return p
   ```

**Approach summary (commit):** The string produced by `dfs(x)` is the post-order string of x's subtree. In one global post-order traversal (children in increasing index order), every subtree's string is a *contiguous block* of the global post-order string `P`, ending exactly where `s[x]` is appended. So build `P` once (iteratively, via the "preorder with reversed children, then reverse" trick), record each node's position and subtree size, then answer "is `P[l..r]` a palindrome" for all blocks deterministically with Manacher's algorithm: block `[l,r]` is a palindrome iff the radius at transformed center `l+r+1` is ≥ `r-l+1`.

**Key state:** `post` (post-order), `size[x]`, `pos[x] = index in post`, Manacher radius array `rad` over `t = '#'+'#'.join(P)+'#'`. For node at post-index `i` with subtree size `sz`: block is `[i-sz+1, i]`, center `2i-sz+2`, answer `rad[2i-sz+2] >= sz`.

**Verified** against Example 1 (`[T,T,F,T,T,T]`) and Example 2 (all true), plus edge cases (n=1, path, parent indices pointing forward).

```python
from typing import List

class Solution:
    def findAnswer(self, parent: List[int], s: str) -> List[bool]:
        n = len(parent)
        children = [[] for _ in range(n)]
        for i in range(1, n):
            children[parent[i]].append(i)

        # Preorder visiting children in decreasing index order.
        # Reversing it gives postorder with children in increasing order,
        # exactly the order dfs() builds the string.
        order = []
        stack = [0]
        while stack:
            x = stack.pop()
            order.append(x)
            stack.extend(children[x])

        # Subtree sizes (reversed preorder processes children before parents).
        size = [1] * n
        for x in reversed(order):
            p = parent[x]
            if p >= 0:
                size[p] += size[x]

        post = order[::-1]
        P = ''.join(s[x] for x in post)

        # Manacher's algorithm over P with separators:
        # rad[i] = max palindrome radius centered at t[i].
        t = '#' + '#'.join(P) + '#'
        m = len(t)
        rad = [0] * m
        c = r = 0
        for i in range(m):
            if i < r:
                v = rad[2 * c - i]
                ri = r - i
                k = v if v < ri else ri
            else:
                k = 0
            while i - k - 1 >= 0 and i + k + 1 < m and t[i - k - 1] == t[i + k + 1]:
                k += 1
            rad[i] = k
            if i + k > r:
                c = i
                r = i + k

        # dfs-string of node at post-index i with subtree size sz is
        # P[i-sz+1 .. i]; palindrome iff rad[(l + r + 1)] >= sz,
        # where l + r + 1 = 2*i - sz + 2 in transformed string t.
        ans = [False] * n
        for i, x in enumerate(post):
            sz = size[x]
            ans[x] = rad[2 * i - sz + 2] >= sz
        return ans
```
