def has_window(B, s):
    # all positive elements; find contiguous subarray with sum == s
    left = 0
    cur = 0
    for x in B:
        cur += x
        while cur > s:
            cur -= B[left]
            left += 1
        if cur == s:
            return True
    return False

Looking at this problem:

- Let T = sum of one period. Any contiguous subsequence of the infinite sequence with length k decomposes into q = floor(k/N) full periods plus a remainder window of length k mod N ≤ N-1. Since all A_i ≥ 1, the remainder window sum s satisfies 0 ≤ s < T. So S is achievable iff s = S mod T equals either 0 (with S ≥ T, guaranteed since S ≥ 1 forces q ≥ 1 in that case), or the sum of some contiguous window of the doubled array B = A + A.
- Conversely, any window of B with sum s, extended by q appended full copies, gives sum q·T + s = S.
- Checking for a window of B with sum s (s ≥ 1, all elements positive) is done with a two-pointer sliding window in O(N).
