```python
def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    strings = data[1:1+n]
    children = [{}]  # node 0 = root
    minlen = [0]  # empty string at root
    out = []

        # query

            if v is None:

            if val > best:
```

Any optimal transformation of T = S_k deletes down to some prefix of length p and then appends. Matching target S_j forces p ≤ LCP(S_k, S_j), and cost = (|S_k|−p)+(|S_j|−p), minimized at p = LCP. Matching the empty string costs |S_k|. So:

answer_k = min(|S_k|, min_{j<k} (|S_k|+|S_j|−2·LCP(S_k,S_j))) = |S_k| − max(0, max_{j<k}(2·LCP_j − |S_j|)).

Treat the empty string as an always-present target so the "0" baseline is the root. Since 2·LCP_j − |S_j| = max_{p≤LCP_j}(2p − |S_j|), we get:

M = max over depths p on S_k's trie path of (2p − min{|S_j| : S_j passes through the node at depth p}).

**Algorithm.** Build a trie incrementally. Each node stores `minlen` = minimum length of an inserted string passing through it (root: 0, from the empty string). For each S_k: walk down its path, take best of `2·depth − minlen` over visited nodes (root included), output `|S_k| − best`; then insert S_k updating `minlen` along its path. Complexity O(Σ|S_i|) dict operations — fast enough in Python using a list of dicts with byte-value keys.

Verified against all three samples (e.g. "snuki": path depths give max 2·4−5=3 → 5−3=2 ✓; "attattat": best 2·5−5=5 → 8−5=3 ✓).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    children = [{}]   # node 0 = root
    minlen = [0]      # empty string passes through root
    out = []
    for i in range(1, n + 1):
        s = data[i]
        L = len(s)
        # query: walk down the trie along s
        best = 0            # root: 2*0 - 0 = 0 (empty-string target)
        d = 0
        cu = children[0]
        for c in s:
            v = cu.get(c)
            if v is None:
                break
            d += 1
            val = (d << 1) - minlen[v]
            if val > best:
                best = val
            cu = children[v]
        out.append(L - best)
        # insert s, updating minlen along its path
        cu = children[0]
        for c in s:
            v = cu.get(c)
            if v is None:
                v = len(children)
                cu[c] = v
                children.append({})
                minlen.append(L)
            elif minlen[v] > L:
                minlen[v] = L
            cu = children[v]
    sys.stdout.write('\n'.join(map(str, out)) + '\n')

main()
```
