Choose any two elements from the first three elements of nums and remove them. The cost of this operation is the maximum of the two elements removed.
If fewer than three elements remain in nums, remove all the remaining elements in a single operation. The cost of this operation is the maximum of the remaining elements.

Looking at this problem:

- **Key invariant**: After the first operation, the array is always `[carried element] + suffix nums[j:]`. Each operation considers the triple `(nums[i], nums[j], nums[j+1])` and removing two leaves a new carried element with suffix starting at `j+2`.
- **DP state**: `dp(i, j)` = min cost to finish from state where remaining is `[nums[i]] + nums[j:]`. Three transitions (remove `j,j+1` / `i,j` / `i,j+1`), base cases `j = n-1` (two elements → max) and `j = n` (one element → itself).
- **Complexity**: O(n²) states but only O(n) space needed since `j → j+2`, so layers can be kept per parity of `j` (two rolling arrays of size n).
- **Edge cases**: `n ≤ 2` → max; `n = 3` naturally handled by terminal layer `j = n` (= 3).

Verified against both examples (12 and 5), an n=5 manual case (got 16 matching brute-force reasoning), and all-equal arrays.

from typing import List

class Solution:
    def minCost(self, nums: List[int]) -> int:
        n = len(nums)
        if n <= 2:
            return max(nums)

        # dp(i, j): min cost when remaining array is [nums[i]] + nums[j:]
        # Keep one layer per parity of j (transition goes j -> j+2).
        layer = [None, None]
        layer[n & 1] = nums[:]                                  # layer j = n  : cost nums[i]
        layer[(n - 1) & 1] = [max(v, nums[-1]) for v in nums]   # layer j = n-1: cost max(nums[i], nums[n-1])

        for j in range(n - 2, 2, -1):
            A = layer[j & 1]                 # currently holds layer j+2
            nj, nj1 = nums[j], nums[j + 1]
            b = nj1 if nj1 > nj else nj      # max(nums[j], nums[j+1])
            c1 = A[j + 1]                    # dp(j+1, j+2)
            c2 = A[j]                        # dp(j,   j+2)
            layer[j & 1] = [
                min(b + A[i],
                    (ni if ni > nj else nj) + c1,
                    (ni if ni > nj1 else nj1) + c2)
                for i, ni in enumerate(nums[:j])
            ]

        L = layer[1]  # layer j = 3 (odd parity); for n == 3 this is nums itself
        # Initial triple nums[0], nums[1], nums[2]:
        #   remove {1,2} -> dp(0,3); remove {0,1} -> dp(2,3); remove {0,2} -> dp(1,3)
        return min(max(nums[1], nums[2]) + L[0],
                   max(nums[0], nums[1]) + L[2],
                   max(nums[0], nums[2]) + L[1])
