You will be given a competitive programming problem.
There are N people divided into three teams.
The people are numbered 1, 2, \ldots, N, and the teams are numbered 1, 2, 3. Currently, person i belongs to team A_i.
Each person has a value called strength; person i has a strength of B_i. The strength of a team is defined as the sum of the strengths of its members.
Determine whether it is possible for zero or more people to switch teams so that all teams have equal strength. If it is possible, find the minimum number of people who need to switch teams to achieve this.
You cannot create new teams other than teams 1, 2, 3.

Input

The input is given from Standard Input in the following format:
N
A_1 B_1
A_2 B_2
\vdots
A_N B_N

Output

If it is possible to make all teams have equal strength, print the minimum number of people who need to switch teams. Otherwise, print -1.

Constraints


- 3 \leq N \leq 100
- A_i \in \lbrace 1, 2, 3 \rbrace
- For each x \in \lbrace 1, 2, 3 \rbrace, there exists some i with A_i = x.
- 1 \leq B_i
- \displaystyle\sum_{i = 1}^{N} B_i \leq 1500 
- All input values are integers.

import numpy as np

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    people = []

    T = total // 3
    INF = 1 << 20

- Classic 2D knapsack DP: `dp[s1][s2]` = min switches so that team 1 has strength `s1`, team 2 has `s2` (team 3's sum is implied by the prefix sum). - Complexity O(N·T²) ≈ 25M — vectorized per person with numpy (shift + minimum), with a pure-Python fallback using row-wise `map(min, ...)`.

                np.minimum(ndp[b:, :], dp[:T + 1 - b, :] + c1, out=ndp[b:, :])
                np.minimum(ndp[:, b:], dp[:, :T + 1 - b] + c2, out=ndp[:, b:])
            dp = ndp
        ans = int(dp[T, T])
    else:
        size = T + 1
        dp = [[INF] * size for _ in range(size)]
        dp[0][0] = 0
        for a, b in people:
            c1 = 0 if a == 1 else 1
            c2 = 0 if a == 2 else 1
            c3 = 0 if a == 3 else 1
            ndp = []
            if b <= T:
                W = size - b
                head = [INF] * b
                for s1 in range(size):
                    row = dp[s1]
                    r3 = [x + c3 for x in row]
                    r2 = head + [x + c2 for x in row[:W]]
                    if s1 >= b:
                        r1 = [x + c1 for x in dp[s1 - b]]
                        ndp.append(list(map(min, r1, r2, r3)))
                    else:
                        ndp.append(list(map(min, r2, r3)))
            else:
                for row in dp:
                    ndp.append([x + c3 for x in row])
            dp = ndp
        ans = dp[T][T]

    print(ans if ans < INF else -1)

main()
