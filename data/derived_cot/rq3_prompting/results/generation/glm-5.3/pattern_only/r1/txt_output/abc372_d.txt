```python
import sys
from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    h = list(map(int, data[1:1+n]))
    ans = [0] * n
    dq = deque()
    for i in range(n - 2, -1, -1):
        x = h[i+1]
        while dq and dq[0] < x:
            dq.popleft()
        dq.appendleft(x)
        ans[i] = len(dq)
    sys.stdout.write(' '.join(map(str, ans)))

main()
```

**Key insight:** For a fixed `i`, building `j > i` satisfies the condition iff `H_j > max(H_{i+1..j-1})` — i.e., `j` is a *left-to-right maximum* of the suffix `H_{i+1..N}` (with `j = i+1` always qualifying since nothing lies between). Prepending `H_{i+1}` invalidates exactly those maxima with value smaller than `H_{i+1}` — which are the smallest ones. Storing maxima in a plain list in *reverse positional order* (values strictly decreasing from bottom to top), the invalidated ones sit at the top: pop while top < `H_{i+1}`, then push `H_{i+1}`. Then `c_i = len(stack)`.

**Invariant:** stack holds LTR maxima of `H_{i+1..N}` in decreasing value order; each element pushed/popped once → O(N) total.
