=== ANSWER ===
Looking at this problem:

**Key insight:** Each button press appends exactly one of: "00", or a single character ("0"–"9"). Since the string is built left-to-right, displaying S means partitioning S (in order) into pieces, each being either a single digit or "00". The answer is `len(S)` minus the maximum number of disjoint "00" pairs.

**Maximum disjoint "00" pairs:** Zeros form runs; within a run of length k, at most ⌊k/2⌋ disjoint adjacent pairs exist. A left-to-right greedy (take a pair whenever two consecutive '0's are seen, then skip both) achieves exactly ⌊k/2⌋ per run — this is the classic unit-interval matching greedy, which is optimal.

**Verification on samples:**
- "1000000007": run of 8 zeros → 4 pairs → 10 − 4 = 6 ✓
- "998244353": no "00" → 9 ✓
- "32000": run of 3 zeros → 1 pair → 5 − 1 = 4 ✓

Edge cases checked: single character (answer 1), odd-length zero runs (leftover single '0' uses the "0" button).

Implementation is a simple O(n) scan:

```python
def main():

    S = sys.stdin.readline().strip()
    n = len(S)
    i = 0

        if S[i] == '0' and S[i + 1] == '0':
            pairs += 1
            i += 2
        else:
            i += 1
    print(n - pairs)

main()
```
