**Input parsing consideration:**
Input might have all numbers on lines, but safest to read all tokens and consume them: first token is N, then 1+2+...+N = N(N+1)/2 tokens follow. Reading token by token avoids any whitespace/line-formatting issues.

Implementation:
```python
import sys

def main():
    data = sys.stdin.read().split()
    idx = 0
    n = int(data[idx]); idx += 1
    A = []
    for i in range(1, n + 1):
        row = [int(data[idx + j]) for j in range(i)]
        idx += i
        A.append(row)
    cur = 1
    for j in range(1, n + 1):
        hi, lo = max(cur, j), min(cur, j)
        cur = A[hi - 1][lo - 1]
    print(cur)

main()
```
