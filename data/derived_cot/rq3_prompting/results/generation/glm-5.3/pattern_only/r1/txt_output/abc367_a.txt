=== ANSWER ===
Looking at this problem:

- Takahashi sleeps from B to C (circular over 24 hours). Sleep duration is `s = (C - B) mod 24`.
- Relative to bedtime B, he is asleep during hours `[0, s)` after B and awake during `[s, 24)`.
- So he's awake at A iff `(A - B) mod 24 >= (C - B) mod 24`. This handles both the wrap-around and non-wrap-around cases uniformly.

Verification with samples:
- Sample 1: `(21-8)%24=13 >= (14-8)%24=6` → Yes ✓
- Sample 2: `(0-21)%24=3 >= (7-21)%24=10` → false → No ✓
- Sample 3: `(10-7)%24=3 >= (17-7)%24=10` → false → No ✓

Python's `%` handles negatives correctly (returns non-negative), so no extra care needed. Boundary case: at exactly C (wake time) he's awake, and `>=` correctly yields Yes there.

```python
A, B, C = map(int, input().split())
print("Yes" if (A - B) % 24 >= (C - B) % 24 else "No")
```
