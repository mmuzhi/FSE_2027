We have K=1. We need to determine if S can be transformed to T with at most 1 edit operation (insert, delete, or replace a character).

This is the classic "one edit distance" problem.

Standard approach:
- Let n = len(S), m = len(T).
- If |n - m| > 1, print "No".
- If n == m: S and T differ in exactly 0 or 1 positions → "Yes" if the number of differing positions is ≤ 1.
- If |n - m| == 1: assume WLOG S is shorter (if not, swap). Then we need to check if S can be transformed into T by one insertion. This means: find the first position where they differ; after that, T[i+1:] must equal S[i:] (i.e., skipping one character in the longer string).

More precisely: let S be the shorter string (length n) and T the longer (length n+1). Find the first index i where S[i] != T[i]. If no such index exists (S is a prefix of T), answer is Yes. Otherwise, check if S[i:] == T[i+1:]. If yes, answer Yes, else No.

def one_edit(S, T):
    n, m = len(S), len(T)
    if abs(n - m) > 1:
        return False
    if n > m:
        S, T, n, m = T, S, m, n
    i, j = 0, 0
    edits = 0
    while i < n and j < m:
        if S[i] == T[j]:
            i += 1
            j += 1
        else:
            edits += 1
            if edits > 1:
                return False
            if n == m:
                i += 1
                j += 1
            else:
                j += 1  # skip char in longer string
    if i < n or j < m:
        edits += 1  # one leftover char in longer string
    return edits <= 1
