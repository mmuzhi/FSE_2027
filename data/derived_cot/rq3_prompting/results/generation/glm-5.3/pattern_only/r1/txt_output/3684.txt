class Solution:
    def hasMatch(self, s: str, p: str) -> bool:
        pre, suf = p.split('*')
        n, lp, ls = len(s), len(pre), len(suf)

=== ANSWER ===
```python
class Solution:
    def hasMatch(self, s: str, p: str) -> bool:
        pre, suf = p.split('*')
        n = len(s)
        lp = len(pre)
        for i in range(n - lp + 1):
            if s[i:i + lp] == pre and s.find(suf, i + lp) != -1:
                return True
        return False
```

**Reasoning summary:**

- **Decisive constraint:** Split `p` at `'*'` into `pre` and `suf`. The pattern becomes `pre + X + suf` (X arbitrary, possibly empty). This is a substring of `s` iff there exist indices `i`, `j` with `s[i:i+|pre|] == pre`, `s[j:j+|suf|] == suf`, and `j >= i + |pre|` (then `X = s[i+|pre|:j]`).
- **Approach:** For each occurrence `i` of `pre` in `s`, use `s.find(suf, i + |pre|)` to check if `suf` occurs at or after where `pre` ends. With lengths ≤ 50, this brute force is trivially fast.
- **Edge cases checked:**
  - Empty `pre` (`p` starts with `*`): loop starts at `i=0`, `s[0:0] == ""` matches; correct.
  - Empty `suf` (`p` ends with `*`): `s.find("", i+|pre|)` returns a non-negative index since `i + |pre| <= n`; correct.
  - `p = "*"`: returns True, valid since `s` is non-empty (choose `X` = one character).
  - `|pre| > |s|`: `range` is empty → False, correct.
- **Verified against examples:** `"leetcode"/"ee*"`→True, `"car"/"c*v"`→False, `"luck"/"u*"`→True.
