There are N boxes arranged in a row, and some of these boxes contain cookies.
The state of these boxes is represented by a string S of length N.

Determine how many of the N boxes will be empty after D days have passed.

- After two days have passed, only the 3rd box from the left contains a cookie. Therefore, four out of the five boxes are empty.

Even though Takahashi might choose differently on each day than in this example, there will still be four empty boxes after two days.

=== ANSWER ===
Looking at this problem:

**Key insight:** Each box holds at most one cookie. Each day, eating one cookie converts exactly one `@` box into an empty box. So after D days, exactly D additional boxes become empty regardless of choices. Answer = (count of `.`) + D = (N − count of `@`) + D.

**Verification with samples:**
- Sample 1: 5 − 3 + 2 = 4 ✓
- Sample 2: 3 − 3 + 3 = 3 ✓
- Sample 3: 10 − 7 + 4 = 7 ✓

**Edge cases:** D = count(`@`) means all cookies eaten → answer = N (formula gives N − c + c = N ✓). Guarantee that count(`@`) ≥ D ensures feasibility.

```python
def main():
    import sys
    data = sys.stdin.read().split()
    n, d = int(data[0]), int(data[1])
    s = data[2]
    print(n - s.count('@') + d)

main()
```
