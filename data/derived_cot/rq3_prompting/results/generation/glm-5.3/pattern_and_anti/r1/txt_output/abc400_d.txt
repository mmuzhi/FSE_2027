- **Key insight**: Kicks only ever turn walls into roads (monotone), so the minimum kicks to make a cell *standable* can be modeled with **0‑1 BFS over cells**:
  - cost 0 edge: move to an adjacent original road cell;
  - cost 1 edge: kick in a direction — cells `u+d` and `u+2d` (if inside the grid) become standable with one kick.

A short exchange argument (any kick that destroys a wall entered later from another side can be postponed/redone from that side at no extra cost) shows this model is exact: real optimum = BFS distance. Verified against all four samples (e.g. sample 3: kick right gives target at `u+2d` with cost 1; sample 2: cost 1).

Implementation: flat grid padded by 2 on all sides (stride `W+4`) so `u±1, u±2, u±stride, u±2*stride` never wrap; padding cells get a preset distance so kicks into them are ignored; `road` is a bytearray (`.→1, #→0`). Distance is assigned at enqueue time (each cell enqueued at most once, no stale entries), 0-edges via `appendleft`, 1-edges via `append`. Early exit when the shop cell is popped.

from collections import deque

def main():
    data = sys.stdin.buffer.read().split()
    H = int(data[0]); W = int(data[1])
    rows = data[2:2 + H]
    A = int(data[2 + H]); B = int(data[3 + H])
    C = int(data[4 + H]); D = int(data[5 + H])

    st = W + 4
    N = (H + 4) * st
    BIG = 1 << 30

    road = bytearray(N)
    dist = [-1] * N

    big2 = [BIG] * (2 * st)
    dist[0:2 * st] = big2
    dist[(H + 2) * st:N] = big2

    tbl = bytes(1 if k == 46 else 0 for k in range(256))
    side = (BIG, BIG)
    for i in range(H):
        off = (i + 2) * st + 2
        road[off:off + W] = rows[i].translate(tbl)
        dist[off - 2:off] = side
        dist[off + W:off + W + 2] = side

    start = (A + 1) * st + (B + 1)
    target = (C + 1) * st + (D + 1)

    dist[start] = 0
    dq = deque([start])
    popleft = dq.popleft
    append = dq.append
    appendleft = dq.appendleft
    st2 = st + st

    while dq:
        u = popleft()
        if u == target:
            print(dist[u])
            return
        d0 = dist[u]
        d1 = d0 + 1
        v = u + 1
        if road[v] and dist[v] < 0:
            dist[v] = d0; appendleft(v)
        v = u - 1
        if road[v] and dist[v] < 0:
            dist[v] = d0; appendleft(v)
        v = u + st
        if road[v] and dist[v] < 0:
            dist[v] = d0; appendleft(v)
        v = u - st
        if road[v] and dist[v] < 0:
            dist[v] = d0; appendleft(v)
        v = u + 1
        if dist[v] < 0:
            dist[v] = d1; append(v)
        v = u + 2
        if dist[v] < 0:
            dist[v] = d1; append(v)
        v = u - 1
        if dist[v] < 0:
            dist[v] = d1; append(v)
        v = u - 2
        if dist[v] < 0:
            dist[v] = d1; append(v)
        v = u + st
        if dist[v] < 0:
            dist[v] = d1; append(v)
        v = u + st2
        if dist[v] < 0:
            dist[v] = d1; append(v)
        v = u - st
        if dist[v] < 0:
            dist[v] = d1; append(v)
        v = u - st2
        if dist[v] < 0:
            dist[v] = d1; append(v)

    print(dist[target])

main()
