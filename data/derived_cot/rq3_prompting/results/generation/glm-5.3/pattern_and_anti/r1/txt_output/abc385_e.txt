Looking at this problem:

- A Snowflake Tree kept as an **induced subgraph** of T has: center `c`, middles = a subset `M` of `c`'s neighbors in T, and each middle `v ∈ M` gets exactly `y` leaves which must be direct neighbors of `v` in T other than `c`. Since T is a tree, no unintended edges can appear among these chosen vertices (any extra edge would create a cycle in T), so the induced subgraph is automatically a valid Snowflake Tree.

- So we must maximize `1 + x + x*y` over choices of center `c`, subset `M ⊆ N(c)` of size `x`, and `y ≥ 1` such that every `v ∈ M` has `deg(v) - 1 ≥ y`.

- For a fixed center `c`, let `a_1 ≥ a_2 ≥ ... ≥ a_k` be the values `deg(v)-1` for `v ∈ N(c)` sorted descending. For `x = i`, best `y = a_i` (if `a_i ≥ 1`), giving candidate `i*(a_i+1)`. Take max over `i`, then add 1 for the center. Answer is `N - best_total`.

Verification on samples:
- Sample 1: center 4, values [2,2,0] → i=2 gives 2*3=6, total 7, answer 8-7=1 ✓
- Sample 2: center 1, values [1] → 1*2=2, total 3, answer 0 ✓
- Sample 3: center 2, values [3,1,1] → i=3 gives 3*2=6, total 7, answer 10-7=3 ✓

Complexity: O(N log N) total (sum of degrees = 2(N-1), each neighbor list sorted). Fine for N = 3×10⁵.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    adj = [[] for _ in range(n + 1)]
    vals = data[1:]
    m2 = 2 * (n - 1)
    for i in range(0, m2, 2):
        u = int(vals[i]); v = int(vals[i + 1])
        adj[u].append(v)
        adj[v].append(u)

    dm = [0] * (n + 1)
    for v in range(1, n + 1):
        dm[v] = len(adj[v]) - 1

    best = 0
    for c in range(1, n + 1):
        lst = [dm[v] for v in adj[c]]
        lst.sort(reverse=True)
        b = best
        i = 0
        for a in lst:
            i += 1
            if a < 1:
                break
            val = i * (a + 1)
            if val > b:
                b = val
        best = b

    print(n - best - 1)

main()
