from collections import Counter

def main():

Looking at this problem:

**Key insight:** A full house from 7 cards exists if and only if there are two *distinct* values a ≠ b where value a appears at least 3 times and value b appears at least 2 times. (We can then pick 3 copies of a and 2 copies of b.)

**Edge case (Sample 3):** Seven identical cards fail because we need x ≠ y — a single value with count ≥ 5 doesn't help since the pair must come from a *different* value.

**Plan:** Count frequencies with `Counter`, then double-loop over distinct values checking the condition. Trivially fast (≤7 distinct values).

**Recheck against samples:**
- Sample 1: cnt[1]=3, cnt[4]=2 → Yes ✓
- Sample 2: max count is 2 → No ✓
- Sample 3: only value 7 (count 7), no other value with count ≥ 2 → No ✓
- Sample 4: cnt[13]=3, cnt[1]=2 → Yes ✓
- Tricky case [1,1,1,1,1,2,3]: cnt[1]=5 but no other value with count ≥ 2 → No (correct, since x≠y required).
