```python
class Solution:
    def minCosts(self, cost: List[int]) -> List[int]:
        answer = []
        current_min = float('inf')
        for c in cost:
            current_min = min(current_min, c)
            answer.append(current_min)
        return answer
```

=== ANSWER ===
Looking at this problem:

- **Decisive insight**: Since swaps with anyone in front of us are allowed at their cost, and anyone behind us swaps with us for free, the optimal strategy to reach position `i` is: pay the cheapest person among `0..i` to swap with them (landing at slot `j ≤ i`), and if `j < i`, the person at slot `i` is now behind us and swaps with us for free to bring us to slot `i`. So `answer[i] = min(cost[0..i])` — the prefix minimum.

- **Verification against Example 1**: cost = [5,3,4,1,3,2] → prefix mins = [5,3,3,1,1,1] ✓. Example 2: [1,2,4,6,7] → [1,1,1,1,1] ✓.

- **Edge case**: n=1 → [cost[0]] (direct swap), handled naturally by the loop.

The invariant is simple: maintain running minimum while scanning left to right.

```python
from typing import List

class Solution:
    def minCosts(self, cost: List[int]) -> List[int]:
        answer = []
        current_min = float('inf')
        for c in cost:
            current_min = min(current_min, c)
            answer.append(current_min)
        return answer
```
