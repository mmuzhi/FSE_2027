We have a grid of n x m elements, limits per row, and k. We want to select at most k elements total, with at most limits[i] from row i, maximizing the sum.

Since all values are non-negative (0 <= grid[i][j] <= 10^5), we want to take as many of the largest elements as possible.

Greedy approach: From each row i, take the top limits[i] elements (since all values are non-negative, taking more can't hurt). Then from this pool of candidates, take the top k elements and sum them.

This works because:
1. Any optimal solution uses elements from row i that are among the top limits[i] of that row (if it uses fewer, or non-top elements, we can swap for top ones without decreasing sum).
2. Since values are non-negative, taking exactly min(k, pool size) elements from the pool top is optimal. Actually since k <= sum(limits), and pool size = sum(limits), we take exactly k elements... well, at most k, and k <= sum(limits), so we take top k from the pool.

Complexity: For each row, sorting takes O(m log m), total O(n * m log m). With n, m <= 500, that's 250,000 elements, fine. Alternatively, use heapq.nlargest.

Implementation:
```python
import heapq

class Solution:
    def maxSum(self, grid: List[List[int]], limits: List[int], k: int) -> int:
        candidates = []
        for row, lim in zip(grid, limits):
            candidates.extend(heapq.nlargest(lim, row))
        return sum(heapq.nlargest(k, candidates))
```

=== ANSWER ===
```python
import heapq
from typing import List

class Solution:
    def maxSum(self, grid: List[List[int]], limits: List[int], k: int) -> int:
        # Gather candidates: top limits[i] elements from each row.
        # Since all values are non-negative, an optimal solution only ever
        # uses elements from this candidate pool.
        candidates = []
        for row, lim in zip(grid, limits):
            if lim > 0:
                candidates.extend(heapq.nlargest(lim, row))
        # Take the top k from the candidate pool (k <= len(candidates) guaranteed).
        return sum(heapq.nlargest(k, candidates))
```
