**Analysis**

For query k, transforming T = S_k into target S_j (j<k) optimally costs |S_k| + |S_j| − 2·LCP(S_k, S_j) (delete down to the common prefix, then append). The empty option costs |S_k|. So:

answer_k = |S_k| − max(0, max_{j<k} (2·LCP(S_k,S_j) − |S_j|)).

**Key fact:** max_j (2·LCP − |S_j|) equals the max over all trie nodes v on S_k's path of (2·depth(v) − minlen(v)), where minlen(v) is the minimum length of an earlier string passing through v. (For any j, at v = LCP node the node value is ≥ its individual value; conversely any node value is achieved-or-beaten by the string realizing minlen.) Root's value is ≤ 0, matching the "empty" clamp.

**Algorithm:** Build a trie incrementally. For each string: first walk its path (stopping when a child doesn't exist — no earlier string shares that prefix), tracking best = max(2·depth − minlen); output |S_k| − best if best > 0 else |S_k|. Then insert the string, updating minlen along the path. Total work O(Σ|S_i|) dictionary operations.

Verified against all three samples (e.g. sample 1: k=3 "snuuk" shares only "snu" (minlen 5): 6−5=1 → 5−1=4 ✓; sample 3 all eight outputs match).

Implementation uses a flat dict keyed by `(node<<5) | char_code` (codes 1..26 via `cb & 31`) for speed and memory.
