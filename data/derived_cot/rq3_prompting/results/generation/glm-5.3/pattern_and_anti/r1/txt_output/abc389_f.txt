Fenwick lower_bound on prefix sums: standard technique — descend the tree. Since values (delta) are non-negative, prefix sums are non-decreasing, so binary lifting works: 

```
def lower_bound(fen, target, size):  # smallest idx with prefix >= target
    pos = 0
    rem = target
    log = size.bit_length() maybe
    pw = highest power of 2 ≤ size
    while pw:
        npos = pos + pw
        if npos <= size and fen[npos] < rem:
            pos = npos
            rem -= fen[npos]
        pw >>= 1
    return pos + 1
```

This gives smallest index with prefix sum ≥ target (or size+1 if none).
