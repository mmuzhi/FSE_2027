**Approach.** The query asks whether the multisets of `A[l..r]` and `B[L..R]` coincide, which requires equal lengths and equal counts of every value. Assign each value `v ∈ [1,N]` an independent random 60-bit integer `h[v]`. Then define prefix sums `PA[i] = Σ h[A_j]` for `j ≤ i` (same for `B`). The multisets match iff `r-l == R-L` and `PA[r]-PA[l-1] == PB[R]-PB[L-1]`: if the count vectors differ, the hash difference is a nonzero linear form in independent uniform 60-bit values, which is zero with probability ≤ 2⁻⁶⁰ per query (≤ ~10⁻¹³ over all queries). This runs in O(N+Q).

**Invariant checked:** `PA[i]` is the sum of hashes of the first `i` elements of `A`, so segment hash differences compare exactly the multiset hash sums; length equality is checked explicitly (hash check alone can't detect pure length mismatch safely).

**Edge cases:** `l-1 = 0` and `R = n` are handled by the 1-indexed prefix arrays with leading 0.

Verified against both samples logically (e.g., sample 1 query 3: `h1+2h2+h3` vs `h1+h2+h3+h4` collide only if `h2=h4`), and Python's arbitrary-precision ints avoid any overflow with 60-bit hashes.
