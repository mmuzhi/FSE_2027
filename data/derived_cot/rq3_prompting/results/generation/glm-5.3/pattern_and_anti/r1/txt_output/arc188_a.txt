For a non-empty string T consisting of A, B, and C, we call it a good string if it can be turned into an empty string by performing the following two types of operations any number of times in any order.

Looking at this problem:

**Key insight — characterization of good strings:** With counts $(a,b,c)$, operations exist iff $a\equiv b\equiv c \pmod 2$ (op1 flips one parity, op2 flips all three; feasibility of ordering follows by doing all op2's first). So a substring is good iff its parity vector of counts is $(0,0,0)$ or $(1,1,1)$, i.e. prefix parity vectors $P_{i-1}, P_j$ lie in the same coset of $\{000,111\}$ in $\mathbb{F}_2^3$. There are 4 cosets (classes); letters A,B,C correspond to the three nonzero steps of $\mathbb{Z}_2^2$. Number of good substrings $=\sum_c \binom{m_c}{2}$ where $m_c$ counts positions $0..N$ whose class is $c$.

So: DP over positions with state = (current class, histogram $m_0..m_3$), score determined by final histogram. State space fits ($\le 4\cdot\binom{54}{4}$ transitions), vectorized with numpy using packed integer keys `c<<18 | m0<<12 | m1<<6 | m2` (m3 implied). Verified against sample 1 (AAAB → classes 0,1,0,1,3, score 2; others score 1) and sample 3. A pure-Python dict fallback is included.
