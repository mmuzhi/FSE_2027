Looking at this problem:

- Only the four people of couples $a,b$ move; each swap exchanges an occurrence of $a$ with an occurrence of $b$. The set of 4 positions is invariant, and **any** assignment of 2 of those positions to $a$ (rest to $b$) is reachable in ≤2 swaps.
- So the goal is achievable iff the 4 sorted positions $x_1<x_2<x_3<x_4$ split into two adjacent dominoes. The pairings $(x_1,x_3),(x_2,x_4)$ and $(x_1,x_4),(x_2,x_3)$ can never both be adjacent (gaps ≥2 and ≥3), so we need $x_2=x_1+1$ and $x_4=x_3+1$.
- Disjoint couples (all of $a$ before all of $b$) would force $a$ adjacent — impossible. Thus only two patterns exist (WLOG $l_a<l_b$, both spans ≥2):
  - **Alternating**: $b$ at $(l_a+1, r_a+1)$ — count pairs where value at $(l,r)$, span ≥2, meets value at $(l+1, r+1)$.
  - **Nested**: $b$ at $(l_a+1, r_a-1)$ — needs inner non-adjacent too, i.e. outer span ≥ 4 — count pairs where value at $(l,r)$, span ≥4, meets value at $(l+1, r-1)$.

Each unordered pair is counted exactly once (from the left/outer member), and no pair matches both patterns. Verified against all three samples (1, 0, 4) and hand-checked nested examples like `[1,2,3,4,4,3,2,1]` → answer 2.

Implementation: map first-occurrence position → second-occurrence position (keys unique), then scan. O(N) per test, total O(ΣN).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    pos = 0
    t = int(data[pos]); pos += 1
    out = []
    for _ in range(t):
        n = int(data[pos]); pos += 1
        m = 2 * n
        arr = data[pos:pos + m]
        pos += m
        first = {}
        d = {}
        for i in range(m):
            v = arr[i]
            if v in first:
                d[first[v]] = i
            else:
                first[v] = i
        cnt = 0
        get = d.get
        for f, s in d.items():
            span = s - f
            if span >= 2:
                g = get(f + 1, -1)
                if g == s + 1:
                    cnt += 1
                elif span >= 4 and g == s - 1:
                    cnt += 1
        out.append(str(cnt))
    sys.stdout.write("\n".join(out) + "\n")

main()
```
