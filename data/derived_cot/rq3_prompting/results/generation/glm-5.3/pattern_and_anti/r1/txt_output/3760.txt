An element at index j can be assigned to a group i if groups[i] is divisible by elements[j].
If there are multiple elements that can be assigned, assign the element with the smallest index j.
If no element satisfies the condition for a group, assign -1 to that group.

Groups 0 and 3 cannot be assigned any element.

Explanation:

```python
class Solution:
    def assignElements(self, groups: List[int], elements: List[int]) -> List[int]:
        M = max(groups)
        best = [-1] * (M + 1)  # best[v] = min element index whose value divides v
        seen = set()

                continue
            seen.add(d)

                if best[m] == -1:

        return [best[g] for g in groups]
```

```python
from typing import List

class Solution:
    def assignElements(self, groups: List[int], elements: List[int]) -> List[int]:
        M = max(groups)
        best = [-1] * (M + 1)
        seen = [False] * (100001)
        for j, d in enumerate(elements):
            if d > M or seen[d]:
                continue
            seen[d] = True
            for m in range(d, M + 1, d):
                if best[m] == -1:
                    best[m] = j
        return [best[g] for g in groups]
```

seen as array of size 100001 (values ≤ 10^5 per constraints). This avoids set hashing overhead slightly. Fine.

Double-check invariant: best[v] after all processing = min index j such that elements[j] divides v. Proof sketch: by induction on j — after processing element j (first occurrence of value d_j), every multiple of d_j that was unmarked gets j; marked ones retain a smaller index from a value dividing them. Any element value that divides v eventually marks v or v was already marked by an earlier-index element. ✓

Complexity: O(len(elements) + M·H(distinct values) + len(groups)) time, O(M) space. Done.

=== ANSWER ===
Looking at the constraints (10^5 groups/elements, values ≤ 10^5), the naive O(n·m) pairing is too slow. Two candidates: (a) enumerate divisors of each group value in O(√g) — up to ~3·10^7 ops in Python, too slow; (b) sieve-style marking: process element values in index order, marking their multiples with the current element index (skip already-marked). Total marking work is bounded by the harmonic sum Σ M/d ≈ M·ln(M) ≈ 1.2M ops — decisively better. Committing to (b).

**Ledger:**
- Invariant: `best[v]` = smallest element index whose value divides v; since we process elements in index order and never overwrite a marked slot, each multiple keeps the first (smallest-index) divisor seen.
- Precompute per-value first occurrence implicitly via `seen` array; skip values > max(groups) (they can't divide any group).
- Edge cases: element value 1 divides everything; duplicates in elements skipped; groups with no divisor get -1.
