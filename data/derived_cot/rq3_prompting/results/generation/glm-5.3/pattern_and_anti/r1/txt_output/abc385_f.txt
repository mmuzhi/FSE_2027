- 1 \leq X_1 < \dots < X_N \leq 10^9

```python
import sys
from decimal import Decimal, getcontext

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    if n == 1:
        print(-1)
        return
    vals = list(map(int, data[1:1+2*n]))
    xs = vals[0::2]
    hs = vals[1::2]
    bn = None
    bd = 1
    for i in range(n-1):
        num = hs[i]*xs[i+1] - hs[i+1]*xs[i]
        den = xs[i+1] - xs[i]
        if bn is None or num*bd > bn*den:
            bn, bd = num, den
    if bn < 0:
        print(-1)
    else:
        getcontext().prec = 60
        print(Decimal(bn)/Decimal(bd))

main()
```

Looking at this problem:

**Key derivation:** From P=(0,h), building i is visible iff ∃y∈[0,H_i] such that the segment from (0,h) to (X_i,y) passes strictly above every building j<i at x=X_j. The constraint on y is y > y_j where y_j = h + (H_j−h)·X_i/X_j (touching counts as intersection, confirmed by sample 1's explanation at h=1.5). Feasibility ⟺ ∀j<i: y_j < H_i, which algebraically reduces to **h > T(j,i) = (H_j·X_i − H_i·X_j)/(X_i − X_j)** — the height at x=0 of the line through the tops of buildings j and i. So all buildings are visible iff h > L = max over pairs j<i of T(j,i).

**Computing L:** Transform each point to (u,v)=(1/X, H/X). Then T(j,i) = (v_j−v_i)/(u_j−v... ) i.e. the slope between transformed points. Since a slope over a long interval is a weighted average of slopes over sub-intervals, the maximum over all pairs is attained by **adjacent indices** (adjacent in u-order = consecutive buildings). So L = max over i of T(i,i+1), computed in O(N) with exact integer fraction comparison.

Answer: if L < 0 (or N=1) print `-1`, else print L (exact rational, high-precision decimal output).

Verified against all four samples: sample 1 gives max(−1, 1.5)=1.5; sample 2 gives −98<0 → −1; sample 3 gives 0; sample 4 gives 120/7 ≈ 17.142857142857. All match.
