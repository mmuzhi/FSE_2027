**Reasoning:**

- **Key fact:** A palindrome `P` with `S` as prefix must have the form `S + reverse(S[:m])` for some `m`, and `P` is a palindrome iff the suffix `S[m:]` of `S` is a palindrome. So the shortest answer uses the smallest `m`, i.e., we need the **longest palindromic suffix** of `S`.
- **How to find it:** A suffix of `S` of length `k` is a palindrome ⇔ that suffix equals the prefix of `reverse(S)` of length `k`. So build `T = reverse(S) + '#' + S` and compute the KMP failure function; the final failure value `lp` is exactly the longest palindromic suffix length. Answer: `S + reverse(S[:n-lp])`.
- **Complexity:** O(n) with n ≤ 500000 (T has ~10^6 chars), fine for Python with an optimized loop.
- **Verification on samples:** `ABC` → lp=1 → `ABCBA`; `Z` → `Z`; `TREE` → lp=2 (`EE`) → `TREERT`. All match. Edge case `S` already a palindrome gives `S` itself.
