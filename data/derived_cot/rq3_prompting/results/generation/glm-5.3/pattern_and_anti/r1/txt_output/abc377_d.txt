def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    best = [m+1] * (m+2)

=== ANSWER ===
**Approach:** For a fixed left endpoint `l`, the pair `(l, r)` is invalid iff there exists an interval `i` with `L_i ≥ l` and `R_i ≤ r`. Define `g(l) = min{ R_i : L_i ≥ l }` (or `M+1` if none). Then valid `r` for this `l` are exactly `l ≤ r < g(l)`, giving `max(0, g(l) - l)` pairs (note `g(l) ≥ l` always since `R_i ≥ L_i ≥ l`).

Compute `best[x] = min R_i` among intervals with `L_i = x`, then `g` is the suffix minimum of `best`, computed in one right-to-left sweep. Total complexity O(N + M).

**Verification on samples:**
- Sample 1: g = [2,4,4,5] for l=1..4 → 1+2+1+1 = 5 ✓
- Sample 2: g(l) = l everywhere → 0 ✓
- Sample 3: hand-computed suffix minima give 102 ✓
