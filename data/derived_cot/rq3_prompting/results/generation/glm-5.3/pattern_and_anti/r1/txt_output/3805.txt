```python
class Solution:
    def maxActiveSectionsAfterTrade(self, s: str) -> int:
        ones = s.count('1')
        # Get runs
        runs = []  # list of (char, length)
        for c in s:
            if runs and runs[-1][0] == c:
                runs[-1][1] += 1
            else:
                runs.append([c, 1])
        best = 0
        # For interior 1-runs (index i in runs, char '1', 0 < i < len(runs)-1)
        # adjacent runs are '0' runs automatically (runs alternate)
        for i in range(1, len(runs) - 1):
            if runs[i][0] == '1':
                gain = runs[i-1][1] + runs[i+1][1]
                best = max(best, gain)
        return ones + best
    ```

=== ANSWER ===
Looking at this problem:

- Augmenting with '1' at both ends, a valid trade zeroes out an interior maximal block of '1's (flanked by '0's), merging it with its two adjacent zero blocks, then refills that entire merged zero block. Net gain = size of left zero block + size of right zero block.
- Filling any unrelated zero block instead yields gain `|W| - L1 ≤ |W| ≤ Z_left + Z_right` for the same 1-block, so refilling the merged block is always optimal.
- Therefore: decompose `s` into runs; for every '1'-run that has runs on both sides (those neighbors are necessarily '0'-runs in the augmented view), take the sum of adjacent zero-run lengths; answer = count('1') + best gain (0 if no valid block).

Verified against all four examples ("01"→1, "0100"→4, "1000100"→7, "01010"→4). O(n) time.
