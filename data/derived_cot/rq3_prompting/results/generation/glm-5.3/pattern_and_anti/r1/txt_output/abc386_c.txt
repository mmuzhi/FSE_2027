Looking at this problem:

- K=1, so we need edit distance ≤ 1 between S and T.
- If lengths differ by ≥ 2 → No.
- If lengths equal → need at most one mismatch (0 mismatches means already equal, 0 operations allowed).
- If lengths differ by exactly 1 → shorter string must match the longer one with one character skipped: find first mismatch index i, then check the remainder matches (shorter[i:] == longer[i+1:]).

Key invariant: after the first divergence point, everything must align exactly. All checks use fast C-level slicing/comparison, with only a linear scan to find the first mismatch.

Ledger:
- Equal lengths: find first mismatch i, then S[i+1:] == T[i+1:] must hold.
- Diff-by-1 lengths: A = shorter, B = longer; find first mismatch i (possibly i == len(A)), then A[i:] == B[i+1:].
- Edge case: no mismatch in equal-length case → Yes (S == T).

import sys

def main():
    data = sys.stdin.read().split()
    # data[0] is K, guaranteed to be 1
    S = data[1]
    T = data[2]

    ls, lt = len(S), len(T)
    if abs(ls - lt) >= 2:
        print("No")
        return

    if ls == lt:
        if S == T:
            print("Yes")
            return
        i = 0
        while S[i] == T[i]:
            i += 1
        print("Yes" if S[i+1:] == T[i+1:] else "No")
        return

    # lengths differ by exactly 1: check deleting one char from longer gives shorter
    if ls < lt:
        A, B = S, T
    else:
        A, B = T, S
    i = 0
    n = len(A)
    while i < n and A[i] == B[i]:
