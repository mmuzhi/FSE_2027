Implementation:

```python
class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        order = []
        for i, row in enumerate(grid):
            if i % 2 == 0:
                order.extend(row)
            else:
                order.extend(reversed(row))
        return order[::2]
```

```python
class Solution:
    def zigzagTraversal(self, grid: List[List[int]]) -> List[int]:
        # Build the full zigzag order: even rows left->right, odd rows right->left.
        # Skip parity is global over the whole traversal, so flatten first, then
        # take every other element starting at index 0.
        order = []
        for i, row in enumerate(grid):
            if i % 2 == 0:
                order.extend(row)
            else:
                order.extend(row[::-1])
        return order[::2]
```
