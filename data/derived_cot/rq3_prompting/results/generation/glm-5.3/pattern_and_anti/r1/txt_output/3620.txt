Let me analyze this problem.

We have an array `nums` and integer `k`. Each element can be changed by adding an integer in [-k, k] at most once (i.e., each element gets a new value in [nums[i]-k, nums[i]+k], or stays the same which is included in that range). We want to maximize the number of distinct elements.

Classic greedy: sort the array. Process elements in order. Maintain `last` = the last assigned distinct value (initialized to -infinity). For each element x (in sorted order), the best we can assign is max(last + 1, x - k). If that value <= x + k, assign it and increment count, update last. Otherwise skip (can't make it distinct from all previous).

Why greedy works: sorting by value, assigning the smallest possible distinct value ≥ previous+1 within [x-k, x+k] maximizes room for future elements.

Edge case: k = 0. Then each element can only stay the same. The greedy handles this: candidate = max(last+1, x - 0) = max(last+1, x). If x > last, candidate = x which is <= x + 0, so it counts. If x == last, candidate = last+1 > x, skip. So duplicates get counted once. Good.

Implementation:

```python
class Solution:
    def maxDistinctElements(self, nums: List[int], k: int) -> int:
        nums.sort()
        last = float('-inf')
        count = 0
        for x in nums:
            cand = max(last + 1, x - k)
            if cand <= x + k:
                count += 1
                last = cand
        return count
```

- Invariant: `last` = largest distinct value assigned so far; candidate = `max(last+1, x-k)`, accepted iff `candidate <= x+k`.
