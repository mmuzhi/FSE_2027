Looking at this problem: a Snake number's first digit t must be strictly greater than all following digits, meaning all remaining digits are in [0, t-1]. This has a clean closed form per length and a simple tight-prefix walk for the boundary number.

**Plan:**
- f(N) = count of Snake numbers ≤ N. Answer = f(R) − f(L−1).
- Lengths strictly shorter than N: for length d, count = Σ_{t=1..9} t^(d−1) (each trailing digit has t choices).
- Same length as N: first digit t < n₀ contributes t^(k−1); for t = n₀, walk positions i = 1..k−1: branching below with digit d ≤ min(nᵢ, t)−1 contributes min(nᵢ, t)·t^(k−1−i); tight path continues only while nᵢ < t. If the whole tight walk survives, N itself is a Snake number (+1).
