```python
def z_function(s):
    n = len(s)
    z = [0] * n
    z[0] = n
    l, r = 0, 0
    for i in range(1, n):
        if i < r:
            z[i] = min(r - i, z[i - l])
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1
        if i + z[i] > r:
            l, r = i, i + z[i]
    return z
```

=== ANSWER ===
Looking at this problem:

**Key insight:** A window `s[i..i+m-1]` is "almost equal" to `pattern` iff (longest common prefix of `s[i:]` and `pattern`) + (longest common suffix of `s[:i+m]` and `pattern`) ≥ m−1. If the gap between the matched prefix and suffix has length ≤ 1, at most one character needs changing (the gap position); if ≥ 2, both gap endpoints are genuine mismatches.

**Plan:** Two Z-functions — one on `pattern + '#' + s` (forward match length `a` per window), one on reversed strings (suffix match length `b` per window). For window `i`: `a = z1[m+1+i]`, and the window's last char `s[i+m-1]` sits at position `n-i-m` in reversed `s`, so `b = z2[m+1+(n-i-m)]`. Answer is smallest `i` with `a+b ≥ m−1`. O(n+m), deterministic.

**Verification on examples:** Ex1 i=1: a=3 ("bcd"), b=2 ("fg"), 5=m−1 ✓. Ex2 i=4: a=2, b=3, 5=m−1 ✓. Ex3: all windows have a+b<2 → −1 ✓. Ex4 (m=1): condition a+b≥0 trivially true → 0 ✓.

Edge cases: separator `#` caps matches at m; exact matches give a=b=m and pass trivially; for m=1 always returns 0. (This also directly generalizes to the k-consecutive follow-up with condition a+b ≥ m−k.)

```python
class Solution:
    def minStartingIndex(self, s: str, pattern: str) -> int:
        def z_function(t):
            n = len(t)
            z = [0] * n
            l = r = 0
            for i in range(1, n):
                zi = min(r - i, z[i - l]) if i < r else 0
                while i + zi < n and t[zi] == t[i + zi]:
                    zi += 1
                z[i] = zi
                if i + zi > r:
                    l, r = i, i + zi
            return z

        n, m = len(s), len(pattern)
        z1 = z_function(pattern + '#' + s)                 # forward prefix matches
        z2 = z_function(pattern[::-1] + '#' + s[::-1])     # suffix matches via reversal

        for i in range(n - m + 1):
            a = z1[m + 1 + i]                    # LCP of s[i:] and pattern (<= m)
            b = z2[m + 1 + (n - i - m)]          # common suffix of s[:i+m] and pattern (<= m)
            if a + b >= m - 1:
                return i
        return -1
```
