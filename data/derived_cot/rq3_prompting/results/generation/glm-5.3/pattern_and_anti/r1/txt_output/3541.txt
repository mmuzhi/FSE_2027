Note: "at least two words in it that exactly match" — this means two positions in message (duplicates count separately, e.g., message = ["a","a"], banned = ["a"] should return true since two words match). So we count occurrences, not distinct words.

Implementation:

```python
class Solution:
    def reportSpam(self, message: List[str], bannedWords: List[str]) -> bool:
        banned = set(bannedWords)
        count = 0
        for word in message:
            if word in banned:
                count += 1
                if count >= 2:
                    return True
        return False
```
