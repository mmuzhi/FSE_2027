import numpy as np

def main():

    H = int(data[0]); W = int(data[1])

    for j in range(W):

    g = np.minimum(pc, W - pc)

    def wht(a):
        h = 1
        while h < n:
            b = a.reshape(-1, 2 * h)
            lo = b[:, :h]
            hi = b[:, h:]
            x = lo + hi
            y = lo - hi
            lo[:] = x
            hi[:] = y
            h *= 2

    prod = F * G
    hres = wht(prod)
    hres //= n
    print(int(hres.min()))

Looking at this problem:

- Operations commute and double-applied operations cancel, so the final state is determined by a row-flip set and column-flip mask `c` (W ≤ 18 bits).
- For a fixed column mask `c`, each row `v = A_i ⊕ c` independently contributes `min(popcount(v), W - popcount(v))` (flip the row or not).
- So the answer is `min over c of sum_v cnt[v] * g[v⊕c]` where `g[u] = min(popcount(u), W-popcount(u))` — a XOR convolution of `cnt` and `g`, computable for all `c` at once via Walsh–Hadamard Transform in O(W·2^W), vectorized with numpy.

Overflow check: |WHT(cnt)| ≤ H = 2×10^5, |WHT(g)| ≤ 9·2^18 ≈ 2.4×10^6, product ≤ 4.7×10^11; intermediate inverse-WHT values ≤ 2^18·4.7×10^11 ≈ 1.24×10^17, safely within int64.
