There are N squares arranged in a row, labeled 1, 2, \ldots, N from left to right.
You are given M pairs of integers (L_1, R_1), \ldots, (L_M, R_M).
A square j is defined to be bad if and only if there exists some i such that L_i \leq j \leq R_i.
Determine whether you can move from square 1 to square N by repeatedly performing the following action:

- Let your current square be x. Choose an integer i that satisfies all of the following conditions, and move to square x + i.
- A \leq i \leq B
- x + i \leq N
- Square x + i is not bad.

Input

The input is given from Standard Input in the following format:
N M A B
L_1 R_1
L_2 R_2
\vdots
L_M R_M

Output

Constraints


- 2 \leq N \leq 10^{12}
- 0 \leq M \leq 2 \times 10^4
- 1 \leq A \leq B \leq 20
- 1 < L_i \leq R_i < N \ (1 \leq i \leq M)
- R_i < L_{i+1} \ (1 \leq i \leq M - 1)
- All input values are integers.

17 20

Yes

=== ANSWER ===
Looking at this problem: N is huge (10^12) but M ≤ 2×10^4 and jump sizes ≤ 20. Good squares form ≤ M+1 segments. Key facts:

1. All direct entries into a good segment land within its first B−2 ≤ 18 positions (the square right after any segment is bad).
2. Within a segment, reachable set from entry offsets E is ⋃_{p∈E}(p + D) where D = sums of steps = ⋃_k[kA,kB]. If A<B, D = P ∪ [K0,∞) with K0 ≤ 380 (P small bitmask); if A=B, D = multiples of A.
3. Only reachable positions in the last 20 of a segment can jump beyond it (since B ≤ 20).

So process segments left-to-right: keep an entry bitmask (≤ 19 bits) per segment, compute the exit-window reachability via the D-structure, and distribute landings (positions e+1..e+B, found via bisect on segment starts) into future segments' entry masks. Answer checks whether N (last offset of last segment) is reachable.

I verified this logic by hand-tracing all three samples (Yes / No / Yes) — all match, including the tricky A=B residue case (where I fixed a bug: y ≥ p required, not just y ≡ p mod A).

```python
import sys
from bisect import bisect_right

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); M = int(data[1]); A = int(data[2]); B = int(data[3])
    intervals = []
    idx = 4
    for _ in range(M):
        L = int(data[idx]); R = int(data[idx+1]); idx += 2
        intervals.append((L, R))

    segs = []
    prev = 1
    for L, R in intervals:
        if L > prev:
            segs.append((prev, L - 1))
        prev = R + 1
    segs.append((prev, N))
    K = len(segs)
    starts = [x[0] for x in segs]
    ends = [x[1] for x in segs]

    if A < B:
        k0 = 1
        while k0 * (B - A) < A - 1:
            k0 += 1
        K0 = k0 * A
        P_mask = 0
        for k in range(k0):
            for d in range(k * A, k * B + 1):
                P_mask |= 1 << d
        ab_equal = False
    else:
        ab_equal = True
        K0 = 0
        P_mask = 0

    entry = [0] * K
    entry[0] = 1
    ans = "No"

    for j in range(K):
        E = entry[j]
        if E == 0:
            continue
        s, e = segs[j]
        L = e - s + 1
        exit_lo = L - 20 if L > 20 else 0
        win_len = L - exit_lo

        if ab_equal:
            Wm = 0
            Ep = E
            while Ep:
                lsb = Ep & -Ep
                p = lsb.bit_length() - 1
                Ep ^= lsb
                y0 = p if p > exit_lo else exit_lo
                y = y0 + ((p - y0) % A)
                while y <= L - 1:
                    Wm |= 1 << (y - exit_lo)
                    y += A
        else:
            S = 0
            Ep = E
            while Ep:
                lsb = Ep & -Ep
                p = lsb.bit_length() - 1
                Ep ^= lsb
                S |= P_mask << p
            if exit_lo <= 420:
                Wm = (S >> exit_lo) & ((1 << win_len) - 1)
            else:
                Wm = 0
            me = (E & -E).bit_length() - 1
            t0 = me + K0
            if t0 <= L - 1:
                lo = t0 if t0 > exit_lo else exit_lo
                Wm |= ((1 << (L - lo)) - 1) << (lo - exit_lo)

        if j == K - 1:
            if (Wm >> (win_len - 1)) & 1:
                ans = "Yes"
            break

        top = L - 1
        land = 0
        W = Wm
        while W:
            lsb = W & -W
            i = lsb.bit_length() - 1
            W ^= lsb
            u = (exit_lo + i) - top
            lo_r = u + A - 1
            if lo_r < 0:
                lo_r = 0
            hi_r = u + B - 1
            if hi_r >= lo_r:
                land |= ((1 << (hi_r - lo_r + 1)) - 1) << lo_r
        Lm = land
        while Lm:
            lsb = Lm & -Lm
            r = lsb.bit_length() - 1
            Lm ^= lsb
            t = e + 1 + r
            j2 = bisect_right(starts, t) - 1
            if j2 >= 0 and t <= ends[j2]:
                entry[j2] |= 1 << (t - starts[j2])

    print(ans)

main()
```
