import sys

def main():
    input_data = sys.stdin.buffer.read().split()
    n = int(input_data[0])
    k = int(input_data[1])
    p = [int(x) - 1 for x in input_data[2:2+n]]
    ans = [0] * n
    visited = [False] * n
    for i in range(n):
        if not visited[i]:
            cycle = []
            j = i
            while not visited[j]:
                visited[j] = True
                cycle.append(j)
                j = p[j]
            L = len(cycle)
            r = pow(2, k, L)
            for idx in range(L):
                ans[cycle[idx]] = cycle[(idx + r) % L]
    sys.stdout.write(' '.join(str(x + 1) for x in ans))

main()

=== ANSWER ===
Looking at this problem:

- One operation transforms P into P∘P (since Q_i = P_{P_i} = P(P(i))), so after K operations the result is P^(2^K).
- Decompose the permutation into cycles; within a cycle of length L, applying P^(2^K) shifts each element by r = 2^K mod L steps (Python's `pow(2, K, L)` handles K up to 10^18 in O(log K)).
- Answer for the element at cycle position idx is the element at position (idx + r) mod L.

Verified against sample 1: cycle [1,5,2,6,4] with L=5, r=8 mod 5=3 gives (6,1,3,2,4,5) ✓. Identity case (sample 2) trivially works, and `pow(2, K, 1) = 0` handles fixed points.

Complexity: O(N + cycles·log K), well within limits.
