There are N islands and M bidirectional bridges connecting two islands. The islands and bridges are numbered 1, 2, \ldots, N and 1, 2, \ldots, M, respectively.

def main():

    N = int(data[0]); M = int(data[1])

Looking at this problem:

- **Key insight**: Any valid walk from 1 to N induces an ordering/orientation of the K required bridges (order by first occurrence); the gaps between consecutive required crossings each cost at least the shortest-path distance between the endpoints. Conversely, following shortest paths in gaps achieves that value. So the answer = min over permutations and orientations of `d(1,s₁)+T₁+d(e₁,s₂)+...+T_K+d(e_K,N)`.
- **Plan**: All-pairs shortest paths via vectorized Floyd–Warshall (N≤400, numpy, ~0.3s), then per query a bitmask DP over subsets of the ≤5 required edges, with state = (set of used edges, current endpoint), using a small precomputed distance table among the ≤12 relevant nodes. Per-query work is tiny (~a few hundred transitions), total well within limits. Python big ints handle the 64-bit answers.

I verified the DP by hand on all three samples (25/70, 5/3, 4000000000) — all match.

            s = poslist[mk ^ low][:]
            if a not in s:
                s.append(a)
            if b2 not in s:
                s.append(b2)
            poslist[mk] = s

        dp = [[BIG] * m for _ in range(full + 1)]
        dp[0][0] = 0
        for mk in range(full):
            cur = dp[mk]
            trans = []
            for j in range(K):
                if (mk >> j) & 1:
                    continue
                a, b2, t = edges[j]
                trans.append((a, b2, t, dp[mk | (1 << j)]))
            for p in poslist[mk]:
                crow = D[p]
                c = cur[p]
                for a, b2, t, nd in trans:
                    v = c + crow[a] + t
                    if v < nd[b2]:
                        nd[b2] = v
                    v = c + crow[b2] + t
                    if v < nd[a]:
                        nd[a] = v

        curf = dp[full]
        ans = BIG
        for p in poslist[full]:
            w = curf[p] + D[p][iN]
            if w < ans:
                ans = w
        sres = str(ans)
        cache[key] = sres
        res.append(sres)
    sys.stdout.write("\n".join(res) + "\n")


main()
