import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    m = int(data[1])
    parent = list(range(n + 1))
    size = [1] * (n + 1)
    
    def find(x):
        root = x
        while parent[root] != root:
            root = parent[root]
        while parent[x] != root:
            parent[x], x = root, parent[x]
        return root
    
    redundant = 0
    idx = 2
    for _ in range(m):
        u = int(data[idx]); v = int(data[idx+1]); idx += 2
        ru, rv = find(u), find(v)
        if ru == rv:
            redundant += 1
        else:
            if size[ru] < size[rv]:
                ru, rv = rv, ru
            parent[rv] = ru
            size[ru] += size[rv]
    
    print(redundant)

main()

=== ANSWER ===
**Analysis:**

- Target: minimum edge deletions to make the graph acyclic. A forest on N vertices with c components has exactly N − c edges, so the answer is M − (N − c), equivalently the number of "redundant" edges that connect two already-connected vertices.
- Approach: Union-Find (DSU with union by size + path compression). For each edge, if both endpoints are already in the same set, the edge closes a cycle and must be counted as deleted. Each such edge can be deleted independently, achieving exactly the cycle rank M − N + c.
- Correctness: keeping only edges that successfully union gives an acyclic graph; keeping more than N − c edges necessarily creates a cycle since components only increase when deleting.
- Complexity: O(M α(N)), fine for N, M ≤ 2×10⁵.
- Edge cases: M = 0 → answer 0 (loop never runs); iterative `find` avoids recursion limits; fast input via `sys.stdin.buffer`.
