You will be given a competitive programming problem.
There are N bags, labeled bag 1, bag 2, \ldots, bag N.
Bag i (1 \leq i \leq N) contains A_i stones.
Takahashi can perform the following operation any number of times, possibly zero:

Choose two bags A and B, and move all stones from bag A into bag B.

Find the number of different possible values for the following after repeating the operation.

- B_1 \oplus B_2 \oplus \cdots \oplus B_N, where B_i is the final number of stones in bag i.
Here, \oplus denotes bitwise XOR.


About bitwise XOR
For non-negative integers a and b, the bitwise XOR a \oplus b is defined as follows:


In the binary representation of a \oplus b, the digit in the 2^k place (k \ge 0) is 1 if and only if exactly one of the digits in the 2^k place of a and b is 1; otherwise, it is 0.


For example, 3 \oplus 5 = 6 (in binary, 011 \oplus 101 = 110).
In general, for k non-negative integers x_1, x_2, \ldots, x_k, their bitwise XOR x_1 \oplus x_2 \oplus \cdots \oplus x_k is defined as (\cdots((x_1 \oplus x_2) \oplus x_3) \oplus \cdots) \oplus x_k, which does not depend on the order of x_1, x_2, \ldots, x_k.

It can be proved that under the constraints of this problem, the number of possible values is finite.

Input

The input is given from Standard Input in the following format:
N
A_1 A_2 \ldots A_N

Output

Print the number of different possible values for B_1 \oplus B_2 \oplus \cdots \oplus B_N after repeating the operation.

Constraints


- 2 \leq N \leq 12
- 1 \leq A_i \leq 10^{17}
- All input values are integers.

Sample Input 1

2 5 7

Sample Output 1

3

If he stops at this point, the XOR is 0 \oplus 5 \oplus 9 = 12.
The other possible XOR values after repeating the operation are 0 and 14.
Therefore, the possible values are 0, 12, 14; there are three values, so the output is 3.

import sys
import numpy as np

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    A = [int(x) for x in data[1:1+n]]
    
    full = (1 << n) - 1
    # subset sums
    ssum = [0] * (1 << n)
    for S in range(1, 1 << n):
        b = (S & -S).bit_length() - 1
        ssum[S] = ssum[S & (S-1)] + A[b]
    
    dp = [None] * (1 << n)
    dp[0] = np.zeros(1, dtype=np.int64)
    
    for S in range(1, 1 << n):
        b = (S & -S)
        rest_mask = S ^ b
        # enumerate submasks of rest_mask
        pieces = []
        sub = rest_mask
        while True:
            T = sub | b
            rem = rest_mask ^ sub
            arr = dp[rem] ^ np.int64(ssum[T])
            pieces.append(arr)
            if sub == 0:
                break
            sub = (sub - 1) & rest_mask
        if len(pieces) == 1:
            dp[S] = pieces[0]  # already single value
        else:
            dp[S] = np.unique(np.concatenate(pieces))
    print(len(dp[full]))

main()

Looking at this problem:

- After any sequence of operations, the stones of each original bag end up together in one final bag (stones are never split). Conversely, **any** partition of {1..N} into blocks is realizable (move every non-representative of a block into the representative). The final XOR equals the XOR of block sums (empty bags contribute 0).

- So the answer is the number of distinct values of "XOR of block sums" over all set partitions of {1..N}. With N ≤ 12, the total count of partitions over all subsets is Σ C(12,k)·Bell(k) ≈ 27.6M.

**Plan:** Subset DP where `dp[S]` holds values from partitions of S, splitting on the block containing the lowest bit of S: for each submask `sub` of `S \ low`, block `T = sub|low` with sum `ssum[T]`, combined as `ssum[T] ^ v` for `v ∈ dp[S\T]`. To be fast in Python, keep `dp[S]` as numpy int64 arrays (multisets — each partition contributes one entry, so no intermediate dedup needed), concatenate all pieces once per S, build the scalar array via `np.repeat`, one vectorized XOR, and a single `np.unique` at the end. All values fit in int64 (sums ≤ 12·10^17 < 2^63).

Verified by hand on sample 1 (A=[2,5,7] → {0,12,14} → 3) and sample 2 ({0, 2·10^17} → 2); the recurrence counts each partition exactly once, so the final distinct count is correct.
