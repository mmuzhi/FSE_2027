=== ANSWER ===
Looking at this problem:

- The `=`s must be centered for the palindrome condition.
- If N is odd, exactly one `=` at the center (two adjacent `=`s can't be mirror-symmetric when N is odd, since that would require N even).
- If N is even, exactly two adjacent `=`s at the two center positions (a single `=` has no center position when N is even).

So the answer is `half` dashes, then `=` (once or twice), then `half` dashes, where the count of `=`s is `1` if N odd else `2`, and `half = (N - count) // 2`.

Verification:
- N=1 → `=` ✓
- N=2 → `==` ✓
- N=3 → `-=-` ✓
- N=4 → `-==-` ✓ (matches sample 1)
- N=7 → `---=---` ✓ (matches sample 2)

All edge cases (N=1, N=2) check out with the unified formula.

n = int(input())
k = 1 if n % 2 == 1 else 2
half = (n - k) // 2
