So the algorithm:
1. Group blocks by column; sort each column's heights.
2. For each block, compute its rank $j$ within its column.
3. $R_j = \max_x h_{x,j}$ for $j = 1..m$ where $m = \min_x k_x$.
4. For query $(T, A)$: answer Yes iff ($j_A > m$) or ($T < R_{j_A}$).

Complexity: $O((N + Q)\log N)$ dominated by sorting. 

Implementation details:
- Column heights: use lists or sort all blocks by (X, Y).

    for _ in range(Q):
        T = int(data[ptr]); A = int(data[ptr + 1]); ptr += 2
        r = rank[A - 1]
        if r > m or T < R[r - 1]:
            out.append("Yes")
        else:
            out.append("No")
    sys.stdout.write("\n".join(out))

main()
