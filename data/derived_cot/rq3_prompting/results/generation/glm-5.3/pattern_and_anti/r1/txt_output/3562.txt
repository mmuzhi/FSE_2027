You will be given a competitive programming problem.
You are given a 2D integer array intervals, where intervals[i] = [l_i, r_i, weight_i]. Interval i starts at position l_i and ends at r_i, and has a weight of weight_i. You can choose up to 4 non-overlapping intervals. The score of the chosen intervals is defined as the total sum of their weights.
Return the lexicographically smallest array of at most 4 indices from intervals with maximum score, representing your choice of non-overlapping intervals.
Two intervals are said to be non-overlapping if they do not share any points. In particular, intervals sharing a left or right boundary are considered overlapping.
An array a is lexicographically smaller than an array b if in the first position where a and b differ, array a has an element that is less than the corresponding element in b.
If the first min(a.length, b.length) elements do not differ, then the shorter array is the lexicographically smaller one.

```python
class Solution:
    def maximumWeight(self, intervals: List[List[int]]) -> List[int]:
        from bisect import bisect_left
        n = len(intervals)
        order = sorted(range(n), key=lambda i: intervals[i][1])
        R = [intervals[i][1] for i in order]
        L = [intervals[i][0] for i in order]
        W = [intervals[i][2] for i in order]
        Idx = [i for i in order]
        T = [bisect_left(R, L[i]) for i in range(n)]

        # dp for current level: lists of (weight, tuple) or None
        # level 1
        cur_w = W
        cur_t = [(Idx[i],) for i in range(n)]
        
        best_w = -1
        best_t = ()
        
        for k in range(1, 5):
            if k == 1:
                pass
            else:
                # compute dp[k][i] from prefix max of dp[k-1]
                # first build prefix arrays of previous level
                pw = [0]*n
                pt = [None]*n
                pw[0] = cur_w[0]; pt[0] = cur_t[0]
                for i in range(1, n):
```

=== ANSWER ===
Looking at this problem:

- **Constraints**: n ≤ 5·10⁴, choose ≤ 4 non-overlapping (closed) intervals, maximize weight, tie-break by lexicographically smallest sorted index array.
- **Approach**: Sort intervals by right endpoint `r`. DP over levels k = 1..4 where `dp[k][j]` = (max weight, lexicographically smallest sorted-index tuple) over valid sets of exactly k intervals whose latest interval in sorted order is `j`. Transition uses a prefix-maximum of level k−1 restricted to intervals with `r < l_j` (found via binary search), since all other chosen intervals must end before `j` starts.
- **Key lemma for tie-breaking**: merging a common new index `x` into two sorted tuples A < B (same size, x absent from both) preserves the order A∪{x} < B∪{x}. Thus prefix maxima keyed by (weight, tuple) compose correctly, and tuples must only be materialized sorted (merge is just insert-and-sort of ≤4 elements).
- Final answer = best over all levels, comparing (weight desc, tuple asc); Python tuple comparison naturally implements the "shorter is smaller" rule for the cross-size ties.

I verified both examples by hand-tracing (outputs `[2,3]` and `[1,3,5,6]`), plus tricky tie cases like weight 16 from `(0,1,3,4)` beating `(2,3,4)`, and equal-weight different-size comparisons like `[0,1,3]` vs `[2,3]`.

Invalid states use weight 0 / empty tuple as sentinels (all real weights ≥ 1), which never win comparisons.

```python
from typing import List
from bisect import bisect_left

class Solution:
    def maximumWeight(self, intervals: List[List[int]]) -> List[int]:
        n = len(intervals)
        order = sorted(range(n), key=lambda i: intervals[i][1])
        L = [0] * n
        R = [0] * n
        W = [0] * n
        Idx = [0] * n
        for pos in range(n):
            it = intervals[order[pos]]
            L[pos] = it[0]
            R[pos] = it[1]
            W[pos] = it[2]
            Idx[pos] = order[pos]
        # T[i] = number of intervals (in sorted order) with r < l_i  -> eligible prefix length
        T = [bisect_left(R, l) for l in L]

        cur_w = W
        cur_t = [(i,) for i in Idx]

        best_w = -1
        best_t = ()

        for level in range(4):
            if level:
                # prefix maxima of previous level: max weight, then min tuple
                pw = cur_w[:]
                pt = cur_t[:]
                for i in range(1, n):
                    wp, tp = pw[i - 1], pt[i - 1]
                    wc, tc = pw[i], pt[i]
                    if wp > wc or (wp == wc and tp < tc):
                        pw[i] = wp
                        pt[i] = tp
                # build dp for level+1 intervals
                nw = [0] * n
                nt = [()] * n
                for i in range(n):
                    ti = T[i]
                    if ti:
                        b = pw[ti - 1]
                        if b:  # valid predecessor state exists
                            nw[i] = b + W[i]
                            nt[i] = tuple(sorted(pt[ti - 1] + (Idx[i],)))
                cur_w, cur_t = nw, nt
            for i in range(n):
                w = cur_w[i]
                if w > best_w or (w == best_w and cur_t[i] < best_t):
                    best_w = w
                    best_t = cur_t[i]
        return list(best_t)
```
