```python
class Solution:
    def sumOfGoodSubsequences(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        size = 10**5 + 3
        count = [0] * size
        total = [0] * size
        
        for x in nums:
            v = x + 1
            cnt = (count[v-1] + count[v+1] + 1) % MOD
            tot = (total[v-1] + total[v+1] + x * cnt) % MOD
            count[v] = (count[v] + cnt) % MOD
            total[v] = (total[v] + tot) % MOD
        
        return sum(total) % MOD
```

Edge cases:
- Single element: nums = [5] → count[6]=1, total[6]=5 → answer 5. Correct.
- x = 0: v = 1, count[v-1] = count[0] which is 0 always (no value maps to index 0 since v = x+1 ≥ 1). Correct — no negative wraparound.
- x = 10^5: v = 10^5+1, count[v+1] = count[10^5+2], within bounds since size = 10^5+3 (indices 0 to 10^5+2). Correct.

The final `sum(total)` could be large but Python handles big integers; take mod at end. Actually sum of up to 10^5 values each < 10^9+7 — fine, then mod.

```python
class Solution:
    def sumOfGoodSubsequences(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        # Offset values by 1 so that value 0's neighbor (v-1) maps to index 0
        size = 10**5 + 3
        count = [0] * size  # count[v+1] = number of good subsequences ending with value v
        total = [0] * size  # total[v+1] = sum of elements of good subsequences ending with value v
        
        for x in nums:
            v = x + 1
            # New subsequences ending at this element with value x:
            # extend any subsequence ending in x-1 or x+1, or start fresh [x]
            cnt = (count[v - 1] + count[v + 1] + 1) % MOD
            tot = (total[v - 1] + total[v + 1] + x * cnt) % MOD
            count[v] = (count[v] + cnt) % MOD
            total[v] = (total[v] + tot) % MOD
        
        return sum(total) % MOD
```
