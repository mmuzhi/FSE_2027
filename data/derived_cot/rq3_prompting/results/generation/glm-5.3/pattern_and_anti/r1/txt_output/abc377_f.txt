from bisect import bisect_left, bisect_right

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    Rset = set(); Cset = set(); Sset = set(); Dset = set()
    idx = 2
    for _ in range(m):
        a = int(data[idx]); b = int(data[idx + 1]); idx += 2
        Rset.add(a); Cset.add(b); Sset.add(a + b); Dset.add(a - b)

    Rl = sorted(Rset); Cl = sorted(Cset)
    Sl = sorted(Sset); Dl = sorted(Dset)

    # ---- singles ----
    bad = len(Rl) * n + len(Cl) * n
    for s in Sl:
        bad += min(s - 1, 2 * n + 1 - s)
    for d in Dl:
        bad += n - abs(d)

    # ---- pairs ----
    pairs = len(Rl) * len(Cl)
    for r in Rl:
        pairs += bisect_right(Sl, r + n) - bisect_left(Sl, r + 1)
        pairs += bisect_right(Dl, r - 1) - bisect_left(Dl, r - n)
    for c in Cl:
        pairs += bisect_right(Sl, c + n) - bisect_left(Sl, c + 1)
        pairs += bisect_right(Dl, n - c) - bisect_left(Dl, 1 - c)
    Deven = [d for d in Dl if not (d & 1)]
    Dodd = [d for d in Dl if (d & 1)]
    for s in Sl:
        lo = max(2 - s, s - 2 * n)
        hi = min(2 * n - s, s - 2)
        lst = Deven if not (s & 1) else Dodd

Looking at this problem:

- A square is unsafe if its row ∈ R, col ∈ C, sum ∈ S, or diff ∈ D (sets of the pieces' rows/cols/diagonals). Occupied squares are automatically covered since their row is in R.
- Answer = N² − |A_R ∪ A_C ∪ A_S ∪ A_D|, via 4-way inclusion–exclusion. All terms are computable in ~O(M²) using bisect range counting and set intersections: e.g., |A_S∩A_D| fixes the square uniquely (parity + bounds), triples like |A_R∩A_S∩A_D| iterate (r,s) with d = 2r−s determined, and the quad iterates (r,c) pairs checking r+c∈S, r−c∈D.

I verified this by hand against all three samples (sample 1 gives |Bad|=62 → answer 2; sample 2 gives 3·10⁹−2 → answer 999999997000000002; sample 3 gives 323 → 77 after carefully recomputing f(17), f(18) and one triple term).
