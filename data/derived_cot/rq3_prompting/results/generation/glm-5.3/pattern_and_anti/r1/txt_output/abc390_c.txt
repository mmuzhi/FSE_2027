import sys

def main():
    data = sys.stdin.buffer.read().split()
    H = int(data[0])
    W = int(data[1])
    grid = [data[2 + i].decode() for i in range(H)]
    
    min_r, max_r = H, -1
    min_c, max_c = W, -1
    for i in range(H):
        row = grid[i]
        for j in range(W):
            if row[j] == '#':
                if i < min_r: min_r = i
                if i > max_r: max_r = i
                if j < min_c: min_c = j
                if j > max_c: max_c = j

        row = grid[i]

                print("No")
                return
    print("Yes")

Looking at this problem:

**Key insight:** Since at least one cell is already black ('#'), the rectangle must contain all '#' cells. Any valid rectangle must contain the minimal bounding box of all '#' cells. If that minimal bounding box contains a '.', then any rectangle containing all '#' cells (which must contain the bounding box) also contains that '.', making it impossible. Conversely, if the bounding box has no '.', we can paint '?' inside it black and '?' outside it white — done.

**Algorithm:**
1. Compute min/max row and min/max column over all '#' cells (using fast `find`/`rfind` per row).
2. Check that no '.' lies inside that bounding box (again with per-row slicing/find at C speed).

This is O(H·W) with negligible Python overhead — well within limits for H, W ≤ 1000.

**Verification on samples:**
- Sample 1: bounding box = rows 1–2, cols 2–4 (1-indexed), contains only '#'/'?' → Yes ✓
- Sample 2: bounding box is the whole grid, contains '.' at center → No ✓
- Sample 3: bounding box is the single '#' cell → Yes ✓

Edge cases: single row/column bounding boxes handled naturally by the loop ranges; guaranteed at least one '#' means bounds are always set.
