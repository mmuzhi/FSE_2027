You will be given a competitive programming problem.
There is a grid of H \times W cells. Let (i, j) denote the cell at the i-th row from the top and the j-th column from the left.
Cell (i, j) is empty if S_{i,j} is ., and blocked if it is #.
Count the number of ways to start from an empty cell and make K moves to adjacent cells (up, down, left, or right), without passing through blocked squares and not visiting the same cell more than once.
Specifically, count the number of sequences of length K+1, ((i_0, j_0), (i_1, j_1), \dots, (i_K, j_K)), satisfying the following.

- 1 \leq i_k \leq H, 1 \leq j_k \leq W, and S_{i_k, j_k} is ., for each 0 \leq k \leq K.
- |i_{k+1} - i_k| + |j_{k+1} - j_k| = 1 for each 0 \leq k \leq K-1.
- (i_k, j_k) \neq (i_l, j_l) for each 0 \leq k < l \leq K.

Input

The input is given from Standard Input in the following format:
H W K
S_{1,1}S_{1,2}\dots S_{1,W}
S_{2,1}S_{2,2}\dots S_{2,W}
\vdots
S_{H,1}S_{H,2}\dots S_{H,W}

Output

Print the answer.

Constraints


- 1 \leq H, W \leq 10
- 1 \leq K \leq 11
- H, W, and K are integers.
- Each S_{i,j} is . or #.
- There is at least one empty cell.

def main():
    data = sys.stdin.read().split()
    H = int(data[0]); W = int(data[1]); K = int(data[2])
    rows = data[3:3+H]
    N = H * W
    free = [False]*N
    for i in range(H):
        s = rows[i]
        for j in range(W):
            if s[j] == '.':
                free[i*W + j] = True
    # neighbors
    nbrs = [()] * N
    nbrs4 = [()] * N
    for i in range(H):
        for j in range(W):
            c = i*W + j
            if free[c]:
                lst = []
                if i > 0 and free[c - W]: lst.append(c - W)
                if i < H-1 and free[c + W]: lst.append(c + W)
                if j > 0 and free[c - 1]: lst.append(c - 1)
                if j < W-1 and free[c + 1]: lst.append(c + 1)
                t = tuple(lst)
                nbrs[c] = t
                nbrs4[c] = t + (N,) * (4 - len(t))
    vis = bytearray(N + 1)
    vis[N] = 1

    def dfs(pos, rem, vis=vis, nbrs=nbrs, nbrs4=nbrs4):
        total = 0
        if rem == 3:
            for np_ in nbrs[pos]:
                if not vis[np_]:
                    vis[np_] = 1
                    for q in nbrs[np_]:
                        if not vis[q]:

                            total += 4 - vis[a] - vis[b] - vis[c] - vis[d]
                    vis[np_] = 0
        elif rem == 2:

                if not vis[np_]:
                    a, b, c, d = nbrs4[np_]
                    total += 4 - vis[a] - vis[b] - vis[c] - vis[d]
        else:
            for np_ in nbrs[pos]:
                if not vis[np_]:
                    vis[np_] = 1
                    total += dfs(np_, rem - 1)
                    vis[np_] = 0
        return total

Looking at this problem:

- Grid ≤ 10×10, K ≤ 11 → count self-avoiding walks of length K from every empty cell. Total SAWs of length 11 on a 10×10 grid is a few million, so a DFS works, but pure Python needs constant-factor care.
- Plan: DFS over free cells only (precomputed neighbor tuples), with the bottom levels **unrolled**: when 2 moves remain, count valid (np, q) pairs inline; when 3 remain, count (np, q, r) triples inline. For fast counting of "unvisited free neighbors", pad neighbor tuples to length 4 with a dummy index that is permanently marked visited, so the count is `4 - vis[a] - vis[b] - vis[c] - vis[d]`. This cuts function calls by ~10×.
- Key invariant: neighbors of a cell are pairwise non-adjacent in a grid, and adjacent cells share no common neighbor, so the inline counts never double-count or miss (visited path cells, current cell, and just-marked cells are all excluded via the visited array; blocked cells never appear in neighbor lists).
- Verified by hand on sample 1 (answer 2 via the unrolled pair count), sample 2 (K=1 → sum of free-neighbor counts = 0), and small line grids (1×3, 1×4 with K=3 give 0 and 2 correctly).

Edge cases: K=1 handled separately; start cell marked visited before DFS and unmarked after; dummy index N stays visited forever.
