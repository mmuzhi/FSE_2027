## Commit

**Key insight:** Write X = 2^E · c² where c is odd (extract the odd square part of X's odd component). X is good ⟺ X is even (E ≥ 1) and its odd part is a perfect square. This gives a canonical form:
- If E is odd, E = 2k+1, X = 2·(2^k c)² → form **2·b²**
- If E is even (E ≥ 2), E = 2k, X = 4·(2^(k-1) c)² → form **4·b²**

These two forms are disjoint (2b₁² = 4b₂² would imply √2 rational), and each b gives a distinct X. So the answer is:

$$\#\{b : 2b^2 \le N\} + \#\{b : 4b^2 \le N\} = \lfloor\sqrt{N/2}\rfloor + \lfloor\sqrt{N/4}\rfloor$$

Using integer arithmetic: `isqrt(N // 2) + isqrt(N // 4)` (valid since 2b² ≤ N ⟺ b² ≤ N//2 for integer b).
