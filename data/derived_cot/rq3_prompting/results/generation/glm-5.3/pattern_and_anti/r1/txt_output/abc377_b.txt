```python
import sys

def main():
```

=== ANSWER ===
Looking at this problem:

- A square (i,j) is safe iff no existing piece is in row i and none is in column j.
- If row i has no '#' and column j has no '#', then square (i,j) is necessarily empty itself.
- Therefore the answer = (number of piece-free rows) × (number of piece-free columns).

**Check against samples:**
- Sample 1: piece-free rows {6,7} → 2; piece-free cols {6,7} → 2; answer 2×2 = 4 ✓
- Sample 2: 8 free rows × 8 free cols = 64 ✓
- Sample 3: free rows {4,6} → 2; free cols {1,7} → 2; answer 4 ✓

Implementation ledger:
- Invariant: safe(i,j) ⇔ '#' not in row i and '#' not in column j (emptiness of (i,j) follows automatically).
- Edge case: no pieces at all → 64 (covered by the formula).

```python
import sys

def main():
    grid = [line.strip() for line in sys.stdin.read().split()]
    row_free = sum(1 for row in grid if '#' not in row)
    col_free = sum(1 for j in range(8) if all(grid[i][j] == '.' for i in range(8)))
    print(row_free * col_free)

main()
```
