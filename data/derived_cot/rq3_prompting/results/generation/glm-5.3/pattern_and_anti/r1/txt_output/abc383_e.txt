You will be given a competitive programming problem.
You are given a simple connected undirected graph with N vertices and M edges, where vertices are numbered 1 to N and edges are numbered 1 to M. Edge i (1 \leq i \leq M) connects vertices u_i and v_i bidirectionally and has weight w_i.
For a path, define its weight as the maximum weight of an edge in the path.
Define f(x, y) as the minimum possible path weight of a path from vertex x to vertex y.
You are given two sequences of length K: (A_1, A_2, \ldots, A_K) and (B_1, B_2, \ldots, B_K). It is guaranteed that A_i \neq B_j (1 \leq i,j \leq K).
Permute the sequence B freely so that \displaystyle \sum_{i=1}^{K} f(A_i, B_i) is minimized.

Input

The input is given from Standard Input in the following format:
N M K
u_1 v_1 w_1
u_2 v_2 w_2
\vdots
u_M v_M w_M
A_1 A_2 \ldots A_K
B_1 B_2 \ldots B_K

Output

Print the minimum value of \displaystyle \sum_{i=1}^{K} f(A_i, B_i).

Constraints


- 2 \leq N  \leq 2 \times 10^5
- N-1 \leq M  \leq \min(\frac{N \times (N-1)}{2},2 \times 10^5)
- 1 \leq K \leq N
- 1 \leq u_i<v_i \leq N (1 \leq i \leq M) 
- 1 \leq w_i \leq 10^9
- 1 \leq A_i,B_i \leq N (1 \leq i \leq K)
- The given graph is simple and connected.
- All input values are integers.

1 3 2
3 4 1

1 4 4
1 1 3

Sample Output 1

8

- f(1,2) = 5: The path from vertex 1 to vertex 2 passing through vertex 4 contains edge 3 with a maximum edge weight of 5. There is no path with a maximum edge weight less than or equal to 4, so 5 is the minimum possible.
- f(1,4) = 2: The path from vertex 1 to vertex 4 passing through vertex 3 contains edge 1 with a maximum edge weight of 2. There is no path with a maximum edge weight less than or equal to 1, so 2 is the minimum possible.
- f(3,4) = 1: The path from vertex 3 to vertex 4 passing through the direct edge contains an edge with a maximum edge weight of 1. No path can have a maximum weight 0 or less, so 1 is the minimum possible.

Thus, \displaystyle \sum_{i=1}^{3} f(A_i, B_i) = 5+2+1=8. No permutation of B yields 7 or less, so the answer is 8.

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    n = int(data[idx]); idx+=1
    m = int(data[idx]); idx+=1
    k = int(data[idx]); idx+=1
    edges = []
    for _ in range(m):
        u = int(data[idx]); v = int(data[idx+1]); w = int(data[idx+2]); idx+=3
        edges.append((w, u, v))
    edges.sort()
    A = data[idx:idx+k]; idx+=k
    B = data[idx:idx+k]
    
    parent = list(range(n+1))
    size = [1]*(n+1)
    cntA = [0]*(n+1)
    cntB = [0]*(n+1)
    for x in A:
        cntA[int(x)] += 1
    for x in B:
        cntB[int(x)] += 1
    
    ans = 0
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    
    for w, u, v in edges:
        ru = find(u); rv = find(v)
        if ru == rv:
            continue
        # union by size
        if size[ru] < size[rv]:

        parent[rv] = ru
        size[ru] += size[rv]

            cntA[ru] = ta - newm
            cntB[ru] = tb - newm

Looking at this problem:

- f(x,y) is the bottleneck (minimax edge) between x and y, which depends only on connectivity thresholds: f(x,y) ≤ t iff x,y are in the same component using edges of weight ≤ t.
- Sum of f over a matching = Σ over thresholds (weight increment) × (number of pairs not yet connected at that threshold). So minimizing the sum means maximizing the number of matched A–B pairs inside the same component at **every** threshold simultaneously.
- Since components form a laminar family (Kruskal merging), a greedy that matches maximally at each merge event achieves the maximum possible matched count at every threshold at once (exchange/counting argument: within a merged component, previously matched pairs carry over and remaining capacity is min(#A,#B) per component). Hence greedy is optimal.

Algorithm: sort edges by weight, run DSU. Each component tracks unmatched counts of A's (cntA) and B's (cntB). When merging components X, Y with edge weight w, newly matchable pairs = min(aX+aY, bX+bY) − min(aX,bX) − min(aY,bY); each contributes w to the answer; update counts by subtracting the matched pairs.

Verified on both samples (sample 1 → 8, sample 2 → 3).

Edge cases: guaranteed A_i ≠ B_j means no zero-cost same-vertex pairs (I still zero-out initial per-vertex min for safety); ties in weight handled naturally since all such matches cost w. Final component contains all K pairs (graph connected), so everything gets matched.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    ptr = 0
    n = int(data[ptr]); m = int(data[ptr+1]); k = int(data[ptr+2]); ptr += 3
    ew = [0]*m; eu = [0]*m; ev = [0]*m
    for i in range(m):
        eu[i] = int(data[ptr]); ev[i] = int(data[ptr+1]); ew[i] = int(data[ptr+2]); ptr += 3
    order = sorted(range(m), key=lambda i: ew[i])

    parent = list(range(n+1))
    rnk = [0]*(n+1)
    cntA = [0]*(n+1)
    cntB = [0]*(n+1)
    for i in range(ptr, ptr+k):
        cntA[int(data[i])] += 1
    ptr += k
    for i in range(ptr, ptr+k):
        cntB[int(data[i])] += 1

    # safety: no vertex can hold both A and B (guaranteed), but zero-out anyway
    for v in range(1, n+1):
        a = cntA[v]; b = cntB[v]
        mm = a if a < b else b
        cntA[v] -= mm
        cntB[v] -= mm

    ans = 0

    def find(x):
        p = parent
        while p[x] != x:
            p[x] = p[p[x]]
            x = p[x]
        return x

    for i in order:
        w = ew[i]
        ru = find(eu[i]); rv = find(ev[i])
        if ru == rv:
            continue
        if rnk[ru] < rnk[rv]:
            ru, rv = rv, ru
        parent[rv] = ru
        if rnk[ru] == rnk[rv]:
            rnk[ru] += 1
        a1 = cntA[ru]; b1 = cntB[ru]
        a2 = cntA[rv]; b2 = cntB[rv]
        ta = a1 + a2; tb = b1 + b2
        m1 = a1 if a1 < b1 else b1
        m2 = a2 if a2 < b2 else b2
        newm = (ta if ta < tb else tb) - m1 - m2
        if newm:
            ans += w * newm
            cntA[ru] = ta - newm
            cntB[ru] = tb - newm
        else:
            cntA[ru] = ta
            cntB[ru] = tb

    sys.stdout.write(str(ans) + "\n")

main()
