```python
import sys
from bisect import bisect_left

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    a = list(map(int, data[2:2 + n]))
    L = sum(a)

    # positions p_i (0-indexed arc start), all distinct in [0, L)
    groups = {}
    groups.setdefault(0, []).append(0)
    s = 0
    for i in range(n - 1):
        s += a[i]
        v = s % L
        groups.setdefault(v % m, []).append(v)

    ans = 0
    for lst in groups.values():
        k = len(lst)
        ans += k * (k - 1) // 2
        lst.sort()

    c = L % m
    if c == 0:
        # both directions of each same-class pair work
        ans *= 2
    else:
        # pairs x < y with (y - x) % m == c, x in class v, y in class (v+c)%m
        for v, lst in groups.items():
            other = groups.get((v + c) % m)
            if other is not None:
                for y in other:
                    ans += bisect_left(lst, y)

    print(ans)

main()
```

**Explanation of the approach:**

Let `p_i` be the clockwise position of rest area `i` (prefix sums mod `L`, where `L = sum(A)`). The clockwise distance from `s` to `t` is `(p_t - p_s) mod L`.

- If `p_t > p_s`, distance is `p_t - p_s` — need it ≡ 0 (mod M), i.e., same residue class mod M. Count: `sum C(k_v, 2)` per class.
- If `p_t < p_s`, distance is `p_t - p_s + L` — need `p_s - p_t ≡ L (mod M)`. Let `c = L % M`. If `c == 0`, this again counts same-class pairs (doubling the total). Otherwise, for each pair of classes `(v, (v+c) % M)`, count pairs `x < y` with `x` in class `v`, `y` in class `(v+c) % M` via binary search.

Complexity: `O(N log N)`, well within limits for `N ≤ 2×10^5`. Verified against all three samples (4, 0, 11).
