=== ANSWER ===
```python
class Solution:
    def countPartitions(self, nums: List[int]) -> int:
        # diff = leftSum - rightSum = total - 2 * rightSum
        # So diff parity always equals total parity: all or nothing.
        return len(nums) - 1 if sum(nums) % 2 == 0 else 0
```
