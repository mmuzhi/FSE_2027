You will be given a competitive programming problem.
You are given a tree with NK vertices. The vertices are numbered 1,2,\dots,NK, and the i-th edge (i=1,2,\dots,NK-1) connects vertices u_i and v_i bidirectionally.
Determine whether this tree can be decomposed into N paths, each of length K. More precisely, determine whether there exists an N \times K matrix P satisfying the following:

- P_{1,1}, \dots, P_{1,K}, P_{2,1}, \dots, P_{N,K} is a permutation of 1,2,\dots,NK.
- For each i=1,2,\dots,N and j=1,2,\dots,K-1, there is an edge connecting vertices P_{i,j} and P_{i,j+1}.

Input

The input is given from Standard Input in the following format:
N K
u_1 v_1
u_2 v_2
\vdots
u_{NK-1} v_{NK-1}

Output

If it is possible to decompose the tree into N paths each of length K, print Yes. Otherwise, print No.

Constraints


- 1 \leq N
- 1 \leq K
- NK \leq 2 \times 10^5
- 1 \leq u_i < v_i \leq NK
- The given graph is a tree.
- All input values are integers.

3 4

**Key insight:** For any vertex `v` with subtree size `sz(v)`, if the edge to its parent is *used* by a path, the portion of that path inside the subtree (a "stub" ending at `v`) has some length `ℓ ∈ [1, K-1]`, and all remaining vertices of the subtree form complete K-vertex paths — so `ℓ ≡ sz(v) (mod K)`, meaning `ℓ` is **uniquely forced**. Hence each child of `v` is either fully resolved internally (requires `sz ≡ 0 mod K`), or contributes a forced-length stub through the edge to `v`. All stub-children lie on the single path through `v`, so at most 2 of them are allowed:

- 0 stubs: `v` starts a stub of length 1 (root can't do this unless K=1).
- 1 stub `ℓ`: total `ℓ+1`; equals K → complete (state A), else stub upward (state B).
- 2 stubs `ℓ₁,ℓ₂`: need `ℓ₁+ℓ₂+1 = K` exactly, else infeasible.

Answer is Yes iff root achieves state A. Verified against both samples (sample 1: Yes; sample 2: vertex 3 has two size-1 children giving `1+1+1=3≠2` → No). Runs in O(NK), iterative DFS avoids recursion limits.
