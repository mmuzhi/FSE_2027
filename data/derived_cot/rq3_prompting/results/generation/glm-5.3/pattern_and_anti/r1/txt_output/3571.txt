We have n points on a 2D plane, and we need to find the longest strictly increasing chain (both x and y strictly increase) that must pass through coordinates[k].

Standard approach: The answer is (longest chain ending at point k) + (longest chain starting at point k) - 1.

Longest increasing chain problem is like the "Russian doll envelopes" problem. For points where both coordinates must strictly increase, we can sort by x, and for equal x, sort y in decreasing order, then find the LIS (strictly increasing) on y values.

For the longest chain ending at point k (i.e., points p with x < x_k and y < y_k, chained among themselves): take all points (excluding k itself) with x < x_k and y < y_k, and find the longest strictly increasing chain among them, plus 1 for point k.

For the longest chain starting at point k: take all points (excluding k) with x > x_k and y > y_k, find the longest strictly increasing chain, plus 1 for point k.

The answer is (L1 + 1) + (L2 + 1) - 1 = L1 + L2 + 1, where L1 is the longest chain among points strictly dominated by point k, and L2 is the longest chain among points strictly dominating point k. If either set is empty, the corresponding L is 0.

Now, how to compute the LIS (strict) on a set of points with x and y strictly increasing constraints?

Sort by x ascending, and for ties in x, sort by y descending. Then compute the longest strictly increasing subsequence of y values. Strict LIS: standard patience sorting with binary search — for strictly increasing, we use bisect_left on the tails array.

Wait, let me be careful: for LIS where we want strictly increasing subsequence, we use bisect_left: tails[i] is the smallest tail of an increasing subsequence of length i+1. For each y, find position = bisect_left(tails, y), replace tails[position] with y, or append if position == len(tails).

Sorting: sort by x ascending; for equal x, y descending. class Solution:
```python
    def maxPathLength(self, coordinates: List[List[int]], k: int) -> int:
        xk, yk = coordinates[k]
        
        def lis(pts):
            # pts: list of (x, y) where chain requires x and y strictly increasing
            pts.sort(key=lambda p: (p[0], -p[1]))
            tails = []
            for _, y in pts:
                pos = bisect_left(tails, y)
                if pos == len(tails):
                    tails.append(y)
                else:
                    tails[pos] = y
            return len(tails)
        
        lower = [(x, y) for x, y in coordinates if x < xk and y < yk]
        upper = [(x, y) for x, y in coordinates if x > xk and y > yk]
        
        return lis(lower) + lis(upper) + 1
```

```python
from bisect import bisect_left
from typing import List

class Solution:
    def maxPathLength(self, coordinates: List[List[int]], k: int) -> int:
        # Any increasing path through point k splits into:
        #   - a chain strictly below k (x < xk and y < yk)
        #   - a chain strictly above k (x > xk and y > yk)
        # Answer = LIS(lower) + LIS(upper) + 1 (for point k itself).
        xk, yk = coordinates[k]

        def lis(pts):
            # Longest strictly increasing chain in both coordinates.
            # Sort by x asc, y desc for ties (prevents chaining equal x),
            # then strict LIS (bisect_left) on y.
            pts.sort(key=lambda p: (p[0], -p[1]))
            tails = []
            for _, y in pts:
                pos = bisect_left(tails, y)
                if pos == len(tails):
                    tails.append(y)
                else:
                    tails[pos] = y
            return len(tails)

        lower = [(x, y) for x, y in coordinates if x < xk and y < yk]
        upper = [(x, y) for x, y in coordinates if x > xk and y > yk]

        return lis(lower) + lis(upper) + 1
```
