=== ANSWER ===
Looking at this problem: after adding one card, we need five cards split as 3+2 of two distinct values. So from the four initial cards, the only viable frequency patterns are:
- one value appears 3 times, another appears 1 time (add one of the second value) → (1,3)
- two values each appear 2 times (add either value) → (2,2)

Any other pattern (all distinct, 2+1+1, or all four same) fails — note 8,8,8,8 can't work since five identical cards are not a Full House.

Verification against samples: {7:3,1:1}→Yes; all distinct→No; {3:2,5:2}→Yes; {8:4}→No; {1:2,3:1,4:1}→No. All match.

Implementation: count frequencies, sort counts, compare to [1,3] or [2,2].

```python
from collections import Counter

def main():
    cards = list(map(int, input().split()))
    counts = sorted(Counter(cards).values())
    if counts == [1, 3] or counts == [2, 2]:
        print("Yes")
    else:
        print("No")

main()
```
