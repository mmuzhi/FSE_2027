class Solution:
    def minArraySum(self, nums: List[int], k: int, op1: int, op2: int) -> int:
        INF = float('inf')
        # dp[a][b]
        dp = [[INF] * (op2 + 1) for _ in range(op1 + 1)]
        dp[0][0] = 0
        for num in nums:
            ndp = [[INF] * (op2 + 1) for _ in range(op1 + 1)]
            h = (num + 1) // 2  # ceil(num/2)
            for a in range(op1 + 1):
                for b in range(op2 + 1):
                    cur = dp[a][b]
                    if cur == INF:
                        continue
                    # no op
                    if cur + num < ndp[a][b]:
                        ndp[a][b] = cur + num
                    # op1
                    if a + 1 <= op1 and cur + h < ndp[a+1][b]:
                        ndp[a+1][b] = cur + h
                    # op2
                    if b + 1 <= op2 and num >= k:
                        v = num - k
                        if cur + v < ndp[a][b+1]:
                            ndp[a][b+1] = cur + v
                        # op2 then op1
                        if a + 1 <= op1:
                            v2 = (v + 1) // 2

                        if cur + v3 < ndp[a+1][b+1]:

            dp = ndp
        return min(min(row) for row in dp)

Looking at this problem:

**Constraints analysis:** n ≤ 100, op1, op2 ≤ n. A DP over indices with state (count of op1 used, count of op2 used) gives ~100×101×101 ≈ 10⁶ states with O(1) transitions each — perfectly feasible.

**Plan:** `dp[a][b]` = minimum sum so far using `a` op1's and `b` op2's. For each number, consider: no op; op1 only; op2 only (needs `num >= k`); both ops in either order (op2→op1 needs `num >= k`, gives `ceil((num-k)/2)`; op1→op2 needs `ceil(num/2) >= k`). Both orders are included since results differ (though op2-first is never worse, including both is cheap and safe).

**Key edge cases:** k=0 (op2 legal but no-op effect), num=0, and taking min over all `(a,b)` at the end since using fewer operations is allowed.

**Verify with examples:** Example 1: op2 on 8→5, op1 on 19→10, sum 23 ✓. Example 2: op1 on 2→1, op1 on 4→2, op2 on 3→0, sum 3 ✓.
