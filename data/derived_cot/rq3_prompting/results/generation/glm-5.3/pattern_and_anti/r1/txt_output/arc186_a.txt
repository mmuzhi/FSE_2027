```python
def main():
```

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); Q = int(data[1])
    Ks = [int(x) for x in data[2:2+Q]]
    dp = [[0] * (N + 1) for _ in range(N + 1)]
    dp[0][0] = 1
    for r in range(N + 1):
        dpr = dp[r]
        maxa = N - r
        if maxa < 2:
            # still need to process c loop? no transitions possible
            continue
        for c in range(N + 1):
            v = dpr[c]
            if not v:
                continue
            maxb = N - c
            if maxb < 2:
                continue
            for a in range(2, maxa + 1):
                dpa = dp[r + a]
                ab_base = a
                for b in range(2, maxb + 1):
                    dpa[c + b] |= v << (a * b)
    ach = 0
    for r in range(N + 1):
        for c in range(N + 1):
            ach |= dp[r][c]
    N2 = N * N
    res = []
    for K in Ks:
        M = N2 - K
        res.append("Yes" if 0 <= M <= N2 and (ach >> M) & 1 else "No")
    sys.stdout.write("\n".join(res) + "\n")

main()
```

Looking at this problem:

**Key reduction:** Build a digraph $D$ on row-vertices and column-vertices: arc $r_i \to c_j$ if $A_{i,j}=1$, arc $c_j \to r_i$ if $A_{i,j}=0$. An element $(i,j)$ is non-fixed iff it lies on an alternating cycle (swap via symmetric-difference decomposition of $A \triangle B$), which is exactly a directed cycle in $D$. An arc lies on a directed cycle iff its endpoints are in the same SCC. So **#fixed = # of (row, column) pairs lying in different SCCs of $D$**.

Each SCC of such a digraph is either a singleton row/column, or contains $a\ge 2$ rows and $b\ge 2$ columns (a 1-row or 1-column SCC can't be strongly connected since both arcs between a pair can't exist). Conversely any such partition is realizable: order blocks, set $A_{ij}=1$ iff block$(r_i) <$ block$(c_j)$ (all inter-block arcs go forward, acyclic), and inside a block with $a,b\ge2$ place a pattern (zeros roughly on a diagonal plus one column, ones elsewhere) making it strongly connected — cross-block arcs can't merge SCCs.

So with blocks $(a_t,b_t), a_t,b_t\ge 2$, $\sum a_t \le N$, $\sum b_t \le N$, the non-fixed count is $M=\sum a_t b_t$ and $K = N^2 - M$. Compute achievable $M$ by DP over (rows used, cols used) storing bitmasks of sums, then answer queries.

Verified on sample 1 ($N=3$: $M\in\{0,4,6,9\}\Rightarrow K\in\{9,5,3,0\}$ — matches 0→Yes, 9→Yes, 7→No) and sample 2 ($160=8\cdot20$, $733=27\cdot27+2\cdot2$, $520=20\cdot26$ achievable; 823, 655, 718 not).

DP size: ~$31\times31$ states, ~$29\times29$ transitions each, big-int bitsets of ≤901 bits — fast enough.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); Q = int(data[1])
    Ks = list(map(int, data[2:2 + Q]))
    dp = [[0] * (N + 1) for _ in range(N + 1)]
    dp[0][0] = 1
    for r in range(N - 1):
        dpr = dp[r]
        for c in range(N - 1):
            v = dpr[c]
            if not v:
                continue
            for a in range(2, N - r + 1):
                dpr2 = dp[r + a]
                for b in range(2, N - c + 1):
                    dpr2[c + b] |= v << (a * b)
    ach = 0
    for row in dp:
        for x in row:
            ach |= x
    N2 = N * N
    print("\n".join("Yes" if (ach >> (N2 - K)) & 1 else "No" for K in Ks))

main()
```
