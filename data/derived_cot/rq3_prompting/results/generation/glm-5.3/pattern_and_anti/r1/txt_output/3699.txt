```python
class Solution:
    def numberOfSubsequences(self, nums: List[int]) -> int:
```

=== ANSWER ===
**Commit:** Count quadruples by iterating over `r`. Maintain a hash map `cnt` counting reduced fractions `nums[p]/nums[q]` over all valid left pairs (`p ≤ q-2`) with `q ≤ r-2` — pairs with `q = r-2` are added just before processing `r`. Then for each `s ≥ r+2`, the equation `nums[p]*nums[r] == nums[q]*nums[s]` becomes `nums[p]/nums[q] == nums[s]/nums[r]`, so we add `cnt[reduced(nums[s], nums[r])]`. This is O(n²) ≈ 10⁶ gcd+dict ops, well within limits.

**Ledger:** invariant — when processing `r`, `cnt` holds exactly pairs with `q ≤ r-2`, `p ≤ q-2`; spacing for `s` is `s ≥ r+2`; all values positive so gcd is safe. Verified by hand on both examples (outputs 1 and 3).

```python
from math import gcd
from collections import defaultdict
from typing import List

class Solution:
    def numberOfSubsequences(self, nums: List[int]) -> int:
        n = len(nums)
        cnt = defaultdict(int)
        ans = 0
        for r in range(2, n - 2):
            q = r - 2
            if q >= 2:
                for p in range(q - 1):  # p <= q - 2
                    a, b = nums[p], nums[q]
                    g = gcd(a, b)
                    cnt[(a // g, b // g)] += 1
            for s in range(r + 2, n):   # s >= r + 2
                a, b = nums[s], nums[r]
                g = gcd(a, b)
                ans += cnt[(a // g, b // g)]
        return ans
```
