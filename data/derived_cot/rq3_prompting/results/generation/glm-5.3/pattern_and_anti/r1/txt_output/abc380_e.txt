def main():

            # find root of x with path halving

Looking at this problem:

**Key insight:** Type-1 queries repaint the *entire maximal monochromatic segment* containing x. Therefore the partition of cells into maximal same-color segments only ever **merges** (never splits): repainting a whole segment to color c keeps it one block, possibly absorbing left/right neighbors already colored c (neighbors of neighbors can't share color c by maximality, so at most 2 merges per query).

**Plan:** DSU over cells where each root stores segment bounds `segl`, `segr`, color `col`, plus union-by-size `sz`, and a global count array `cnt[color]`.
- Type 1: find root of x; if color changes, adjust `cnt` by segment length, set color, then check/merge with root of `l-1` and `r+1` if their color equals c (right end `r` is unaffected by a left merge).
- Type 2: answer `cnt[c]`.

Complexity: O(N + Q·α(N)). Verified against the sample: outputs 3 and 4. Edge cases handled: N=1, repaint to same color (no-op skip), boundary conditions `l>1`, `r<N`.
