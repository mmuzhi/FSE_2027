There are N toys numbered from 1 to N, and N-1 boxes numbered from 1 to N-1.

Takahashi wants to store all the toys in separate boxes, and he has decided to perform the following steps in order:

- Place each of the N toys into one of the N boxes (the N-1 existing boxes plus the newly purchased box).

He wants to execute step 2 by purchasing a sufficiently large box in step 1, but larger boxes are more expensive, so he wants to purchase the smallest possible box.
Determine whether there exists a value of x such that he can execute step 2, and if it exists, find the minimum such x.

B_1 B_2 \dots B_{N-1}

Output

Constraints


- 2 \leq N \leq 2 \times 10^5
- 1 \leq A_i, B_i \leq 10^9
- All input values are integers.

3

Looking at this problem:

- Sort toys A ascending and boxes B ascending. Adding a box of size x, feasibility (classic greedy matching) is: the merged sorted box array C satisfies C[i] >= A[i] for all i.
- Feasibility is monotone in x, but we can compute the answer directly: if the new box x sits at merged index p, then feasibility requires B[j] >= A[j] for j < p (prefix condition), x >= A[p], and B[j-1] >= A[j] for j > p (suffix condition).
- Key claim: if prefix condition `preOK[p]` and suffix condition `sufOK[p]` both hold, then x = A[p] is always feasible (verified by case analysis on where A[p] actually merges into B — when it merges earlier than p, all skipped B values are >= A[p]; when later, sufOK forces B[i] >= A[i+1] >= A[i]).
