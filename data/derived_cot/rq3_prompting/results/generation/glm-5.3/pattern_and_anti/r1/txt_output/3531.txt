```python
class Solution:
    def minDamage(self, power: int, damage: List[int], health: List[int]) -> int:
        n = len(damage)
        items = [((h + power - 1) // power, d) for h, d in zip(health, damage)]
        # sort so that a before b iff d_a * t_b > d_b * t_a (d/t descending)
        def cmp(a, b):

            tb, db = b
            diff = db * ta - da * tb  # negative → a first
            if diff < 0:
```

- Enemy i needs `t_i = ceil(health[i]/power)` attack-seconds to die, and deals `damage[i]` per second until (and including) the second it dies.
- Splitting attacks never helps (it only delays deaths), so kill enemies one at a time in some order.
- Total damage = Σ `damage[i] * T_i` where `T_i` is the cumulative time when enemy i dies.
- Exchange argument for adjacent pair (a then b) vs (b then a): difference is `d_b*t_a - d_a*t_b`, so a should go first iff `d_a/t_a >= d_b/t_b` → sort by ratio `damage/t` descending.

Verification with Example 1: t=[1,2,2,2], ratios → order enemy3, enemy2, then tie {0,1}. Cost: 4·2 + 3·4 + 2·6 + 1·7 = 8+12+12+7 = 39 ✓ (tie orders give same total since `d_b*t_a = d_a*t_b`).

For exact ratio comparison without floats (d, t ≤ 10⁴, distinct rationals differ by ≥ 10⁻⁸, so scaling by 10⁹ with floor division preserves order exactly), I use key `d * 10**9 // t`.

Recheck Example 2: order 0,1,2,3 → 1+3+6+10=20 ✓. Example 3: t=8, 40·8=320 ✓.

```python
from typing import List

class Solution:
    def minDamage(self, power: int, damage: List[int], health: List[int]) -> int:
        SCALE = 10 ** 9
        enemies = []
        for d, h in zip(damage, health):
            t = (h + power - 1) // power
            enemies.append((d * SCALE // t, d, t))
        enemies.sort(reverse=True)
        total = 0
        elapsed = 0
        for _, d, t in enemies:
            elapsed += t
            total += d * elapsed
        return total
```
