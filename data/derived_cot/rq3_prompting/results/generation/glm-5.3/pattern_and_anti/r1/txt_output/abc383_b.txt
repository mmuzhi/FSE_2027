The AtCoder company office can be represented as a grid of H rows and W columns. Let (i, j) denote the cell at the i-th row from the top and j-th column from the left.

After placing the humidifiers, a cell (i,j) is humidified if and only if it is within a Manhattan distance D from at least one of the humidifier cells (i',j'). The Manhattan distance between (i,j) and (i',j') is defined as |i - i'| + |j - j'|.

```python
import sys

def main():
    data = sys.stdin.read().split()
    H, W, D = int(data[0]), int(data[1]), int(data[2])
    grid = data[3:3+H]
    floors = [(i, j) for i in range(H) for j in range(W) if grid[i][j] == '.']
    n = len(floors)
    masks = []
    for i in range(n):
        xi, yi = floors[i]
        m = 0
        for k in range(n):
            xk, yk = floors[k]
            if abs(xi - xk) + abs(yi - yk) <= D:
                m |= 1 << k
        masks.append(m)
    best = 0
    for i in range(n):
        for j in range(i+1, n):
            cnt = bin(masks[i] | masks[j]).count('1')
            if cnt > best:
                best = cnt
    print(best)

main()
```

=== ANSWER ===
Looking at this problem:

- **Constraints**: H, W ≤ 10, so at most 100 cells, and thus at most 100 floor cells → at most C(100,2) ≈ 4950 humidifier pairs.
- **Approach**: Pure brute force. For each floor cell, precompute a bitmask of floor cells within Manhattan distance D. For each pair of humidifier positions, the humidified count is the popcount of the OR of their masks. Take the maximum.

**Implementation ledger:**
- Main invariant: mask[i] has bit k set iff dist(floor[i], floor[k]) ≤ D.
- Pair count = popcount(mask[i] | mask[j]).
- Edge cases: D=0 gives answer 2 (each humidifier cell only humidifies itself); at least two floor cells guaranteed so pairs exist.

**Verification on sample 1**: floors are (1,1),(1,5),(2,1),(2,3). Pair ((1,1),(1,5)) with D=1 covers (1,1),(2,1),(1,5) → 3. ✓
**Sample 3**: humidifiers at (1,1) and (4,4) with D=2 cover 5+5=10 cells with no overlap → 10. ✓

Complexity: O(n²) mask building + O(n²) pair loop with popcount, n ≤ 100 — trivially fast.
