Looking at this problem:

- Alice's symmetry is $i \mapsto -i$, Bob's is $i \mapsto 2K-i$. After each move, the whole colored set must be invariant under the mover's reflection.
- Consider orbits under the group $G$ generated by both reflections (rotation by $2K$ plus reflection). Since each orbit is preserved by both reflections, after Alice's move every orbit's colored set must be $r_0$-closed, and after Bob's every orbit must be $r_K$-closed.
- A subset of an orbit invariant under both reflections is a union of $G$-orbits, so within one component the only "both-closed" states are ∅ and full. Hence once a component starts being colored, every consecutive move must add to it until it's full (otherwise the next player's global symmetry fails). So each component is colored in one consecutive alternating block.
- The first vertex added to a component must be a fixed point of the mover's reflection (no partner exists yet). Components that are cycles (orbits of the form $\{a+R\}\cup\{-a+R\}$ with $R$ generated by $2K$) have no fixed points, so they can never be colored. Such double orbits exist whenever $g_2=\gcd(2K,N)\ge 3$ (take $a=1$) → **No**.
- If $g_2=1$ ($N$ odd, $\gcd(K,N)=1$): single path component of odd size with one A-fixed and one B-fixed endpoint; it can be colored starting with Alice → **Yes**.
- If $g_2=2$ ($N$ even, $\gcd(K,N/2)=1$): two path components (evens, odds).
  - If $N/2$ odd: both are odd paths, each works starting with A or B; blocks of odd size alternate start types correctly → **Yes**.
  - If $4\mid N$ ($N/2$ even): evens path has two A-fixed endpoints (A-start only), odds path two B-fixed endpoints (B-start only). Second block (size even) would start on an odd position (A-move), but odds needs B-start; the reverse order fails at position 1 → **No**. So $4\mid N$ is always No.
