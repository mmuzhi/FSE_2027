import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    P = list(map(int, data[1:1+n]))
    # BIT over values 1..n
    tree = [0] * (n + 1)
    def update(i):
        while i <= n:
            tree[i] += 1
            i += i & (-i)
    def query(i):  # prefix sum [1..i]
        s = 0
        while i > 0:
            s += tree[i]
            i -= i & (-i)
        return s
    ans = 0
    for idx, a in enumerate(P, 1):
        c = query(a - 1)  # smaller values seen before
        S = a - 1 - c
        if S:
            ans += S * (c + 1) + S * (S - 1) // 2
        update(a)
    print(ans)

main()

Looking at this problem:

- Each swap at position i costs i = the old position of the element moving **right** (equivalently the new position of the element moving left).
- Total cost = sum over all right-moves of each element's old position at that move.
- For element `a` starting at position `s(a)`: it must move left past `R(a)` bigger elements before it and right past `S(a)` smaller elements after it (each inverted pair crosses exactly once in an optimal solution). Since an element's position only depends on its own moves, doing **all left moves before right moves** minimizes its right-move positions: they become `s(a)-R(a), s(a)-R(a)+1, ..., ` giving cost `S(a)·(s(a)−R(a)) + S(S−1)/2`.
- This is a valid lower bound per element (any interleaving only raises old positions of right moves; counts satisfy L≥R, W≥S with W−L = S−R), and it's achievable by a greedy schedule (swap any adjacent unresolved inversion whose right-mover finished all left moves — a deadlock argument with a minimal-gap/minimal-position inversion pair shows this always completes).
- With `c` = number of smaller elements before `a` (Fenwick/BIT prefix count): `S(a) = a−1−c` and `s(a)−R(a) = c+1`, so contribution = `S·(c+1) + S(S−1)/2`.
