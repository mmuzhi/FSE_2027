def main():

    idx = 0
    N = int(input_data[idx]); idx+=1
    Q = int(input_data[idx]); idx+=1
    A = [0]*(N+1)  # A[2..N]
    for i in range(2, N+1):

    # modular values
    Am = [0]*(N+1)
    for i in range(2, N+1):

    # inverses 1..N

    for i in range(2, N+1):
        inv[i] = (MOD - (MOD//i) * inv[MOD % i]) % MOD
    # prefix sums

    S2 = [0]*(N+1)  # S2[x] = sum_{i=2}^{x} A_i / i mod

        S2[i] = (S2[i-1] + Am[i]*inv[i]) % MOD

Looking at this problem:

**Key insight:** Summing over all $(N-1)!$ trees is expectation under the model where each vertex $i$ picks its parent uniformly from $[1, i-1]$ independently. Since $\text{dist}(u,v)=\sum_i A_i[\text{edge } i \text{ on path}]$ and edge $i$ is on the path iff exactly one of $u,v$ is in subtree of $i$:

- $\Pr[x \in \text{subtree}(i)] = 1$ if $x=i$, $= 1/i$ if $i<x$ (classical recursive tree fact, via martingale $s_j/j$ where $s_j$ = subtree size).
- $\Pr[u,v \in \text{subtree}(i)]$ for $i<u$: conditioning on subtree size $s_u$ and using $\Pr[v\in S\mid s_u]=s_u/u$, plus the second moment $E[s_j^2]=\frac{2j(j+1)}{i(i+1)}-\frac{j}{i}$ (derived from $m_j = \frac{j+1}{j-1}m_{j-1}+\frac1i$), gives $r_i = \frac{2}{i(i+1)}$.

So for query $(u,v)$, $u<v$, the expected distance is:
$$\sum_{i=2}^{u-1} A_i\frac{2(i-1)}{i(i+1)} + A_u\frac{u-1}{u} + \sum_{i=u+1}^{v-1}\frac{A_i}{i} + A_v$$

Multiplied by $(N-1)!$. Verified by hand against samples 1, 2, and two queries of sample 3 (exact rational computation mod 998244353 matched: 55973424 and 496202632), plus brute-force enumeration for $N=3,4$.
