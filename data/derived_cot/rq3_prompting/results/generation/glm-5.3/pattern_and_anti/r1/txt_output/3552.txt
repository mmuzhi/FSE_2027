Looking at this problem: n up to 10^5 means we must exploit the palindrome structure — the number is fully determined by its first half (m = ceil(n/2) digits). We want the lexicographically largest half such that the full value ≡ 0 mod k.

**Key invariant:** Each half position j contributes `d * (10^j + 10^(n-1-j)) mod k` to the total (or `d * 10^j` if j is the exact middle when n is odd). Compute suffix-reachability bitmasks `g[j]` (which remainders are achievable using half positions j..m-1), then greedily pick digits 9→0 from the front, choosing the largest digit whose remainder still admits completion. This is O(n·10) time, O(n) memory.

Verified against all three examples by hand (595, 8, 89898) plus n=1,k=7→"7", n=2,k=4→"88", n=2,k=7→"77". Edge cases: middle digit for odd n, first digit ≥ 1, k=1 (everything ≡ 0, gives all 9s).

```python
class Solution:
    def largestPalindrome(self, n: int, k: int) -> str:
        m = (n + 1) // 2
        pw = [0] * n
        pw[0] = 1 % k
        for i in range(1, n):
            pw[i] = pw[i - 1] * 10 % k

        coef = [0] * m
        for j in range(m):
            mirror = n - 1 - j
            if j == mirror:
                coef[j] = pw[j]
            else:
                coef[j] = (pw[j] + pw[mirror]) % k

        # g[j]: bitmask of remainders achievable from half positions j..m-1
        g = [0] * (m + 1)
        g[m] = 1
        low_mask = (1 << k) - 1
        for j in range(m - 1, -1, -1):
            lo = 1 if j == 0 else 0
            c = coef[j]
            nxt = g[j + 1]
            shifted = 0
            for d in range(lo, 10):
                shifted |= nxt << ((d * c) % k)
            # shifts are < k, so bits stay below 2k; fold once
            g[j] = (shifted & low_mask) | (shifted >> k)

        # greedy construction
        half = []
        acc = 0
        for j in range(m):
            c = coef[j]
            lo = 1 if j == 0 else 0
            for d in range(9, lo - 1, -1):
                need = (-(acc + d * c)) % k
                if (g[j + 1] >> need) & 1:
                    half.append(chr(48 + d))
                    acc = (acc + d * c) % k
                    break

        h = ''.join(half)
        if n & 1:
            return h + h[-2::-1]
        return h + h[::-1]
```
