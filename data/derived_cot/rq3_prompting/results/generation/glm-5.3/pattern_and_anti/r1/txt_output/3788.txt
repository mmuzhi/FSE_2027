```python
class Solution:
    def maxSum(self, nums: List[int]) -> int:
        # Deletions let any subsequence become a contiguous subarray,
        # so the best choice is: take every distinct positive value once.
        # If no positive value exists, we must still pick one element -> the maximum.
        total = sum(v for v in set(nums) if v > 0)
        return total if total > 0 else max(nums)
```
