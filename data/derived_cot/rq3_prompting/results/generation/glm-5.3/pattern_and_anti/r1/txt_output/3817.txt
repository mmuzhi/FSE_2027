=== ANSWER ===
**Commit:** The deck has exactly `n*n` cells, each holding one container of weight `w`. The only two limits are cell count and weight capacity, so the answer is `min(n*n, maxWeight // w)` — an O(1) formula.

**Ledger:** Invariant: loaded containers = `k` satisfies `k*w <= maxWeight` and `k <= n*n`; taking both maxima independently is valid since they don't interact. Edge case: `maxWeight < w` gives `0`, handled by `min`.

**Recheck:** Example 1: `min(4, 15//3=5) = 4` ✓. Example 2: `min(9, 20//5=4) = 4` ✓. Edge `maxWeight < w` → `0` ✓.

```python
class Solution:
    def maxContainers(self, n: int, w: int, maxWeight: int) -> int:
        return min(n * n, maxWeight // w)
```
