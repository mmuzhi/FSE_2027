Looking at this problem:

- n ≤ 5000, so ~12.5M splits — need O(n²) with vectorization.
- Split (i, j): nums1 = nums[0:i], nums2 = nums[i:j], nums3 = nums[j:], with i ≥ 1, j ≤ n-1.
- Condition A: lcp(0, i) ≥ i and j ≥ 2i → contributes (n−2i) per valid i.
- Condition B: lcp(i, j) ≥ j−i.
- Answer = |A| + |B| − |A∩B| via inclusion-exclusion. LCP table computed row-by-row (bottom-up DP `lcp[i][j] = match ? lcp[i+1][j+1]+1 : 0`) with numpy, counting per row j where lcp ≥ j−i (and restricted to j ≥ 2i for the overlap, conditioned on A_i = lcp(0,i) ≥ i).

Verified against examples: [1,1,2,1] → 2; [1,2,3,4] → 0; also hand-checked [1,1,1,1,1] → 6 and [1,1,1,2,2,2] → 6.
