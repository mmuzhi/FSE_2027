=== ANSWER ===
**Approach:** Model the state as (vertex, parity of number of reversals) — two layers of the graph. Moving along an edge stays in the same layer using that layer's orientation (layer 0 uses original edges, layer 1 uses reversed edges) at cost 1; reversing jumps between layers at the same vertex with cost X. Run Dijkstra from (vertex 1, layer 0) and take min of distances to (vertex N, layer 0) and (vertex N, layer 1). Complexity: O((N+M) log N), answer fits in Python ints naturally (sample 3 = 7X + 7).

Key checks: parity suffices since two reversals restore the graph; early return when a target node is popped from the heap is valid in Dijkstra; multi-edges/self-loops are harmless.
