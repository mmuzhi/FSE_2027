Looking at this problem:

- N ≤ 3000, so an O(N²) approach over all common differences d works.
- For a fixed difference d, the condition "equal heights at equal intervals d" means: along each chain of indices r, r+d, r+2d, ..., find the longest run of **equal consecutive heights**. If eq[i] = (H[i]==H[i+d]), then a run of T consecutive `True` values in a chain corresponds to T+1 chosen buildings.
- Key invariant: for each d, pad eq with `False` to length m·d, reshape to (m, d) and transpose so row r is chain r, append a `False` separator per row, flatten — then the answer candidate for this d is (max gap between consecutive False positions), since positions strictly between two Falses are all True. Baseline answer is 1.
- Edge cases checked: N=1 (empty loop → 1), N=2 with equal heights (d=1 gives candidate 2), all-equal heights (candidate N). Verified by hand against sample 1 (d=3 chain residue 1 gives 3).
