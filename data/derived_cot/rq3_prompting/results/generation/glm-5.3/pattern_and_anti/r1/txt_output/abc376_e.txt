Looking at this problem:

- Sort pairs (A_i, B_i) ascending by A. If the item with the largest index in S (in sorted order) is at position j, then max A = A_sorted[j], and S ⊆ {0..j} must include j. For fixed j, the best sum is B_j plus the (K−1) smallest B values among positions 0..j−1.
- Sweep j from left to right maintaining a max-heap (size K−1) of the smallest B values seen so far; candidate = A_sorted[j] × (B_sorted[j] + heap sum) once the heap is full.
- Answer = min over all valid j. Note: the max item must be *forced included* (the key edge case — simply taking K smallest B over a prefix underestimates, as shown by sample 1 where prefix logic would give 36 instead of 42).

Verified against all three samples (42, 60, 14579 — traced sample 3 by hand: at item (61,48), heap sum 163 → 61×211 = 14579 ✓). Complexity O(N log K) per case, total sum N ≤ 2×10⁵. K=1 handled as min(A_i×B_i).

```python
import sys, heapq

def main():
    data = sys.stdin.buffer.read().split()
    pos = 0
    T = int(data[pos]); pos += 1
    out = []
    heappush = heapq.heappush
    heappop = heapq.heappop
    for _ in range(T):
        N = int(data[pos]); K = int(data[pos + 1]); pos += 2
        A = data[pos:pos + N]; pos += N
        B = data[pos:pos + N]; pos += N
        pairs = sorted(zip(map(int, A), map(int, B)))
        K1 = K - 1
        if K == 1:
            best = min(a * b for a, b in pairs)
        else:
            heap = []
            s = 0
            best = None
            for a, b in pairs:
                if len(heap) == K1:
                    c = a * (b + s)
                    if best is None or c < best:
                        best = c
                heappush(heap, -b)
                s += b
                if len(heap) > K1:
                    s += heappop(heap)
        out.append(best)
    sys.stdout.write('\n'.join(map(str, out)) + '\n')

main()
```
