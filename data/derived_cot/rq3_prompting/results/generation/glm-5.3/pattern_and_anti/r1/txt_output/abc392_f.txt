=== ANSWER ===
Looking at this problem:

- N up to 5×10⁵ rules out naive list insertion (O(N²) worst case).
- Key insight: process insertions **backwards** (i = N down to 1). When element i was inserted, it had exactly P_i − 1 elements of {1,…,i−1} before it, and relative order never changes. So processing backward, element i takes the **P_i-th currently free slot** in the final array (the free slots to its left will be filled by elements 1..i−1 later).
- Finding/removing the k-th free slot: a segment tree over slots storing free counts. I descend from the root (going right when the left child's count < k) while decrementing counts along the path in the same pass — this fuses query and update into one 19-step loop per element → O(N log N).

I verified the descent invariant (k ≤ subtree count holds since at step i exactly i slots are free and P_i ≤ i) and traced both samples: sample 1 yields `4 2 3 1`, sample 2 yields `1 2 3 4 5`. Edge case N=1 works (m=1, loop skipped, ans=[1]).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    P = list(map(int, data[1:1 + n]))
    m = 1
    while m < n:
        m <<= 1
    # segment tree: leaves m..2m-1, leaf = 1 if slot is free
    seg = [0] * m + [1] * n + [0] * (m - n)
    for i in range(m - 1, 0, -1):
        ii = i + i
        seg[i] = seg[ii] + seg[ii + 1]
    ans = [0] * n
    for j in range(n - 1, -1, -1):
        k = P[j]
        idx = 1
        while idx < m:
            seg[idx] -= 1          # this query consumes one slot below
            idx += idx             # left child
            c = seg[idx]
            if c < k:
                k -= c
                idx += 1           # go to right sibling
        seg[idx] -= 1              # consume the leaf's free slot
        ans[idx - m] = j + 1
    sys.stdout.write(' '.join(map(str, ans)) + '\n')

main()
```
