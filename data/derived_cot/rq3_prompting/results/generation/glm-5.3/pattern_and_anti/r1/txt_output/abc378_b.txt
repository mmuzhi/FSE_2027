def main():

- **Core task**: For each query, find smallest day x ≥ d with x mod q == r.
- **Key formula**: In Python, `(r - d) % q` is always non-negative, so answer = `d + ((r - d) % q)`. This handles the "same day" case automatically (gives 0 offset).
- **Verification with sample**:
  - (q=7, r=3, d=1): 1 + 2 = 3 ✓
  - (d=3): 3 + 0 = 3 ✓
  - (d=4): 4 + 6 = 10 ✓
  - (d=15): 15 + 2 = 17 ✓
  - (q=4, r=2, d=7): 7 + 3 = 10 ✓
