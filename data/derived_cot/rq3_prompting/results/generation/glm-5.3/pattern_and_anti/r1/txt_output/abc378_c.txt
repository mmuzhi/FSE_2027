**Problem restatement:**
We have a sequence A of N positive integers. For each i (1-indexed), B_i is the largest j < i such that A_j = A_i, or -1 if no such j exists.

**Constraints analysis:**
- N up to 2×10^5
- A_i up to 10^9

The values A_i can be up to 10^9, so we can't use an array indexed by value directly. We need a hash map (dictionary in Python) mapping value → last seen position (1-indexed).

**Approach:**
Simple single-pass with a dictionary:
- Initialize `last = {}` (empty dict).
- For i from 1 to N:
  - If A_i in `last`, B_i = `last[A_i]`, else B_i = -1.
  - Update `last[A_i] = i`.
- Print B separated by spaces.

**Complexity:** O(N) average time with hash map, O(N) space. This easily handles N = 2×10^5.

**Edge cases:**
- N = 1: output is just "-1".
- All distinct elements: all -1.
- All same elements: -1, 1, 2, 3, ..., N-1.
- Large values (up to 10^9): handled by dict since keys can be arbitrary integers.

**Implementation ledger:**
- Invariant: after processing index i, `last[v]` holds the most recent position ≤ i where value v appeared.
- Transition: B_i = last.get(A_i, -1), then last[A_i] = i.
- Edge case: 1-indexing — B uses positions 1-indexed; make sure to loop i from 1.
- Output format: single line, space-separated. Use `' '.join(map(str, B))`.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = data[1:1+n]  # keep as bytes—hashable, works as dict keys
    last = {}
    res = []
    append = res.append
    for i, v in enumerate(a, 1):
        append(str(last.get(v, -1)))
        last[v] = i
    sys.stdout.write(' '.join(res))

main()
```
