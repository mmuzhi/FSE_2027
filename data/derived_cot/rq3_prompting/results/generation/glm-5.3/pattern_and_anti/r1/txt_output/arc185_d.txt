def main():

    N, M = int(input_data[0]), int(input_data[1])

Looking at this problem:

**Structure**: Edge $i$ connects $i$ and $\max(i-N,0)$, so the tree is a "broom": center vertex 0 with $N$ arms, each arm being a path of $M$ vertices ($v, v+N, v+2N, \dots$).

**Decomposition**: The walk splits into excursions from the center. Each excursion picks a uniformly random arm (i.i.d.) and is an independent walk into that arm until returning to the center. An arm becomes fully painted exactly when its tip (depth $M$) is first reached — success probability per excursion is $q = P(\text{hit } M \text{ before } 0 \text{ from } 1) = 1/M$ (gambler's ruin — my first guess $2^{-(M-1)}$ was wrong, caught by checking $N=1$ where the answer must be $M^2$).

**Excursion length**: By Kac's lemma, mean full excursion length is $2M$ (return time to center). The process stops *at the tip* of the last arm, so subtract the counterfactual return from tip to center: $\sum_{d=1}^M (2(M-d)+1) = M^2$.
