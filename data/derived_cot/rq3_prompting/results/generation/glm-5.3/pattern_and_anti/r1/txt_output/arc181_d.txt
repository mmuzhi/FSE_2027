- Operation k: For i=1,2,\dots,k-1 in this order, if P_i > P_{i+1}, swap the values of the i-th and (i+1)-th elements of P.

 What is the inversion number of a sequence?

The inversion number of a sequence x=(x_1,x_2,\dots,x_n) of length n is the number of pairs of integers (i,j)\ (1\leq i < j \leq n) such that x_i > x_j.

- 2 \leq A_i \leq N
- P is a permutation of (1,2,\dots,N).
- A_i \leq A_{i+1} for i=1,2,\dots,M-1.
- All input values are integers.

```python
import sys
from bisect import bisect_left

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    P = data[1:1+n]
    m = int(data[1+n])
    A = list(map(int, data[2+n:2+n+m]))
    
    tree = [0]*(n+1)
    c0 = [0]*n
    inv0 = 0
    cnt = 0
    for vb in P:
        v = int(vb)
        s = 0
        i = v
        while i:
            s += tree[i]
            i -= i & (-i)
        c = cnt - s
        c0[cnt] = c
        inv0 += c
        cnt += 1
        i = v
        while i <= n:
            tree[i] += 1
            i += i & (-i)
    
    D = [0]*(m+2)
    for p in range(1, n+1):
        c = c0[p-1]
        if c:
            j1 = bisect_left(A, p) + 1
            if j1 <= m:
                D[j1] += 1
                e = j1 + c
                if e <= m:
                    D[e] -= 1
    
    out = []
    cur = inv0
    s = 0
    for j in range(1, m+1):
        s += D[j]
        cur -= s
        out.append(cur)
    sys.stdout.write('\n'.join(map(str, out)))

main()
```

=== ANSWER ===
Looking at this problem:

**Key insight 1:** Operation k does exactly (number of non-records in prefix 1..k) swaps, since each non-record (element with a larger element to its left, within the prefix) moves left exactly once per covering operation, and each swap reduces inversions by 1.

**Key insight 2:** For an element e at position p, define c(e) = number of larger elements to its left. A larger element can only cross e from left to right (crossing requires them adjacent with larger on left), one crossing per operation that covers e. So each operation covering e (while c(e)>0) decreases c(e) by exactly 1 and moves e left by 1. Since A is non-decreasing, once e is covered it stays covered until it becomes a record (c=0), because its position only decreases while A only increases.

**Conclusion:** Element e starting at position p₀ with initial count c₀ contributes exactly one swap to each of operations j₁, j₁+1, ..., j₁+c₀−1, where j₁ is the first index with A_{j₁} ≥ p₀. So the answer after op j = initial inversion count − cumulative swap counts, computed with a difference array over intervals.

Verified against both samples (sample 2 matches all 15 lines exactly) and several brute-forced custom cases (e.g. P=(4,3,2,1), A=[2,3,4,4] → 5,4,2,1 ✓).

Implementation: BIT for per-element inversion counts c₀, binary search for j₁, difference array for interval stabbing, prefix sums for answers. Complexity O((N+M) log N).

```python
import sys
from bisect import bisect_left

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    P = list(map(int, data[1:1 + n]))
    m = int(data[n + 1])
    A = list(map(int, data[n + 2:n + 2 + m]))

    # c0[i] = number of j < i with P[j] > P[i]  (via BIT over values)
    tree = [0] * (n + 1)
    c0 = [0] * n
    inv0 = 0
    for i in range(n):
        v = P[i]
        s = 0
        j = v
        while j:
            s += tree[j]
            j -= j & (-j)
        c = i - s
        c0[i] = c
        inv0 += c
        j = v
        while j <= n:
            tree[j] += 1
            j += j & (-j)

    # Each element at initial position p with count c contributes a swap to ops
    # [j1, j1+c-1] where j1 = first op index with A[j1] >= p
    D = [0] * (m + 2)
    for p in range(1, n + 1):
        c = c0[p - 1]
        if c:
            j1 = bisect_left(A, p) + 1
            if j1 <= m:
                D[j1] += 1
                e = j1 + c
                if e <= m:
                    D[e] -= 1

    out_lines = []
    cur = inv0
    s = 0
    for j in range(1, m + 1):
        s += D[j]
        cur -= s
        out_lines.append(str(cur))
    sys.stdout.write('\n'.join(out_lines) + '\n')

main()
```
