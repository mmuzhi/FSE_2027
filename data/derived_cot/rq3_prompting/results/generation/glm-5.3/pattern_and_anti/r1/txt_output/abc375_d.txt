def main():
    import sys
    S = sys.stdin.readline().strip()
    count = [0] * 26
    sumpos = [0] * 26
    ans = 0
    for idx, ch in enumerate(S, start=1):
        c = ord(ch) - 65
        ans += count[c] * (idx - 1) - sumpos[c]
        count[c] += 1
        sumpos[c] += idx
    print(ans)

main()

=== ANSWER ===
**Analysis:** A length-3 string is a palindrome iff its first and last characters are equal. So we count pairs (i, k) with i < k and S_i = S_k; each such pair contributes (k − i − 1) choices for j (any index strictly between).

**Plan (O(n), single pass):** Maintain per character c: `count[c]` = occurrences seen so far, `sumpos[c]` = sum of their 1-indexed positions. At position `idx` with character c, the new pairs formed with all previous occurrences contribute `count[c]*(idx-1) - sumpos[c]`.

**Verification on samples:**
- Sample 1 (ABCACC): A pair (1,4)→2; C pairs (3,5)→1, (3,6)→2, (5,6)→0 ⇒ total 5 ✓
- Sample 2 (8 O's): total = C(8,3) = 56 ✓
- Sample 3: X positions give 55, Y positions give 20 ⇒ 75 ✓

**Edge cases:** strings of length < 3 yield 0 automatically; large counts fit in Python ints.
