```python
class Solution:
    def stringSequence(self, target: str) -> List[str]:
        res = []
        cur = []
        base = ord('a')
        for ch in target:
            cur.append('a')
            res.append(''.join(cur))
            for i in range(1, ord(ch) - base + 1):
                cur[-1] = chr(base + i)
                res.append(''.join(cur))
        return res
```

The sequence of intermediate strings is forced by this greedy: after each key 2 press, record the string.

Edge cases: all 'a's — no key 2 presses. Length 1. All handled.

```python
class Solution:
    def stringSequence(self, target: str) -> List[str]:
        res = []
        cur = []
        base = ord('a')
        for ch in target:
            # Press key 1: append 'a'
            cur.append('a')
            res.append(''.join(cur))
            # Press key 2 until the last character becomes ch
            for i in range(1, ord(ch) - base + 1):
                cur[-1] = chr(base + i)
                res.append(''.join(cur))
        return res
```
