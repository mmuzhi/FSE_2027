```python
class Solution:
    def countComponents(self, nums: List[int], threshold: int) -> int:
        T = threshold
        S = [v for v in nums if v <= T]
        ans = len(nums) - len(S)  # singletons > T
        S.sort()
        if not S:
            return ans
        parent = list(range(T + 1))
        size = [1] * (T + 1)  # or rank
        
        def find(x):
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            return x
        
        rep = [0] * (T + 1)
        for v in S:
            if 2 * v > T:
                break  # sorted; larger v also skip
            for m in range(2 * v, T + 1, v):
                r = rep[m]
                if r == 0:
                    rep[m] = v
                else:
                    ra, rb = find(r), find(v)
                    if ra != rb:
                        # union by size
                        if size[ra] < size[rb]:
                            ra, rb = rb, ra
                        parent[rb] = ra
                        size[ra] += size[rb]
        # count distinct roots among S
        roots = set()
        for v in S:
            roots.add(find(v))
        return ans + len(roots)
```

```python
class Solution:
    def countComponents(self, nums: List[int], threshold: int) -> int:
        T = threshold
        S = [v for v in nums if v <= T]
        res = len(nums) - len(S)          # values > threshold: isolated nodes
        S.sort()
        parent = list(range(T + 1))
        sz = [1] * (T + 1)
        rep = [0] * (T + 1)
        for v in S:
            for m in range(v, T + 1, v):
                r = rep[m]
                if r == 0:
                    rep[m] = v
                else:
                    a = r
                    while parent[a] != a:
                        parent[a] = parent[parent[a]]
                        a = parent[a]
                    b = v
                    while parent[b] != b:
                        parent[b] = parent[parent[b]]
                        b = parent[b]
                    if a != b:
                        if sz[a] < sz[b]:
                            a, b = b, a
                        parent[b] = a
                        sz[a] += sz[b]
        roots = set()
        for v in S:
            x = v
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            roots.add(x)
        return res + len(roots)
```

=== ANSWER ===
Looking at this problem:

- Any value `> threshold` can never share an edge (lcm ≥ max value), so it's an isolated component.
- For values `≤ threshold` (call this set S, all ≤ 2·10⁵): the key fact is that for any `m ≤ threshold`, all values of S dividing `m` are **pairwise adjacent**, since for divisors `a, b` of `m`, `lcm(a,b)` divides `m`, hence `≤ threshold`. Conversely every edge `a—b` has `lcm(a,b) = m ≤ threshold` with both `a, b` dividing `m`. So components are exactly obtained by, for each `m = 1..threshold`, unioning all members of S that divide `m`.

Implementation: sieve-style — for each `v` in S, walk its multiples `m = v, 2v, ... ≤ threshold`; the first visitor sets `rep[m]`, later visitors union with `rep[m]` (DSU with path halving + union by size). This captures every edge (each endpoint of an edge visits `m = lcm`, including the crucial self-term `m = v` so that e.g. `4—8—16` with threshold 20 links `16` into the group of `m=16`).

Verified on Example 1 → 4 and Example 2 → 2, plus tricky cases: `[4,6], T=12` → 1 (direct lcm edge, no divisor chain exists), `[6,10], T=12` → 2 (shared divisor 2 does **not** imply an edge — grouping must be by common multiple, not divisor). Complexity ≈ `threshold · ln(threshold)` ≈ 2.4M steps worst case.

```python
class Solution:
    def countComponents(self, nums: List[int], threshold: int) -> int:
        T = threshold
        S = [v for v in nums if v <= T]
        res = len(nums) - len(S)          # values > threshold are isolated nodes
        if not S:
            return res
        S.sort()
        if S[0] == 1:                     # 1 connects to every value <= threshold
            return res + 1
        parent = list(range(T + 1))
        sz = [1] * (T + 1)
        rep = [0] * (T + 1)
        for v in S:
            for m in range(v, T + 1, v):
                r = rep[m]
                if r == 0:
                    rep[m] = v
                else:
                    a = r
                    while parent[a] != a:
                        parent[a] = parent[parent[a]]
                        a = parent[a]
                    b = v
                    while parent[b] != b:
                        parent[b] = parent[parent[b]]
                        b = parent[b]
                    if a != b:
                        if sz[a] < sz[b]:
                            a, b = b, a
                        parent[b] = a
                        sz[a] += sz[b]
        roots = set()
        for v in S:
            x = v
            while parent[x] != x:
                parent[x] = parent[parent[x]]
                x = parent[x]
            roots.add(x)
        return res + len(roots)
```
