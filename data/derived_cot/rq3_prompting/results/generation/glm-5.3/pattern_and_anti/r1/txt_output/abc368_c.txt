```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    A = 0
    for i in range(1, n + 1):
        H = int(data[i])
        r = A % 3
        q, rem = divmod(H, 5)
        if rem == 0:
            m = 3 * q
        elif r == 0:
            m = 3 * q + rem if rem <= 2 else 3 * (q + 1)
        elif r == 1:
            m = 3 * q + 1 if rem == 1 else 3 * q + 2
        else:
            m = 3 * q + 1 if rem <= 3 else 3 * q + 2
        A += m
    print(A)

main()
```

Looking at this problem:

- Damage sequence over attacks is periodic: attack with T ≡ 0 (mod 3) deals 3, others deal 1. So every 3 consecutive attacks deal exactly 5 total damage (1+1+3), with partial prefix sums within a cycle depending on the starting residue of T.

**Key idea:** Track total attacks `A` so far. The next attack is number `A+1`, whose position in the cycle is `r = A % 3`. For each enemy with health `H`, compute minimal attacks `m` so cumulative damage ≥ H, using the cycle structure:

- Starting residue r=0 (damage pattern 1,1,3): partial sums within a cycle = [0,1,2]
- Starting residue r=1 (pattern 1,3,1): partial sums = [0,1,4]
- Starting residue r=2 (pattern 3,1,1): partial sums = [0,3,4]

With `q, rem = divmod(H, 5)`: if rem==0, m = 3q (exactly reaches H; one fewer attack is always short since max 2-attack partial is 4 < 5). Otherwise pick minimal suffix s from the table (or roll into next cycle when r=0 and rem∈{3,4}).
