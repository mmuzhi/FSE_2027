2. **Answer ≤ 1**: a single op with pivot $k$ sorts $P$ iff $P_k = k$ and $\{P_1..P_{k-1}\} = \{1..k-1\}$ (i.e., prefix max $\le k-1$; the suffix condition then follows automatically).

3. **Answer ≤ 2 iff $P_1 \ne N$ or $P_N \ne 1$**:
   - If $P_1 \ne N$: ops $(1, N)$ work — op 1 sorts the suffix (pushing $N$ to the last position), then op $N$ sorts the prefix, which now consists of exactly $\{1..N-1\}$. Symmetrically, if $P_N \ne 1$, ops $(N, 1)$ work.
   - Conversely, if $P_1 = N$ and $P_N = 1$: tracking value $N$ (starts at pos 1, ends an op at position $k-1$ or stays at 1) and value 1 (starts at pos $N$): after the first op with $k_1\in[2,N-1]$, $N$ sits at $k_1-1$ and $1$ at $k_1+1$; the second op would need $k_2 \le k_1-2$ (to push $N$ to position $N$) and $k_2 \ge k_1+2$ (to push $1$ to position 1) — contradiction. Edge cases $k_1=1$ or $k_1=N$ also fail. So 2 ops are impossible, and the 1-op condition can never hold when $P_1=N$ (prefix max would be $N > k-1$).

4. **Answer = 3 when $P_1 = N$ and $P_N = 1$**: one op with $k=3$ makes the first element $\min(P_1,P_2) < N$, after which 2 ops suffice. So the answer is never more than 3.

All samples check out: $(2,1,3,5,4)\to 1$ ($k=3$: $P_3=3$, prefix max 2), identity $\to 0$, $(3,2,1,7,5,6,4)\to 2$ ($P_1=3\ne 7$).

Algorithm per test: $O(N)$ scan checking identity, fixed points with clean prefix (running max), then endpoints.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    t = int(data[0])
    idx = 1
    out = []
    for _ in range(t):
        n = int(data[idx]); idx += 1
        p = list(map(int, data[idx:idx + n]))
        idx += n
        identity = True
        one_op = False
        mx = 0
        for i in range(n):
            v = p[i]
            if v != i + 1:
                identity = False
            elif mx <= i:
                one_op = True
            if v > mx:
                mx = v
        if identity:
            out.append(0)
        elif one_op:
            out.append(1)
        elif p[0] != n or p[-1] != 1:
            out.append(2)
        else:
            out.append(3)
    sys.stdout.write('\n'.join(map(str, out)) + '\n')

main()
```
