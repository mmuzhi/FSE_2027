import sys

def main():
    data = sys.stdin.buffer.read().split()
    s = data[0].decode()
    q = int(data[1])
    ks = data[2:2+q]
    n = len(s)
    out = []
    for kb in ks:
        k = int(kb)
        b, o = divmod(k - 1, n)
        c = s[o]
        if bin(b).count('1') & 1:
            c = c.swapcase()
        out.append(c)
    sys.stdout.write(' '.join(out))

## Approach

**Key insight:** After all doublings, the final string consists of blocks of length `n = |S|`. Block `b` (0-indexed) equals `S` if `popcount(b)` is even, and the case-flipped `S` if odd.

**Why:** By induction — after operation 1, blocks are `S, flip(S)` (popcounts 0, 1). Each new operation appends `flip(W)`, so block `b` in the appended half is the flip of block `b - 2^(t-1)`; since `b`'s top bit got set, `popcount(b) = popcount(b-2^(t-1)) + 1`, preserving the invariant.

Since `K ≤ 10^18` and block index `b = (K-1)//n < 2^60 ≪ 2^(10^100)`, the final string definitely covers position K.

**Per query:** `b, o = divmod(K-1, n)`; answer is `S[o]`, swapcased if `popcount(b)` is odd. O(1) per query.
