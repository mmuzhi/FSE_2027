```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = data[1:1+n]
    last = {}
    ans = n + 1
    for i, x in enumerate(a):
        j = last.get(x, -1)
        if j >= 0:
            ans = min(ans, i - j + 1)
        last[x] = i
    print(ans if ans <= n else -1)

main()
```

=== ANSWER ===
**Approach:** A subarray contains a repeated value iff it contains two occurrences of some value. The shortest such subarray must have its two equal values exactly at its endpoints, so the answer is the minimum over all values of the gap between consecutive occurrences, plus 1. Track the last seen index of each value in one pass; for each repeated value seen at index `i` previously at `j`, candidate length is `i - j + 1`. If none, print `-1`.

**Key checks:**
- Sample 1: value 3 at indices 0 and 3 → 4. ✓
- Sample 2: all distinct → -1. ✓
- Sample 3: `1 1 ...` → 2. ✓
- Edge case N=1: no repeat possible, sentinel stays, prints -1. ✓

Complexity O(N).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = data[1:1 + n]
    last = {}
    ans = n + 1
    for i, x in enumerate(a):
        j = last.get(x, -1)
        if j >= 0:
            d = i - j + 1
            if d < ans:
                ans = d
        last[x] = i
    print(ans if ans <= n else -1)

main()
```
