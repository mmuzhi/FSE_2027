## Approach

The buttons append either a single digit or `"00"` to the display. So displaying `S` means partitioning `S` sequentially into pieces, each of which is a single character or `"00"`. Minimizing presses = minimizing the number of pieces = maximizing the number of `"00"` pieces.

A `"00"` piece can only be placed where two adjacent characters are both `'0'`, and pieces cannot overlap. For a maximal run of `m` zeros, the max number of disjoint adjacent pairs is `⌊m/2⌋`, achieved greedily by scanning left to right and pairing consecutive zeros as they appear.

**Verification against samples:**
- `1000000007` (len 10): run of 8 zeros → 4 pairs → 10 − 4 = **6** ✓
- `998244353` (len 9): no zeros → **9** ✓
- `32000` (len 5): run of 3 zeros → 1 pair → 5 − 1 = **4** ✓

**Ledger:**
- Invariant: greedy left-to-right scan; consume 2 chars when `S[i]==S[i+1]=='0'`, else 1 char; count 1 press per step.
- Edge case: single trailing `'0'` after a consumed pair (handled by the bounds check `i+1 < n`).

```python
S = input().strip()
i = 0
count = 0
n = len(S)
while i < n:
    if i + 1 < n and S[i] == '0' and S[i + 1] == '0':
        i += 2
    else:
        i += 1
    count += 1
print(count)
```
