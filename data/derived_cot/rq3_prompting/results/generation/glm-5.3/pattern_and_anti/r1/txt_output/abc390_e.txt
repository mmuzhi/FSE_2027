There are N foods, each containing exactly one of vitamins 1, 2, and 3.

Find the maximum possible value of this: the minimum intake among vitamins 1, 2, and 3.

N X
V_1 A_1 C_1
V_2 A_2 C_2

- 1 \leq X \leq 5000
- 1 \leq V_i \leq 3
- 1 \leq A_i \leq 2 \times 10^5
- 1 \leq C_i \leq X

## Approach

**Decisive constraints:** N, X ≤ 5000 → knapsack DP over calories is O(N·X) ≈ 25M operations, which needs vectorization in Python (numpy). Values A_i ≤ 2×10⁵ mean the answer can be up to ~10⁹, suggesting binary search on the answer.

**Plan:**
1. **Independent knapsacks per vitamin:** Foods of different vitamins only interact through the shared calorie budget. For each vitamin v, compute `dp_v[c]` = max vitamin v intake using ≤ c calories from that group. Each item's 0/1 knapsack update `dp[c:] = max(dp[c:], dp[:-C]+A)` is a pure function of the old array → safely vectorized with numpy in one shot per item.
2. **Binary search on answer t:** "min intake ≥ t" is feasible iff `mincost_1(t) + mincost_2(t) + mincost_3(t) ≤ X`, where `mincost_v(t)` is the smallest budget with `dp_v[c] ≥ t`. Since each `dp_v` is non-decreasing (provably maintained by the update), `mincost` is found via `np.searchsorted`.

**Key edge cases:** a vitamin with no foods → its dp stays all zeros → any t ≥ 1 infeasible → answer 0 (matches sample 2). Feasibility is monotone in t, and t=0 is always feasible (empty subset).

**Verification on sample 1:** dp₁ gives 8 at cost 5; dp₂: 3@5, 10@10; dp₃: 2@5, 3@10, 5@15. t=3: 5+5+10=20 ≤ 25 ✓; t=4: 5+10+15=30 > 25 ✗ → answer 3. ✓
