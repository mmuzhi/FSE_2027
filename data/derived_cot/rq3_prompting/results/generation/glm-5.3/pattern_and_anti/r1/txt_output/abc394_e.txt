def main():

Looking at this problem:

- N ≤ 100, need shortest palindrome-labeled walk for all pairs.
- Classic approach: BFS over states (u, v) meaning "a palindrome walk from u to v is being built outside-in". Base states: (u,u) with distance 0 (empty palindrome) and (u,v) with distance 1 for each direct edge. Transition from (x,y) at distance d: if there's an edge u→x labeled c and an edge y→v labeled c, then (u,v) gets distance d+2. Answer for (i,j) is dist of state (i,j).
- Naive expansion could be O(N⁴) = 10⁸ in the worst case (complete graph, one letter), too slow in Python. Fix: bitset masks per (vertex, letter) for predecessors/successors, and a per-row visited bitmask `vis[u]` over v. For each state, iterate bits of pred mask; the cross product with succ is handled via `sm & ~vis[u]`, so total work is Σ over states of indeg(x) ≤ N·N² = 10⁶ bit operations — fast.

Verified by hand against both samples (sample 1 fully traced: distances 0,1,2,3,4 states reproduce the expected matrix exactly; sample 2 also matches, including A[5][3]=5 via "tsust").

Key edge cases: diagonal always 0 even with self-loops (empty string is a palindrome, marked first); level order processes distance 0 and 1 states before expansions (each expansion adds exactly +2, so layer-ordered BFS yields minimum distances).
