```python
class Solution:
    def minOperations(self, queries: List[List[int]]) -> int:
        def f(n):
            total = 0
            p = 1  # 4^(k-1)
            k = 1
            while p <= n:
                cnt = min(n, p * 4 - 1) - p + 1
                total += k * cnt
                p *= 4
                k += 1
            return total
        ans = 0
        for l, r in queries:
            s = f(r) - f(l - 1)
            ans += (s + 1) // 2
        return ans
```

=== ANSWER ===
Looking at this problem:

**Key insight:** Each element x needs d(x) divisions by 4 to reach 0, where d(x) = number of base-4 digits of x (x reaches 0 when 4^k > x). Each operation performs 2 divisions (possibly wasting one on an already-zero element, which is harmless). So the minimum operations for a query = ceil(S/2) where S = total divisions needed. This is achievable by always pairing two elements that still need division (array has ≥2 elements since l < r, so a lone straggler can pair with a zero).

**Computing S fast:** Prefix function f(n) = sum of d(x) for x in [1,n], using digit-blocks [4^(k-1), 4^k - 1] contributing k each. Then S = f(r) - f(l-1). Since r ≤ 10^9 < 4^15, at most 15 blocks per call.

**Verification with examples:**
- [1,2]: d=1+1=2 → ceil(2/2)=1 ✓
- [2,4]: d=1+2+2=5... wait: d(2)=1,d(3)=1,d(4)=2 → S=4 → 2 ✓ (f(4)=1·3+2·1=5, f(1)=1, S=4)
- [2,6]: f(6)=1·3+2·3=9, f(1)=1, S=8 → 4 ✓

Edge check: l=1 → f(0)=0 via loop not executing (p=1 > 0). Complexity: ~30 loop iterations per query over 10^5 queries — fine.

```python
class Solution:
    def minOperations(self, queries: List[List[int]]) -> int:

            total = 0
            p = 1  # 4^(k-1), elements in [p, 4p-1] need k divisions
            k = 1
            while p <= n:

                total += k * cnt
                p *= 4
                k += 1
            return total

        ans = 0
        for l, r in queries:
            s = f(r) - f(l - 1)
            ans += (s + 1) // 2
        return ans
```
