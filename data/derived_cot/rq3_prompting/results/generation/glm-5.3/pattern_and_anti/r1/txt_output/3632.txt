```python
class Solution:
    def buttonWithLongestTime(self, events: List[List[int]]) -> int:
        best_index = events[0][0]
        best_time = events[0][1]
        for i in range(1, len(events)):
            duration = events[i][1] - events[i - 1][1]
            if duration > best_time or (duration == best_time and events[i][0] < best_index):
                best_time = duration
                best_index = events[i][0]
        return best_index
```
