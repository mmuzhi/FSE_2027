You will be given a competitive programming problem.
KEYENCE is famous for quick delivery.

In this problem, the calendar proceeds as Day 1, Day 2, Day 3, \dots.
There are orders 1,2,\dots,N, and it is known that order i will be placed on Day T_i.
For these orders, shipping is carried out according to the following rules.

- At most K orders can be shipped together.
- Order i can only be shipped on Day T_i or later.
- Once a shipment is made, the next shipment cannot be made until X days later.
- That is, if a shipment is made on Day a, the next shipment can be made on Day a+X.



For each day that passes from order placement to shipping, dissatisfaction accumulates by 1 per day.
That is, if order i is shipped on Day S_i, the dissatisfaction accumulated for that order is (S_i - T_i).
Find the minimum possible total dissatisfaction accumulated over all orders when you optimally schedule the shipping dates.

Input

The input is given from Standard Input in the following format:
N K X
T_1 T_2 \dots T_N

Output

Print the answer as an integer.

Constraints


- All input values are integers.
- 1 \le K \le N \le 100
- 1 \le X \le 10^9
- 1 \le T_1 \le T_2 \le \dots \le T_N \le 10^{12}

Sample Input 1

5 2 3
1 5 6 10 12

Sample Output 1

2

import sys
import numpy as np

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); k = int(data[1]); x = int(data[2])
    T = list(map(int, data[3:3+n]))
    sumT = sum(T)

    pend_d = [[] for _ in range(n+1)]
    pend_c = [[] for _ in range(n+1)]
    pend_d[0].append(np.array([T[0]-x], dtype=np.int64))
    pend_c[0].append(np.array([0], dtype=np.int64))

    for i in range(n+1):
        dd = np.concatenate(pend_d[i])
        cc = np.concatenate(pend_c[i])
        order = np.argsort(dd, kind='stable')
        dd = dd[order]; cc = cc[order]
        new_grp = np.empty(dd.size, dtype=bool)
        new_grp[0] = True
        if dd.size > 1:
            new_grp[1:] = dd[1:] != dd[:-1]
        starts = np.flatnonzero(new_grp)
        ud = dd[starts]
        uc = np.minimum.reduceat(cc, starts)
        if ud.size > 1:
            pm = np.minimum.accumulate(uc)
            keep = np.empty(uc.size, dtype=bool)
            keep[0] = True
            keep[1:] = uc[1:] < pm[:-1]
            ud = ud[keep]; uc = uc[keep]
        if i == n:
            print(int(uc.min()) - sumT)
            return
        base = ud + x
        hi = min(i+k, n)
        for e in range(i+1, hi+1):
            c = e - i
            nd = np.maximum(base, T[e-1])
            nc = uc + nd * c
            pend_d[e].append(nd)
            pend_c[e].append(nc)

main()

=== ANSWER ===
Looking at this problem:

- Orders sorted by T; batches are consecutive blocks of size ≤ K (standard exchange argument).
- For a fixed partition, the pointwise-minimal (greedy) schedule ships batch t at d_t = max(d_{t-1}+X, E_t) where E_t = max T in batch t, and this minimizes Σ c_t·d_t.
- So DP over (orders shipped so far i, exact date d of the last batch): dp[i][d] = min Σ c_t·d_t. Transition: next batch = orders i+1..e (e ≤ i+K), new date max(d+X, T_e), cost += (e−i)·newdate. Answer = min dp[N][d] − ΣT.
- Since future cost is non-decreasing in d, states are pruned to a Pareto frontier (dates ascending, costs strictly descending), keeping state counts tiny. Verified by hand against all three samples (sample 1 gives 2, sample 3 gives 175−140=35).

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); k = int(data[1]); x = int(data[2])
    T = list(map(int, data[3:3 + n]))
    sumT = sum(T)
    try:
        import numpy as np
        have_np = True
    except Exception:
        have_np = False
    if have_np:
        pend_d = [[] for _ in range(n + 1)]
        pend_c = [[] for _ in range(n + 1)]
        pend_d[0].append(np.array([T[0] - x], dtype=np.int64))
        pend_c[0].append(np.array([0], dtype=np.int64))
        for i in range(n + 1):
            dd = np.concatenate(pend_d[i]); cc = np.concatenate(pend_c[i])

            new_grp[1:] = dd[1:] != dd[:-1]
            starts = np.flatnonzero(new_grp)
            ud = dd[starts]; uc = np.minimum.reduceat(cc, starts)

                keep = np.empty(uc.size, dtype=bool); keep[0] = True
                keep[1:] = uc[1:] < pm[:-1]
