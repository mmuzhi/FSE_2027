**Approach.** The stack size changes by ±1 each step, so its size parity always equals the step index parity. Working out which subsequences can be the *final* stack content: between two surviving elements, everything appended must be deleted in-place (an even-length balanced window), and similarly before the first and after the last survivor. This yields the exact characterization:

- Final stack = positions `i_1 < i_2 < ... < i_k` where `i_1` is odd, consecutive differences are odd (parities alternate starting with odd), and `N - i_k` is even (equivalently `k ≡ N mod 2`).

Conversely any such subsequence is achievable by filling gaps with (append, delete) pairs. Since position parity must equal the element's rank parity, a simple O(N) DP suffices: `p0/p1` = best sum using a valid alternating subsequence so far with an even/odd number of picks, where a pick at position `i` is only allowed into the state matching `i mod 2`. Answer is `p1` if `N` is odd else `p0` (which naturally includes the empty stack, sum 0, when `N` is even).
