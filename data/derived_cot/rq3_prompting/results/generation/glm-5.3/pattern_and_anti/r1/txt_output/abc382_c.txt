You will be given a competitive programming problem.
There are N people numbered from 1 to N visiting a conveyor belt sushi restaurant.
The gourmet level of person i is A_i.

Each piece of sushi passes in front of people 1, 2, \dots, N in this order.
Each person, when a sushi whose deliciousness is not less than their gourmet level passes in front of them, will take and eat that sushi; otherwise, they do nothing.
A sushi that person i takes and eats will no longer pass in front of person j\ (j > i).
For each of the M pieces of sushi, determine who eats that sushi, or if nobody eats it.

The input is given from Standard Input in the following format:

A_1 A_2 \dots A_N
B_1 B_2 \dots B_M

- 1 \leq N, M \leq 2 \times 10^5
- 1 \leq A_i, B_i \leq 2 \times 10^5
- All input values are integers.

```python
from itertools import accumulate

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    MAXV = 200000
    INF = n + 1
    minIdx = [INF] * (MAXV + 1)
```

=== ANSWER ===
**Approach:** For each sushi with deliciousness b, the answer is the smallest index i with A_i ≤ b. Precompute `minIdx[v]` = smallest person index whose gourmet level equals v, then take a prefix minimum over values (since A_i ≤ b means value in [1, b]). Answer each query in O(1). Total O(N + M + maxV).

Key checks against samples: for b below all A_i the prefix min stays at n+1 → output -1; sample 1 gives [1, 3, -1], sample 3 gives [1, 7, 4, 10, -1] — both match.

```python
import sys
from itertools import accumulate

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    MAXV = 200000
    INF = n + 1
    minIdx = [INF] * (MAXV + 1)
    for i in range(2, 2 + n):
        a = int(data[i])
        idx = i - 1  # person number (1-based)
        if minIdx[a] > idx:
            minIdx[a] = idx
    # first[v] = smallest person index with A_i <= v (prefix minimum over values)
    first = list(accumulate(minIdx, min))
    out = []
    for j in range(2 + n, 2 + n + m):
        b = int(data[j])
        r = first[b]
        out.append(str(r) if r <= n else '-1')
    sys.stdout.write('\n'.join(out) + '\n')

main()
```
