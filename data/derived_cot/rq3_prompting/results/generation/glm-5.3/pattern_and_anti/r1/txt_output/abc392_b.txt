Looking at this problem:

- **Constraints**: N ≤ 1000, so a simple O(N + M) set-membership scan is more than sufficient — no need to consider anything fancier.
- **Plan**: Read all input, put A into a set, iterate i from 1 to N collecting i not in the set (automatically ascending), print count then the space-joined list.
- **Edge case**: When nothing is missing (M = N), print `0` and an empty second line — `print(" ".join([]))` naturally emits an empty line, matching the expected format.

**Trace on samples**:
- Sample 1: A={3,9,2} → missing = [1,4,5,6,7,8,10], prints `7` then the list. ✓
- Sample 2: A={1..6} → missing = [], prints `0` then empty line. ✓
- Sample 3: A={9} → missing = [1..8], prints `8` then list. ✓

Invariant check: iterating 1..N guarantees ascending order regardless of A's order; using `read().split()` makes parsing robust to line breaks.

import sys

def main():
