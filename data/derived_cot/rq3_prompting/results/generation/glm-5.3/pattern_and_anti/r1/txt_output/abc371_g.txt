What is lexicographical order?
 For sequences of length N, A = (A_1, A_2, \ldots, A_N) and B = (B_1, B_2, \ldots, B_N), A is lexicographically smaller than B if and only if:

- there exists an integer i\ (1\leq i\leq N) such that A_i < B_i, and A_j = B_j for all 1\leq j < i.

Input

- P_i\neq P_j\ (1\leq i<j\leq N)
- 1\leq A_i\leq N\ (1\leq i\leq N)
- A_i\neq A_j\ (1\leq i<j\leq N)
- All input values are integers.

import sys
from math import gcd

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    P = [int(x) - 1 for x in data[1:1+n]]
    A = [int(x) for x in data[1+n:1+2*n]]
    
    # smallest prime factor sieve
    spf = list(range(n+1))
    i = 2
    while i * i <= n:
        if spf[i] == i:
            for j in range(i*i, n+1, i):
                if spf[j] == j:
                    spf[j] = i
        i += 1
    
    ans = [0] * n
    visited = [False] * n
    pw = {}   # prime -> exponent in M
    Rmod = {} # prime -> R mod p^e
    
    for i in range(n):
        if visited[i]:
            continue
        # build cycle starting at i (minimal index)
        cyc = []
        j = i
        while not visited[j]:
            visited[j] = True
            cyc.append(j)
            j = P[j]
        L = len(cyc)
        v = [A[c] for c in cyc]
        
        # compute g = gcd(M, L) using factorization of L
        # factor L
        fl = {}  # prime -> exp
        x = L
        while x > 1:
            p = spf[x]
            e = 0
            while x % p == 0:
                x //= p
                e += 1
            fl[p] = e
        
        g = 1
        g_parts = []  # (p, min_exp, R mod p^min_exp)
        for p, f in fl.items():
            e = pw.get(p, 0)
            m = min(e, f)
            if m > 0:
                g *= p ** m
                g_parts.append((p ** m, Rmod[p] % (p ** m)))
        
        # R mod g via CRT
        if not g_parts:
            r0 = 0
        else:
            r0, mm = g_parts[0]
            for a2, m2 in g_parts[1:]:
                # combine x ≡ r0 mod mm, x ≡ a2 mod m2
                # r0 + mm * t ≡ a2 mod m2 → t ≡ (a2 - r0) * inv(mm) mod m2
                t = (a2 - r0) * pow(mm % m2, -1, m2) % m2
                r0 = r0 + mm * t
                mm *= m2
            # r0 in [0, g), since CRT result mod product; r0 < mm = g
        
        # choose r among r0 + t*g, t in [0, L//g), minimizing v
        best_t = 0
        best_val = v[r0]
        cnt = L // g
        for t in range(1, cnt):
            val = v[r0 + t * g]
            if val < best_val:
                best_val = val
                best_t = t
        r = r0 + best_t * g  # already < L
        
        # assign
        for jj in range(L):
            ans[cyc[jj]] = v[(jj + r) % L]
        
        # update pw, Rmod with r mod L
        for p, f in fl.items():
            if f > pw.get(p, 0):
                pw[p] = f
                Rmod[p] = r % (p ** f)
            # else keep
    
    sys.stdout.write(' '.join(map(str, ans)))

Looking at this problem:

- After k operations, position i holds value A[P^k(i)]. So each P-cycle of length L rotates its A-values by k mod L, but **the same k applies to all cycles**, so choices are coupled through gcd of cycle lengths (naive per-cycle independence fails, e.g. two 2-cycles where best shifts conflict mod 2).
- Greedy lexicographic over positions 1..N: when first touching a cycle D (at its minimal index), the constraint so far is k ≡ R (mod M) with M = lcm of processed cycle lengths. Achievable residues mod L are exactly those ≡ R (mod g), g = gcd(M,L). Pick the one minimizing the value there (values in a cycle are distinct ⇒ unique residue fixes the whole cycle), then update the constraint system.
- To avoid huge numbers, track M factorized (prime → exponent) and R modulo each prime power; compute R mod g by CRT over prime powers (≤6 primes), and update factorwise when new cycle length L arrives.
