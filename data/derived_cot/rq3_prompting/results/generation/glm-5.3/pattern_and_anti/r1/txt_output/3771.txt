A special substring is a substring where:

Any character present inside the substring should not appear outside it in the string.
The substring is not the entire string s.

Note that all k substrings must be disjoint, meaning they cannot overlap.
Return true if it is possible to select k such disjoint special substrings; otherwise, return false.
 
Example 1:

Input: s = "abcdbaefab", k = 2
Output: true
Explanation:

We can select two disjoint special substrings: "cd" and "ef".
"cd" contains the characters 'c' and 'd', which do not appear elsewhere in s.
"ef" contains the characters 'e' and 'f', which do not appear elsewhere in s.

Input: s = "cdefdc", k = 3
Output: false
Explanation:
There can be at most 2 disjoint special substrings: "e" and "f". Since k = 3, the output is false.

Example 3:

Input: s = "abeabe", k = 0
Output: true

2 <= n == s.length <= 5 * 10^4

```python
class Solution:
    def maxSubstringLength(self, s: str, k: int) -> bool:
        n = len(s)
        from bisect import bisect_left
        pos = [[] for _ in range(26)]
        for i, ch in enumerate(s):
            pos[ord(ch) - 97].append(i)
        first = {}
        last = {}
        chars = [c for c in range(26) if pos[c]]
        closures = set()
        for c in chars:
            L, R = pos[c][0], pos[c][-1]
            # closure
            included = set()
            while True:
                changed = False
                for d in chars:
                    if d in included:
                        continue
                    # does d occur in [L, R]?
                    lst = pos[d]
                    i = bisect_left(lst, L)
                    if i < len(lst) and lst[i] <= R:
                        # occurs
                        included.add(d)
                        L = min(L, lst[0])
                        R = max(R, lst[-1])
                        changed = True
                if not changed:
                    break
            if L > 0 or R < n - 1:  # proper
                closures.add((L, R))
        # count minimal
        closures = list(closures)
        cnt = 0
        for (L1, R1) in closures:
            minimal = True
            for (L2, R2) in closures:
                if (L2, R2) != (L1, R1) and L2 >= L1 and R2 <= R1:
                    minimal = False
                    break
            if minimal:
                cnt += 1
        return cnt >= k
```

```python
from bisect import bisect_left

class Solution:
    def maxSubstringLength(self, s: str, k: int) -> bool:
        n = len(s)
        pos = {}
        for i, ch in enumerate(s):
            pos.setdefault(ch, []).append(i)
        chars = list(pos.keys())
        closures = set()
        for c in chars:
            L, R = pos[c][0], pos[c][-1]
            done = {c}
            while True:
                nl, nr = L, R
                for d in chars:
                    if d in done:
                        continue
                    lst = pos[d]
                    j = bisect_left(lst, L)
                    if j < len(lst) and lst[j] <= R:
                        done.add(d)
                        nl = min(nl, lst[0])
                        nr = max(nr, lst[-1])
                if (nl, nr) == (L, R):
                    break
                L, R = nl, nr
            if (L, R) != (0, n - 1):
                closures.add((L, R))
        best = 0
        for (L1, R1) in closures:
            if not any(L2 >= L1 and R2 <= R1 and (L2, R2) != (L1, R1) for (L2, R2) in closures):
                best += 1
```

```python
from bisect import bisect_left

class Solution:
    def maxSubstringLength(self, s: str, k: int) -> bool:
        n = len(s)
        pos = {}
        for i, ch in enumerate(s):
            if ch in pos:
                pos[ch].append(i)
            else:
                pos[ch] = [i]
        chars = list(pos)
        closures = set()
        for c in chars:
            L, R = pos[c][0], pos[c][-1]
            done = {c}
            while True:
                nl, nr = L, R
                for d in chars:
                    if d in done:
                        continue
                    lst = pos[d]
                    j = bisect_left(lst, L)
                    if j < len(lst) and lst[j] <= R:
                        done.add(d)
                        if lst[0] < nl:
                            nl = lst[0]
                        if lst[-1] > nr:
                            nr = lst[-1]
                if nl == L and nr == R:
                    break
                L, R = nl, nr
            if L != 0 or R != n - 1:
                closures.add((L, R))
        best = 0
        cl = list(closures)
        for L1, R1 in cl:
            contained = False
            for L2, R2 in cl:
                if (L2, R2) != (L1, R1) and L2 >= L1 and R2 <= R1:
                    contained = True
                    break
            if not contained:
                best += 1
        return best >= k
```

```python
from bisect import bisect_left

class Solution:
    def maxSubstringLength(self, s: str, k: int) -> bool:
        n = len(s)
        pos = {}
        for i, ch in enumerate(s):
            pos.setdefault(ch, []).append(i)
        chars = list(pos.keys())
        closures = set()
        for c in chars:
            L, R = pos[c][0], pos[c][-1]
            done = {c}
            while True:
                nl, nr = L, R
                for d in chars:
                    if d in done:
                        continue
                    lst = pos[d]
                    j = bisect_left(lst, L)
                    if j < len(lst) and lst[j] <= R:
                        done.add(d)
                        if lst[0] < nl:
                            nl = lst[0]
                        if lst[-1] > nr:
                            nr = lst[-1]
                if nl == L and nr == R:
                    break
                L, R = nl, nr
            if L != 0 or R != n - 1:
                closures.add((L, R))
        best = 0
        cl = list(closures)
        for L1, R1 in cl:
            if not any((L2, R2) != (L1, R1) and L2 >= L1 and R2 <= R1 for L2, R2 in cl):
                best += 1
        return best >= k
```

=== ANSWER ===
Looking at this problem: a special substring `[l, r]` requires every character occurring inside it to have all its occurrences inside it. Each special substring must fully contain the occurrence set of its left-endpoint character, so I consider each character's **closure** — the minimal special substring containing its occurrences (computed by iteratively expanding the interval `[first, last]` whenever a character *occurring* inside has occurrences outside).

Key proven facts:
- Any valid selection of k disjoint special substrings yields k pairwise-disjoint, proper closures (witness characters at left endpoints), so max k ≤ max number of pairwise disjoint proper closures.
- Closures form a **laminar family** (two closures that partially overlap lead to contradiction: characters in the overlap are confined to it, so a closure can never grow out of it — hence only disjoint or nested is possible).
- Therefore the answer equals the number of *minimal* proper closures (they're pairwise disjoint and any disjoint selection injects into them), excluding closures equal to the whole string.

This closure-based count correctly handles cases like `"cycdydz"` where naive interval scheduling over `[first,last]` intervals overcounts (intervals of `c` and `d` are disjoint but their closures coincide, and truth is 2, not 3). Verified against all three examples (counts 4, 2, 0 → true/false/true), plus hand-checked cases like `"aba"`→1, `"abab"`→0, `"abeabe"`→0.

Implementation: at most 26 characters, closure via ≤26 rounds of bisect checks — trivially fast for n = 5·10⁴.
