Looking at this problem:

**Key insight:** Unwrap the square boundary onto a line of length `L = 4*side` (perimeter parameter `t`). For two boundary points:
- Manhattan ≤ min cyclic perimeter gap (any perimeter arc's length ≥ |Δx|+|Δy|).
- Same/adjacent edges: Manhattan = min gap exactly. Opposite edges: Manhattan ≥ side.

Since k ≥ 4, any feasible min distance d satisfies `k·d ≤ L`, so `d ≤ side`, which means opposite-edge pairs (Manhattan ≥ side) never violate d. Therefore **"all pairwise Manhattan ≥ d" ⟺ "k points in cyclic order with all consecutive gaps ≥ d"** for d ≤ L//k.

**Check(d):** For each candidate as the first (smallest-parameter) pick, greedy (earliest next pick ≥ last + d) is pointwise optimal. Implement all starts at once: doubled sorted array, `nxt[i]` = first index with value ≥ t[i]+d (binary search), then advance `k-1` steps for every start via repeated array mapping, and require last pick ≤ t[start] + L − d (wrap gap). Binary search over d ∈ [0, L//k].

Verified against all three examples (answers 2, 1, 1) and tricky opposite-edge cases.

```python
class Solution:
    def maxDistance(self, side: int, points: List[List[int]], k: int) -> int:
        from bisect import bisect_left
        L = 4 * side
        t = []
        for x, y in points:
            if y == 0:
                t.append(x)              # bottom edge
            elif x == side:
                t.append(side + y)       # right edge
            elif y == side:
                t.append(3 * side - x)   # top edge
            else:
                t.append(L - y)          # left edge
        t.sort()
        n = len(t)
        base = t + [v + L for v in t]
        T = base + [1 << 62]             # sentinel slot at index 2n
        m = 2 * n
        bl = bisect_left

        def check(d):
            # nxt[i] = first index with T value >= T[i] + d (sentinel = m)
            nxt = [bl(T, v + d) for v in base]
            nxt.append(m)
            P = range(n)
            for _ in range(k - 1):
                P = [nxt[x] for x in P]
            rem = L - d
            for a in range(n):
                if T[P[a]] - T[a] <= rem:   # wrap gap >= d
                    return True
            return False

        lo, hi = 0, L // k
        while lo < hi:
            mid = (lo + hi + 1) >> 1
            if check(mid):
                lo = mid
            else:
                hi = mid - 1
        return lo
```
