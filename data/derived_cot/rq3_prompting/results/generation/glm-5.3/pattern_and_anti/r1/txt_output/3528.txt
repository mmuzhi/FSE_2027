You are given an integer array nums of length n.
Your goal is to start at index 0 and reach index n - 1. You can only jump to indices greater than your current index.
The score for a jump from index i to index j is calculated as (j - i) * nums[i].
Return the maximum possible total score by the time you reach the last index.
 
Example 1:

Input: nums = [1,3,1,5]
Output: 7
Explanation:
First, jump to index 1 and then jump to the last index. The final score is 1 * 1 + 2 * 3 = 7.

Input: nums = [4,3,1,3,2]
Output: 16
Explanation:
Jump directly to the last index. The final score is 4 * 4 = 16.

We start at index 0, want to reach index n-1, jumping only forward. Jump from i to j scores (j-i)*nums[i]. Maximize total score.

Key observation: The total score can be decomposed. If we jump through indices 0 = i0 < i1 < ... < ik = n-1, the score is sum over consecutive pairs (i_{t+1} - i_t) * nums[i_t]. This is like: for each step of distance 1 from position p to p+1, we pay nums[current checkpoint]. So total = sum over each unit segment [p, p+1] of nums[last checkpoint index <= p]. So we want to maximize, for each unit step, the value of nums at the most recent checkpoint.

Greedy: to maximize, at each index, we should jump only when the next index has a larger nums value... Actually the classic result: the optimal is to jump from index i to the next index j where nums[j] > nums[i] (the next strictly greater element), and from each such index continue; if no greater element exists, jump straight to n-1.

for i in range(1, n):

    cur = max(cur, nums[i])
return ans

```python
class Solution:
    def findMaximumScore(self, nums: List[int]) -> int:
        ans = 0
        cur = nums[0]
        for i in range(1, len(nums)):
            ans += cur
            if nums[i] > cur:
                cur = nums[i]
        return ans
```

**Commit:** The score decomposes into unit segments: each segment [p, p+1] contributes `nums[checkpoint ≤ p]`. Since checkpoints just need to be increasing, we can place them at every prefix-maximum position, so the answer is `sum over p in [0, n-2] of max(nums[0..p])` — an O(n) running-max scan.

**Implementation ledger:**
- Invariant: before processing index `i`, `cur = max(nums[0..i-1])`; add `cur` to answer, then update `cur`.
