You will be given a competitive programming problem.
A sequence X = (X_1, X_2, \ldots) of positive integers (possibly empty) is called a 1122 sequence if and only if it satisfies all of the following three conditions: (The definition of a 1122 sequence is the same as in Problem F.)

- \lvert X \rvert is even. Here, \lvert X \rvert denotes the length of X.
- For each integer i satisfying 1\leq i\leq \frac{|X|}{2}, X_{2i-1} and X_{2i} are equal.
- Each positive integer appears in X either not at all or exactly twice. That is, every positive integer contained in X appears exactly twice in X.

Given a sequence A = (A_1, A_2, \ldots, A_N) of length N consisting of positive integers, print the maximum length of a (contiguous) subarray of A that is a 1122 sequence.

Input

The input is given from Standard Input in the following format:
N
A_1 A_2 \ldots A_N

Output

Print the maximum length of a (contiguous) subarray of A that is a 1122 sequence.

Constraints


- 1\leq N \leq 2 \times 10^5
- 1\leq A_i \leq N
- All input values are integers.

Sample Input 1

2 3 1 1 2 2 1 1

Sample Output 1

4

- A 1122 subarray decomposes into adjacent equal pairs at positions l, l+2, l+4, ... with all pair-values distinct.
- Key insight: pairs align by parity of the start index, so I run two independent sliding windows — one for even pair positions, one for odd pair positions. A single combined two-pointer would miss windows of the other parity spanning a "mismatch" boundary (e.g., `[1,1,2,2,2,3,3,4,4,5,5]` where answer 8 comes from the odd-parity chain `2,2,3,3,4,4,5,5`).

**Plan (per parity p):** iterate pair positions i of parity p. If `A[i] == A[i+1]`, shrink from left while value already in set, add it, update answer with window length `i - left + 2`. If mismatch, the chain breaks: clear set, move `left` to `i+2`.

Invariant: `left[p]` and `i` share parity; set holds values of current maximal chain; valid left ends form a suffix range (monotone), so two pointers are correct. Amortized O(N).

Traced all three samples (4, 2, 0) and the tricky parity case (8) — all correct. Edge case N=1 gives empty loop → 0.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    A = list(map(int, data[1:1 + n]))
    ans = 0
    sets = (set(), set())
    left = [0, 1]
    for i in range(n - 1):
        p = i & 1
        if A[i] == A[i + 1]:
            v = A[i]
            s = sets[p]
            while v in s:
                s.remove(A[left[p]])
                left[p] += 2
            s.add(v)
            length = i - left[p] + 2
            if length > ans:
                ans = length
        else:
            sets[p].clear()
            left[p] = i + 2
    print(ans)

main()
```
