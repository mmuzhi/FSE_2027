=== ANSWER ===
```python
from collections import Counter

class Solution:
    def maxDifference(self, s: str) -> int:
        freq = Counter(s)
        odd_max = max(c for c in freq.values() if c % 2 == 1)
        even_min = min(c for c in freq.values() if c % 2 == 0)
        return odd_max - even_min
```
