=== ANSWER ===
**Commit:** Sum all 81 products i×j (i, j ∈ 1..9), skipping cells equal to X. Total is 45×45 = 2025; answer = 2025 − X·(count of cells equal to X), but direct summation implements this in one line.

**Ledger:**
- Invariant: iterate all 81 cells, add i*j only when i*j != X (each occurrence of X excluded per cell).
- Edge cases: X with no representation (like 11) → count 0 → 2025; X = 1 → single cell → 2024; X = 24 → 4 cells (3×8, 4×6, 6×4, 8×3) → 2025 − 96 = 1929. All match samples.

**Check:** O(81) work, trivially within limits.
