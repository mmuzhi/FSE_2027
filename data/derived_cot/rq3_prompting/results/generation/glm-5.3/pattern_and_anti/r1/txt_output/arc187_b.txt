Find the sum, modulo 998244353, of f(B') over all possible B'.

Input

N M
B_1 \ldots B_N

Output

Looking at this problem:

**Key insight — components are contiguous intervals.** If $i \sim j$ (connected) and $i<k<j$, take a path edge $(a,b)$ crossing $k$ ($a<k<b$, so $A_a \le A_b$). If $A_k \ge A_a$, edge $(a,k)$ exists; else $A_k < A_b$, edge $(k,b)$ exists. Either way $k$ connects too. Hence
$$f(A) = 1 + \sum_{j=1}^{N-1}\,[\min(A_1..A_j) > \max(A_{j+1}..A_N)].$$
Verified on samples 1 and 2 (sample 2 hand-check: cuts give 16807+19976+11006+8846+11006 = 67641, plus $8^6=262144$ → 329785 ✓).

**Counting per cut $j$:** condition $\min(\text{pre}) > \max(\text{suf})$. Sum over $t=\max(\text{suf})$: prefix all $\ge t+1$ gives $(M-t)^{z_j}$ ways (if fixed prefix min $mn_j \ge t+1$), suffix max exactly $t$ gives $[mx_j\le t]t^{w_j}-[mx_j\le t-1](t-1)^{w_j}$, where $z_j,w_j$ are -1 counts. This reduces to two power-table range sums per $j$: $\sum_{t=\max(1,mx_j)}^{mn_j-1}(M-t)^{z_j}t^{w_j} - \sum_{u=mx_j}^{mn_j-2}(M-1-u)^{z_j}u^{w_j}$. Total $O(NM)$ using a precomputed table $t^e \bmod p$, vectorized with numpy (pure-Python fallback included). Answer $= M^q + \sum_j \text{Cut}_j$.
