import sys
import math
import numpy as np

def main():
    data = sys.stdin.buffer.read().split()
    q = int(data[0])
    MAXN = 10**6

    sieve = np.ones(MAXN + 1, dtype=bool)
    sieve[0] = False
    sieve[1] = False
    for i in range(2, int(MAXN ** 0.5) + 1):
        if sieve[i]:
            sieve[i * i::i] = False
    primes = np.nonzero(sieve)[0]

    cnt = np.zeros(MAXN + 1, dtype=np.int8)
    for p in primes:
        cnt[p::p] += 1

    best = np.where(cnt == 2, np.arange(MAXN + 1, dtype=np.int64), np.int64(0))

        b = best[s]

    sys.stdout.write('\n'.join(out))

        sys.stdout.write('\n')

main()

**Analysis:** A 400 number is exactly N = m² where m has exactly 2 distinct prime factors (N = p^(2a)·q^(2b)). So for a query A, take s = isqrt(A) and find the largest m ≤ s with exactly 2 distinct prime factors; answer is m².

**Plan:** Sieve count of distinct prime factors for all m ≤ 10⁶ (since A ≤ 10¹² ⇒ s ≤ 10⁶), build a prefix-max array `best[m]`, then answer each query in O(1) with `math.isqrt`. Use numpy for the sieve for speed; Q ≤ 2·10⁵ queries handled in a tight loop.

**Verification on samples:** isqrt(404)=20 → 20=2²·5 ✓ → 400; isqrt(36)=6=2·3 → 36; isqrt(60)=7 → best 6 → 36; isqrt(10¹²)=10⁶=2⁶·5⁶ → 10¹²; isqrt(123456789)=11111=41·271 → 123454321. All match. Since A ≥ 36, s ≥ 6 and best[s] ≥ 6 always exists.
