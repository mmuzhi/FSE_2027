Given these constraints, n is at most 100. The simplest approach: brute force over all subarrays of lengths from l to r. That's O(n * (r - l + 1)) which is at most O(n^2) = 10,000 operations — trivially fast.

Approach: 
- Compute prefix sums so subarray sum from i to j is prefix[j+1] - prefix[i].
- For each starting index i, for each length len in [l, r] where i + len <= n, compute the sum. If sum > 0, track the minimum.

Alternative even simpler: for each start i, maintain running sum as we extend the end j from i to i+r-1 (bounded by n-1), and when the length (j - i + 1) is >= l and the sum > 0, update the answer.

```python
class Solution:
    def minimumSumSubarray(self, nums: List[int], l: int, r: int) -> int:
        n = len(nums)
        ans = -1
        for i in range(n):
            s = 0
            for j in range(i, min(i + r, n)):
                s += nums[j]
                length = j - i + 1
                if length >= l and s > 0:
                    if ans == -1 or s < ans:
                        ans = s
        return ans
```
