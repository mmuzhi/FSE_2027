A string T is called an 11/22 string when it satisfies all of the following conditions:

- |T| is odd. Here, |T| denotes the length of T.
- The 1-st through (\frac{|T|+1}{2} - 1)-th characters are all 1.
- The (\frac{|T|+1}{2})-th character is /.
- The (\frac{|T|+1}{2} + 1)-th through |T|-th characters are all 2.

For example, 11/22, 111/222, and / are 11/22 strings, but 1122, 1/22, 11/2222, 22/11, and //2/2/211 are not.

import sys
from bisect import bisect_left

def main():
    data = sys.stdin.buffer.read().split()
    ptr = 0
    n = int(data[ptr]); ptr += 1
    q = int(data[ptr]); ptr += 1
    s = data[ptr].decode(); ptr += 1
    
    ones = [0] * (n + 1)
    twos = [0] * (n + 1)
    slashes = []
    for i in range(1, n + 1):
        c = s[i - 1]
        ones[i] = ones[i - 1] + (1 if c == '1' else 0)
        twos[i] = twos[i - 1] + (1 if c == '2' else 0)
        if c == '/':
            slashes.append(i)
    
    out = []
    for _ in range(q):
        L = int(data[ptr]); ptr += 1
        R = int(data[ptr]); ptr += 1
        lo = bisect_left(slashes, L)
        hi = bisect_left(slashes, R + 1) - 1
        if lo > hi:
            out.append('0')
            continue
        base1 = ones[L - 1]
        base2 = twos[R]
        # f(p) = ones[p-1] - base1, g(p) = base2 - twos[p]
        # binary search for first index in [lo, hi] where f >= g
        a, b = lo, hi + 1
        while a < b:
            mid = (a + b) // 2
            p = slashes[mid]
            if ones[p - 1] - base1 >= base2 - twos[p]:
                b = mid
            else:
                a = mid + 1
        best = 0
        # candidate a (first with f >= g), and a-1
        for idx in (a - 1, a):
            if lo <= idx <= hi:
                p = slashes[idx]
                v = min(ones[p - 1] - base1, base2 - twos[p])
                if v > best:
                    best = v
        out.append(str(2 * best + 1))
    
    sys.stdout.write('\n'.join(out) + '\n')

main()

=== ANSWER ===
Looking at this problem:

- An 11/22 string is k ones, one '/', k twos. So we pick a '/' at position p in [L,R], then k = min(#1s in [L,p-1], #2s in [p+1,R]), answer = 2k+1. Take max over all '/' positions in range; 0 if no '/'.
- f(p) = #1s before p (non-decreasing in p), g(p) = #2s after p (non-increasing). min(f,g) is unimodal over slash positions, so binary search the crossing (first slash index with f >= g) and check it plus the previous one.
- Complexity: O((N+Q) log N) with prefix sums of '1'/'2' and a sorted list of slash positions.

Verified against all 5 sample queries (answers 5, 0, 3, 1, 7 — including the edge case where the best k is 0 but a slash exists, giving 1).

Key edge cases handled: no slash in range → 0; single character range with '/' → 1; predicate monotonic since f−g is non-decreasing over sorted slash positions.
