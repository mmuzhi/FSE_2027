    def maxCollectedFruits(self, fruits: List[List[int]]) -> int:
        n = len(fruits)
        ans = sum(fruits[i][i] for i in range(n))
        
        def solve(g):
            # child starting top-right, moving down with j-1/j/j+1, to (n-1,n-1)
            NEG = float('-inf')
            # row 0: j = n-1 only
            lo0 = max(0, n-1)  # n-1
            dp = [NEG] * n
            dp[n-1] = g[0][n-1] if n-1 != 0 else 0
            # actually g[0][n-1], and 0 != n-1 since n>=2
            for i in range(1, n):
                lo = max(i, n-1-i)
                ndp = [NEG] * n
                row = g[i]
                for j in range(lo, n):
                    best = NEG
                    if j-1 >= 0 and dp[j-1] > best: best = dp[j-1]

                    if j+1 < n and dp[j+1] > best: best = dp[j+1]
                    if best > NEG:
                        ndp[j] = best + (row[j] if j != i else 0)
                dp = ndp
            return dp[n-1]
        
        ans += solve(fruits)
        # transpose
        t = list(zip(*fruits))
        ans += solve(t)
        return ans

Looking at this problem:

- **Child 1** (from (0,0)): each move increases i+j by 1 or 2, and over n−1 moves it must gain 2(n−1), so every move is diagonal — the path is *forced* onto the main diagonal. Contribution: `sum(fruits[i][i])`.
- **Child 2** (from (0,n−1)): one row down per move, j wiggles by ±1/0. At row i any valid (complete) path has `j ≥ n−1−i` (can't move left faster) and `j ≥ i` (must return to j=n−1). So it lives in the band `max(i, n−1−i) ≤ j ≤ n−1`.
- **Child 3** is the transpose case of child 2.

Since any cell child 2 or 3 could share with child 1 lies on the main diagonal (already fully collected), and child 2 (j ≥ i) and child 3 (i ≥ j) can only ever meet on the diagonal — zeroing out diagonal values for children 2 and 3 makes all three regions **disjoint**, so the three maximizations are independent. DP over the band per row for child 2, and run the same DP on the transposed grid for child 3.

Verified against Example 1: 34 (diagonal) + 24 (red: 4+8+12) + 42 (blue: 13+14+15) = 100 ✓, and Example 2: 2+1+1 = 4 ✓.
