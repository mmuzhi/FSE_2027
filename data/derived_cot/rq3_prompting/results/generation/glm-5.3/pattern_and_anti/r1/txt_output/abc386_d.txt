There is an N \times N grid. Takahashi wants to color each cell black or white so that all of the following conditions are satisfied:

- 1\leq X_i,Y_i\leq N
- (X_i,Y_i)\neq (X_j,Y_j)\ (i\neq j)
- C_i is B or W.
- All input numbers are integers.

Looking at this problem:

- Each valid coloring corresponds to row prefix lengths R_r (leftmost R_r cells of row r black) that must be **non-increasing** (so columns also have top-prefix black cells).
- A black cell (x,y) forces R_x ≥ y, hence R_r ≥ y for all r ≤ x.
- A white cell (x,y) forces R_x ≤ y-1.

Define L(r) = max{ y' : black cell (x', y') with x' ≥ r } (0 if none). L is non-increasing, and R = L is the pointwise minimal valid assignment. So a white cell (x,y) is satisfiable iff L(x) ≤ y-1.

Therefore the answer is **Yes** iff for every white cell (x, y) there is **no** black cell (x', y') with x' ≥ x and y' ≥ y.
