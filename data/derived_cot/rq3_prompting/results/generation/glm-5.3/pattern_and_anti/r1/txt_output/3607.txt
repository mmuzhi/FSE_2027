```python
class Solution:
    def minOperations(self, nums: List[int]) -> int:
        MAX = 10 ** 6
        spf = list(range(MAX + 1))
        # simple sieve to find primes up to sqrt(MAX)
        lim = 1000
        is_comp = [False] * (lim + 1)
        primes = []
        for i in range(2, lim + 1):
            if not is_comp[i]:
                primes.append(i)
                for j in range(i * i, lim + 1, i):
                    is_comp[j] = True
        for p in reversed(primes):

            if x <= limit:
                limit = x
            else:
                s = spf[x]
                if s <= limit:
                    ops += 1
                    limit = s
                else:
                    return -1
        return ops
```

Looking at this problem:

**Key insight:** Dividing `x` by its greatest proper divisor `gpd(x) = x / spf(x)` (where `spf` = smallest prime factor) yields exactly `spf(x)`. So a composite `x` can only become `spf(x)` in one operation, after which it's prime (or 1) and stuck. Thus each element has at most two possible values: `x` (cost 0) or `spf(x)` (cost 1).

**Strategy:** Greedy from right to left. Keep the rightmost element as-is; for each element moving left, prefer its original value if it fits under the limit (right neighbor's final value), otherwise use its smallest prime factor; if neither fits, return -1. Choosing the larger feasible value is optimal (minimizes cost and relaxes the constraint for the left neighbor).

Verification:
- `[25,7]`: 25 > 7, spf(25)=5 ≤ 7 → 1 op ✓
- `[7,7,6]`: 7 > 6, spf(7)=7 > 6 → -1 ✓
- `[1,1,1,1]`: all fit → 0 ✓

Implementation uses an SPF sieve up to 10^6 (built fast via reversed-prime slice assignment so the smallest prime wins), then an O(n) sweep.

```python
class Solution:
    def minOperations(self, nums: List[int]) -> int:
        MAX = 10 ** 6
        spf = list(range(MAX + 1))

        # primes up to sqrt(MAX) = 1000
        lim = 1000
        is_comp = bytearray(lim + 1)
        primes = []
        for i in range(2, lim + 1):
            if not is_comp[i]:
                primes.append(i)
                for j in range(i * i, lim + 1, i):
                    is_comp[j] = True

        # write larger primes first so the smallest prime factor ends up last
        for p in reversed(primes):
            k = (MAX - p * p) // p + 1
            spf[p * p::p] = [p] * k

        n = len(nums)
        ops = 0
        limit = nums[-1]
        for i in range(n - 2, -1, -1):
            x = nums[i]
            if x <= limit:
                limit = x
                continue
            s = spf[x]
            if s <= limit:
                ops += 1
                limit = s
            else:
                return -1
        return ops
```
