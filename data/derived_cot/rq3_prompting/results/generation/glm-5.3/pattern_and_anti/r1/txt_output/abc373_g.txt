You will be given a competitive programming problem.
There are 2N points P_1,P_2,\ldots,P_N, Q_1,Q_2,\ldots,Q_N on a two-dimensional plane.
The coordinates of P_i are (A_i, B_i), and the coordinates of Q_i are (C_i, D_i).
No three different points lie on the same straight line.
Determine whether there exists a permutation R = (R_1, R_2, \ldots, R_N) of (1, 2, \ldots, N) that satisfies the following condition. If such an R exists, find one.

- For each integer i from 1 through N, let segment i be the line segment connecting P_i and Q_{R_i}.  Then, segment i and segment j (1 \leq  i < j \leq N) never intersect.

Input

A_1 B_1
A_2 B_2
\vdots 
A_N B_N

\vdots
C_N D_N

Output

If there is no R satisfying the condition, print -1.
If such an R exists, print R_1, R_2, \ldots, R_N separated by spaces. If there are multiple solutions, you may print any of them.

Constraints


- 1 \leq N \leq 300
- 0 \leq A_i, B_i, C_i, D_i \leq 5000 (1 \leq i \leq N)
- (A_i, B_i) \neq (A_j, B_j) (1 \leq i < j \leq N)
- (C_i, D_i) \neq (C_j, D_j) (1 \leq i < j \leq N)
- (A_i, B_i) \neq (C_j, D_j) (1 \leq i, j \leq N)
- No three different points lie on the same straight line.
- All input values are integers.

Looking at this problem:

**Key insight**: A non-crossing perfect matching between P-points and Q-points always exists (so `-1` is never printed), and can be built with an angular-split recursion:

1. Take the bottom-most (then leftmost) point `b` among all remaining points (say it's a `P`; the `Q` case is symmetric).
2. Sort all other remaining points by angle around `b`. Since `b` is bottom-most, all angles lie in `[0, π)`, and no three collinear points guarantees distinct angles (integer coordinates make `atan2` safe).
3. Sweep in angular order counting `+1` for Q, `−1` for P; stop at the first moment the count reaches 1 — that point must be a Q, match it to `b`. Points seen before it have equal numbers of P and Q, and so do points after it. Both groups lie strictly on opposite sides of line `b`—partner, so recursing into each group keeps all segments non-intersecting (segments from one recursion stay inside that open half-plane).

This runs in about O(N² log N) total — trivial for N ≤ 300. Verified against sample 1 (produces a valid permutation `2 3 1`, which is in the accepted list).
