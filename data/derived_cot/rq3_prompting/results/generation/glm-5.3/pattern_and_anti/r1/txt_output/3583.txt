=== ANSWER ===
## Approach

**Commit:** For each value `g`, count pairs whose GCD is *exactly* `g`, then answer queries via prefix sums + binary search.

- Let `cnt[v]` = multiplicity of value `v`. Then `C[g]` = number of elements divisible by `g` = `sum(cnt[g], cnt[2g], ...)`, and pairs with both divisible by `g` = `C(g,2)`.
- Inclusion–exclusion top-down: `exact[g] = C(g,2) − sum(exact[m])` for multiples `m = 2g, 3g, ...` — this costs `O(M log M)` (harmonic sum), with `M = max(nums) ≤ 5·10⁴`.
- Prefix sums of `exact` over increasing `g` give positions in the sorted `gcdPairs`; each query answered with `bisect_right`.

**Invariant:** `pref[i]` = number of pairs with gcd ≤ i; query `q` maps to smallest `i` with `pref[i] > q`, i.e. `bisect_right(pref, q)`. Verified on all three examples (e.g. example 2 gives `exact = [3,2,0,1]` for g=1..4 → sorted `[1,1,1,2,2,4]` → answers `[4,2,1,1]`).

**Edge cases:** zero-count gcd values create duplicate prefix entries — `bisect_right` correctly skips them; constraint `q < n(n−1)/2` guarantees the returned index stays in range.

```python
from typing import List
from bisect import bisect_right
from itertools import accumulate

class Solution:
    def gcdValues(self, nums: List[int], queries: List[int]) -> List[int]:
        MAX = max(nums)
        cnt = [0] * (MAX + 1)
        for x in nums:
            cnt[x] += 1

        exact = [0] * (MAX + 1)
        # exact[g] = number of pairs whose gcd is exactly g
        for g in range(MAX, 0, -1):
            c = sum(cnt[g::g])              # elements divisible by g
            total = c * (c - 1) // 2        # pairs both divisible by g
            if total:
                total -= sum(exact[2 * g::g])  # remove pairs with larger gcd
            exact[g] = total

        # pref[i] = number of pairs with gcd <= i (gcd values are in ascending order)
        pref = [0]
        pref.extend(accumulate(exact[1:]))

        return [bisect_right(pref, q) for q in queries]
```

**Recheck:** Example 1: `exact[1]=2, exact[2]=1` → pref `[0,2,3,3,3]` → queries `[0,2,2]` → `[1,2,2]` ✓. Example 3: `exact[2]=1` → pref `[0,0,1]` → query `0` → `2` ✓. Complexity: `O(M log M + n + Q log M)`, comfortably within limits.
