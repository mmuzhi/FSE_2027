**Reasoning:**

- Sort blacks descending, sort whites descending. For choosing exactly `i` blacks the best sum is prefix `Bpref[i]`; for `j` whites it's `Wpref[j]`.
- Answer = max over pairs `i ≥ j` of `Bpref[i] + Wpref[j]`. Iterate `i` from 0..N, maintaining `run_w = max(Wpref[0..min(i,M)])`, and take `Bpref[i] + run_w`. Include the empty choice (0).

- Sample 1: Bpref = [0,8,13,16,15], run_w max over Wpref=[0,3,1,-3] gives 3 from i≥1 → max(0, 11, 16, 19, 18) = 19 ✓
- Sample 2: gives 5+3? Bpref=[0,5,3,-2,-12], Wpref=[0,8,12,13] → max(0,13,15,11,1)=15 ✓

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); m = int(data[1])
    B = list(map(int, data[2:2 + n]))
    W = list(map(int, data[2 + n:2 + n + m]))
    B.sort(reverse=True)
    W.sort(reverse=True)

    bp = [0] * (n + 1)
    for i in range(n):
        bp[i + 1] = bp[i] + B[i]
    wp = [0] * (m + 1)
    for j in range(m):
        wp[j + 1] = wp[j] + W[j]

    best = 0  # choose nothing
    run_w = 0  # max of wp[0..min(i,m)]
    for i in range(n + 1):
        lim = i if i <= m else m
        if wp[lim] > run_w:
            run_w = wp[lim]
        cand = bp[i] + run_w
        if cand > best:
            best = cand
    print(best)

main()
```
