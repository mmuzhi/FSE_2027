```python
class Solution:
    def minTime(self, skill: List[int], mana: List[int]) -> int:
        n, m = len(skill), len(mana)
        P = [0] * n
        s = 0
        for i, sk in enumerate(skill):
            s += sk
            P[i] = s
        R = [0] + P[:-1]
        try:
            import numpy as np
            Pn = np.array(P, dtype=np.int64)
            Rn = np.array(R, dtype=np.int64)
            t = 0
            for j in range(m - 1):
                a, b = mana[j], mana[j + 1]
                t += int((Pn * a - Rn * b).max())
            return t + P[-1] * mana[-1]
        except ImportError:
            t = 0
            for j in range(m - 1):
                a, b = mana[j], mana[j + 1]
                t += max(p * a - r * b for p, r in zip(P, R))
            return t + P[-1] * mana[-1]
```

=== ANSWER ===
**Commit:** This is a no-wait flow shop. If potion j starts at wizard 0 at time t_j, wizard i finishes it at t_j + P[i]·mana[j] where P is the prefix sum of skill. No-wait means potion j+1's arrival at wizard i must be ≥ wizard i's finish of potion j:

t_{j+1} ≥ t_j + max_i ( P[i]·mana[j] − P[i−1]·mana[j+1] ), with P[−1]=0.

Since the delta is a constant independent of t, greedy minimal start times are optimal, and the answer is t_{m−1} + P[n−1]·mana[m−1]. Complexity O(n·m) = 25M — vectorize the inner max with numpy (pure-Python fallback kept).

**Verified on examples:** Ex1: deltas 52, 2, 32 → 86 + 24 = 110 ✓. Ex2: deltas 1,1 → 2 + 3 = 5 ✓. Ex3: delta 1 → 1 + 20 = 21 ✓. Edge cases m=1 and n=1 fall out naturally.
