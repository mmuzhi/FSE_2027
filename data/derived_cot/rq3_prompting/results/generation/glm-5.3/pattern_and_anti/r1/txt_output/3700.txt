A sequence of numbers seq of size 5 contains a unique middle mode if the middle element (seq[2]) is a unique mode.

Output: 0

```python
class Solution:
    def subsequencesWithMiddleMode(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        from collections import Counter
        rightCnt = Counter(nums)
        leftCnt = Counter()
        S1 = S2 = T2 = 0  # sum l*r, sum l*r^2, sum r*l^2
        EL = 0  # sum C(l_v,2)
        ER = sum(r*(r-1)//2 for r in rightCnt.values())
        
        def C2(x):
            return x*(x-1)//2
        
        ans = 0
        for i, c in enumerate(nums):
            l = leftCnt[c]
            r = rightCnt[c]
            # remove c from right
            rightCnt[c] = r - 1
            S1 -= l
            S2 -= l*(2*r - 1)
            T2 -= l*l
            ER -= (r - 1)
            # process
            L, R = i, n - 1 - i
            if L >= 2 and R >= 2:
                fL, fR = l, r - 1
                gL, gR = L - fL, R - fR
                ELp = EL - C2(fL)
                ERp = ER - C2(fR)
                Wge2 = C2(L)*C2(R) - C2(gL)*C2(gR) - fL*gL*C2(gR) - C2(gL)*fR*gR
                sumA = gL*C2(gR) - gR*(S1 - fL*fR) + (S2 - fL*fR*fR) - gL*ERp
                sumB = gR*C2(gL) - gL*(S1 - fL*fR) + (T2 - fR*fL*fL) - gR*ELp
                ans += Wge2 + fL*sumA + fR*sumB
            # add c to left
            rr = r - 1  # right count after removal
            leftCnt[c] = l + 1
            S1 += rr
            S2 += rr*rr
            T2 += rr*(2*l + 1)
            EL += l
        
        return ans % MOD
    ```

from collections import Counter
from typing import List

class Solution:
    def subsequencesWithMiddleMode(self, nums: List[int]) -> int:
        MOD = 10**9 + 7
        n = len(nums)
        
        def C2(x):
            return x * (x - 1) // 2
        
        rightCnt = Counter(nums)
        leftCnt = Counter()

        S1 = S2 = T2 = 0
        EL = 0  # sum over values C(l_v, 2)
        ER = sum(C2(r) for r in rightCnt.values())
        
        ans = 0
        for i, c in enumerate(nums):
            l = leftCnt[c]
            r = rightCnt[c]
            # remove c from right side
            rightCnt[c] = r - 1
            S1 -= l
            S2 -= l * (2 * r - 1)
            T2 -= l * l
            ER -= r - 1

            if L >= 2 and R >= 2:
                fL, fR = l, r - 1
                gL, gR = L - fL, R - fR
                ELp = EL - C2(fL)
                ERp = ER - C2(fR)
                # k >= 2: always good
                Wge2 = (C2(L) * C2(R) - C2(gL) * C2(gR)
                        - fL * gL * C2(gR) - C2(gL) * fR * gR)
                # k = 1, good

                sumB = gR * C2(gL) - gL * (S1 - fL * fR) + (T2 - fR * fL * fL) - gR * ELp
                ans += Wge2 + fL * sumA + fR * sumB

            S1 += rr
            S2 += rr * rr
            T2 += rr * (2 * l + 1)
            EL += l
        
        return ans % MOD

Looking at this problem: fix the middle element `c = nums[i]`, choose 2 from left, 2 from right. If `c` appears `k` more times among the 4 chosen (k = a+b from left/right):
- `k ≥ 2` → always good (c appears ≥3 times, others ≤2).
- `k = 0` → always bad.
- `k = 1` → good iff the 3 non-c chosen elements are pairwise distinct.

For `k=1`, case A (a=1,b=0) needs: left non-c value `v` distinct from both right non-c values, which are distinct from each other → good right pairs = C(g_R,2) − r_v(g_R−r_v) − E_R. Case B symmetric. Maintain incrementally: S1=Σl·r, S2=Σl·r², T2=Σl²·r, E_L=ΣC(l,2), E_R=ΣC(r,2) as elements move from right to left, giving O(n) total. I verified this against all three examples by hand trace (e.g., example 2 gives contributions 2+2=4 via middle indices 2 and 3).

Key invariants per index: after removing `nums[i]` from right, `fL=l`, `fR=r−1`; for the k=1 sums, exclude value c via `S1−fL·fR`, `S2−fL·fR²`, `T2−fR·fL²`, `E_R−C(fR,2)`, `E_L−C(fL,2)`. Exact integer arithmetic avoids negative-mod issues; take mod at the end.
