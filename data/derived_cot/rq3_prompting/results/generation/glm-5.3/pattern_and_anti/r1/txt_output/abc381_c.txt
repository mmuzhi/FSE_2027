=== ANSWER ===
Looking at this problem:

**Key insight:** An 11/22 string is exactly `k` ones, then `/`, then `k` twos. So every 11/22 substring is centered on some `/` character. For each `/` at position `i`, the longest 11/22 string centered there has length `2 * min(consecutive 1s immediately left, consecutive 2s immediately right) + 1`.

**Plan (O(N)):**
- `L[i]` = number of consecutive `1`s ending just before position `i` (leftward run): `L[i] = L[i-1]+1` if `S[i-1]=='1'` else `0`.
- `R[i]` = number of consecutive `2`s starting just after position `i`: `R[i] = R[i+1]+1` if `S[i+1]=='2'` else `0`.
- Answer = max over all `/` positions of `2*min(L[i], R[i]) + 1`. Since at least one `/` exists, answer ≥ 1.

**Verification on samples:**
- Sample 1 `211/2212`: slash at index 3, L=2 (indices 1,2 are '1'), R=2 (indices 4,5 are '2') → 5 ✓
- Sample 2 `22/11`: slash at index 2, L=0, R=0 → 1 ✓
- Sample 3: slash at index 14 has L=3 (`111` at 11-13), R=4 (`2222` at 15-18) → min=3, length 7 ✓

Edge cases: slash at index 0 or N-1 handled naturally (L or R = 0); single character "/" gives 1.
