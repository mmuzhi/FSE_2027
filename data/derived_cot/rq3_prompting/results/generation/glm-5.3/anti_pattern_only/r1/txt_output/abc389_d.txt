Looking at this problem:

A unit square centered at integer (i, j) is completely inside the circle iff its farthest corner from the origin is within distance R, which gives the condition (2|i|+1)² + (2|j|+1)² ≤ 4R².

For each a = |i| in [0, R−1] (writing t = 2a+1), the allowed |j| values are 0..f(a) where f(a) = (isqrt(4R² − t²) − 1) // 2 (largest b with (2b+1)² ≤ 4R² − t²; boundary equality is impossible mod 4, so no ambiguity).

Weighting each a by 1 (a=0) or 2 (a≥1) and each j by symmetry, the total simplifies (using the fact that f(0) = R−1) to:

**answer = 4 · Σ_{a=0}^{R−1} f(a) + 1**

This matches all samples:
- R=2: f = [1,0], sum=1 → 5 ✓
- R=4: f = [3,3,2,1], sum=9 → 37 ✓
- R=26: sum=506 → 2025 ✓ (verified by hand-computing all 26 rows)

This is O(R) with R ≤ 10⁶ iterations of `math.isqrt`, which runs comfortably fast.

    #   f(a) = (isqrt(4R^2 - t^2) - 1) // 2.
