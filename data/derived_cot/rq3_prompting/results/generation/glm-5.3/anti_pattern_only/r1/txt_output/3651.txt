class Solution:
    def constructTransformedArray(self, nums: List[int]) -> List[int]:

=== ANSWER ===
```python
class Solution:
    def constructTransformedArray(self, nums: List[int]) -> List[int]:
        n = len(nums)
        # For positive nums[i]: (i + nums[i]) % n moves right
        # For negative nums[i]: (i + nums[i]) % n moves left (Python's % yields non-negative)
        # For zero: lands on i itself, giving nums[i] = 0
        return [nums[(i + nums[i]) % n] for i in range(n)]
```
