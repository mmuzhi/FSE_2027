You will be given a competitive programming problem.
You are given a string S of length N. You are also given Q queries, which you should process in order.
The i-th query is as follows:

- Given an integer X_i and a character C_i, replace the X_i-th character of S with C_i. Then, print the number of times the string ABC appears as a substring in S.

Here, a substring of S is a string obtained by deleting zero or more characters from the beginning and zero or more characters from the end of S.
For example, ab is a substring of abc, but ac is not a substring of abc.

Input

The input is given from Standard Input in the following format:
N Q
S
X_1 C_1
X_2 C_2
\vdots
X_Q C_Q

Output

Print Q lines.
The i-th line (1 \le i \le Q) should contain the answer to the i-th query.

Constraints


- 3 \le N \le 2 \times 10^5
- 1 \le Q \le 2 \times 10^5
- S is a string of length N consisting of uppercase English letters.
- 1 \le X_i \le N
- C_i is an uppercase English letter.

Key insight: When we change position X (1-indexed), only occurrences of "ABC" that include position X can be affected. Those are occurrences starting at positions X-2, X-1, X (1-indexed). So we can:

1. Maintain a count of occurrences of "ABC".
2. For each query:

   - Print the count.

To check if "ABC" occurs at position i (0-indexed start), we need S[i]=='A', S[i+1]=='B', S[i+2]=='C', with 0 <= i <= N-3.

=== ANSWER ===
Looking at this problem:

- Maintain a running count of "ABC" occurrences.
- When position `pos` (0-indexed) changes, only occurrences starting at `pos-2`, `pos-1`, `pos` can be affected. Remove those before the change, apply the change, then add the new ones.
- If the new character equals the old one, nothing changes.

I verified this logic against all three samples (tracing through sample 1 and sample 3 manually — e.g., in sample 1, after query 2, removing the occurrence at start 0 and finding no new one gives count 1; in sample 3, query 7 changing position 7 creates "ABC" at start 6 giving count 2, etc.). All match.

Complexity: O(N + Q) with tiny constants — well within limits.
