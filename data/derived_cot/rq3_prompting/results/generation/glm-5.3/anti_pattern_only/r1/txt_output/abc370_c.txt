You will be given a competitive programming problem.
You are given two strings S and T consisting of lowercase English letters. Here, S and T have equal lengths.
Let X be an empty array, and repeat the following operation until S equals T:

- Change one character in S, and append S to the end of X.

Find the array of strings X with the minimum number of elements obtained in this way. If there are multiple such arrays with the minimum number of elements, find the lexicographically smallest one among them.
 What is lexicographical order on arrays of strings?
A string S = S_1 S_2 \ldots S_N of length N is lexicographically smaller than a string T = T_1 T_2 \ldots T_N of length N if there exists an integer 1 \leq i \leq N such that both of the following are satisfied:

-  S_1 S_2 \ldots S_{i-1} = T_1 T_2 \ldots T_{i-1}
-  S_i comes earlier than T_i in alphabetical order.

An array of strings X = (X_1,X_2,\ldots,X_M) with M elements is lexicographically smaller than an array of strings Y = (Y_1,Y_2,\ldots,Y_M) with M elements if there exists an integer 1 \leq j \leq M such that both of the following are satisfied:

-  (X_1,X_2,\ldots,X_{j-1}) = (Y_1,Y_2,\ldots,Y_{j-1})
-  X_j is lexicographically smaller than Y_j.

def main():
    import sys
    data = sys.stdin.read().split()
    S = list(data[0])
    T = list(data[1])
    n = len(S)
    res = []
    cur = S[:]
    while True:
        diff = [i for i in range(n) if cur[i] != T[i]]
        if not diff:
            break
        # find smallest i with T[i] < cur[i]
        best = None
        for i in diff:
            if T[i] < cur[i]:
                best = i
                break
        if best is None:
            best = diff[-1]  # largest index
        cur[best] = T[best]
        res.append(''.join(cur))
    print(len(res))
    for x in res:
        print(x)

=== ANSWER ===
Looking at this problem:

- The minimum number of operations equals the Hamming distance D between S and T (each operation must fix one differing position directly to T's character; anything else wastes moves).
- Greedy per step: the next string is current S with exactly one differing position i set to T[i]. Comparing candidates:
  - If any differing position has T[i] < S[i], the smallest such i gives the lexicographically smallest next string (it beats candidates at earlier positions since those make the string larger there, and beats later ones by fixing an earlier position to a smaller char).
  - Otherwise all differing positions have S[i] < T[i]; fixing any makes the string larger at that position, so picking the largest index postpones the "damage" as late as possible, giving the smallest string.
- Since the array comparison prioritizes earlier elements and any order of fixing remaining positions is available, this greedy yields the lexicographically smallest minimal array.

Verified against all three samples (e.g., sample 1: fix position 1 (d→c), then 3 (e→c), then 0 (a→b)).

import sys

def main():
    data = sys.stdin.read().split()
    cur = list(data[0])
