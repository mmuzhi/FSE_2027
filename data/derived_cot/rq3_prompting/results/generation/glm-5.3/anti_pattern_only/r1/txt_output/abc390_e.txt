There are N foods, each containing exactly one of vitamins 1, 2, and 3.
Specifically, eating the i-th food gives you A_i units of vitamin V_i, and C_i calories.

Find the maximum possible value of this: the minimum intake among vitamins 1, 2, and 3.

Input

The input is given from Standard Input in the following format:
N X
V_1 A_1 C_1
V_2 A_2 C_2
\vdots
V_N A_N C_N

- 1 \leq N \leq 5000
- 1 \leq X \leq 5000
- 1 \leq V_i \leq 3
- 1 \leq A_i \leq 2 \times 10^5
- 1 \leq C_i \leq X
- All input values are integers.

def solve():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    x = int(data[1])
    items = ([], [], [], [])
    ptr = 2
    for _ in range(n):

        a = int(data[ptr + 1])
        c = int(data[ptr + 2])
        ptr += 3
        items[v].append((a, c))

    try:
        import numpy as np
    except ImportError:
        np = None

    if np is not None:
        dps = []
        for v in (1, 2, 3):
            dp = np.zeros(x + 1, dtype=np.int64)

                    np.maximum(dp[c:], dp[:x + 1 - c] + a, out=dp[c:])
            dps.append(dp)
        d1, d2, d3 = dps
        hi = min(int(d1[x]), int(d2[x]), int(d3[x]))

            dps.append(dp)

        hi = min(d1[x], d2[x], d3[x])

            lo = mid
        else:
            ans_hi = mid - 1
    print(lo)

Looking at this problem:

1. **Per-vitamin knapsack**: For each vitamin v ∈ {1,2,3}, compute `dp[v][c]` = maximum amount of vitamin v obtainable with ≤ c calories (0/1 knapsack over calories, X ≤ 5000). The dp is non-decreasing in c.

2. **Binary search on the answer t**: t is feasible iff `mincost_1(t) + mincost_2(t) + mincost_3(t) ≤ X`, where `mincost_v(t)` is the smallest calorie budget achieving ≥ t of vitamin v (found via binary search / `searchsorted` on the non-decreasing dp array). Feasibility is monotone in t, and t ≤ min over v of `dp[v][X]`.

The knapsack is vectorized with numpy (`dp[c:] = max(dp[c:], dp[:X+1-c] + a)` is exactly the standard descending 0/1 knapsack update, since `dp[c-c']` values used are all pre-update values). Total work: N·X element-ops, ~25M, fast with numpy. A pure-Python fallback (map-based knapsack) is included in case numpy is unavailable.

Verified against both samples (sample 1 → 3, sample 2 → 0 since vitamin 3 has no foods).
