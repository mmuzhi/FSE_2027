You are holding a ring with both hands.

Initially, your left hand is holding part 1, and your right hand is holding part 2.
In one operation, you can do the following:

- Move one of your hands to an adjacent part of the part it is currently holding. However, you can do this only if the other hand is not on the destination part.

The following figure shows the initial state and examples of operations that can and cannot be made from there. The number written on each part of the ring represents the part number, and the circles labeled L and R represent your left and right hands, respectively.

You need to follow Q instructions given to you in order.
The i-th (1 \leq i \leq Q) instruction is represented by a character H_i and an integer T_i, meaning the following:

- Perform some number of operations (possibly zero) so that your left hand (if H_i is L) or your right hand (if H_i is R) is holding part T_i.
  Here, you must not move the other hand not specified by H_i.

It is guaranteed that only achievable instructions are given.

Details
Under the settings of this problem, it can be proved that the positions of both hands are uniquely determined just before following the i-th instruction for each i.
At that time, if we denote the positions of the left and right hands as parts l_i and r_i, respectively, it is guaranteed that T_i \neq r_i when H_i is L, and T_i \neq l_i when H_i is R.


Find the minimum total number of operations required to follow all the instructions.

Input

The Input is given from Standard Input in the following format:
N Q
H_1 T_1
H_2 T_2
\vdots

Output

Print the minimum total number of operations required to follow all the instructions.

Constraints


- 3 \leq N \leq 100
- 1 \leq Q \leq 100
- H_i is L or R.
- 1 \leq T_i \leq N
- N, Q, and T_i are integers.
- Only achievable instructions are given (see the problem statement for details).

R 6

Sample Output 1

8

```python
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0]); q = int(data[1])
    l = 1
    r = 2
    total = 0
    idx = 2
    for _ in range(q):
        h = data[idx]; t = int(data[idx + 1]); idx += 2
        if h == 'L':
            other = r
        else:
            other = l
        if h == 'L':
            cur = l
        else:
            cur = r
        cp = (cur - other - 1) % n
        tp = (t - other - 1) % n
        total += abs(cp - tp)
        if h == 'L':
            l = t
        else:
            r = t
    print(total)

main()
```

Looking at this problem:

- The two hands can never cross each other (a hand can never land on the part occupied by the other hand).
- During instruction i, only hand H_i may move; the other hand is a **static obstacle**. Removing the obstacle's part from the ring leaves a simple path containing both the moving hand's current part and the target T_i (guaranteed T_i ≠ obstacle).
- Every operation moves the hand exactly one step along this path, so the minimum cost for the instruction is exactly the distance along that path, and the end state (moving hand at T_i, other hand unchanged) is forced regardless of path taken.

Thus the total minimum is just the sum of these forced path distances.

To compute the distance: with the other hand at part `o`, index every other part `x` as `pos(x) = (x - o - 1) mod N` (position along the path `o+1, o+2, ..., o+N-1`). Cost = `|pos(cur) - pos(target)|`.

Verification against samples:
- Sample 1: costs 2 (2→3→4), 2 (1→6→5), 4 (4→3→2→1→6) = 8 ✓
- Sample 3: costs 21+3+3+19+0+20+17+9 = 92 ✓ (note instruction 6: right hand 29→30→1→…→19, 20 steps, since 20 is blocked)

The simulation is deterministic, and greedy per-instruction minimization is globally optimal since end states don't depend on the path chosen.

```python
import sys

def main():
    data = sys.stdin.read().split()
    n = int(data[0])
    q = int(data[1])
    l, r = 1, 2
    total = 0
    idx = 2
    for _ in range(q):
        h = data[idx]
        t = int(data[idx + 1])
        idx += 2
        if h == 'L':
            cur, other = l, r
        else:
            cur, other = r, l
        total += abs((cur - other - 1) % n - (t - other - 1) % n)
        if h == 'L':
            l = t
        else:
            r = t
    print(total)

main()
```
