You will be given a competitive programming problem.
You are given a simple connected undirected graph with N vertices numbered 1 through N and M edges numbered 1 through M. Edge i connects vertices u_i and v_i, and has a label w_i.
Among all simple paths (paths that do not pass through the same vertex more than once) from vertex 1 to vertex N, find the minimum XOR of the labels of the edges on the path.

Notes on XOR

For non-negative integers A and B, their XOR A \oplus B is defined as follows:


- In the binary representation of A \oplus B, the digit in the place corresponding to 2^k \,(k \ge 0) is 1 if and only if exactly one of the digits in the same place of A and B is 1; otherwise, it is 0.


For example, 3 \oplus 5 = 6 (in binary: 011 \oplus 101 = 110).

In general, the XOR of k integers p_1, \dots, p_k is defined as (\cdots ((p_1 \oplus p_2) \oplus p_3) \oplus \cdots \oplus p_k). It can be proved that it does not depend on the order of p_1, \dots, p_k.

Looking at this problem:

- N ≤ 10, so the total number of simple paths from vertex 1 is small (at most ~10^6 path prefixes even for K_10).
- Simple brute-force DFS from vertex 1, tracking visited vertices and current XOR, recording the XOR whenever we reach vertex N (a simple path can't pass through N and continue, since that would revisit it).
- Python big integers handle values up to 2^60 natively.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    N = int(data[idx]); idx += 1
    M = int(data[idx]); idx += 1
    adj = [[] for _ in range(N + 1)]
    for _ in range(M):
        u = int(data[idx]); idx += 1
        v = int(data[idx]); idx += 1
        w = int(data[idx]); idx += 1
        adj[u].append((v, w))
        adj[v].append((u, w))

    best = None
    visited = [False] * (N + 1)
    visited[1] = True

    # Iterative DFS to enumerate all simple paths from 1 to N
    stack = [(1, 0, iter(adj[1]))]
    while stack:
        node, cur, it = stack[-1]
        if node == N:
            if best is None or cur < best:
                best = cur
            stack.pop()
            visited[node] = False
            continue
        advanced = False
        for nxt, w in it:
            if not visited[nxt]:
                visited[nxt] = True
                stack.append((nxt, cur ^ w, iter(adj[nxt])))
                advanced = True
                break
        if not advanced:
            stack.pop()
            if node != 1:
                visited[node] = False

    print(best)

main()
```
