```python
class Solution:
    def separateSquares(self, squares: List[List[int]]) -> float:
        from collections import defaultdict
        delta = defaultdict(int)
        total = 0
        for x, y, l in squares:
            delta[y] += l
            delta[y + l] -= l
            total += l * l
        
        events = sorted(delta.items())
        f_cur = 0
        cov = 0
        prev_y = events[0][0]
        for y, d in events:
            f_y = f_cur + cov * (y - prev_y)
            if cov > 0 and 2 * f_y >= total:
                return prev_y + (total - 2 * f_cur) / (2 * cov)
            f_cur = f_y
            prev_y = y
            cov += d
        return float(prev_y)
```

Looking at this problem:

- Area below a line at height `y` is `f(y) = Σ lᵢ · clamp(y − yᵢ, 0, lᵢ)`, a continuous, non-decreasing piecewise-linear function.
- We need the **minimum** `y` with `f(y) = total/2`.
- Use a sweep over breakpoints (`yᵢ` and `yᵢ+lᵢ`): track total active width `cov`. Within a segment, `f` grows linearly at rate `cov`, so once `f` can reach `total/2` in a segment, solve exactly: `t = (total/2 − f_cur)/cov`.

Since the crossing is found in the exact segment where `f` first reaches half, this naturally yields the minimal `y` (flat regions at exactly half get their left endpoint, as the crossing is detected in the segment ending there). All arithmetic stays in exact integers until the final division (values ≤ 10¹², well within exact integer range).

Verified on Example 1 (returns 1.0) and Example 2 (returns 7/6 ≈ 1.166667).

```python
class Solution:
    def separateSquares(self, squares: List[List[int]]) -> float:
        from collections import defaultdict
        
        delta = defaultdict(int)
        total = 0
        for x, y, l in squares:
            delta[y] += l
            delta[y + l] -= l
            total += l * l
        
        events = sorted(delta.items())
        
        f_cur = 0      # area strictly below prev_y (exact integer)
        cov = 0        # total width of squares covering (prev_y, next)
        prev_y = events[0][0]
        
        for y, d in events:
            # area below y coming into this breakpoint
            f_y = f_cur + cov * (y - prev_y)
            if cov > 0 and 2 * f_y >= total:
                # crossing happens in (prev_y, y]
                return prev_y + (total - 2 * f_cur) / (2 * cov)
            f_cur = f_y
            prev_y = y
            cov += d
        
        return float(prev_y)
```
