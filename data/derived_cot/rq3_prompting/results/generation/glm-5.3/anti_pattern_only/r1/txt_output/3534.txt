```python
class Solution:
    def countPairs(self, nums: List[int]) -> int:
        def reachable(x):
            s = str(x)
            res = {x}
            for i in range(len(s)):
                for j in range(i + 1, len(s)):
                    lst = list(s)
                    lst[i], lst[j] = lst[j], lst[i]
                    res.add(int(''.join(lst)))
            return res
        
        sets = [reachable(x) for x in nums]
        n = len(nums)
        ans = 0
        for i in range(n):
            si = sets[i]
            for j in range(i + 1, n):
                if nums[j] in si or nums[i] in sets[j]:
                    ans += 1
        return ans
```

=== ANSWER ===
Looking at this problem:

- Two numbers x, y are almost equal iff x == y, or y can be obtained from x by one digit swap, or x can be obtained from y by one digit swap (leading zeros allowed after the swap).
- For each number, precompute the set of values reachable by at most one swap (the number itself plus all single-swap results, converted back to int so leading zeros naturally shrink the value, e.g. "30" → "03" = 3).
- Then check all pairs (n ≤ 100, each number has ≤ 7 digits → ≤ 21 swaps, so this is trivially fast). Note the check must be directional/bidirectional membership (y in reach(x) OR x in reach(y)) — merely checking whether reachable sets intersect would be wrong (e.g. 123 and 312 share swap variants like 132 but are not almost equal).

Verification with examples:
- [3,12,30,17,21]: pairs (3,30) since swap "30"→"03"=3, and (12,21) → 2 ✓
- [1,1,1,1,1]: all 10 pairs equal → 10 ✓
- [123,231]: no single swap of either yields the other → 0 ✓

Also handles cases like (10, 1): swap in 10 gives "01" = 1 → counted, while swap in 1 is impossible — the bidirectional check catches it.
