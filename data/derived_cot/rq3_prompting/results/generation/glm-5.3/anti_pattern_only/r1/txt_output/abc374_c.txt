=== ANSWER ===
Looking at this problem:

- N ≤ 20, so we can enumerate all subsets of departments assigned to Group A (up to 2^20 ≈ 1M).
- For a subset with sum `a`, the other group has sum `total - a`; we minimize `max(a, total - a)` over all subsets.
- By symmetry (swapping group labels doesn't change the max), we can fix department 0 in Group A, halving the enumeration to 2^19 subsets.
- Subset sums of the remaining departments are built efficiently by doubling a list: start with `[0]`, and for each element `x`, append `s + x` for all existing sums `s`.

Verification with samples:
- Sample 1: total=32, fix K[0]=2 in A. Best subset sum of rest is 15 (3+12 or 5+10) → A=17, B=15 → answer 17. ✓
- Sample 2: total=2, s=0 → A=1, B=1 → answer 1. ✓
- Sample 3: total=171, fix 22. Best achievable s near 63.5 is 67 (45+22) → A=89, B=82 → answer 89. ✓

Performance: 2^19 = 524,288 sums, built via fast list comprehensions, then a single `min/max` pass — well within time limits.
