```python
class Solution:
    def minCosts(self, cost: List[int]) -> List[int]:
        answer = []
        current_min = float('inf')
        for c in cost:
            current_min = min(current_min, c)
            answer.append(current_min)
        return answer
```

=== ANSWER ===
Looking at this problem:

- To end at position `i`, consider the first moment we move from a position `> i` to a position `≤ i`. That requires a paid swap with the person occupying a position `≤ i`, and at that first moment, all people in positions `0..i` are exactly the original persons `0..i` (anyone with a label `> i` couldn't have moved into that region yet). So we must pay at least `min(cost[0..i])`.
- Conversely, we can achieve exactly `min(cost[0..i])`: let `j ≤ i` be the position of that minimum. Swap directly with person `j` (pay `cost[j]`), placing us at position `j`. Then the person currently at position `i` (which is person `i` if `i ≠ j`) is behind us, so swapping with them is free, putting us at position `i` at total cost `cost[j]`.

So `answer[i]` is simply the prefix minimum of `cost`. This matches both examples:
- `[5,3,4,1,3,2]` → `[5,3,3,1,1,1]`
- `[1,2,4,6,7]` → `[1,1,1,1,1]`

```python
class Solution:
    def minCosts(self, cost: List[int]) -> List[int]:
        answer = []
        current_min = float('inf')
        for c in cost:
            if c < current_min:
                current_min = c
            answer.append(current_min)
        return answer
```
