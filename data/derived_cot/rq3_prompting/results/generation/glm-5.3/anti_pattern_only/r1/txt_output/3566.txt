=== ANSWER ===
```python
from typing import List

class Solution:
    def stringSequence(self, target: str) -> List[str]:
        result = []
        prefix = ""
        for c in target:
            # Press key 1 (append 'a'), then press key 2 until last char == c.
            # Each key press produces one recorded screen state:
            # prefix + 'a', prefix + 'b', ..., prefix + c
            for k in range(ord(c) - ord('a') + 1):
                result.append(prefix + chr(ord('a') + k))
            prefix += c
        return result
```

**Explanation:**

- The only way to grow the string is key 1 (appending `'a'`), so we must press it exactly once per target character. After that, the last character is `'a'`, and key 2 increments it by 1 (mod 26). The minimum number of key-2 presses to turn `'a'` into character `c` is `ord(c) - ord('a')` (wrapping around would only take longer).
- Therefore the optimal strategy is fully determined: for each character of `target`, record the states `prefix + 'a'`, `prefix + 'b'`, …, `prefix + c`, then fix the prefix.
- With `n ≤ 400`, this produces at most `26n` strings totaling ~2M characters — well within limits.
