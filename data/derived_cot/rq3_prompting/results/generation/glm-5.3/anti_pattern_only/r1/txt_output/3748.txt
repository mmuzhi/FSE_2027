=== ANSWER ===
Looking at this problem:

- The diagonals run in the top-left to bottom-right direction, grouped by `i - j`.
- Diagonals with `i - j >= 0` (bottom-left triangle, including the main diagonal) get sorted in **non-increasing** order.
- Diagonals with `j - i > 0` (top-right triangle) get sorted in **non-decreasing** order.

Verification with Example 1: main diagonal `[1,8,6]` → `[8,6,1]`; diagonal `[9,5]` stays; `[7,2]` → `[2,7]`; result `[[8,2,3],[9,6,7],[4,5,1]]` matches.

```python
class Solution:
    def sortMatrix(self, grid: List[List[int]]) -> List[List[int]]:
        n = len(grid)
        
        # Bottom-left triangle (including main diagonal): i - j = d, d >= 0
        # Sort each such diagonal in non-increasing order.
        for d in range(n):
            cells = [(i, i - d) for i in range(d, n)]
            vals = sorted((grid[r][c] for r, c in cells), reverse=True)
            for (r, c), v in zip(cells, vals):
                grid[r][c] = v
        
        # Top-right triangle: j - i = d, d > 0
        # Sort each such diagonal in non-decreasing order.
        for d in range(1, n):
            cells = [(i, i + d) for i in range(n - d)]
            vals = sorted(grid[r][c] for r, c in cells)
            for (r, c), v in zip(cells, vals):
                grid[r][c] = v
        
        return grid
```
