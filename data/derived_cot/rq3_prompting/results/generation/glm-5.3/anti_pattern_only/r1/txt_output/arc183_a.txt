You will be given a competitive programming problem.
You are given positive integers N and K.
An integer sequence of length NK where each integer from 1 to N appears exactly K times is called a good integer sequence.
Let S be the number of good integer sequences.
Find the \operatorname{floor}((S+1)/2)-th good integer sequence in lexicographical order.
Here, \operatorname{floor}(x) represents the largest integer not exceeding x.
 What is lexicographical order for sequences?
A sequence S = (S_1,S_2,\ldots,S_{|S|}) is lexicographically smaller than a sequence T = (T_1,T_2,\ldots,T_{|T|}) if either 1. or 2. below holds.
Here, |S| and |T| represent the lengths of S and T, respectively.

-  |S| \lt |T| and (S_1,S_2,\ldots,S_{|S|}) = (T_1,T_2,\ldots,T_{|S|}). 
-  There exists an integer 1 \leq i \leq \min\lbrace |S|, |T| \rbrace such that both of the following hold:

-  (S_1,S_2,\ldots,S_{i-1}) = (T_1,T_2,\ldots,T_{i-1})
-  S_i is (numerically) smaller than T_i.

Input

The input is given from Standard Input in the following format:
N K

Output

Print the desired integer sequence, with elements separated by spaces.

Constraints


- 1 \leq N \leq 500
- 1 \leq K \leq 500
- All input values are integers.

Looking at this problem:

**Key insight 1:** S = (NK)!/(K!)^N. Its 2-adic valuation is N·s₂(K) − s₂(NK) ≥ s₂(K)·(N − s₂(N)) > 0 for N ≥ 2 (using s₂(ab) ≤ s₂(a)s₂(b)), so S is **even** for N ≥ 2, and the target is the (S/2)-th sequence. For N=1 the answer is trivially all 1s.

**Key insight 2:** The map comp(s) = (N+1−s₁, ..., N+1−s_{NK}) is an involution that reverses lexicographic order, so rank(comp(s)) = S+1−rank(s). If s is the median (rank S/2), then comp(s) has rank S/2+1, i.e., **comp(s) = next(s)** (the immediate successor). Conversely, comp(s)=next(s) forces rank(s)=S/2. So the median is the *unique* good sequence with comp(s) = next(s).

**Constructing s:** Take s = [middle-ish prefix] + [values in nonincreasing blocks]. Checking both parities:
- N = 2m: s = [m], then N repeated K times, N−1 repeated K times, …, m+1 K times, m (K−1) times, m−1 K times, …, 1 K times. The only increasable position is position 1; next(s) = [m+1] + ascending rest, which matches comp(s) block-by-block exactly.
- N = 2m+1: s = [m+1]×K, [m], then N×K, …, (m+2)×K, m×(K−1), (m−1)×K, …, 1×K. The rightmost increasable position is K+1; next(s) = [m+1]^K + [m+2] + ascending rest, which again equals comp(s) block-by-block.
