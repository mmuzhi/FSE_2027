- 2 \leq N \leq 2 \times 10^5
- 1 \leq A_i, B_i \leq 10^9
- All input values are integers.

3

Looking at this problem:

- The purchased box will hold exactly one toy, and its size x only needs to be ≥ that toy's size. So the answer is the minimum A_i over all toys i such that the remaining N-1 toys can be perfectly matched with the N-1 existing boxes.
- A perfect matching between toys and boxes exists iff, after sorting both ascending, the element-wise condition A_sorted[j] ≤ B_sorted[j] holds for all j (standard exchange argument).
- So sort A and B. For each removal position k in sorted A (removing A[k]), the remaining toys matched against B require:
  - Prefix condition: A[j] ≤ B[j] for all j < k
  - Suffix condition: A[j+1] ≤ B[j] for all j in [k, N-2]
- Precompute prefix feasibility and suffix feasibility arrays, then the answer is A[k] for the smallest valid k (A is sorted, so first valid k gives minimum x). If no k is valid, output -1.
