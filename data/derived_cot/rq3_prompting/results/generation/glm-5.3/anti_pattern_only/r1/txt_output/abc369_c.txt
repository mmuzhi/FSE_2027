=== ANSWER ===
```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))
    ans = n  # all length-1 subarrays
    if n >= 2:
        run = 1
        prev_d = a[1] - a[0]
        for i in range(2, n):
            d = a[i] - a[i - 1]
            if d == prev_d:
                run += 1
            else:
                ans += run * (run + 1) // 2
                run = 1
                prev_d = d
        ans += run * (run + 1) // 2
    print(ans)

main()
```

**Explanation:** A subarray of length ≥ 2 is an arithmetic progression iff all consecutive differences within it are equal. Consider the difference array D_i = A_{i+1} − A_i. Each pair (l, r) with r > l corresponds to a non-empty contiguous range [l, r−1] of D, and it forms an AP iff that range consists of equal values — which happens exactly when the range lies inside a maximal run of equal differences (adjacent runs differ by maximality). A maximal run of length k contributes k(k+1)/2 such pairs, plus N single-element subarrays. This gives an O(N) solution.
