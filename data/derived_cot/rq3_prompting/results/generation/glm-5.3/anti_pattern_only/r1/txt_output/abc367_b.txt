=== ANSWER ===
Looking at this problem:

- Input is a real number always given with exactly 3 decimal places (e.g., "1.012", "12.340", "0.000").
- We must remove trailing zeros from the decimal part, and if the decimal part becomes empty, remove the decimal point too.

The safest approach is pure string manipulation (avoiding float parsing issues):

1. Read the input as a string.
2. If it contains a decimal point, strip trailing `'0'` characters — this only affects the fractional part since `rstrip('0')` stops at the `'.'` (a non-zero character), never touching integer digits.
3. Then strip a trailing `'.'` if one remains (case where all decimal digits were zeros, e.g., "0.000" → "0." → "0").
4. Print the result.

Verification against samples:
- "1.012" → no trailing zeros → "1.012" ✓
- "12.340" → strip one '0' → "12.34" ✓
- "99.900" → strip two '0's → "99.9" ✓
- "0.000" → strip zeros → "0." → strip dot → "0" ✓

Edge case like "10.000" (if it occurred): rstrip('0') stops at '.', giving "10." → "10", correctly preserving the integer part. This works because `rstrip('0')` can never cross the decimal point.

```python
s = input().strip()
if '.' in s:
    s = s.rstrip('0').rstrip('.')
print(s)
```
