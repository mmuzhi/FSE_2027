Consider an N \times N grid. Let (i,j) denote the cell at the i-th row from the top and the j-th column from the left. Initially, no cell is colored.

- Let j = N + 1 - i.
- If i \leq j, fill the rectangular region whose top-left cell is (i,i) and bottom-right cell is (j,j) with black if i is odd, or white if i is even. If some cells are already colored, overwrite their colors.  
- If i > j, do nothing.

After all these operations, it can be proved that there are no uncolored cells. Determine the final color of each cell.

N

- If cell (i,j) is finally colored white, the j-th character of S_i should be ..

- 1 \leq N \leq 50
- All input values are integers.

=== ANSWER ===
Looking at this problem:

- For each i from 1 to N, if i ≤ N+1-i, we fill the square region from (i,i) to (N+1-i, N+1-i) with black (i odd) or white (i even), overwriting.
- Later operations overwrite earlier ones, so simulating directly is straightforward and guaranteed correct.

The simulation approach:
1. Start with an N×N grid (any initial value, since operation i=1 covers everything).
2. For each i where i ≤ j = N+1-i, fill the rectangle [i-1 .. j-1] × [i-1 .. j-1] (0-indexed) with '#' if i is odd, '.' if i is even.
3. Print the grid.

Verification with N=5:
- i=1: fill all with '#'
- i=2: fill inner 3×3 with '.'
- i=3: fill center cell with '#'
- Result: `#####`, `#...#`, `#.#.#`, `#...#`, `#####` ✓

Verification with N=8, row 4: layer of cell (r,c) = min(r, c, N+1-r, N+1-c), which determines the last operation covering it. For row 4: layers are 1,2,3,4,4,3,2,1 → `#.#..#.#` ✓ matches sample.
