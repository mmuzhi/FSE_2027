class Solution:
    def minMaxSums(self, nums: List[int], k: int) -> int:
        MOD = 10**9 + 7
        nums.sort()
        n = len(nums)
        
        # Precompute factorials up to n
        fact = [1] * (n + 1)
        for i in range(1, n + 1):
            fact[i] = fact[i-1] * i % MOD
        inv_fact = [1] * (n + 1)
        inv_fact[n] = pow(fact[n], MOD - 2, MOD)
        for i in range(n, 0, -1):
            inv_fact[i-1] = inv_fact[i] * i % MOD
        
        r = k - 1  # max number of additional elements
        
        # f[m] = sum_{j=0}^{min(m, r)} C(m, j) mod MOD
        f = [0] * n
        f[0] = 1
        # column of binomials C(t, r) for t >= r; we need C(m-1, r) when m-1 >= r, i.e., m >= r+1 = k
        # maintain binom = C(m-1, r) inside loop
        # C(r, r) = 1

            if m <= r:

        for i in range(n):
            ans = (ans + nums[i] * (f[i] + f[n-1-i])) % MOD
        return ans

Looking at this problem:

**Approach:** Sort the array. For each element at sorted index `i`:
- As **maximum** (attributed to the largest index among max-valued elements to handle duplicates): choose up to `k-1` additional elements from the `i` elements before it → count `f(i) = Σ_{j=0}^{min(i,k-1)} C(i,j)`
- As **minimum** (attributed to smallest index): choose up to `k-1` from the `n-1-i` elements after it → count `f(n-1-i)`

Answer = `Σ nums[i] * (f(i) + f(n-1-i)) mod 1e9+7`.

The function `f(m) = Σ_{j=0}^{min(m,r)} C(m,j)` (with `r = k-1`) satisfies:
- `f(m) = 2·f(m-1)` when `m ≤ r`
- `f(m) = 2·f(m-1) - C(m-1, r)` when `m > r` (via Pascal's rule)

Binomials come from precomputed factorials, giving O(n) after sorting.

**Verification with examples:**
- `[1,2,3], k=2`: f = [1,2,3]; 1·(1+3) + 2·(2+2) + 3·(3+1) = 4+8+12 = 24 ✓
- `[5,0,6], k=1`: f all 1; 2·(0+5+6) = 22 ✓
- `[1,1,1], k=2`: f = [1,2,3]; 1·4·3 = 12 ✓
- Extra check `[1,2,3,4], k=3`: f=[1,2,4,7] gives 70, matching brute force.

Duplicate handling verified with `[2,1,2], k=2` → 20, matching brute force (each subsequence counted exactly once as max via largest index, once as min via smallest index).
