=== ANSWER ===
Looking at this problem:

For three integers to form an arithmetic sequence in some order, the middle element must be the average of the other two. With A and B fixed, x can play three roles:

1. **x is the middle element**: A + B = 2x, so x = (A+B)/2 (valid only if A+B is even).
2. **A is the middle element**: B + x = 2A, so x = 2A - B.
3. **B is the middle element**: A + x = 2B, so x = 2B - A.

So I just collect these candidate values in a set (to handle duplicates, e.g., when A = B all three candidates coincide) and count distinct values.

Verification with samples:
- A=5, B=7: candidates {3, 9, 6} → 3 ✓
- A=6, B=1: candidates {11, -4} (sum odd, no middle candidate) → 2 ✓
- A=3, B=3: candidates {3, 3, 3} → 1 ✓

Note that candidates from cases 2 and 3 coincide only when A = B, and the case-1 candidate coincides with others only when A = B as well, so the set approach handles everything correctly.

```python
A, B = map(int, input().split())
candidates = set()
candidates.add(2 * A - B)
candidates.add(2 * B - A)
if (A + B) % 2 == 0:
    candidates.add((A + B) // 2)
print(len(candidates))
```
