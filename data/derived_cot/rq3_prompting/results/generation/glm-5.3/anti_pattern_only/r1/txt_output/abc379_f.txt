You will be given a competitive programming problem.
There are N buildings, building 1, building 2, \ldots, building N, arranged in this order in a straight line from west to east. Building 1 is the westernmost, and building N is the easternmost. The height of building i\ (1\leq i\leq N) is H_i.
For a pair of integers (i,j)\ (1\leq i\lt j\leq N), building j can be seen from building i if the following condition is satisfied.

- There is no building taller than building j between buildings i and j. In other words, there is no integer k\ (i\lt k\lt j) such that H_k > H_j.

You are given Q queries. In the i-th query, given a pair of integers (l_i,r_i)\ (l_i\lt r_i), find the number of buildings to the east of building r_i (that is, buildings r_i + 1, r_i + 2, \ldots, N) that can be seen from both buildings l_i and r_i.

Input

The input is given from Standard Input in the following format:
N Q
H_1 H_2 \ldots H_N
l_1 r_1
l_2 r_2
\vdots
l_Q r_Q

Output

Print Q lines. The i-th line (1 \leq i \leq Q) should contain the answer to the i-th query.

Constraints


- 2 \leq N \leq 2 \times 10^5
- 1 \leq Q \leq 2 \times 10^5
- 1 \leq H_i \leq N
- H_i\neq H_j\ (i\neq j)
- 1 \leq l_i < r_i \leq N
- All input values are integers.

```python
import numpy as np
```

```python
def main():
    data = sys.stdin.buffer.read().split()
```

```python
import sys
import numpy as np

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); q = int(data[1])
    H = np.array(list(map(int, data[2:2 + n])), dtype=np.int64)

    qvals = list(map(int, data[2 + n:2 + n + 2 * q]))
    L1 = np.array(qvals[0::2], dtype=np.int64)
    R1 = np.array(qvals[1::2], dtype=np.int64)

    Hl = H.tolist()

    # next greater element index (0-indexed), -1 if none
    ng = [-1] * n
    stack = []
    for j in range(n - 1, -1, -1):
        h = Hl[j]
        while stack and Hl[stack[-1]] < h:
            stack.pop()
        if stack:
            ng[j] = stack[-1]
        stack.append(j)

    # dist[j]: length of next-greater chain starting at j
    dist = [1] * n
    for j in range(n - 1, -1, -1):
        g = ng[j]
        if g >= 0:
            dist[j] = dist[g] + 1
    dist_arr = np.array(dist, dtype=np.int64)
    ng_arr = np.array(ng, dtype=np.int64)

    # sparse table for range argmax (0-indexed, inclusive)
    LOG = max(1, n.bit_length())
    sp = np.zeros((LOG, n), dtype=np.int32)
    sp[0] = np.arange(n, dtype=np.int32)
    for k in range(1, LOG):
        length = 1 << k
        m = n - length + 1
        if m <= 0:
            break
        half = length >> 1
        prev = sp[k - 1]
        left = prev[:m]
        right = prev[half:half + m]
        sp[k, :m] = np.where(H[left] > H[right], left, right)

    # floor log2 table
    logt = np.zeros(n + 1, dtype=np.int64)
    w = 2
    lvl = 1
    while w <= n:
        logt[w:min(2 * w, n + 1)] = lvl
        lvl += 1
        w <<= 1

    L0 = L1        # 0-indexed start (= 1-indexed l+1 minus 1)
    R0 = R1 - 1    # 0-indexed end (= 1-indexed r minus 1)
    ln = R1 - L1   # length >= 1
    K = logt[ln]
    p2 = np.left_shift(np.int64(1), K)
    i1 = sp[K, L0]
    i2 = sp[K, R0 - p2 + 1]
    mstar = np.where(H[i1] > H[i2], i1, i2)
    g = ng_arr[mstar]
    ans = np.where(g >= 0, dist_arr[g], 0)

    out = '\n'.join(map(str, ans.tolist()))
    sys.stdout.write(out + '\n')

main()
```

```python
    LOG = max(1, n.bit_length())

    sp[0] = np.arange(n, dtype=np.int32)

        m = n - length + 1
        if m <= 0:
            break
        half = length >> 1
        prev = sp[k - 1]
        left = prev[:m]
        right = prev[half:half + m]

    logt = np.zeros(n + 1, dtype=np.int64)
    w = 2
    lvl = 1
```

Looking at this problem:

**Key insight:** Building j (> r) is seen from both l and r iff it's seen from l (since the condition from l is stricter — the range (l,j) contains (r,j)). Being seen from l means H_j > max(H_{l+1..j-1}), i.e., j is a prefix maximum of the suffix starting at l+1. These prefix maxima form the "next greater element" chain: l+1, ng(l+1), ng²(l+1), ...

The chain elements with position ≤ r are the prefix maxima of the window H[l+1..r], whose last element is m* = argmax(H[l+1..r]). All further chain elements (which are exactly the counted buildings) start at ng(m*). So the answer is `dist[ng(m*)]` — the length of the next-greater chain starting at ng(m*) (0 if ng(m*) doesn't exist).

To find m* = argmax over [l+1, r] for each query offline: sweep positions left to right maintaining a monotonic stack of suffix maxima of H[0..pos]; the argmax of [L, R] is the smallest stack position ≥ L (found by binary search, since stack positions are sorted increasing and heights decrease).

Verified against both samples (sample 2 gives exactly 1,3,1,2,1,0,1,1,0,0).

Complexity: O((N+Q) log N) with small constants.
