=== ANSWER ===
Looking at this problem:

**Key insight:** |x| + |y| = max over the four diagonal projections: (x+y), (x−y), (−x+y), (−x−y). So it suffices to maximize, for each of the 4 sign directions, the projection value at some prefix.

For a fixed direction (e.g., northeast, where 'N' and 'E' are "good" moves adding +1 to the projection, and 'S','W' are "bad" adding −1): at prefix length `i` with `q` bad moves, each change of a bad move to a good move gains +2. With at most `k` changes, the best achievable projection is:

- `i` if `q ≤ k` (fix all bad moves),
- `i - 2*(q - k)` otherwise.

This is both an upper bound (each change can increase the good-count by at most 1, only `k` changes available) and achievable (apply changes to bad moves within that prefix). Take the max over all 4 directions and all prefixes.

**Verification with examples:**
- "NWSE", k=1: direction (−1,+1) (good = N,W): prefix "NWS" gives q=1 ≤ k, value 3. ✓
- "NSWWEW", k=3: direction (−1,+1) (good = N,W): at i=6, q=2 (S,E), value 6. ✓

Complexity: O(4n) time, O(1) space.

```python
class Solution:
    def maxDistance(self, s: str, k: int) -> int:
        ans = 0
        # Four diagonal directions; each tuple holds the two "good" characters
        for a, b in (('N', 'E'), ('S', 'E'), ('N', 'W'), ('S', 'W')):
            bad = 0
            best = 0
            for i, ch in enumerate(s, 1):
                if ch != a and ch != b:
                    bad += 1
                # With up to k fixes, projection value at prefix i:
                cur = i if bad <= k else i - 2 * (bad - k)
                if cur > best:
                    best = cur
            if best > ans:
                ans = best
        return ans
```
