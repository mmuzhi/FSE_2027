=== ANSWER ===
Looking at this problem, since we can delete **any** elements before selecting the subarray, any set of distinct values from `nums` can be realized as a subarray (just delete everything else — the remaining chosen elements become contiguous, and the array stays non-empty).

So the problem reduces to: pick a non-empty set of distinct values maximizing the sum.
- Take every **distinct positive value** (each contributes positively).
- Skip zeros and negatives (they never help).
- If there are no positive values at all, we must still pick at least one element, so take the maximum element (largest value ≤ 0).

**Verification with examples:**
- `[1,2,3,4,5]` → distinct positives {1,2,3,4,5} → 15 ✓
- `[1,1,0,1,1]` → distinct positives {1} → 1 ✓
- `[1,2,-1,-2,1,0,-1]` → distinct positives {1,2} → 3 ✓

Edge cases: all non-positive arrays (e.g., `[-1,-2]` → -1, `[0,0]` → 0) handled by falling back to `max(nums)`.

```python
class Solution:
    def maxSum(self, nums: List[int]) -> int:
        positives = {x for x in nums if x > 0}
        if positives:
            return sum(positives)
        return max(nums)
```
