Looking at this problem:

- Let D(t) be the cumulative wind displacement after t steps (D(0) = origin).
- Smoke generated at time s sits at origin at time s+0.5, then moves with the wind, so at time t+0.5 it is at D(t) − D(s).
- Smoke is generated at time s exactly when (0,0) is empty after the wind at time s, which happens iff D(s) differs from D(s') for all earlier generation times s'. Working through this recursively shows generation times are exactly the **first occurrences** of each distinct value in the sequence D(0), D(1), ..., D(N).

Therefore, at time t+0.5, smoke exists at (R,C) iff there is some s ≤ t with D(s) = D(t) − (R,C) — because if the value D(t)−(R,C) appears at all in D(0..t), its first occurrence is a generation time s ≤ t.

So the algorithm is simply: iterate t = 1..N, maintain the set of seen D values, and check whether D(t) − (R,C) is in {D(0), ..., D(t−1)} (target can't equal D(t) itself since (R,C) ≠ (0,0)).

I verified this against all three samples (e.g., sample 1: D values (0,0),(-1,0),(-2,0),(-2,1),(-2,2),(-2,1),(-1,1) with targets shifted by (2,−1) gives 001010 ✓; samples 2 and 3 also match exactly).

Positions are encoded as integers `r * BIG + c` with BIG = 2^20 (> max coordinate spread of 800000) to keep hashing fast for N up to 200,000.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0])
    R = int(data[1])
    C = int(data[2])
    S = data[3].decode()

    BIG = 1 << 20  # larger than max coordinate difference (<= 800000)

    r, c = 0, 0
    seen = {0}  # D(0) = (0,0)
    out = []
    for ch in S:
        if ch == 'N':
            r -= 1
        elif ch == 'S':

            c -= 1

            c += 1
