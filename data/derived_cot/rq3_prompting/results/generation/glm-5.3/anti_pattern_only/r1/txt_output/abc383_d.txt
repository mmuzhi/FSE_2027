```python
import sys
import math
from bisect import bisect_right

def main():
    N = int(sys.stdin.readline())

    sqrtN = math.isqrt(N)
    # Sieve primes up to sqrt(N)
    sieve = bytearray([1]) * (sqrtN + 1)
    sieve[0] = 0
    if sqrtN >= 1:
        sieve[1] = 0
    for i in range(2, math.isqrt(sqrtN) + 1):
        if sieve[i]:
            sieve[i * i::i] = bytearray((sqrtN - i * i) // i + 1)
    primes = [i for i in range(2, sqrtN + 1) if sieve[i]]

    ans = 0

    # Case 1: n = p^8 <= N
    for p in primes:
        if p ** 8 <= N:
            ans += 1
        else:
            break

    # Case 2: n = p^2 * q^2 <= N with primes p < q
    for p in primes:
        if p * p * p * p > N:
            break
        qmax = math.isqrt(N // (p * p))
        if qmax <= p:
            continue
        hi = bisect_right(primes, qmax)
        lo = bisect_right(primes, p)
        ans += hi - lo

    print(ans)

main()
```

**Explanation:** A number has exactly 9 divisors in only two ways: either it is `p^8` (divisor count 8+1=9) or `p^2·q^2` for distinct primes p < q (divisor count (2+1)(2+1)=9).

- For `p^8 ≤ N`, since N ≤ 4×10^12, p ≤ N^(1/8) is tiny — just check primes directly.
- For `p^2·q^2 ≤ N`, equivalently `pq ≤ √N`, so with p < q we have p ≤ N^(1/4) ≈ 1414. Sieve all primes up to √N ≈ 2×10^6, then for each small prime p count primes q with `p < q ≤ isqrt(N / p²)` using binary search.

Verified against both samples: N=200 gives 3 (36, 100, 196), and the algorithm handles the general case in well under a second.
