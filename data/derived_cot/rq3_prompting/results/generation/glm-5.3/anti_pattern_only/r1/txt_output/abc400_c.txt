Looking at this problem:

**Key insight:** X = 2^a × b² with a, b ≥ 1. 
- If a is even (a = 2k, k ≥ 1): X = (2^k·b)², a perfect square of an even number.
- If a is odd (a = 2k+1): X = 2·(2^k·b)², twice a perfect square.

Conversely, any even square s² (s even) equals 2²·(s/2)², and any 2s² equals 2¹·s². A number can't be both a square and twice a square (would imply √2 is rational), so no double counting.

**Answer** = (count of even s with s² ≤ N) + (count of s with 2s² ≤ N)
= isqrt(N) // 2 + isqrt(N // 2)

**Verification:**
- N=20: isqrt(20)=4, 4//2=2 (squares 4,16); isqrt(10)=3 (values 2,8,18). Total 5 ✓
- N=400: isqrt(400)=20, 20//2=10; isqrt(200)=14. Total 24 ✓
- N=1234567890: isqrt=35136, //2=17568; isqrt(617283945)=24845. Total 42413 ✓
