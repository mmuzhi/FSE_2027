=== ANSWER ===
Looking at this problem:

- N ≤ 6 segments, each must be printed by moving (at speed S, straight line) to one endpoint, then traversing the full segment (at speed T).
- Total time = sum of segment lengths / T (constant) + sum of travel distances between consecutive print start points / S.
- So we minimize the travel: choose a permutation of segments and a direction (which endpoint to start from) for each. With N ≤ 6, a bitmask DP over (printed set, last segment, direction) — at most 64 × 6 × 2 states — solves it easily.

Verification with Sample 2: print segment 2 first starting at (2,0) (travel 2 from origin, ends at (0,2)), then move to (0,0) (travel 2), print segment 1. Travel = 4, printing = 12√2, total ≈ 20.9705627... ✓

Verification with Sample 1: travels √2/2 + 1/2, printing √5+2+1 → 6.443174758... ✓

The DP: `dp[mask][j][d]` = minimum travel time after printing the set `mask`, where the last printed segment is `j` with direction `d` (d=0 means started at (A,B) so current position is (C,D); d=1 means current position is (A,B)). Transitions add Euclidean distance to the next segment's chosen start endpoint divided by S.

```python
import sys
from math import hypot

def main():
    data = sys.stdin.buffer.read().split()
    idx = 0
    N = int(data[idx]); idx += 1
    S = float(data[idx]); idx += 1
    T = float(data[idx]); idx += 1
    segs = []
    total_len = 0.0
    for i in range(N):
        a = float(data[idx]); idx += 1
        b = float(data[idx]); idx += 1
        c = float(data[idx]); idx += 1
        d = float(data[idx]); idx += 1
        segs.append((a, b, c, d))
        total_len += hypot(c - a, d - b)

    INF = float('inf')
    full = (1 << N) - 1
    dp = [[[INF] * 2 for _ in range(N)] for _ in range(1 << N)]

    # base: first printed segment j, choose starting endpoint
    for j in range(N):
        a, b, c, d = segs[j]
        dp[1 << j][j][0] = hypot(a, b) / S  # start at (A,B)
        dp[1 << j][j][1] = hypot(c, d) / S  # start at (C,D)

    for mask in range(1, 1 << N):
        for i in range(N):
            if not (mask >> i) & 1:
                continue
            row = dp[mask][i]
            a, b, c, d = segs[i]
            for di in range(2):
                cur = row[di]
                if cur == INF:
                    continue
                # current laser position after printing segment i with direction di
                ex, ey = (c, d) if di == 0 else (a, b)
                for j in range(N):
                    if (mask >> j) & 1:
                        continue
                    a2, b2, c2, d2 = segs[j]
                    nmask = mask | (1 << j)
                    # start next segment at (a2,b2)
                    t0 = cur + hypot(a2 - ex, b2 - ey) / S
                    if t0 < dp[nmask][j][0]:
                        dp[nmask][j][0] = t0
                    # start next segment at (c2,d2)
                    t1 = cur + hypot(c2 - ex, d2 - ey) / S
                    if t1 < dp[nmask][j][1]:
                        dp[nmask][j][1] = t1

    best = INF
    for i in range(N):
        for di in range(2):
            if dp[full][i][di] < best:
                best = dp[full][i][di]

    print("%.15f" % (best + total_len / T))

main()
```
