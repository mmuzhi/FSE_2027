You will be given a competitive programming problem.
You are given N strings S_1,S_2,\ldots,S_N. Each string consists of lowercase English letters.
For each k=1,2,\ldots,N, solve the following problem.

Let T=S_k and consider performing the following two types of operations any number of times in any order:

- Pay a cost of 1 to delete the last character of T. This operation is possible when T is not empty.
- Pay a cost of 1 to add any lowercase English letter to the end of T.

Find the minimum total cost needed to make T either empty or match one of S_1,S_2,\ldots,S_{k-1}.

Input

The input is given from Standard Input in the following format:
N
S_1
S_2
\vdots
S_N

Output

Print N lines.
The i-th line (1\le i\le N) should contain the answer for k=i.

Constraints


- 1\le N\le 2\times 10^5
- Each S_i is a string of length at least 1 consisting of lowercase English letters.
- \displaystyle \sum_{i=1}^N |S_i|\le 2\times 10^5

snuuk

=== ANSWER ===
Looking at this problem:

- Transforming `S_k` into `S_j` (for j < k) costs `|S_k| + |S_j| - 2·LCP(S_k, S_j)` (keep the common prefix, delete the rest of `S_k`, append the rest of `S_j`). Making it empty costs `|S_k|`.
- So the answer is `min(|S_k|, |S_k| + min_{j<k}(|S_j| - 2·LCP))`.

Key fact: `min_{j<k}(|S_j| - 2·LCP(S_k,S_j)) = min_{d=0..|S_k|} (A_d - 2d)` where `A_d` = minimum length among previous strings having the prefix `S_k[0..d)`. This holds because any string with prefix `p_d` has LCP ≥ d (giving the ≤ direction), and each string `S_j` with LCP = d contributes at least `A_d - 2d` (giving ≥).

So use a trie storing at each node the minimum length of inserted strings passing through it. For each `S_k` (before inserting it), walk down the trie along `S_k`, taking `min(minlen[node] - 2·depth)`, stop when the path ends (no previous string shares that prefix). Then insert `S_k` updating the min-lengths. Total time O(Σ|S_i|).

I verified this against all three samples (e.g. sample 3 produces 2 4 3 8 3 6 3 1). Note that updating `minlen` in-place during the walk is safe since each node on the path is read exactly once before being written, and the root value is captured before update.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])

    children = [{}]
    minlen = [1 << 30]
    INF = 1 << 30

    out = []
    for k in range(n):
        s = data[k + 1]
        L = len(s)

        # A_0 = min length among previously inserted strings
        m = minlen[0]
        if L < m:
            minlen[0] = L

        node = 0
        depth = 0
        for c in s:
            nxt = children[node].get(c, -1)
            if nxt < 0:
                break
            node = nxt
            depth += 1
            cur = minlen[node]
            v = cur - 2 * depth
            if v < m:
                m = v
            if L < cur:
                minlen[node] = L

        if m < INF:
            t = L + m
            out.append(t if t < L else L)
        else:
            out.append(L)

        for j in range(depth, L):
            new = len(children)
            children.append({})
            minlen.append(L)
            children[node][s[j]] = new
            node = new

    sys.stdout.write('\n'.join(map(str, out)) + '\n')

main()
```
