Implementation:

```python
class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        i = 0
        n = len(s)
        while i < n:
            j = i
            while j < n and s[j] == s[i]:
                j += 1
            if j - i == k:
                return True
            i = j
        return False
```

from itertools import groupby

class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:

=== ANSWER ===
Looking at this problem: a substring of length exactly k made of one character, with different characters on both sides (where they exist), is precisely a **maximal run** of identical characters whose length is exactly k. If the run were longer than k, then at least one side of the substring would touch the same character; if shorter, we couldn't fit length k inside it.

So the solution reduces to: split `s` into runs of equal consecutive characters and check whether any run has length exactly `k`.

Verification with examples:
- `"aaabaaa"`, k=3 → runs are `aaa`(3), `b`(1), `aaa`(3) → a run of length 3 exists → `true` ✓
- `"abc"`, k=2 → runs `a`, `b`, `c` all length 1 → `false` ✓

Edge cases: `s="a", k=1` → run of length 1 → `true` (no neighbors, vacuously fine). `s="aa", k=1` → single run of length 2 → `false` (every 'a' has a same neighbor). Both behave correctly under this interpretation.

```python
from itertools import groupby

class Solution:
    def hasSpecialSubstring(self, s: str, k: int) -> bool:
        return any(sum(1 for _ in group) == k for _, group in groupby(s))
```
