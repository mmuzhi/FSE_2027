Looking at this problem:

**Key insight:** A graph becomes a forest exactly when each connected component retains at most (vertices_in_component - 1) edges. The minimum number of edges to delete equals the cyclomatic number: M - (N - c), where c is the number of connected components. This is because any spanning forest keeps N - c edges (the maximum possible for an acyclic subgraph), and every additional edge creates a cycle that requires at least one deletion (the cycle space has dimension M - N + c).

**Algorithm:** Process edges with Union-Find (DSU). Each edge whose endpoints are already in the same set is "redundant" — it must be deleted. The count of such edges is exactly M - (N - c), since each successful union reduces the component count by 1 (there are exactly N - c successful unions total).

**Verification with samples:**
- Sample 1: 4 vertices, 4 edges, 1 component → 4 - 3 = 1 ✓
- Sample 2: 5 vertices, 0 edges, 5 components → 0 - 0 = 0 ✓
- Sample 3: 10 vertices, 10 edges, 2 components (vertex 3 isolated) → 10 - 8 = 2 ✓
