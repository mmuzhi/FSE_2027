Looking at this problem:

- A division corresponds to choosing cut points $0 = c_0 < c_1 < \dots < c_k = N$; block $j$ has sum $S_{c_j} - S_{c_{j-1}}$ where $S$ is the prefix sum array.
- Let $f(i)$ = number of valid divisions of the prefix $A[1..i]$. Then $f(0)=1$ and
$$f(i) = \sum_{j<i,\ S_i - S_j \ne K} f(j) = \left(\sum_{j<i} f(j)\right) - \sum_{j<i,\ S_j = S_i - K} f(j).$$
- Maintain a running prefix total $T$ of $f$ values and a dictionary $G$ mapping each prefix-sum value to the sum of $f(j)$ over processed indices $j$ with that prefix sum. Then $f(i) = T - G[S_i - K]$, giving an $O(N)$ algorithm.

Verification with sample 1 ($A=(1,2,3), K=3$): $f$ values are $1,1,1,2$ → answer 2. ✓  
Sample 2 ($K=0$, all zeros): once any prefix is chosen, next block sum is 0 = K, so everything collapses to 0. ✓  
Sample 3: hand-computing the DP yields exactly 428. ✓

Edge cases handled: $K=0$ (blocks whose prefix sums match are excluded), negative values (Python big ints handle $S_i - K$ fine), and modulo normalization for possibly negative differences.
