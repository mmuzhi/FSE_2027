def main():

Looking at this problem:

- Let final upper lengths be $u_i$ with common row sum $H$: lower lengths are $H - u_i$. Cost per pair is $(U_i - u_i) + (D_i - (H-u_i)) = S_i - H$ where $S_i = U_i + D_i$. So **total cost $= \sum S_i - N\cdot H$** regardless of the split — we just need the **maximum feasible $H$**.

- Feasibility: $u_i \in [\max(0, H-D_i), \min(U_i, H)]$ with $|u_i - u_{i+1}| \le X$.

- **Necessity:** for any two indices $j, j'$: $H - D_j \le u_j \le u_{j'} + X|j-j'| \le U_{j'} + X|j-j'|$, so $H \le D_j + U_{j'} + X|j-j'|$.

- **Sufficiency:** if $H \le M := \min_{j,j'}(D_j + U_{j'} + X|j-j'|)$, take $g(i) = \min_j(D_j + X|i-j|)$ (a two-pass distance transform, which is $X$-Lipschitz) and set $u_i = \max(0, H - g(i))$. Then $u_i \ge H - D_i$, $u_i \le U_i$ (since $H \le U_i + g(i)$), and $|u_i - u_{i+1}| \le |g(i)-g(i+1)| \le X$. Feasible.

So $H^* = \min_i (U_i + g(i))$ with $g(i) = \min_j (D_j + X|i-j|)$, computed in $O(N)$, and the answer is $\sum S_i - N\cdot H^*$.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    x = int(data[1])

    U = [0] * n
    D = [0] * n
    total = 0
    ptr = 2
    for i in range(n):
        u = int(data[ptr]); d = int(data[ptr + 1])
        ptr += 2
        U[i] = u
        D[i] = d
        total += u + d

    # g[i] = min_j (D[j] + x * |i - j|)  via two-pass distance transform
    g = D[:]
    for i in range(1, n):
        t = g[i - 1] + x
        if t < g[i]:
            g[i] = t
    for i in range(n - 2, -1, -1):
        t = g[i + 1] + x
        if t < g[i]:
            g[i] = t

    h = min(g[i] + U[i] for i in range(n))
    print(total - n * h)

main()
