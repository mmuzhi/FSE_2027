```python
def main():
```

Looking at this problem: we need to count 3-term arithmetic progressions in the set S. For each possible middle element B, the number of fine triplets with middle B equals the number of unordered pairs {A, C} ⊂ S with A + C = 2B (A ≠ C).

Using the indicator vector f of S, the convolution (f*f)[k] counts ordered pairs (x,y) ∈ S² with x+y = k. For k = 2B (B ∈ S), this equals 2·(#pairs with A≠C) + 1 (the diagonal (B,B)). So the contribution of B is ((f*f)[2B] − 1)/2. Since values ≤ 10⁶, one FFT-based convolution of size up to 2²¹ suffices; float64 errors (~1e-8 against integer values ≤ 10⁶) are far below 0.5.

I verified against all three samples (e.g., sample 1: B=2 gives (3−1)/2=1, B=3 gives 1, B=5 gives 1 → total 3; sample 2 gives 5; sample 3 gives 10).

```python
import sys
import numpy as np

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    s = np.fromiter(map(int, data[1:1 + n]), dtype=np.int64, count=n)
    mx = int(s.max())
    m = mx + 1
    f = np.zeros(m, dtype=np.float64)
    f[s] = 1.0
    need = 2 * mx + 1
    size = 1
    while size < need:
        size <<= 1
    F = np.fft.rfft(f, size)
    conv = np.fft.irfft(F * F, size)
    vals = np.rint(conv[2 * s]).astype(np.int64)
    ans = int(((vals - 1) >> 1).sum())
    print(ans)

main()
```
