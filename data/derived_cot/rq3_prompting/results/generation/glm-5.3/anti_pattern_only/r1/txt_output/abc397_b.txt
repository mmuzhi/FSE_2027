=== ANSWER ===
Looking at this problem:

- The final valid string is always a prefix of the infinite alternating string "ioioio..." (odd positions 'i', even positions 'o'), with even length.
- Since insertions preserve order, S must be a subsequence of that prefix.
- So I find the minimal position `cur` where S can finish matching using greedy earliest-position matching against "ioio...", round up to even length, and the answer is that length minus `len(S)`.

Greedy matching: for character 'i', the next available odd position > cur; for 'o', the next even position > cur.

Verification:
- "ioi": positions 1,2,3 → round to 4 → answer 4−3=1 ✓
- "iioo": positions 1,3,4,6 → answer 6−4=2 ✓
- "io": positions 1,2 → answer 0 ✓

```python
S = input().strip()
cur = 0
for c in S:
    if c == 'i':
        cur = cur + 1 if cur % 2 == 0 else cur + 2
    else:
        cur = cur + 1 if cur % 2 == 1 else cur + 2
```
