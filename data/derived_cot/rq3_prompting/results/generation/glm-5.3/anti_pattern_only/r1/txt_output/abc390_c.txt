=== ANSWER ===
Looking at this problem:

- Since at least one cell is already black (`#`), the target rectangle must be non-empty and must contain all `#` cells.
- The minimal candidate rectangle is the bounding box of all `#` cells (rows `[a,b]`, cols `[c,d]` where `a,b` are min/max rows of `#` and `c,d` are min/max cols of `#`).
- Any valid rectangle must contain this bounding box. So if a `.` cell lies inside the bounding box, it lies inside every valid rectangle → impossible.
- Conversely, if no `.` lies inside the bounding box, we can choose the bounding box itself as the rectangle: paint all `?` inside it black, and all `?` outside it white (no `#` exists outside the bounding box by definition). This is valid.

So the answer is **Yes** iff the bounding box of all `#` cells contains no `.` cell.

Verification with samples:
- Sample 1: `#` at (1,2),(1,4),(2,3) → box rows 1–2, cols 2–4 contains only `#`/`?` → Yes ✓
- Sample 2: box is the whole 3×3 grid, which contains `.` at (2,2) → No ✓
- Sample 3: box is the single `#` cell → Yes ✓

Complexity is O(H·W), well within limits.
