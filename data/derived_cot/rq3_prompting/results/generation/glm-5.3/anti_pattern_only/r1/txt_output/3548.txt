```python
from math import factorial

class Solution:
    def countGoodIntegers(self, n: int, k: int) -> int:
        m = (n + 1) // 2
        seen = set()
        digits = '0123456789'
        tail_len = n - m
        for first in range(10**(m-1), 10**m):
            s = str(first)
            pal = s + s[:tail_len][::-1]
            if int(pal) % k == 0:
                seen.add(tuple(pal.count(c) for c in digits))
        
        ans = 0
        fact = [factorial(i) for i in range(n+1)]
        for counts in seen:
            denom = 1
            for c in counts:
                denom *= fact[c]
            perm = fact[n] // denom
            if counts[0]:
                denom0 = fact[counts[0]-1]
                for i in range(1, 10):
                    denom0 *= fact[counts[i]]
                perm -= fact[n-1] // denom0
            ans += perm
        return ans
```

```python
from math import factorial

class Solution:
    def countGoodIntegers(self, n: int, k: int) -> int:
        m = (n + 1) // 2
        tail = n - m
        seen = set()
        for first in range(10 ** (m - 1), 10 ** m):
            s = str(first)

            if int(pal) % k == 0:
                seen.add(tuple(pal.count(c) for c in '0123456789'))

            ans += total
        return ans
```

Looking at this problem:

1. **Enumerate all n-digit palindromes** via their first half (length m = (n+1)//2, first digit 1-9). For n=10 that's 90,000 palindromes — fast enough.
2. For each palindrome divisible by k, record its **digit-count multiset** (as a tuple of 10 counts) in a set to deduplicate.
3. For each distinct multiset, count distinct n-digit integers (no leading zero) with those digits: total distinct permutations `n!/∏(cᵢ!)` minus arrangements starting with 0, which is `(n-1)!/((c₀-1)!·∏_{i>0}(cᵢ!))`.

I verified this by hand against all three examples: n=3,k=5 gives 2+8·3+1=27; n=1,k=4 gives 2; and a full careful enumeration for n=5,k=6 by multiset type (2,2,1 / 3,2 / 4,1 / 5 partitions) yields 2220+188+59+1 = 2468.

Key details:
- Palindromes are built as `s + s[:n-m][::-1]` where s is the first half — this correctly handles both even and odd n.
- Since the palindrome's first digit is never 0, multisets like {0,0,b} (which can only form palindromes with leading zeros) never enter the set.
- All divisions are exact multinomial coefficients.
