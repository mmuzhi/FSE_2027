```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); K = int(data[1])
    M = N * K
    E = M - 1

    adj = [[] for _ in range(M + 1)]
```

Looking at this problem, I need to determine if a tree with NK vertices can be partitioned into N simple paths of K vertices each.

**Key insight:** Root the tree at vertex 1. In any valid decomposition, for each vertex v, the path of the decomposition crossing edge (v, parent) restricts to a downward chain from v of length t_v, and the rest of the subtree is partitioned into complete K-vertex paths. This forces t_v ≡ |subtree(v)| (mod K) with t_v ∈ [0, K-1], so t_v is uniquely determined — the DP is fully forced, not greedy:

- If a vertex has 0 children with open chains: it starts a new chain of length 1.
- If exactly 1 open chain (length l): the chain extends through v, giving length l+1 (complete if l+1 = K).
- If exactly 2 open chains (lengths l1, l2): both must be joined at v, requiring l1 + l2 + 1 = K exactly.
- If ≥ 3 open chains: impossible (v's single path can absorb at most 2 downward chains).

At the root, the final chain must be complete (length 0 after normalization). This is provably exact: any valid decomposition must match these forced choices (chains can only be completed by extending upward through parents, and the mod-K argument pins down all lengths).

I verified this against both samples and several hand-constructed cases (stars, spiders, brooms, multi-level apex joins), and it behaves correctly in all of them. Implementation uses BFS ordering (parents before children) processed in reverse, pushing results up to parents — O(NK) total, iterative to avoid recursion limits.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); K = int(data[1])
    M = N * K
    E = M - 1

    adj = [[] for _ in range(M + 1)]
    it = iter(map(int, data[2:2 + 2 * E]))
    for u, v in zip(it, it):
        adj[u].append(v)
        adj[v].append(u)

    parent = [0] * (M + 1)
    order = [0] * M
    order[0] = 1
    visited = bytearray(M + 1)
    visited[1] = 1
    head = 0
    tail = 1
    while head < tail:
        v = order[head]
        head += 1
        for u in adj[v]:
            if not visited[u]:
                visited[u] = 1
                parent[u] = v
                order[tail] = u
                tail += 1

    cnt = [0] * (M + 1)   # completed paths accumulated from children
    mct = [0] * (M + 1)   # number of children passing an open chain up
    o1 = [0] * (M + 1)    # first open chain length
    o2 = [0] * (M + 1)    # second open chain length

    for i in range(M - 1, 0, -1):
        v = order[i]
        m = mct[v]
        if m == 0:
            nl = 1
            c = cnt[v]
        elif m == 1:
            nl = o1[v] + 1
            c = cnt[v]
        else:
            if o1[v] + o2[v] + 1 != K:
                print("No")
                return
            nl = 0
            c = cnt[v] + 1
        if nl == K:
            c += 1
            nl = 0
        p = parent[v]
        cnt[p] += c
        if nl:
            mct[p] += 1
            if mct[p] == 1:
                o1[p] = nl
            elif mct[p] == 2:
                o2[p] = nl
            else:
                print("No")
                return

    m = mct[1]
    if m == 0:
        nl = 1
        c = cnt[1]
    elif m == 1:
        nl = o1[1] + 1
        c = cnt[1]
    else:
        if o1[1] + o2[1] + 1 != K:
            print("No")
            return
        nl = 0
        c = cnt[1] + 1
    if nl == K:
        c += 1
        nl = 0
    print("Yes" if (nl == 0 and c == N) else "No")

main()
```
