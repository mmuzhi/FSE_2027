Looking at this problem:

1. **Feasibility check**: Using a difference array, verify every index `i` is covered by at least `nums[i]` queries. If not, return -1.

2. **Minimize kept queries** (then answer = total - kept): Sweep indices left to right. Maintain a max-heap of right endpoints for available queries (those with `l <= i`, not yet chosen) and a min-heap of right endpoints of chosen queries (to expire ones ending before `i`). Whenever the count of active chosen queries is below `nums[i]`, greedily pick the available query with the largest right endpoint (exchange argument shows this is optimal: any optimal solution can be modified to include these picks without increasing size).

Verified against all three examples (outputs 1, 2, -1).

```python
import heapq
from typing import List

class Solution:
    def maxRemoval(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        q = len(queries)

        # Step 1: feasibility check — each index must be covered by >= nums[i] queries
        diff = [0] * (n + 1)
        for l, r in queries:
            diff[l] += 1
            diff[r + 1] -= 1
        cover = 0
        for i in range(n):
            cover += diff[i]
            if cover < nums[i]:
                return -1

        # Step 2: greedy — find the minimum number of queries to keep
        queries.sort(key=lambda x: x[0])

        available = []  # max-heap (negated) of right ends of unselected queries with l <= i
        active = []     # min-heap of right ends of selected, still-active queries
        used = 0
        qi = 0

        for i in range(n):
            # add all queries starting at or before i
            while qi < q and queries[qi][0] <= i:
                heapq.heappush(available, -queries[qi][1])
                qi += 1

            # expire selected queries that end before i
            while active and active[0] < i:
                heapq.heappop(active)

            # pick more queries (largest right end first) until demand is met
            need = nums[i] - len(active)
            while need > 0:
                if not available or -available[0] < i:
                    return -1  # defensive; unreachable when feasible
                heapq.heappush(active, -heapq.heappop(available))
                used += 1
                need -= 1

        return q - used
```
