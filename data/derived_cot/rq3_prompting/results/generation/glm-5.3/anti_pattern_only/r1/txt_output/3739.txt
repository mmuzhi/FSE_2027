=== ANSWER ===
Looking at this problem:

**Key insight:** By linearity of expectation/counting, swap the order of summation. For each unordered pair of cells (a, b), the number of arrangements (sets of k occupied cells) containing both cells is C(mn−2, k−2), since the remaining k−2 pieces go into the remaining mn−2 cells. So:

Answer = C(mn−2, k−2) × S, where S = Σ over all unordered cell pairs of Manhattan distance.

**Computing S:** Manhattan distance splits into row and column contributions.
- Row part: for each pair of distinct rows {i, j}, there are n² cell pairs (one cell from each row), contributing |i−j|. So row part = n² × Σ_{d=1}^{m−1} d·(m−d) = n² × m(m−1)(m+1)/6.
- Column part symmetrically: m² × n(n−1)(n+1)/6.

**Verification:**
- Example 1 (m=n=k=2): S = 4·1 + 4·1 = 8, C(2,0)=1 → 8 ✓
- Example 2 (m=1,n=4,k=3): S = 0 + 1·10 = 10, C(2,1)=2 → 20 ✓

Since m(m−1)(m+1) is a product of three consecutive integers, division by 6 is exact (do it before taking mod). Binomial coefficient computed via factorials mod 10⁹+7 (N = mn ≤ 10⁵).

```python
class Solution:
    def distanceSum(self, m: int, n: int, k: int) -> int:
        MOD = 10**9 + 7
        N = m * n
        
        # Precompute factorials for binomial coefficient C(N-2, k-2)
        fact = [1] * (N + 1)
        for i in range(1, N + 1):
            fact[i] = fact[i - 1] * i % MOD
        inv_fact = [1] * (N + 1)
        inv_fact[N] = pow(fact[N], MOD - 2, MOD)
        for i in range(N, 0, -1):
            inv_fact[i - 1] = inv_fact[i] * i % MOD
        
        # Number of arrangements containing any fixed pair of cells
        comb = fact[N - 2] * inv_fact[k - 2] % MOD * inv_fact[N - k] % MOD
        
        # Sum of Manhattan distances over all unordered pairs of cells
        # Row contribution: n^2 * sum_{d=1}^{m-1} d*(m-d) = n^2 * m(m-1)(m+1)/6
        # Column contribution: m^2 * n(n-1)(n+1)/6
        row_sum = (m * (m - 1) * (m + 1) // 6) % MOD
        col_sum = (n * (n - 1) * (n + 1) // 6) % MOD
        S = ((n * n % MOD) * row_sum + (m * m % MOD) * col_sum) % MOD
        
        return comb * S % MOD
```
