- Let S_{l\ldots r} denote the substring of S from the l-th character through the r-th character.
- We define a substring S_{l\ldots r} of S to be a 1-block if it satisfies all of the following conditions:
- S_l = S_{l+1} = \cdots = S_r =  1
- l = 1 or S_{l-1} =  0
- r = N or S_{r+1} =  0

- T_i =  0 for r_{K-1} + (r_K - l_K) + 2 \leq i \leq r_K
- T_i = S_i for r_K + 1 \leq i \leq N

Looking at this problem:

1. Find the K-th 1-block and the (K-1)-th 1-block.
2. The transformation (per the problem's definition) keeps everything up to the end of block K-1, then places the K-th block's 1s right after it, then the zeros that filled the gap (and where the block used to be), then everything after the K-th block unchanged.

Specifically, if `prev_end` is the 0-indexed end of block K-1, and `[cur_start, cur_end]` is the 0-indexed range of block K, then:

- Result = `S[:prev_end+1]` + `'1' * (cur_end - cur_start + 1)` + `'0' * (cur_start - prev_end - 1)` + `S[cur_end+1:]`

The zero count is exactly the gap between the two blocks (`cur_start - prev_end - 1`), since the region between `prev_end` and `cur_end` in the original consists of that gap of zeros plus the block itself, and the block just moves to the front of that region.
