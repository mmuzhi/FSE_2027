Looking at this problem:

- Compute X = 1 + N + N² + ... + N^M.
- If X ≤ 10⁹ print X, else print "inf".
- Key edge cases: N = 1 gives X = M + 1 (always ≤ 10⁹ since M ≤ 100); X exactly equal to 10⁹ must print the number (sample 3); since N ≥ 1, all terms are positive, so once a partial sum exceeds 10⁹ we can stop early and print "inf" (Python big ints make this safe anyway, but early exit avoids pointless huge computations like (10⁹)^100).

Tracing samples:
- 7 3 → 1+7+49+343 = 400 ✓
- 1000000 2 → 1000001000001 > 10⁹ → inf ✓
- 999999999 1 → 1000000000 (equal to limit, not greater) → prints the number ✓
- 998244353 99 → exceeds on 3rd term → inf ✓

```python
import sys

def main():
    data = sys.stdin.read().split()
    n, m = int(data[0]), int(data[1])
    limit = 10 ** 9
    x = 0
    p = 1
    for _ in range(m + 1):
        x += p
        if x > limit:
```
