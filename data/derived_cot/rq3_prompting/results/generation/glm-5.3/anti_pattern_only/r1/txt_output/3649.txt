```python
class Solution:
    def findMinimumTime(self, strength: List[int], K: int) -> int:
        n = len(strength)
        full = (1 << n) - 1
        INF = float('inf')
        dp = [INF] * (1 << n)
        dp[0] = 0
        for mask in range(1 << n):
            if dp[mask] == INF:
                continue
            x = 1 + K * bin(mask).count('1')
            for i in range(n):
                if not (mask >> i) & 1:
                    cost = (strength[i] + x - 1) // x
                    nm = mask | (1 << i)
                    if dp[mask] + cost < dp[nm]:
                        dp[nm] = dp[mask] + cost
        return dp[full]
```

=== ANSWER ===
Looking at this problem:

- The sword's energy at integer minute `t` (since last reset) is `X * t`, since it gains `X` per minute and resets to 0 on a break.
- Waiting is never beneficial: accumulated energy is lost on a break and X only changes on breaks. So the only real decision is the **order** in which locks are broken.
- If a lock with strength `s` is broken as the `j`-th lock (0-indexed), it costs `ceil(s / (1 + K*j))` minutes, since `X = 1 + K*j` at that point.

So the answer is the minimum over all permutations of `sum ceil(strength[p[j]] / (1 + K*j))`. With `n ≤ 8`, a bitmask DP over subsets (`dp[mask]` = min time to break the locks in `mask`, with `X = 1 + K * popcount(mask)`) solves it in `O(2^n · n)`.

Verification with examples:
- `[3,4,1], K=1`: order 1,4,3 → `ceil(1/1)+ceil(4/2)+ceil(3/3) = 1+2+1 = 4` ✓
- `[2,5,4], K=2`: order 2,5,4 → `ceil(2/1)+ceil(5/3)+ceil(4/5) = 2+2+1 = 5` ✓

```python
class Solution:
    def findMinimumTime(self, strength: List[int], K: int) -> int:
        n = len(strength)
        full = (1 << n) - 1
        INF = float('inf')
        dp = [INF] * (full + 1)
        dp[0] = 0
        for mask in range(full + 1):
            cur = dp[mask]
            if cur == INF:
                continue
            x = 1 + K * bin(mask).count('1')
            for i in range(n):
                bit = 1 << i
                if mask & bit:
                    continue
                cost = (strength[i] + x - 1) // x  # ceil(strength[i] / x)
                nm = mask | bit
                if cur + cost < dp[nm]:
                    dp[nm] = cur + cost
        return dp[full]
```
