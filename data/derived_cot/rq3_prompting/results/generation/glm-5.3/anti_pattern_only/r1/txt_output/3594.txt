=== ANSWER ===
Looking at this problem:

**Key insight:** If `S` is the sum element and `X` is the outlier, then the total sum `T` = (sum of specials) + S + X = S + S + X. Therefore **X = T - 2S**.

So for each candidate sum element `S` in the array, compute `X = T - 2S` and check that `X` exists in the array at a *different index*:
- If `X != S`: just need `X` to appear at least once.
- If `X == S`: need at least 2 occurrences of that value (distinct indices for sum element and outlier).

**Why this is sufficient:** If `S` is at index `i` and `X` at index `j ≠ i`, the remaining `n-2` elements sum to `T - S - X = S` exactly, so they form valid special numbers.

**Verification with examples:**
- `[2,3,5,10]`, T=20: S=5 → X=10 ✓ (answer 10)
- `[-2,-1,-3,-6,4]`, T=-8: S=-6 → X=4 ✓ (answer 4)
- `[1,1,1,1,1,5,5]`, T=15: S=5 → X=5, count[5]=2 ✓ (answer 5)

Take the maximum valid `X` across all candidates. Time complexity O(n).

```python
from typing import List
from collections import Counter

class Solution:
    def getLargestOutlier(self, nums: List[int]) -> int:
        total = sum(nums)
        count = Counter(nums)
        best = float('-inf')
        for s in count:
            x = total - 2 * s
            if x in count and (x != s or count[s] >= 2):
                if x > best:
                    best = x
        return best
```
