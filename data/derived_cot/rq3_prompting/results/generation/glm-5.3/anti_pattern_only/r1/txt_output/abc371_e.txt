```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = data[1:1+n]
    last = [0] * (n + 1)  # last occurrence index (1-based) of value v
    ans = 0
    for k in range(1, n + 1):
        v = int(a[k-1])
        p = last[v]
        ans += (k - p) * (n - k + 1)
        last[v] = k
    print(ans)

main()
```

=== ANSWER ===
**Approach:** For each position `k`, count the subarrays where `A_k` is the *first* occurrence of its value. If `prev` is the previous occurrence of `A_k` (or 0), then `A_k` contributes to `f(i,j)` exactly when `prev < i ≤ k ≤ j`. That gives `(k - prev) * (N - k + 1)` subarrays. Summing over all `k` yields the answer in O(N).

Verification on sample 1 (`[1,2,2]`): `1·3 + 2·2 + 1·1 = 8` ✓. Sample 2 also sums to `111` ✓.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    last = [0] * (n + 1)  # last occurrence (1-based) of each value
    ans = 0
    for k in range(1, n + 1):
        v = int(data[k])
        p = last[v]
        ans += (k - p) * (n - k + 1)
        last[v] = k
    print(ans)

main()
```
