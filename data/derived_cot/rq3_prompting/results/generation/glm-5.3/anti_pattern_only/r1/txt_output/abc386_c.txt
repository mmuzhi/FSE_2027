def first_mismatch(A, B, limit):
    # largest p <= limit such that A[:p] == B[:p]
    lo, hi = 0, limit
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if A[:mid] == B[:mid]:

        else:

Looking at this problem, it's the classic "edit distance ≤ 1" check:

- If |len(S) − len(T)| > 1 → No.
- If lengths are equal → at most one position may differ.
- If lengths differ by exactly one (S longer) → deleting the character at the first mismatch position from S must yield T; symmetrically for insertion when T is longer.

For each case: find the length `p` of the common prefix, then verify the remaining suffixes match after skipping the single differing/deleted/inserted character. To keep it fast in Python for strings up to 500,000 characters, I find the common prefix via binary search using C-speed slice comparisons (prefix equality is monotonic), then do one final slice comparison.

Verification against samples:
1. `abc`/`agc`: prefix p=1, `S[2:]`=`T[2:]`=`c` → Yes ✓
2. `abc`/`awtf`: m=n+1, p=1, `bc` ≠ `tf` → No ✓
3. `abc`/`ac`: n=m+1, p=1, `S[2:]`=`T[1:]`=`c` → Yes ✓
4. `back`/`black`: m=n+1, p=1, `ack`=`ack` → Yes ✓
5. equal strings → Yes ✓
6. `leap`/`read`: p=0, `eap` ≠ `ead` → No ✓

Edge cases handled: when the common prefix covers the whole shorter string (extra char at the end), the suffix slices are both empty and compare equal correctly. A `K == 0` guard is included for safety, though constraints guarantee `K = 1`.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    K = int(data[0])
    S = data[1]
    T = data[2]
    n, m = len(S), len(T)

    if K == 0:
        print("Yes" if S == T else "No")
        return

    if abs(n - m) > 1:
        print("No")
        return

    def common_prefix_len(limit):
        # largest p <= limit such that S[:p] == T[:p] (monotonic predicate)
        lo, hi = 0, limit
        while lo < hi:
            mid = (lo + hi + 1) // 2
            if S[:mid] == T[:mid]:
                lo = mid
            else:
                hi = mid - 1
        return lo

    if n == m:
        if S == T:
            print("Yes")
            return
        p = common_prefix_len(n)
        print("Yes" if S[p + 1:] == T[p + 1:] else "No")
    elif n == m + 1:
        # delete one char from S at first mismatch
        p = common_prefix_len(m)
        print("Yes" if S[p + 1:] == T[p:] else "No")
    else:
        # m == n + 1: insert one char into S (skip one char of T)
        p = common_prefix_len(n)
        print("Yes" if S[p:] == T[p + 1:] else "No")

main()
```
