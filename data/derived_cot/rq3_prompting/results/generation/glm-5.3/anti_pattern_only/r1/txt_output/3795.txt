```python
class Solution:
    def minZeroArray(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        # Precompute for each index, list of (query_index, val) covering it
        cov = [[] for _ in range(n)]
        for i, (l, r, v) in enumerate(queries):
            for j in range(l, r + 1):
                cov[j].append((i, v))
        
        def feasible(k):
            for j in range(n):
                target = nums[j]
                if target == 0:
                    continue
```

=== ANSWER ===
Looking at this problem:

- For each query, we independently choose (per index in range) whether to decrement by `val_i`. So decisions at different indices are completely independent.
- For index `j` and a prefix of `k` queries, we need `nums[j]` to be an **exact subset sum** of the values `val_i` from queries among the first `k` that cover `j` (can't overshoot, since values only decrease and must land exactly on 0).
- Feasibility is monotone in `k` (extra queries can select empty subsets), so I process queries incrementally, maintaining per-index a bitset of achievable sums (Python big int). Sums above the target are useless (all `val ≥ 1`), so masks are truncated to `nums[j]+1` bits. Once every index's target bit is set, the current query count is the answer.

Verified against all four examples (e.g., Example 4: index 4 reaches 6 via 2+4 after query index 3, giving k=4).

Complexity: O(q·n) big-int operations on ≤1001-bit integers — trivial for the constraints.

```python
from typing import List

class Solution:
    def minZeroArray(self, nums: List[int], queries: List[List[int]]) -> int:
        n = len(nums)
        done = [x == 0 for x in nums]
        done_count = sum(done)
        if done_count == n:
            return 0
        
        masks = [1] * n                      # bit s set => subset sum s achievable
        limits = [(1 << (x + 1)) - 1 for x in nums]  # keep only sums <= target
        
        for i, (l, r, v) in enumerate(queries):
            for j in range(l, r + 1):
                if not done[j]:
                    m = masks[j] | (masks[j] << v)
                    m &= limits[j]
                    masks[j] = m
                    if (m >> nums[j]) & 1:
                        done[j] = True
                        done_count += 1
            if done_count == n:
                return i + 1
        return -1
```
