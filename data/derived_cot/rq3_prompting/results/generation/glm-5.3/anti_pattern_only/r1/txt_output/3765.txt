class Solution:
    def minimumCost(self, nums: List[int], cost: List[int], k: int) -> int:
        n = len(nums)
        SN = [0] * (n + 1)
        SC = [0] * (n + 1)
        for i in range(n):
            SN[i + 1] = SN[i] + nums[i]
            SC[i + 1] = SC[i] + cost[i]
        total_sc = SC[n]
        P = k * total_sc
        # D[i] = max over partitions of prefix i of sum of w(l, r)
        # w(l, r) = SC[l]*(SN[r]-SN[l]) + k*SC[r] - P
        # D[i] = k*SC[i] - P + max_{l<i} (D[l] - SC[l]*SN[l]) + SC[l]*SN[i]
        A = [0] * n  # A[l] = D[l] - SC[l]*SN[l], for l in 0..n-1
        D = 0  # D[0]
        # A[0] = 0
        best_D = None
        for i in range(1, n + 1):
            sni = SN[i]
            best = -10**30
            # l from 0 to i-1
            for l in range(i):
                v = A[l] + SC[l] * sni
                if v > best:
                    best = v
            cur = best + k * SC[i] - P
            if i < n:
                A[i] = cur - SC[i] * sni
            else:
                best_D = cur

Looking at this problem, I need to handle the tricky `k*i` term where the cost multiplier depends on the subarray's index.

**Key transformation:** Using summation by parts on the total cost `Σ (SN[b_i] + k·i)·(SC[b_i] − SC[b_{i−1}])`, I can show:

Total = SN[n]·SC[n] + k·SC[n] − H, where H = Σ over subarrays [l+1..r] of `w(l,r) = SC[l]·(SN[r]−SN[l]) + k·SC[r] − k·SC[n]`

So minimizing total cost becomes maximizing H, which is a **standard partition DP with no cross-subarray coupling**:

`D[i] = k·SC[i] − k·SC[n] + max_{l<i} (D[l] − SC[l]·SN[l] + SC[l]·SN[i])`

This gives O(n²) time, which is fine for n ≤ 1000.

**Verification with Example 1** (nums=[3,1,4], cost=[4,6,6], k=1): D[3] computes to 34 via partition [3,1],[4], giving answer 8·16 + 16 − 34 = 110 ✓
