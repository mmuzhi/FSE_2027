Looking at this problem:

- Damage pattern over time: T=1→1, T=2→1, T=3→3, repeating with period 3 (each cycle of 3 attacks deals 5 damage).
- For each enemy, given the residue `p = (first attack T) mod 3` of when we start attacking it, the cumulative damage after `m = 3q + s` attacks is `5q + prefix[s]`, where prefix damages after 1, 2, 3 attacks are:
  - p=1: [1, 2, 5] (damages 1,1,3)
  - p=2: [1, 4, 5] (damages 1,3,1)
  - p=0: [3, 4, 5] (damages 3,1,1)

For health h: write h = 5·q0 + r. If r=0, exactly 3·q0 attacks suffice (minimal, since prefix[2] ≤ 4 < 5). Otherwise find the smallest s ∈ {1,2,3} with prefix[s] ≥ r (prefix of 3 full cycle = 5 ≥ r always works), giving m = 3·q0 + s. Sum all m values (tracking total attacks S, whose value determines the next phase).
