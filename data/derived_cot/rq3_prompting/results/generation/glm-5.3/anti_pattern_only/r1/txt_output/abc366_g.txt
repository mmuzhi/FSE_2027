You are given a simple undirected graph with N vertices and M edges. The i-th edge connects vertices u_i and v_i bidirectionally.

- For every vertex v with a degree of at least 1, the total XOR of the numbers written on its adjacent vertices (excluding v itself) is 0.


What is XOR?

The XOR of two non-negative integers A and B, denoted as A \oplus B, is defined as follows:


- In the binary representation of A \oplus B, the bit at position 2^k \, (k \geq 0) is 1 if and only if exactly one of the bits at position 2^k in the binary representations of A and B is 1. Otherwise, it is 0.


For example, 3 \oplus 5 = 6 (in binary: 011 \oplus 101 = 110).

In general, the bitwise XOR of k integers p_1, \dots, p_k is defined as (\cdots ((p_1 \oplus p_2) \oplus p_3) \oplus \cdots \oplus p_k).  It can be proved that this is independent of the order of p_1, \dots, p_k.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    ptr = 0
    N = int(data[ptr]); ptr += 1
    M = int(data[ptr]); ptr += 1
    
    adj = [0] * N
    for _ in range(M):
        u = int(data[ptr]) - 1; ptr += 1
        v = int(data[ptr]) - 1; ptr += 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u
    
    S = [v for v in range(N) if adj[v] != 0]
    ans = [1] * N
    
    n = len(S)
    if n == 0:
        print("Yes")
        print(" ".join(map(str, ans)))
        return
    
    pos = [-1] * N
    for i, v in enumerate(S):
        pos[v] = i
    
    # Build equations over columns indexed by S
    mat = []
    for v in S:
        mask = 0
        a = adj[v]
        for u in S:
            if (a >> u) & 1:
                mask |= 1 << pos[u]
        mat.append(mask)
    
    m = len(mat)
    pivot_row_of = [-1] * n
    used = [False] * m
    for col in range(n):
        pr = -1
        for i in range(m):
            if not used[i] and (mat[i] >> col) & 1:
                pr = i
                break
        if pr == -1:
            continue
        used[pr] = True
        pivot_row_of[col] = pr
        prow = mat[pr]
        for i in range(m):
            if i != pr and (mat[i] >> col) & 1:
                mat[i] ^= prow
    
    free_cols = [c for c in range(n) if pivot_row_of[c] == -1]
    if not free_cols:
        print("No")
        return
    
    pivot_cols = [c for c in range(n) if pivot_row_of[c] != -1]
    basis = []
    for f in free_cols:
        x = 1 << f
        for p in pivot_cols:
            if (mat[pivot_row_of[p]] >> f) & 1:
                x |= 1 << p
        basis.append(x)
    
    covered = 0
    for b in basis:
        covered |= b
    if covered != (1 << n) - 1:
        print("No")
        return
    
    for i in range(n):
        val = 0
        for j, b in enumerate(basis):
            if (b >> i) & 1:
                val |= 1 << j
        ans[S[i]] = val
    
    print("Yes")
    print(" ".join(map(str, ans)))

main()
```

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    ptr = 0
    N = int(data[ptr]); ptr += 1
    M = int(data[ptr]); ptr += 1

    adj = [0] * N
    for _ in range(M):
        u = int(data[ptr]) - 1; ptr += 1
        v = int(data[ptr]) - 1; ptr += 1
        adj[u] |= 1 << v
        adj[v] |= 1 << u

    S = [v for v in range(N) if adj[v] != 0]
    ans = [1] * N

    n = len(S)
    if n == 0:
        print("Yes")
        print(" ".join(map(str, ans)))
        return

    pos = [-1] * N
    for i, v in enumerate(S):
        pos[v] = i

    mat = []
    for v in S:
        mask = 0
        a = adj[v]
        for u in S:
            if (a >> u) & 1:
                mask |= 1 << pos[u]
        mat.append(mask)

    m = len(mat)
    pivot_row_of = [-1] * n

            if i != pr and (mat[i] >> col) & 1:
```

Looking at this problem:

- For each vertex v with degree ≥ 1, we need XOR of neighbors' values = 0. Working bitwise, each of the 60 bit positions must independently be a vector x in the kernel of the adjacency matrix restricted to non-isolated vertices (isolated vertices get value 1, they appear in no equation).
- Each vertex's value must be nonzero, i.e., for each vertex some chosen kernel vector must have a 1 at its position.
- Taking a basis of the kernel (dimension ≤ N ≤ 60), a vertex is coverable iff some basis vector has a 1 there (since any kernel vector with a 1 at position i is a combination of basis vectors, one of which must have a 1 at i). So the answer is Yes iff every non-isolated vertex is "hit" by some kernel basis vector. Then use the basis vectors as the 60 bit patterns — each vertex gets a nonzero value < 2^60.

Implementation: Gaussian elimination over GF(2) (bitmask rows) to RREF, extract special solutions for free columns as kernel basis, check coverage of all coordinates, build values. Verified against all samples (e.g., triangle → all 1s; single edge → No; K4 minus edge → (3,1,1,2) which checks out).
