You are given an integer sequence A=(A_1,A_2,\ldots,A_N) of length N.
For each integer pair (L,R) with 1 \le L \le R \le N, define f(L,R) as follows:

- Choose integers l, r with l \le r such that every integer from l through r appears at least once on the blackboard. Then, erase all integers from l through r that are on the blackboard.

- All input values are integers.

import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))
    
    B = [0] * (n + 2)
    cur1 = 0
    S = 0
    ans = 0
    for R, v in enumerate(a, 1):
        bv = B[v]
        cur1 += R - bv
        if v > 1:

            if b > bv:
                S += b - bv
        if v < n:
            b = B[v + 1]
            if b > bv:
                S += b - bv
        B[v] = R
        ans += cur1 - S
    
    print(ans)

Looking at this problem:

**Key insight:** For a window, each operation's chosen range $[l,r]$ must consist entirely of currently-present values. Since present values only shrink, an operation can never span two maximal runs of consecutive values (a missing value in between blocks it). Each maximal run of consecutive values needs ≥1 operation, and 1 suffices per run. So $f(L,R)$ = number of maximal runs of consecutive values in the distinct-value set $S(L,R)$ = $|S| - \#\{x\in S : x-1\in S\}$.

So Answer = $\sum_{[L,R]}|S(L,R)| - \sum_{[L,R]}\#\{x: x,x-1\in S(L,R)\}$.

Sweep $R$ from $1$ to $N$, maintaining $B[v]$ = latest occurrence of value $v$ in prefix $[1,R]$. Since $x\in S(L,R)\iff L\le B[x]$:
- $\sum_{L=1}^R |S(L,R)| = \sum_v B[v]$ (maintained as `cur1`, updated by `R - old B[v]` when value $v$ occurs).
- $\sum_{L=1}^R \#\text{pairs}\ = \sum_{x=2}^N \min(B[x],B[x-1])$ (maintained as `S`). When $v$ occurs at $R$, only pairs $(v,v-1)$ and $(v+1,v)$ change: new min is $\min(R, B[v\pm1]) = B[v\pm1]$ (since $B[v\pm1] < R$), old min was $\min(B[v],B[v\pm1])$, so the change is $\max(0, B[v\pm1]-B[v])$.

Add `cur1 - S` for each $R$. This is $O(N)$ and verified against all three samples (16, 23, 129).
