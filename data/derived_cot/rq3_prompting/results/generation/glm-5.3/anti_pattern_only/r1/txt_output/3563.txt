```python
class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        n = len(grid)
        rows_with = {}
        for r in range(n):
            for v in grid[r]:
                rows_with.setdefault(v, set()).add(r)
        
        size = 1 << n
        NEG = float('-inf')
        dp = [NEG] * size
        dp[0] = 0
        for v, rows in rows_with.items():
            ndp = dp[:]
            for r in rows:
                bit = 1 << r
                for mask in range(size):
                    if dp[mask] != NEG and not (mask & bit):
                        cand = dp[mask] + v
                        if cand > ndp[mask | bit]:
                            ndp[mask | bit] = cand
            dp = ndp
        return max(dp)
```

```python
class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        n = len(grid)
        rows_with = {}
        for r in range(n):
            for v in grid[r]:
                if v in rows_with:
                    rows_with[v].add(r)
                else:
                    rows_with[v] = {r}
        
        size = 1 << n
        dp = [-1] * size
        dp[0] = 0
        for v, rows in rows_with.items():
            ndp = dp[:]
            for r in rows:
                bit = 1 << r
                for mask in range(size):

                    if cur >= 0 and not (mask & bit):

                        if cur + v > ndp[nm]:
```

=== ANSWER ===
Looking at this problem:

- At most one cell per row → track used rows with a bitmask (≤ 10 rows → 1024 masks).
- Values must be unique → process each **distinct value** exactly once; for each value either skip it or place it in some row that contains it and isn't used yet.

DP over distinct values, state = bitmask of used rows. Every valid selection (set of (row, value) pairs with distinct rows and distinct values, value present in its row) corresponds to exactly one path through this DP, and transitions never reuse a value (reads come from the previous value's DP array) or a row (bitmask check).

Verified on Example 1: picks 3 (row 0) + 4 (row 1) + 1 (row 2) = 8 ✓. Example 2: 7 (row 0) + 8 (row 1) = 15 ✓.

Complexity: distinct (value, row) pairs ≤ 100 cells, so ≤ ~100 × 2^10 transitions — trivial.

```python
class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        n = len(grid)
        # For each distinct value, which rows contain it
        rows_with = {}
        for r in range(n):
            for v in grid[r]:
                if v in rows_with:
                    rows_with[v].add(r)
                else:
                    rows_with[v] = {r}

        size = 1 << n
        # dp[mask] = best score using exactly the rows in mask, -1 = unreachable
        dp = [-1] * size
        dp[0] = 0

        for v, rows in rows_with.items():
            ndp = dp[:]  # option: skip this value entirely
            for r in rows:
                bit = 1 << r
                for mask in range(size):
                    cur = dp[mask]
                    if cur >= 0 and not (mask & bit):
                        nm = mask | bit
                        val = cur + v
                        if val > ndp[nm]:
                            ndp[nm] = val
            dp = ndp

        # Grid is non-empty with positive values, so max > 0 (at least one cell selected)
        return max(dp)
```
