The problem: find smallest x >= n such that binary representation of x contains only set bits (all 1s). These are numbers of form 2^k - 1: 1, 3, 7, 15, 31, 63, ...

So find the smallest k such that 2^k - 1 >= n. Equivalently, count bits of n: let b = number of bits in n; then 2^b - 1 >= n always. But maybe a smaller one works if n itself is all ones.

Simple approach: iterate k from 1 upward, compute 2^k - 1, return first that is >= n.

Or: start with x = 1, while x < n: x = x*2 + 1. Return x. That's O(log n).

Given constraints n <= 1000, trivial.

Code:

```python
class Solution:
    def smallestNumber(self, n: int) -> int:
        x = 1
        while x < n:
            x = (x << 1) | 1
        return x
```

Check: n=5: x=1, 3, 7 -> 7. n=10: 1,3,7,15 -> 15. n=3: 1,3 -> 3. Good.
