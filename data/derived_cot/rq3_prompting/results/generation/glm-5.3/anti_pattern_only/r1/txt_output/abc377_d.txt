So the algorithm:
1. Compute minR[l] for l = M down to 1: minR[l] = min(minR[l+1], min{R_i : L_i = l}).

3. Answer = sum over l of max(0, maxr - l + 1).

This is O(N + M).

=== ANSWER ===
Looking at this problem:

- A pair (l, r) is **invalid** if there exists i with `l ≤ L_i` and `R_i ≤ r`.
- For a fixed `l`, only intervals with `L_i ≥ l` can possibly be contained. The pair is valid iff `r < min{R_i : L_i ≥ l}`, i.e., `r ≤ min(M, minR(l) - 1)` where `minR(l) = min{R_i : L_i ≥ l}` (treat as M+1 if empty).
- So the answer is `Σ_l max(0, min(M, minR(l)-1) - l + 1)`.

Compute `minR(l)` for decreasing `l` with a suffix minimum of the smallest R for each exact L value — O(N + M).

Verification on sample 3: suffix minimums of R give counts per l: 5,9,8,7,7,6,5,4,4,3,2,8,7,6,6,5,4,3,2,1 which sum to 102 ✓. Samples 1 and 2 also check out (5 and 0).

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    m = int(data[1])
    minR_at = [m + 1] * (m + 2)
    idx = 2
    for _ in range(n):
        L = int(data[idx]); R = int(data[idx + 1]); idx += 2
        if R < minR_at[L]:
            minR_at[L] = R
    ans = 0
    cur = m + 1  # min{R_i : L_i >= l}, m+1 means none
    for l in range(m, 0, -1):
        r = minR_at[l]
        if r < cur:
            cur = r
        maxr = cur - 1
        if maxr > m:
            maxr = m
        if maxr >= l:
            ans += maxr - l + 1
    print(ans)

main()
```
