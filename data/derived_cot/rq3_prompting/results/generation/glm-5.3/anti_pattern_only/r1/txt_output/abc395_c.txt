Looking at this problem:

**Key insight**: A subarray has a repeated value if and only if it contains two positions `p < q` with `A_p = A_q`. Given any such pair, the subarray `[p, q]` itself works and is the shortest one containing that particular pair. Moreover, the optimal pair is always between *consecutive* occurrences of some value (if there were an occurrence in between, that pair would be closer).

So the answer is the minimum of `q - p + 1` over all consecutive occurrence pairs `(p, q)` of equal values, or `-1` if all values are distinct.

**Algorithm**: Scan the array once, keeping a dictionary mapping each value to the index of its last occurrence. When we see a value again at index `i` with last occurrence `j`, the candidate length is `i - j + 1`. Take the minimum. This is O(N).

**Verification with samples**:
- Sample 1: `3 9 5 3 1` — value 3 at positions 1 and 4 → length 4. ✓
- Sample 2: all distinct → -1. ✓
- Sample 3: `1 1 2 ...` — value 1 at positions 1 and 2 → length 2. ✓

Edge cases: N=1 gives -1; using sentinel `ans = n` works since any real gap `i - j` satisfies `1 ≤ i - j ≤ n - 1 < n`.
