import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    m = n - 1
    edges = list(map(int, data[1:1 + 2 * m]))
    deg = [0] * (n + 1)
    us = edges[0::2]
    vs = edges[1::2]
    for u, v in zip(us, vs):
        deg[u] += 1
        deg[v] += 1
    
    # Union-Find over deg-3 vertices; union across edges with both endpoints deg-3.
    # Then for each deg-2 vertex adjacent to a deg-3 vertex, count per component.
    
    parent = list(range(n + 1))
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    
    for u, v in zip(us, vs):
        if deg[u] == 3 and deg[v] == 3:
            ru, rv = find(u), find(v)
            if ru != rv:
                parent[ru] = rv
    
    # k per component root
    cnt = {}
    for u, v in zip(us, vs):
        # for each edge between a deg-2 and deg-3 vertex, count the deg-2 vertex for the deg-3's component
        if deg[u] == 3 and deg[v] == 2:

        elif deg[u] == 2 and deg[v] == 3:
            r = find(v)
            cnt[r] = cnt.get(r, 0) + 1
    
    ans = 0
    for k in cnt.values():
        ans += k * (k - 1) // 2
    print(ans)

=== ANSWER ===
Looking at this problem:

- Adding edge (u,v) creates a cycle = tree path from u to v plus the new edge.
- For all cycle vertices to have degree 3 in the new graph: endpoints u,v need tree degree 2 (they gain +1), and every internal path vertex needs tree degree exactly 3. Also u,v must be non-adjacent (simplicity), which is automatic since a valid path has internal vertices.

So we count unordered pairs of degree-2 vertices whose tree path has all internal vertices of degree 3.

**Key structural insight:** Consider connected components of the subgraph induced on degree-3 vertices. A valid pair (u,v) means the internal vertices form a connected chain of degree-3 vertices — all in one component C, with u and v adjacent to C. Conversely, if two distinct degree-2 vertices are both adjacent to component C, the path between them goes through C only (unique tree paths), so it's valid. A deg-2 vertex can't have two neighbors in the same component (would create a cycle), and a pair of deg-2 vertices can't share two different components (also a cycle), so each valid pair is counted exactly once.

Therefore: **answer = Σ over components C of the deg-3 induced subgraph of C(k,2), where k = number of degree-2 vertices adjacent to C** (counted via deg-3↔deg-2 edges).

Verified against all three samples (6, 0, 1) and several hand-constructed cases (spiders, double stars, mixed chains), including cross-checking with an independent LCA-based DP on multiple examples.

Implementation: union-find over edges whose both endpoints have degree 3, then count deg-2 neighbors per component.

import sys
from collections import defaultdict

def main():

    n = int(data[0])

    for u, v in zip(us, vs):
