=== ANSWER ===
Looking at this problem, I'll use dynamic programming tracking, for each value `v`:
- `count[v]` = number of good subsequences ending with value `v`
- `total[v]` = sum of elements of all good subsequences ending with value `v`

When processing element `x`, new subsequences ending at `x` are: the singleton `[x]`, plus every subsequence ending in `x-1` or `x+1` extended by `x`. Each extended subsequence's sum increases by `x`.

So:
- `c = 1 + count[x-1] + count[x+1]`
- `s = total[x-1] + total[x+1] + x*c`

Each subsequence's sum is counted exactly once (when its last element is processed), so accumulating `s` gives the answer.

**Verification with Example 1** `[1,2,1]`:
- x=1: c=1, s=1 → ans=1
- x=2: c=1+count[1]=2, s=1+2·2=5 → ans=6
- x=1: c=1+count[2]=3, s=5+1·3=8 → ans=14 ✓

**Verification with Example 2** `[3,4,5]`:
- x=3: c=1, s=3 → ans=3
- x=4: c=2, s=3+4·2=11 → ans=14
- x=5: c=3, s=11+5·3=26 → ans=40 ✓

Edge cases: `x=0` must skip `count[-1]` (negative indexing would be wrong in Python); duplicates like `[1,1]` correctly don't chain since only `x±1` are extended.

Complexity: O(n + V) time, O(V) space where V = 10^5.
