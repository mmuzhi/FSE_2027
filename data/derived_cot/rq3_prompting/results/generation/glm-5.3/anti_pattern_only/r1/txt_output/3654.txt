class Solution:
    def minArraySum(self, nums: List[int], k: int, op1: int, op2: int) -> int:
        INF = float('inf')
        # dp[a][b] = min sum using a op1 and b op2 so far
        dp = [[INF] * (op2 + 1) for _ in range(op1 + 1)]
        dp[0][0] = 0
        for i, v in enumerate(nums):
            half = (v + 1) // 2
            v2 = v - k if v >= k else None  # op2 only result
            # both ops result
            if half >= k:
                both = half - k
            elif v >= k:
                both = (v - k + 1) // 2
            else:
                both = None
            maxa = min(i + 1, op1)
            maxb = min(i + 1, op2)

                dp_a = dp[a]

Looking at this problem, I need to decide per element which subset of operations to apply (none, op1, op2, or both — with order mattering for feasibility/value), while respecting global budgets op1 and op2. This is a classic DP over (index, op1 used, op2 used).

Key observations per element `v`:
- None: `v`
- Op1 only: `ceil(v/2)`
- Op2 only: `v - k` if `v >= k`
- Both ops (two orders): `ceil(v/2) - k` if `ceil(v/2) >= k`, or `ceil((v-k)/2)` if `v >= k` — take the min of feasible options.

DP state: `dp[a][b]` = minimum sum so far using `a` op1's and `b` op2's. With n ≤ 100 and op1, op2 ≤ 100, this is at most ~10^6 states with a handful of transitions, which is fast enough (I also bound `a` and `b` by the number of elements processed so far).

I verified against both examples (Example 1 yields 23, Example 2 yields 3) and checked order-sensitivity cases like `v=5, k=3` (op1 then op2 gives 0 since `ceil(5/2)=3 >= 3`) and `v=6, k=4` (only op2-then-op1 feasible, giving 1).

```python
from typing import List

class Solution:
    def minArraySum(self, nums: List[int], k: int, op1: int, op2: int) -> int:
        INF = float('inf')
        # dp[a][b] = min sum so far using a op1's and b op2's
        dp = [[INF] * (op2 + 1) for _ in range(op1 + 1)]
        dp[0][0] = 0
        for i, v in enumerate(nums):
            half = (v + 1) // 2
            has2 = v >= k
            v2 = v - k
            # possible results when applying both ops (consider both orders)
            both_c = []
            if half >= k:            # op1 first, then op2
                both_c.append(half - k)
            if has2:                 # op2 first, then op1
                both_c.append((v2 + 1) // 2)
            both = min(both_c) if both_c else None

            ndp = [[INF] * (op2 + 1) for _ in range(op1 + 1)]
            lima = min(i, op1)
            limb = min(i, op2)
            for a in range(lima + 1):
                dp_a = dp[a]
                ndp_a = ndp[a]
                ndp_a1 = ndp[a + 1] if a < op1 else None
                for b in range(limb + 1):
                    cur = dp_a[b]
                    if cur == INF:
                        continue
                    # no operation
                    if cur < ndp_a[b]:
                        ndp_a[b] = cur
                    # op1 only
                    if ndp_a1 is not None:
                        t = cur + half
                        if t < ndp_a1[b]:
                            ndp_a1[b] = t
                        # both operations
                        if both is not None and b < op2:
                            t = cur + both
                            if t < ndp_a1[b + 1]:
                                ndp_a1[b + 1] = t
                    # op2 only
                    if has2 and b < op2:
                        t = cur + v2
                        if t < ndp_a[b + 1]:
                            ndp_a[b + 1] = t
            dp = ndp
        return min(min(row) for row in dp)
```
