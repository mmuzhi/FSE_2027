=== ANSWER ===
Looking at this problem:

- An alternating permutation has a forced parity pattern once the first element's parity is chosen. If we place a number of parity `p` at the current position, all remaining positions have fixed parities (alternating starting with `1-p`).
- Given a prefix, the number of completions is `ro! * re!` if the remaining odd/even counts exactly match the odd/even position counts in the forced pattern, else 0.
- So we build the answer position by position: for each candidate (in increasing order), count completions; if `k` exceeds that count, subtract and move on; otherwise place it. This is the standard k-th lexicographic construction. Big integers handle counts like `50! * 50!` fine.

Verified against all three examples (n=4,k=6 → [3,4,1,2]; n=3,k=2 → [3,2,1]; n=2,k=3 → []).

from typing import List

class Solution:
    def permute(self, n: int, k: int) -> List[int]:

        rem_e = n // 2

                    continue
                p = cand & 1
                if p == prev_parity:
                    continue

                if rem_after == 0:
                    cnt = 1
                else:
                    # parity pattern of remaining positions, first one is 1-p
                    start = 1 - p
                    n_start = (rem_after + 1) // 2
                    n_other = rem_after // 2

                        po, pe = n_start, n_other

                        po, pe = n_other, n_start

                    else:
                        cnt = 0

                if cnt == 0:
                    continue
                if k > cnt:
                    k -= cnt
                    continue

                # place candidate
                used[cand] = True
                if p == 1:
                    rem_o -= 1
                else:
                    rem_e -= 1
                result.append(cand)
                prev_parity = p
                placed = True
                break

            if not placed:

        return result
