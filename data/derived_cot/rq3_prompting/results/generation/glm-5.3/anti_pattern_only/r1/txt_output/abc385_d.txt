- For i=1,2,\ldots,M in order, he moves as follows:

- 1 \leq N \leq 2\times 10^5

- The pairs (X_i,Y_i) are distinct.
- -10^9 \leq S_x,S_y \leq 10^9
- There is no house at (S_x,S_y).

```python
import sys
from bisect import bisect_right
from collections import defaultdict

def main():
    data = sys.stdin.buffer.read().split()
    N = int(data[0]); M = int(data[1])
    Sx = int(data[2]); Sy = int(data[3])
    
    base = 4
    vals = data[base:base + 2*N]
    X = list(map(int, vals[0::2]))
    Y = list(map(int, vals[1::2]))
    
    pos = base + 2*N
    x, y = Sx, Sy
    vcols = defaultdict(list)
    hrows = defaultdict(list)
    
    for _ in range(M):
        D = data[pos]
        C = int(data[pos+1])
        pos += 2
        if D == b'U':
            vcols[x].append((y, y + C))
            y += C
        elif D == b'D':
            vcols[x].append((y - C, y))
            y -= C
        elif D == b'R':
            hrows[y].append((x, x + C))
            x += C
        else:  # b'L'
            hrows[y].append((x - C, x))
            x -= C
    
    def merge(ivmap):
        out = {}
        for key, ivals in ivmap.items():
            ivals.sort()
            los = []
            his = []
            clo, chi = ivals[0]
            for l, h in ivals[1:]:
                if l <= chi:
                    if h > chi:
                        chi = h
                else:
                    los.append(clo)
                    his.append(chi)
                    clo, chi = l, h
            los.append(clo)
            his.append(chi)
            out[key] = (los, his)
        return out
    
    vmap = merge(vcols)
    hmap = merge(hrows)
    
    count = 0
    vget = vmap.get
    hget = hmap.get
    for xi, yi in zip(X, Y):
        e = vget(xi)
        if e is not None:
            los, his = e
            j = bisect_right(los, yi) - 1
            if j >= 0 and his[j] >= yi:
                count += 1
                continue
        e = hget(yi)
        if e is not None:
            los, his = e
            j = bisect_right(los, xi) - 1
            if j >= 0 and his[j] >= xi:
                count += 1
    
    sys.stdout.write(f"{x} {y} {count}\n")

main()
```

=== ANSWER ===
Looking at this problem:

1. **Final position**: Simple simulation with Python's arbitrary-precision integers (no overflow issues).

2. **Counting houses**: Each move is an axis-aligned segment. A house (X,Y) is covered iff some vertical segment at column X has Y in its y-range, or some horizontal segment at row Y has X in its x-range. 

Key insight: group vertical segments by column (and horizontal by row), then **merge overlapping intervals** within each group. A house at column X is covered by vertical moves iff its Y lies in the union of merged intervals — checkable with binary search on the disjoint sorted intervals (find last interval with `lo <= Y`, check `hi >= Y`). Each house needs at most 2 dict lookups + 2 binary searches, giving O((N+M) log(N+M)) total, with no per-house repeated work (duplicates counted once automatically since we check each house exactly once against the union).

Verified against both samples:
- Sample 1: final (2,3), houses (2,2) and (2,1) covered → 2 ✓
- Sample 2: final (3000000000, 0), house (1,1) not on row 0 → 0 ✓

Closed ranges `[lo, hi]` correctly include segment endpoints (passed through or arrived at).
