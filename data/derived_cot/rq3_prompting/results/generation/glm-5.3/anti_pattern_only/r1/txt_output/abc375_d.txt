```python
import sys
from collections import defaultdict

def main():
    S = sys.stdin.read().strip()
    pos = defaultdict(list)
    for idx, ch in enumerate(S):
        pos[ch].append(idx)
    ans = 0
    for ps in pos.values():
        m = len(ps)
        if m < 2:
            continue
        total = sum(p * (2 * t - m + 1) for t, p in enumerate(ps))
        ans += total - m * (m - 1) // 2
    print(ans)

main()
```

Looking at this problem:

A length-3 string S_i S_j S_k is a palindrome iff S_i == S_k (the middle character can be anything). So I need to count, for every pair (i, k) with i < k and S_i == S_k, the number of indices j strictly between them, which is (k - i - 1).

So the answer is: sum over all pairs i < k with S[i] == S[k] of (k - i - 1).

For each character, collect its positions p_0 < p_1 < ... < p_{m-1}. The sum of pairwise differences can be computed as Σ_t p_t · (2t - m + 1) (each position counts positively as the larger element t times and negatively as the smaller element m-1-t times). Then subtract the number of pairs C(m,2) to account for the "-1" per pair.
