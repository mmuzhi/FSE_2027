class Solution:
    def minOperations(self, queries: List[List[int]]) -> int:
        # pw[j] = 4^j, pref[j] = sum_{x=1}^{4^j - 1} d(x)
        MAXJ = 17
        pw = [1] * (MAXJ + 1)
        for j in range(1, MAXJ + 1):
            pw[j] = pw[j - 1] * 4
        pref = [0] * (MAXJ + 1)
        for j in range(1, MAXJ + 1):
            pref[j] = pref[j - 1] + j * (pw[j] - pw[j - 1])

        def F(n):
            if n <= 0:
                return 0
            K = (n.bit_length() + 1) // 2
            return pref[K - 1] + K * (n - pw[K - 1] + 1)

        total = 0
        for l, r in queries:
            s = F(r) - F(l - 1)
            total += (s + 1) // 2
        return total

Looking at this problem:

- Each number x needs d(x) divisions by 4 to reach 0, where d(x) = k for x in [4^(k-1), 4^k - 1].
- Each operation performs 2 divisions (on two elements), so the total division count S = Σd(x) gives a lower bound of ⌈S/2⌉ operations.
- For any range [l, r] with l < r (at least 2 elements), the max d value k satisfies S ≥ d(r-1) + d(r) ≥ 2k-1, so ⌈S/2⌉ ≥ k, meaning ⌈S/2⌉ is always achievable (pair two elements with largest remaining counts; zeros can be harmlessly paired).

So the answer per query is ⌈S(l,r)/2⌉ where S is computed via a prefix function F(n) = Σ_{x=1}^{n} d(x), using the fact that numbers in [4^(k-1), 4^k - 1] each contribute k. F(n) can be computed in O(1) using precomputed power-of-4 boundaries and prefix sums, with K = (n.bit_length()+1)//2 giving d(n)'s tier.
