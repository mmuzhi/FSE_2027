You are given integers N and M.
Print all integer sequences (A_1, A_2, \ldots, A_N) of length N that satisfy all of the following conditions, in lexicographical order.

- 1 \leq A_i
- A_{i - 1} + 10 \leq A_i for each integer i from 2 through N
- A_N \leq M

What is lexicographical order?
A sequence S = (S_1, S_2, \ldots, S_N) of length N is smaller in lexicographical order than a sequence T = (T_1, T_2, \ldots, T_N) of length N if and only if there exists an integer 1 \leq i \leq N such that both of the following hold:

-  (S_1, S_2, \ldots, S_{i-1}) = (T_1, T_2, \ldots, T_{i-1})
-  S_i is less than T_i (as a number).

Input

The input is given from Standard Input in the following format:

The first line should contain the value of X.

def main():

=== ANSWER ===
Looking at this problem:

- Sequences are strictly increasing with gaps of at least 10, starting at ≥1, ending at ≤M.
- Since M ≤ 10N, the minimum sequence (1, 11, ..., 10(N-1)+1) has last element 10N-9, so there's at most 9 units of "slack". The number of valid sequences is bounded by C(21, 12) ≈ 294k, which is small enough for simple backtracking.
- A DFS trying values in increasing order at each position (bounding each value so the remaining elements can still fit under M) naturally produces sequences in lexicographical order.

At position `idx` (0-based), the value must be at least `prev + 10` (or 1 for the first), and at most `M - 10*(N - idx - 1)` so that the remaining `N - idx - 1` elements (each needing +10) can still satisfy `A_N ≤ M`.

Verified against the sample: N=3, M=23 gives exactly the 10 listed sequences in the same order.
