class Solution:
    def countNonDecreasingSubarrays(self, nums: List[int], k: int) -> int:
        rev = nums[::-1]
        n = len(rev)
        # stack entries: [index, value, block_size]
        stack = []
        head = 0  # bottom pointer; records below head are dead
        A = 0
        cost = 0
        ans = 0
        for B in range(n):
            v = rev[B]
            # add element at B
            S = 0
            while len(stack) > head and stack[-1][1] <= v:
                idx, w, s = stack.pop()
                cost += (v - w) * s
                S += s
            stack.append([B, v, S + 1])
            # shrink window from left while cost too high
            while cost > k:
                u = rev[A]
                if stack[head][0] == A:
                    # A is the bottom record; pop it (cost change 0)
                    head += 1
                else:
                    # A inside bottom block
                    cost -= stack[head][1] - u
                    stack[head][2] -= 1
                A += 1
            ans += B - A + 1
        return ans

Looking at this problem:

- The minimum operations to make subarray `nums[l..r]` non-decreasing is `Σ (max(nums[l..i]) - nums[i])` (each element must be raised to the running max).
- Reversing the array, this cost for a window `[A,B]` of `rev` becomes `Σ (max(rev[j..B]) - rev[j])` (suffix maxima).
- For fixed `B`, cost decreases as `A` increases (dropping a non-negative term); for fixed `A`, cost increases with `B`. So a sliding window works: for each `B`, find minimal `A` with cost ≤ k, add `B - A + 1`.

To maintain the cost, keep a stack of "records from the right" (indices increasing, values decreasing), where each record covers a block of positions whose suffix max equals its value:
- **Add right** (`v` at `B`): pop records with value ≤ `v`, adding `(v - w) * block_size` to cost (their suffix max rises to `v`), then push new record with merged block size + 1.
- **Remove left** (`A`): if `A` is the bottom record (its block is exactly `{A}`), advance the head pointer (cost unchanged, contribution 0); otherwise cost decreases by `bottom_value - rev[A]` and the bottom block shrinks by 1.

A head pointer guards against popping dead (already-passed) records from the bottom. Verified against both examples (17 and 12) and several hand-traced cases.

```python
class Solution:
    def countNonDecreasingSubarrays(self, nums: List[int], k: int) -> int:
        rev = nums[::-1]
        n = len(rev)
        stack = []  # entries: [index, value, block_size] — records from the right
        head = 0    # index of leftmost alive record in stack
        A = 0       # left end of current window in rev
        cost = 0
        ans = 0
        for B in range(n):
            v = rev[B]
            S = 0
            # merge blocks whose suffix max rises to v
            while len(stack) > head and stack[-1][1] <= v:
                _, w, s = stack.pop()
                cost += (v - w) * s
                S += s
            stack.append([B, v, S + 1])
            # shrink from left while too expensive
            while cost > k:
                bot = stack[head]
                if bot[0] == A:
                    # A is the bottom record; its block is exactly {A}, contributes 0
                    head += 1
                else:
                    cost -= bot[1] - rev[A]
                    bot[2] -= 1
                A += 1
            ans += B - A + 1
        return ans
```
