You will be given a competitive programming problem.
There are N types of items. The i-th type of item has a weight of w_i and a value of v_i. Each type has 10^{10} items available.
Takahashi is going to choose some items and put them into a bag with capacity W. He wants to maximize the value of the selected items while avoiding choosing too many items of the same type. Hence, he defines the happiness of choosing k_i items of type i as k_i v_i - k_i^2. He wants to choose items to maximize the total happiness over all types while keeping the total weight at most W. Calculate the maximum total happiness he can achieve.

Input

The input is given from Standard Input in the following format:
N W
w_1 v_1
w_2 v_2
\vdots
w_N v_N

Output

Print the answer.

Constraints


- 1 \leq N \leq 3000
- 1 \leq W \leq 3000
- 1 \leq w_i \leq W
- 1 \leq v_i \leq 10^9
- All input values are integers.

Sample Input 1

2 10
3 4
3 2

Sample Output 1

5

By choosing 2 items of type 1 and 1 item of type 2, the total happiness can be 5, which is optimal.
Here, the happiness for type 1 is 2 \times 4 - 2^2 = 4, and the happiness for type 2 is 1 \times 2 - 1^2 = 1.
The total weight is 9, which is within the capacity 10.

```python
def main():
    data = sys.stdin.buffer.read().split()

    by_weight = defaultdict(list)

        by_weight[w].append(v)
```

```python
        if M <= 0:

        if not heap:
            continue

        prefix = []
        s = 0

            gain = -negg
            if gain <= 0:
```

```python
import sys
import heapq
import numpy as np
from collections import defaultdict

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); W = int(data[1])
    by_weight = defaultdict(list)
    idx = 2
    for _ in range(n):
        w = int(data[idx]); v = int(data[idx + 1])
        idx += 2
        by_weight[w].append(v)

    dp = np.zeros(W + 1, dtype=np.int64)
    buf = np.empty(W + 1, dtype=np.int64)
    Wp1 = W + 1

    for w, vs in by_weight.items():
        M = W // w
        if M <= 0:
            continue
        heap = [(-(v - 1), v, 1) for v in vs if v > 1]
        if not heap:
            continue
        heapq.heapify(heap)
        prefix = []
        s = 0
        push = heapq.heappush
        pop = heapq.heappop
        while heap and len(prefix) < M:
            negg, v, j = pop(heap)
            gain = -negg
            if gain <= 0:
                break
            s += gain
            prefix.append(s)
            nxt = v - 2 * j - 1  # v - (2(j+1) - 1)
            if nxt > 0:
                push(heap, (-nxt, v, j + 1))

        if not prefix:
            continue

        dp_new = dp.copy()
        for m in range(1, len(prefix) + 1):
            shift = m * w
            L = Wp1 - shift
            tmp = buf[:L]
            np.add(dp[:L], prefix[m - 1], out=tmp)
            seg = dp_new[shift:]
            np.maximum(seg, tmp, out=seg)
        dp = dp_new

    print(int(dp[W]))

main()
```

```python
import sys
import heapq
import numpy as np
from collections import defaultdict

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); W = int(data[1])
    by_weight = defaultdict(list)
    idx = 2
    for _ in range(n):
        w = int(data[idx]); v = int(data[idx + 1])
        idx += 2
        by_weight[w].append(v)

    Wp1 = W + 1
    dp = np.zeros(Wp1, dtype=np.int64)
    buf = np.empty(Wp1, dtype=np.int64)

    for w, vs in by_weight.items():
        M = W // w
        if M <= 0:
            continue
```
```python
        if len(vs) > M:
            vs = sorted(vs, reverse=True)[:M]
        heap = [(-(v - 1), v, 1) for v in vs if v > 1]
        if not heap:
            continue
        heapq.heapify(heap)
        prefix = []
        ap = prefix.append
        s = 0
        hpush = heapq.heappush
        hpop = heapq.heappop
        while heap and len(prefix) < M:
            negg, v, j = hpop(heap)
            gain = -negg
            if gain <= 0:
                break
            s += gain
            ap(s)
            nxt = v - 2 * j - 1

            tmp = buf[:L]

            seg = dp_new[shift:]
```

```python
import sys
import heapq
import numpy as np
from collections import defaultdict

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0]); W = int(data[1])
    by_weight = defaultdict(list)
    idx = 2
    for _ in range(n):
        w = int(data[idx]); v = int(data[idx + 1])
        idx += 2
        by_weight[w].append(v)

    Wp1 = W + 1
    dp = np.zeros(Wp1, dtype=np.int64)
    buf = np.empty(Wp1, dtype=np.int64)

    for w, vs in by_weight.items():
        M = W // w
        if M <= 0:
            continue
        if len(vs) > M:
            vs = sorted(vs, reverse=True)[:M]
        heap = [(-(v - 1), v, 1) for v in vs if v > 1]
        if not heap:
            continue
        heapq.heapify(heap)
        prefix = []
        s = 0
        hpush = heapq.heappush
        hpop = heapq.heappop
        ap = prefix.append
        while heap and len(prefix) < M:
            negg, v, j = hpop(heap)
            gain = -negg
            if gain <= 0:
                break
            s += gain
            ap(s)
            nxt = v - 2 * j - 1
            if nxt > 0:
                hpush(heap, (-nxt, v, j + 1))

        if not prefix:
            continue

        dp_new = dp.copy()
        for m in range(1, len(prefix) + 1):
            shift = m * w
            L = Wp1 - shift
            tmp = buf[:L]
            np.add(dp[:L], prefix[m - 1], out=tmp)
            seg = dp_new[shift:]
            np.maximum(seg, tmp, out=seg)
        dp = dp_new

    print(int(dp[W]))

main()
```

=== ANSWER ===
Looking at this problem:

- Happiness for type i with k items is k·v_i − k², whose marginal gains are v_i−1, v_i−3, v_i−5, … (decreasing, so concave).
- **Group types by weight w.** For a fixed total count m of items of weight w, the best happiness g_w(m) equals the sum of the m largest marginal gains among all types of that weight (each type contributes a prefix of its decreasing gain sequence). This g_w is concave in m.
- Then run a knapsack DP over weight groups: `dp_new[j] = max_m dp_old[j−m·w] + g_w(m)`, answer is `dp[W]`.

Computing g_w: use a heap merging the sorted gain sequences, taking at most ⌊W/w⌋ gains (only positive gains matter — non-positive marginal gains are never beneficial since dp is monotone). Also only the top ⌊W/w⌋ types by value can ever be used (used types form a prefix sorted by v with non-increasing counts).

Total work: Σ_w ⌊W/w⌋ ≈ W·ln W ≈ 26k gain extractions and ≈26k vectorized DP steps (≈4×10⁷ element ops), easily fast enough with numpy. Values fit in int64 (total happiness ≤ 3000·10⁹).

Verified against all three samples (5, 14, 12) and several hand brute-force cases.
