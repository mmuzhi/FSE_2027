Looking at this problem:

- Build the implicit ternary tree: leaves are characters of A; each internal node is the majority of its 3 consecutive children.
- Define f(v) = minimum leaf changes inside v's subtree to **flip** v's output. For a node with children values (b1,b2,b3) and costs (f1,f2,f3), letting m = majority:
  - If all children equal m: need ≥2 children flipped → cost = sum of two smallest fᵢ.
  - If exactly two children equal m: need ≥1 of those flipped (keeping/flipping the minority child otherwise only costs more) → cost = min of fᵢ over children with value m.
- These case analyses are exact (any change set induces a set of flipped children; costs are independent across disjoint subtrees), so a bottom-up pass over all levels gives the answer = f(root). This is O(3^N), fine for N ≤ 13.

Verified on both samples (answers 1 and 2). Implementation: fast numpy level-by-level reduction, with a pure-Python fallback (same logic, tight loops).
