You are given an array points where points[i] = [x_i, y_i] represents the coordinates of a point on an infinite plane.
Your task is to find the maximum area of a rectangle that:

Can be formed using four of these points as its corners.
Does not contain any other point inside or on its border.
Has its edges parallel to the axes.

Return the maximum area that you can obtain or -1 if no such rectangle is possible.
 
Example 1:

Input: points = [[1,1],[1,3],[3,1],[3,3]]
Output: 4
Explanation:

We can make a rectangle with these 4 points as corners and there is no other point that lies inside or on the border. Hence, the maximum possible area would be 4.

Explanation:

There is only one rectangle possible is with points [1,1], [1,3], [3,1] and [3,3] but [2,2] will always lie inside it. Hence, returning -1.

```python
class Solution:
    def maxRectangleArea(self, points: List[List[int]]) -> int:
        from itertools import combinations
        n = len(points)
        best = -1
        for combo in combinations(range(n), 4):
            xs = sorted(points[i][0] for i in combo)
            ys = sorted(points[i][1] for i in combo)
            # Must form an axis-parallel rectangle: x values {a,a,b,b}, y values {c,c,d,d}
            if xs[0] != xs[1] or xs[2] != xs[3] or xs[0] == xs[2]:
                continue
            if ys[0] != ys[1] or ys[2] != ys[3] or ys[0] == ys[2]:
                continue
            x1, x2 = xs[0], xs[2]
            y1, y2 = ys[0], ys[2]
            # Since points are unique, xs/ys conditions guarantee the 4 corners form the rectangle
            # Check that no other point lies inside or on the border
            valid = True
            combo_set = set(combo)
            for j in range(n):
                if j in combo_set:
                    continue
                px, py = points[j]
                if x1 <= px <= x2 and y1 <= py <= y2:
                    valid = False
                    break
            if valid:
                area = (x2 - x1) * (y2 - y1)
                if area > best:
                    best = area
        return best
```
