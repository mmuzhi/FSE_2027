This is a simple problem. A square's color on a chessboard can be determined by the parity of (column index + row index). If both squares have the same parity, they're the same color.

Column: 'a' = 1, 'b' = 2, etc. Row: '1' = 1, '2' = 2, etc.

For "a1": 1 + 1 = 2 (even) → black (based on example, a1 is black).
For "c3": 3 + 3 = 6 (even) → black. Same parity → same color → true. ✓

For "a1": even. "h3": 8 + 3 = 11 (odd) → white. Different parity → false. ✓

So the solution:

```python
class Solution:
    def checkTwoChessboards(self, coordinate1: str, coordinate2: str) -> bool:
        def parity(c):
            return (ord(c[0]) - ord('a') + int(c[1])) % 2
        return parity(coordinate1) == parity(coordinate2)
```

class Solution:
