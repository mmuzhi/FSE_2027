=== ANSWER ===
Looking at this problem:

- We need the shortest palindrome with S as a prefix. If `p` is the length of the **longest palindromic suffix** of S, the answer is `S + reverse(S[:n-p])`.
- To find `p`: let `R = reverse(S)`. A suffix `S[n-k:]` is a palindrome iff `S[n-k:] == R[:k]` (since `reverse(S[n-k:]) == R[:k]`). So `p` is the longest prefix of R that matches a suffix of S — which is exactly the KMP failure function value at the end of `T = R + '\x00' + S` (the separator ensures borders never exceed n).

I verified with the samples: "ABC" → p=1 ("C") → "ABC"+"BA" = "ABCBA"; "TREE" → p=2 ("EE") → "TREERT"; "Z" → "Z".

The KMP runs over ~10⁶ characters with an amortized-O(n) loop, fast enough in pure Python using bytes.
