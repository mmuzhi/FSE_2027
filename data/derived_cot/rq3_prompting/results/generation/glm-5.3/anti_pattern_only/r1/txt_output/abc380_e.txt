There are N cells in a row, numbered 1 to N.
For each 1 \leq i < N, cells i and i+1 are adjacent.

N Q

- There is at least one query of the second type.
- All input values are integers.

Looking at this problem:

- Cells form maximal monochromatic runs. A type-1 query repaints the **entire run** containing x, which never splits runs — it only possibly merges the run with adjacent runs already colored c (at most one on each side, since those were maximal).
- So I maintain a DSU where each component is exactly one run. At each root I store the run's left end `rl`, right end `rr`, color `rc`, and size (for union by size). A `count[c]` array tracks cells per color.
- For `1 x c`: find root of x; if color differs, update counts, set new color, then check `find(l-1)` and `find(r+1)` for same-color neighbors and union (updating the merged run's bounds at the surviving root).
- For `2 c`: just output `count[c]`.

Total merges ≤ N−1, finds ≤ 3Q, with union-by-size + path halving giving near-constant amortized cost. Verified against the sample (outputs 3 and 4) and several hand-traced edge cases (both-side merges, root swapping under union by size, repaint-same-color skip).

```python
import sys

def main():
    vals = list(map(int, sys.stdin.buffer.read().split()))
    N = vals[0]
    Q = vals[1]
    ptr = 2

    parent = list(range(N + 1))
    rl = parent[:]
    rr = parent[:]
    rc = parent[:]
    sz = [1] * (N + 1)
    count = [0] + [1] * N

    out = []

    for _ in range(Q):
        if vals[ptr] == 1:
            x = vals[ptr + 1]
            c = vals[ptr + 2]
            ptr += 3
            a = x
            while parent[a] != a:
                parent[a] = parent[parent[a]]
                a = parent[a]
            rx = a
            old = rc[rx]
            if old != c:
                l = rl[rx]
                r = rr[rx]
                ln = r - l + 1
                count[old] -= ln
                count[c] += ln
                rc[rx] = c
                if l > 1:
                    b = l - 1
                    while parent[b] != b:
                        parent[b] = parent[parent[b]]
                        b = parent[b]
                    pl = b
                    if rc[pl] == c:
                        if sz[pl] > sz[rx]:
                            parent[rx] = pl
                            sz[pl] += sz[rx]
                            rr[pl] = r
                            rx = pl
                        else:
                            parent[pl] = rx
                            sz[rx] += sz[pl]
                            rl[rx] = rl[pl]
                        l = rl[rx]
                if r < N:
                    b = r + 1
                    while parent[b] != b:
                        parent[b] = parent[parent[b]]
                        b = parent[b]
                    pr = b
                    if rc[pr] == c:
                        if sz[pr] > sz[rx]:
                            parent[rx] = pr
                            sz[pr] += sz[rx]
                            rl[pr] = l
                            rx = pr
                        else:
                            parent[pr] = rx
                            sz[rx] += sz[pr]
                            rr[rx] = rr[pr]
        else:
            c = vals[ptr + 1]
            ptr += 2
            out.append(str(count[c]))

    sys.stdout.write('\n'.join(out) + '\n')

main()
```
