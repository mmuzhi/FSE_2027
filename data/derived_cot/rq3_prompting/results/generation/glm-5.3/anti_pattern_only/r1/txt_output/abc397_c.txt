We need to split array A at position i (1 ≤ i ≤ N-1) into prefix (A_1..A_i) and suffix (A_{i+1}..A_N). We want to maximize the sum of distinct counts in prefix and suffix.

Standard approach: 
- Compute prefix distinct count: for each i, pre[i] = number of distinct values in A[1..i]. This can be computed incrementally with a seen array.
- Compute suffix distinct count: suf[i] = number of distinct values in A[i..N], computed from right.
- Answer = max over i from 1 to N-1 of pre[i] + suf[i+1].

This is O(N) time and space, well within constraints (N ≤ 3×10^5).

=== ANSWER ===
Looking at this problem:

- For each split position, the answer is (distinct count in prefix) + (distinct count in suffix).
- Precompute prefix distinct counts incrementally with a "seen" array (values are in [1, N]).
- Then sweep from the right, maintaining suffix distinct counts, and combine with the corresponding prefix count.

This is O(N) time and space, which easily handles N ≤ 3×10⁵.

Verification on sample 1: prefix counts = [1,2,3,3,4], suffix counts (from right) = [4,3,3,2,1] (suffix starting at each index). Best split gives max = 5. ✓

Verification on sample 2: prefix = [1,2,3,3,3,4,5,6,6,6], suffix (from index i) = [6,6,5,4,4,3,3,2,1]... combining pre[i-1] + suf[i] yields max 8. ✓

Edge case N=2: split gives 1+1=2, handled correctly by the loop.

```python
import sys

def main():
    data = sys.stdin.buffer.read().split()
    n = int(data[0])
    a = list(map(int, data[1:1 + n]))

    # pre[i] = number of distinct values in a[0..i]
    pre = [0] * n
    seen = [False] * (n + 1)
    c = 0
    for i in range(n):
        v = a[i]
        if not seen[v]:
            seen[v] = True
            c += 1
        pre[i] = c

    # sweep suffix distinct counts from right, combine with prefix
    seen2 = [False] * (n + 1)
    c2 = 0
    ans = 0
    for i in range(n - 1, 0, -1):
        v = a[i]
        if not seen2[v]:
            seen2[v] = True
            c2 += 1
        s = pre[i - 1] + c2
        if s > ans:
            ans = s

    print(ans)

main()
```
