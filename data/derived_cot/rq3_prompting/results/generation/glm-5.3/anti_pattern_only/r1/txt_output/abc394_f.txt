Looking at this problem:

- An alkane is a tree with all degrees in {1,4} and at least one degree-4 vertex. By degree counting, $n_1 + 4n_4 = 2(n_1+n_4-1)$ gives $n_1 = 2n_4+2$, so sizes are $3n_4+2$ — i.e., 2, 5, 8, 11, ... Any valid set of size ≥ 3 with degrees in {1,4} automatically has a degree-4 vertex.

- A subgraph of a tree that is itself a tree must be a **connected vertex subset** $S$ with all induced edges (dropping edges disconnects it). So each vertex's degree equals its number of neighbors inside $S$.

- Root $T$ at vertex 1. Any connected $S$ has a unique "top" vertex $r$ (closest to root); $r$'s parent is not in $S$. The top has exactly 1 or 4 children in $S$; every other vertex of $S$ has 0 or 3 children in $S$ (parent edge + children = 1 or 4).

- DP bottom-up: $m[v]$ = best size of a "hanging" configuration at $v$ (parent edge used): $m[v] = \max(1,\ 1 + \text{sum of 3 largest } m[\text{children}])$. Candidates: top with 1 child: $1+\max m[c]$; top with 4 children: $1 + \text{sum of 4 largest } m[c]$. Answer is the max candidate if ≥ 5, else -1 (size 2 = single edge isn't an alkane).

    while stack:
        v = stack.pop()
        order.append(v)
        for u in adj[v]:
            if not visited[u]:
                visited[u] = True
                parent[u] = v
                stack.append(u)

    # childvals[v]: list of m-values of v's children (filled bottom-up)
    childvals = [[] for _ in range(n + 1)]
    ans = 0

    for v in reversed(order):
        vals = childvals[v]
        L = len(vals)
        if L >= 3:
            vals.sort(reverse=True)
            # v as an internal (degree-4) vertex hanging from its parent:
            # parent edge + 3 best children
            mv = 1 + vals[0] + vals[1] + vals[2]
            # v as the top of the subgraph with degree 1 (single child)
            c = 1 + vals[0]
            if c > ans:
                ans = c
            # v as the top of the subgraph with degree 4 (four children)
            if L >= 4:
                c = mv + vals[3]
                if c > ans:
                    ans = c
        else:
            mv = 1  # v can only be a leaf hanging from its parent
            if L:
                c = 1 + max(vals)
                if c > ans:
                    ans = c
        p = parent[v]
        if p:
            childvals[p].append(mv)

    print(ans if ans >= 5 else -1)

main()
