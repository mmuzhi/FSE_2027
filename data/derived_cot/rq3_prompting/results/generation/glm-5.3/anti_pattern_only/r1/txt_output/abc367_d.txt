Looking at this problem:

- Positions: rest area 1 at 0, rest area i+1 at p_i + A_i. Circumference L = sum(A).
- The minimum clockwise steps from s to t is d = (p_t − p_s) mod L ∈ (0, L).
- We need d ≡ 0 (mod M).

For an unordered pair with p_j < p_i (index order = position order since A_i ≥ 1):
- Direction j→i: d = p_i − p_j, multiple of M iff p_i ≡ p_j (mod M).
- Direction i→j: d = p_j − p_i + L, multiple of M iff p_i ≡ p_j + L (mod M).

So with c = L mod M, sweep positions in increasing order keeping cnt[r] = number of earlier positions with residue r. For each new position with residue s, add cnt[s] (forward pairs) + cnt[(s − c) mod M] (backward pairs), then increment cnt[s].
