The problem: grid is 2 x n. Robot 1 goes from (0,0) to (1,n-1), moving only right or down, collecting points. Then robot 2 does the same, but cells visited by robot 1 become 0. Robot 1 wants to minimize the points robot 2 collects. Return the points robot 2 collects with optimal play.

Standard solution: For each column i where robot 1 goes down, robot 2 can collect either the top row suffix (columns > i in row 0) or the bottom row prefix (columns < i in row 1). Robot 1 wants to minimize max(top suffix, bottom prefix).

The classic solution:
```python
class Solution:
    def gridGame(self, grid: List[List[int]]) -> int:
        result = float("inf")
        top, bottom = sum(grid[0]), 0
        for i in range(len(grid[0])):
            top -= grid[0][i]
            result = min(result, max(top, bottom))
            bottom += grid[1][i]
        return result
```
