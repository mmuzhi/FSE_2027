class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        backward, res = {}, []
        for i, word in enumerate(words):
            backward[word[::-1]] = i

        for i, word in enumerate(words):
            
            if word in backward and backward[word] != i:

    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        backward, res = {}, []
        for i, word in enumerate(words):
            backward[word[::-1]] = i

        for i, word in enumerate(words):

```python
class Solution:
    def palindromePairs(self, words: List[str]) -> List[List[int]]:
        backward, res = {}, []
        for i, word in enumerate(words):
            backward[word[::-1]] = i

        for i, word in enumerate(words):
            
            if word in backward and backward[word] != i:
                res.append([i, backward[word]])
                
            if word != "" and "" in backward and word == word[::-1]:
                res.append([i, backward[""]])
                res.append([backward[""], i])
                
            for j in range(len(word)):
                if word[j:] in backward and word[:j] == word[j-1::-1]:
                    res.append([backward[word[j:]], i])
                if word[:j] in backward and word[j:] == word[:j-1:-1]:
                    res.append([i, backward[word[:j]]])
                    
        return res
```

The bug was in the first split condition of the inner loop: `word[j::-1]` produces the reverse of `word[:j+1]` (length `j+1`), which can never equal `word[:j]` (length `j`), so that branch never fired and valid pairs like `"b" + "ab"` were missed. The fix `word[j-1::-1]` is the reverse of `word[:j]` (length `j`), correctly testing that the prefix is a palindrome — mirroring the already-correct `word[:j-1:-1]` (reverse of `word[j:]`) in the second condition. The `j = 0` case is intentionally inert with this slice form, since full-reverse pairs are handled by the `word in backward` check and empty-string pairs by the special-case block, avoiding duplicates and self-pairs. Verified against `["abcd","dcba","lls","s","sssll"]`, `["bat","tab","cat"]`, `["a",""]`, and `["a","b","c","ab","ac","aa"]`.
