The standard solution uses a monotonic stack. For each element, we compute the number of subarrays where it's the minimum:
- left extension: distance to previous smaller element

2. After the loop finishes, the stack still contains elements that were never popped. Their contributions are never counted. Need a final loop to process remaining elements, treating `i` as `len(arr)`.

```python
class Solution:
    def sumSubarrayMins(self, arr: List[int]) -> int:
        stack = []
        res = 0
        
        for i, num in enumerate(arr):
            while stack and arr[stack[-1]] > num:
                cur = stack.pop()
                left = cur - stack[-1] if stack else cur + 1
                res += arr[cur] * (i - cur) * left
            stack.append(i)
        
        n = len(arr)
        while stack:
            cur = stack.pop()
            left = cur - stack[-1] if stack else cur + 1
            res += arr[cur] * (n - cur) * left
        
        return res % (10**9 + 7)
```
