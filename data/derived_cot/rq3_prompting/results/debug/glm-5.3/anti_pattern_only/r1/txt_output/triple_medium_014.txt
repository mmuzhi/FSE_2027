The problem: Given two arrays of integers with equal lengths, return the maximum value of:
|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j|

The standard solution: for each combination of signs (s1, s2, s3) where s1, s2, s3 ∈ {-1, 1} but note |i-j| means we need to handle i-j. Actually the trick is:

|arr1[i] - arr1[j]| + |arr2[i] - arr2[j]| + |i - j| = max over signs of s1*(arr1[i]-arr1[j]) + s2*(arr2[i]-arr2[j]) + (i-j)

Since |x| = max(x, -x), we have:
|a| + |b| + |c| = max over (s1, s2, s3) of s1*a + s2*b + s3*c

So for each sign combination, compute max of s1*arr1[i] + s2*arr2[i] + s3*i and take difference of max and min.

The four combinations here (since s3 can be absorbed... actually with all 8 combos, but by symmetry only 4 matter because flipping all signs gives the same difference):

val1: i + arr1[i] + arr2[i]
val2: i + arr1[i] - arr2[i]
val3: i - arr1[i] + arr2[i]
val4: i - arr1[i] - arr2[i]

Answer = max over these of (max - min). Yes, this is correct.
